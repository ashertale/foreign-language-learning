Core Idea

migration 不是把資料複製過去而已，而是把狀態、語意、權限和使用者連續性一起搬到新環境。

Meaning

簡短定義

Migration

指遷移、移轉，可用於資料、系統、人口、動物或平台轉換。

不是 Copy

copy 是複製；migration 要處理狀態、相容性和切換。

舊環境存在
→
移到新環境
→
保持連續性

Origin

字源

來自 Latin migrare，意思是移動、遷徙。

移動、遷徙的字源很直覺；現代工程用法重連續性。

Memory Hook

記憶鉤子

把 migration 想成資料搬完後，舊權限、新 schema 和下游報表都還要對得起來。

搬動檔案只是最容易看見的一層。

Usage

生活與專業情境

資料

data migration 最怕不是搬資料，而是搬完後語意和權限對不起來。

系統

System migration needs rollback, compatibility, and user communication.

計畫

計畫情境下，migration 不是複製資料，而是從舊環境搬到新環境並保持可用。

Collocations

常見搭配與語域

migration 常接 data、system、plan。搭配會說明遷移的是資料、整個系統，還是遷移路線本身。

data migration 資料 / 系統

資料從舊環境移到新環境並保持語意可用。

system migration IT / 工程

系統平台或架構移轉。

migration plan 專案 / 工程

遷移計畫，包含順序、驗證和回退。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Migration 遷移、移動到新系統或地點 用在從舊環境移到新環境，且需要維持可用性和語意連續時。
Copy 複製 只建立副本。
Transfer 轉移 較通用，可指所有權、資料或人。
Porting 移植 常指軟體移到新平台。

Modern Use

現代延伸

Migration 的真正風險通常在 invisible contract。資料有沒有同義？權限有沒有等價？下游有沒有假設舊格式？

好的 migration 不只問怎麼搬，也問怎麼驗、怎麼停、怎麼回。
