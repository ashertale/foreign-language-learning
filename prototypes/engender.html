Engender

en-JEN-der · UK /ɪnˈdʒen.dər/ · US /ɪnˈdʒen.dɚ/

不是瞬間製造，而是在互動中慢慢生成某種結果。

C1

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

engender 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Engender

表示引起、產生或促成某種情緒與狀態。

不是 Create

如果 create 已經能讓句子成立，就不必硬換；需要「引起、產生或促成某種情緒與狀態」時，engender 才有必要。

先遇到 engender trust
→
看它是否只是 產生
→
再決定是否需要 engender

Origin

字源

14世紀初，engendren，意指「產生、繁殖」，源自古法語engendrer（12世紀）「生育、產子；引起、導致」，又可追溯至拉丁語ingenerare「植入、產生、繁殖」，由in-（意為「在……之中」，來自原始印歐語根*en「在」）和generare（「帶來、產生、繁殖」，源自genus「種族、類別」，來自原始印歐語根*gene-「生育、繁殖」，其衍生詞多與生殖及家庭、部落群體有關）組成。

像一連串小動作堆起來，最後空氣裡真的出現了信任或不安

Memory Hook

記憶鉤子

engender：像一連串小動作堆起來，最後空氣裡真的出現了信任或不安

能用這個畫面回到「引起、產生或促成某種情緒與狀態」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 engender trust 時，焦點通常就在「在互動中慢慢生成某種結果」上，所以這個搭配很能代表 engender 的語感。

數位 / 專業版

到了 人際 / 社會 的場景，engender resentment 會更常出現；這裡要說清楚的，正是「在互動中慢慢生成某種結果」。

Collocations

常見搭配與語域

常見用法集中在 engender trust 和 engender resentment；這幾個搭配分別落在 團隊 / 協作 和 人際 / 社會 的場景裡。

engender trust 團隊 / 協作

在 團隊 / 協作 的語境裡，這個搭配會把動作直接落在 trust 上。

engender resentment 人際 / 社會

在 人際 / 社會 的語境裡，這個搭配會把動作直接落在 resentment 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Engender 引起、產生或促成某種情緒與狀態 當較普通的說法太鬆，無法交代 動作是否真的落地 時。
Create 產生 如果上下文還沒有給出足夠理由支撐 engender，先用 create。

Modern Use

現代延伸

現在最常見的就是 engender trust 和 engender resentment 這類說法；它們一出現，通常就在替句子劃清「在互動中慢慢生成某種結果」的範圍。

當句子要把「在互動中慢慢生成某種結果」說準時，engender 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
