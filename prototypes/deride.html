Deride

dih-RYD · UK /dɪˈraɪd/ · US /dɪˈraɪd/

不是開玩笑，而是把對方當成值得被看低的對象。

Core Idea

deride 的核心是把「嘲弄、譏笑、輕蔑地取笑」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Deride

表示嘲弄、譏笑、輕蔑地取笑。

不是 Mock

把它們分開記：mock 先保留大方向，deride 負責把邊界收乾淨。

Origin

字源

\"嘲笑，嘲弄，嘲笑蔑視\"，1520年代，來自法語 derider，源自拉丁語 deridere \"嘲笑，嘲弄\"，由 de \"向下\"（見 de-)和 ridere \"笑\"（見 risible）組成。

像有人剛開口，旁邊就先傳來一陣帶刺的笑聲

Memory Hook

記憶鉤子

deride：像有人剛開口，旁邊就先傳來一陣帶刺的笑聲

這個畫面能幫你把 deride 和 Mock 分開，因為它把「把對方當成值得被看低的對象」那條界線變得可見。

Usage

生活與專業情境

日常版

像 deride the proposal 這樣的說法，多半出現在 評論 / 公共 的場景；句子真正要說的，就是「把對方當成值得被看低的對象」。

數位 / 專業版

到了 辯論 / 媒體 的場景，deride as naive 會更常出現；這裡要說清楚的，正是「把對方當成值得被看低的對象」。
