Substantiate

不是講得像真的，而是拿出材料把它撐起來。

Core Idea

substantiate 不只是 Verify 的近義替代；它用來描述「拿出材料把它撐起來」這種更窄、更準確的情境。

Meaning

簡短定義

Substantiate

表示用證據、數據或細節證實某項主張。

不是 Verify

Verify 可以先說大方向；substantiate 用在你要把「拿出材料把它撐起來」這條語氣邊界說得更準的時候。

Origin

字源

\"使實際，賦予實質\"的意思始於1650年代，源自現代拉丁語 substantiatus，是 substantiare 的過去分詞，源自拉丁語 substantia，意爲\"存在，本質，物質\"（參見 substance）。1803年開始出現\"證明或證實\"的意思。

像桌腳本來晃，墊上真正合適的木塊後才穩穩站住

Memory Hook

記憶鉤子

substantiate：像桌腳本來晃，墊上真正合適的木塊後才穩穩站住

這個畫面能幫你把 substantiate 和 Verify 分開，因為它把「拿出材料把它撐起來」那條界線變得可見。

Usage

生活與專業情境

日常版

像 substantiate the claim 這樣的說法，多半出現在 研究 / 分析 的場景；句子真正要說的，就是「拿出材料把它撐起來」。

數位 / 專業版

到了 法務 / 程序 的場景，substantiate the report 會更常出現；這裡要說清楚的，正是「拿出材料把它撐起來」。

Collocations

常見搭配與語域

常見用法集中在 substantiate the claim 和 substantiate the report；這幾個搭配分別落在 研究 / 分析 和 法務 / 程序 的場景裡。

substantiate the claim 研究 / 分析

在 研究 / 分析 的語境裡，這個搭配會把動作直接落在 the claim 上。

substantiate the report 法務 / 程序

在 法務 / 程序 的語境裡，這個搭配會把動作直接落在 the report 上。

Modern Use

現代延伸

現在最常見的就是 substantiate the claim 和 substantiate the report 這類說法；它們一出現，通常就在替句子劃清「拿出材料把它撐起來」的範圍。

比起 verify，substantiate 更適合用在你想直接點出「用證據、數據或細節證實某項主張」的時候。
