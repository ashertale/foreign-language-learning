Fervent

不是熱情一下，而是心裡長時間都燒得很亮。

Core Idea

fervent 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Fervent

表示熱烈、真摯、充滿強烈情感的。

不是 Passionate

passionate 可以先說出 熱情的；fervent 則把句子推到「心裡長時間都燒得很亮」這個更細的位置。

Origin

字源

14世紀中葉，源自古法語 fervent “熱情的，熱烈的”（12世紀），來自拉丁語 ferventem（主格 fervens）“沸騰的，熱的，發光的”，比喻意義爲“猛烈的，衝動的，狂暴的”， fervere “沸騰，發光”的現在分詞，源自 PIE 詞根 *bhreu- “沸騰，冒泡，發泡，燃燒”。比喻意義“充滿激情的”首次見於約1400年。

像火爐不是閃一瞬，而是整夜都穩穩發熱

Memory Hook

記憶鉤子

fervent：像火爐不是閃一瞬，而是整夜都穩穩發熱

這個畫面之所以有用，是因為它能幫你確認 fervent 是否真的在談「心裡長時間都燒得很亮」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 fervent supporter 這樣的說法，多半出現在 公共 / 政治 的場景；句子真正要說的，就是「心裡長時間都燒得很亮」。

數位 / 專業版

到了 情感 / 敘事 的場景，fervent hope 會更常出現；這裡要說清楚的，正是「心裡長時間都燒得很亮」。

Collocations

常見搭配與語域

常見用法集中在 fervent supporter 和 fervent hope；這幾個搭配分別落在 公共 / 政治 和 情感 / 敘事 的場景裡。

fervent supporter 公共 / 政治

在 公共 / 政治 的語境裡，這個搭配通常就在形容 supporter 的狀態或氣質。

fervent hope 情感 / 敘事

在 情感 / 敘事 的語境裡，這個搭配通常就在形容 hope 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fervent 熱烈、真摯、充滿強烈情感的 當句子需要把「心裡長時間都燒得很亮」說清楚，而不是只留在 熱情的 的外圈時。
Passionate 熱情的 當你只需要先說 熱情的，不必把語氣收進「心裡長時間都燒得很亮」時。

Modern Use

現代延伸

現在最常見的就是 fervent supporter 和 fervent hope 這類說法；它們一出現，通常就在替句子劃清「心裡長時間都燒得很亮」的範圍。

當句子要把「心裡長時間都燒得很亮」說準時，fervent 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
