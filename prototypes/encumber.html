Encumber

en-KUM-ber · UK /ɪnˈkʌm.bər/ · US /ɪnˈkʌm.bɚ/

不是單純增加，而是加到讓行動和判斷都變笨重。

Core Idea

encumber 的核心是把「成為負擔、拖累或加上束縛」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Encumber

表示成為負擔、拖累或加上束縛。

不是 Burden

把它們分開記：burden 先保留大方向，encumber 負責把邊界收乾淨。

Origin

字源

14世紀初，“負擔，煩惱，不便”，源自古法語 encombrer “阻塞，妨礙，挫敗”，源自晚期拉丁語 incombrare，源自 in- “在”（源自 PIE 詞根 *en “在”）和 combrus “路障，障礙”，可能源自拉丁語 cumulus “堆積”（參見 cumulus）。意爲“妨礙，阻礙”在14世紀後期的英語中得到證實。相關： Encumbered； encumbering。

像背包一件件塞滿後，人還能走，但每一步都慢了

Memory Hook

記憶鉤子

encumber：像背包一件件塞滿後，人還能走，但每一步都慢了

這個畫面有用，是因為它先把「加到讓行動和判斷都變笨重」釘住；回到實際搭配時，就不容易把它和 Burden 混成一團。

Usage

生活與專業情境

日常版

像 encumber the workflow 這樣的說法，多半出現在 流程 / 管理 的場景；句子真正要說的，就是「加到讓行動和判斷都變笨重」。

數位 / 專業版

到了 財務 / 法務 的場景，encumbered by debt 會更常出現；這裡要說清楚的，正是「加到讓行動和判斷都變笨重」。

Collocations

常見搭配與語域

常見用法集中在 encumber the workflow 和 encumbered by debt；這幾個搭配分別落在 流程 / 管理 和 財務 / 法務 的場景裡。

encumber the workflow 流程 / 管理

在 流程 / 管理 的語境裡，這個搭配會把動作直接落在 the workflow 上。

encumbered by debt 財務 / 法務

在 財務 / 法務 的語境裡，這個搭配最容易看出「加到讓行動和判斷都變笨重」實際怎麼落在句子裡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Encumber 成為負擔、拖累或加上束縛 當搭配和語境都已經指向「加到讓行動和判斷都變笨重」，這個字才自然。
Burden 成為負擔 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 流程 / 管理、財務 / 法務、產品 / 設計 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
