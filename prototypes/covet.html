Covet

KUV-it · UK /ˈkʌv.ɪt/ · US /ˈkʌv.ɪt/

不是普通想要，而是盯上了別人已經擁有的東西。

Core Idea

covet 最值得保留的語感，是它讓「貪求、覬覦某人擁有的財物、位置或生活」不再只是模糊大意。

Meaning

簡短定義

Covet

表示貪求、覬覦某人擁有的財物、位置或生活。

不是 Want

把它們分開記：want 先保留大方向，covet 負責把邊界收乾淨。

先遇到 covet the position
→
看它是否只是 想要
→
再決定是否需要 covet

Origin

字源

13世紀中葉，“過度渴望或不考慮他人權利而渴望或希望擁有”，源自古法語 coveitier “渴望，希望，對...有慾望”（12世紀，現代法語 convoiter，受 con- 詞彙影響），可能最終源自拉丁語 cupiditas “熱情的渴望，渴望，雄心”，源自 cupidus “非常渴望”，源自 cupere “渴望，希望”（參見 cupidity）。從14世紀中葉開始，有了好的意義，“熱切地渴望或希望，渴望獲得或擁有”。相關： Coveted； coveting。

像視線一直黏在別人手上的那把鑰匙，腦中已經開始想像它在自己口袋裡

Memory Hook

記憶鉤子

covet：像視線一直黏在別人手上的那把鑰匙，腦中已經開始想像它在自己口袋裡

能用這個畫面回到「貪求、覬覦某人擁有的財物、位置或生活」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 covet the position 這樣的說法，多半出現在 職場 / 競爭 的場景；句子真正要說的，就是「盯上了別人已經擁有的東西」。

數位 / 專業版

到了 人際 / 比較 的場景，covet their success 會更常出現；這裡要說清楚的，正是「盯上了別人已經擁有的東西」。

Collocations

常見搭配與語域

常見用法集中在 covet the position 和 covet their success；這幾個搭配分別落在 職場 / 競爭 和 人際 / 比較 的場景裡。

covet the position 職場 / 競爭

在 職場 / 競爭 的語境裡，這個搭配會把動作直接落在 the position 上。

covet their success 人際 / 比較

在 人際 / 比較 的語境裡，這個搭配會把動作直接落在 their success 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Covet 貪求、覬覦某人擁有的財物、位置或生活 當搭配和語境都已經指向「盯上了別人已經擁有的東西」，這個字才自然。
Want 想要 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 職場 / 競爭、人際 / 比較、生活 / 收藏 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
