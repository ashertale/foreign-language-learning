Consensus

kun-SEN-sus · UK /kənˈsen.səs/ · US /kənˈsen.səs/

不是每個人都熱烈同意，而是足夠多人接受同一個方向。

Core Idea

consensus 不是全員熱烈同意，而是分歧被處理到足夠多人願意一起往前走。

Meaning

簡短定義

Consensus

指共識或共同接受的看法。它可以不是百分之百一致，而是達到可行動的共同方向。

不是 Unanimity

unanimity 是一致同意；consensus 可以是可工作的共同接受。

分歧被說清
→
共同方向形成
→
大家願意前進

Origin

字源

源自 Latin consentire，有「一起感受、一起同意」的意思。

字源的「一起感受 / 同意」提供方向；現代用法裡，重點是足以共同前進。

Memory Hook

記憶鉤子

把 consensus 想成設計會議裡那句「我們可以先這樣走」。

不是每個人都拿到最想要的版本，但大家願意承擔這個方向。

Usage

生活與專業情境

工程決策

工程決策常靠 rough consensus，不是等到每個人都完全滿意。

組織

To build consensus, you usually need to surface disagreement before smoothing it over。

研究 / 評論

The consensus view 代表主流看法，但仍可能被新證據改寫。

Collocations

常見搭配與語域

consensus 的搭配常揭示共識的品質：rough、broad、scientific、consensus view。

rough consensus 工程 / 網路治理

不追求全票，但反對意見已被聽見並足以往前。

build consensus 組織 / 政治

共識不是自然掉下來，而是透過溝通與取捨形成。

consensus view 研究 / 投資 / 評論

多數專家或市場目前接受的看法。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Consensus 共同接受的看法或決策方向 用在分歧仍可能存在，但共同方向已足以支撐行動時。
Unanimity 全體一致 要求每個人都同意，門檻高很多。
Agreement 同意、協議 範圍較廣，可是兩人之間，也可正式合約。

Modern Use

現代延伸

Consensus 在工程文化裡很有價值，因為它承認複雜決策不一定有完美答案。

但共識也可能被濫用成壓過少數意見。好的 consensus 會記錄 trade-off，而不是假裝沒有人擔心。
