Probity

PROB-uh-tee · UK /ˈprəʊ.bə.ti/ · US /ˈproʊ.bə.t̬i/

不是誠實而已，而是行為和標準都站得住。

Core Idea

probity 指行為和標準都站得住。

Meaning

簡短定義

Probity

指行為和標準都站得住。

不是 Integrity

integrity 用得更廣；probity 更偏正式，也更常落在廉潔與操守。

有原則可依
→
做事不偷換標準
→
因此能被長期信任

Origin

字源

probity 來自法語、拉丁語裡「正直、被證明為好」的概念，和 prove、probable 同族；所以它不是嘴上誠實，而是經得起檢驗的操守。

Memory Hook

記憶鉤子

把 probity 想成天平不是只會擺平，而是每次秤都不作弊。

這個字帶著很正式的道德重量。

Usage

生活與專業情境

公職

談公職人物時，probity 常用來稱讚那種可以經得起放大檢視的操守。

治理

制度再漂亮，如果沒有基本 probity，最後還是會被掏空。

Collocations

常見搭配與語域

financial probity 治理 / 財務

一個人的品格、廉潔和做事底線值得信任。

personal probity 正式 / 評論

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Probity 正直操守 用在一個人的品格、廉潔和做事底線值得信任時。
Integrity 完整性與價值一致 若你想談整體一致與誠信，用 integrity 更常見。

Modern Use

現代延伸

probity 在治理、審計與正式評論中很有用，因為它把『值得信任的操守』說得很準。
