Aptitude

AP-ti-tood · UK /ˈæp.tɪ.tjuːd/ · US /ˈæp.tə.tuːd/

不是已經會了，而是很適合學會某件事的潛力。

Core Idea

aptitude 說的是人和某種學習曲線剛好合拍。它不是已完成的技能，而是看得出來這個人很容易長出那種能力。

Meaning

簡短定義

Aptitude

指適合學某件事、理解某類問題或發展某種能力的潛質。它看的是底子和吸收速度，不等於已經練成的熟練度。

不是 Skill

skill 是已經練成的能力；aptitude 是容易學會的底子。

Origin

字源

來自 Latin aptus「適合的」；重點是適性，而不是成績單。

aptus 的「適合」很好記：aptitude 就是人和任務之間的合身感。

Memory Hook

記憶鉤子

aptitude 像一個人第一次拿起 unfamiliar tool，卻很快找到力道。

重點不是他已經專精，而是那個問題似乎剛好接上他的理解方式。這和 skill 的完成感不同。

Usage

生活與專業情境

面試 / 培訓

新人還沒熟悉 codebase，但 debug 問題時能自己切 hypothesis，這可能顯示 technical aptitude。

教育 / 評量

Aptitude tests 想量的是學習潛力，不是單純問你背了多少既有知識。

用字邊界

稱讚 someone has an aptitude for languages，是在說他對語音、結構或記憶有天然入口，不是說他已經流利。

Collocations

常見搭配與語域

它常和領域名詞黏在一起：technical、mathematical、verbal。搭配的問題通常是「這個人適合在哪一類能力上長出來？」

technical aptitude 職場 / 招募 / 工程

看的是拆問題、學工具、吸收系統細節的底子。

aptitude for math 教育 / 評量

不是考一次分數，而是對抽象關係、規則與推理的適性。

natural aptitude 日常 / 教育 / 人才

暗示能力還沒完全成形，但學起來不像硬推。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Aptitude 天生或早期展現出的學習能力與適性 用在你想談「很適合學會」而不是「已經會了」的時候。
Skill 已經練成、可展示的能力 履歷上寫具體會做什麼，多半用 skill。
Talent 天分，語氣更像先天禮物 talent 比 aptitude 更容易聽起來像天生亮眼。

Modern Use

現代延伸

在招募與培訓裡，aptitude 能讓討論不只看當下技能清單。尤其對 junior role，它常比 years of experience 更接近未來成長曲線。

這個字也有界線：看見 aptitude 不代表可以省掉訓練。它只是說土壤合適，還不是說樹已經長成。
