Core Idea

cite 把一句主張接回可追查的來源。它不是順口提到，而是指出證據、判例、權威或原始依據。

Meaning

簡短定義

Cite

表示引用、舉出或援引來源、證據、例子、法律或判例。重點是讓主張可以被追查，而不只是順口提到。

不是 Quote

quote 多是逐字引用；cite 重點是把來源或依據標出來。

Origin

字源

源自 Latin citare，有召喚、傳喚、引用的方向。

Latin citare 有召喚、傳喚的方向；現代用法裡，你是在把來源叫到句子旁邊作證。

Memory Hook

記憶鉤子

cite 像 spec 裡那個 section number：它讓讀者知道限制從哪裡來。

引用不是裝飾，而是把話接回可驗證的依據。

Usage

生活與專業情境

文件

設計文件 cite spec，讀者才能追到限制從哪裡來。

法律 / 判例

A court may cite precedent to show that a decision follows earlier reasoning。

研究

Cite evidence 不一定逐字 quote；重點是把證據來源標出來。

Collocations

常見搭配與語域

cite 的對象通常是可追查的東西：source、evidence、precedent、example。搭配越清楚，句子越有責任感。

cite evidence 研究 / 辯論 / 報告

用證據支撐主張，而不是只表示意見。

cite a source 學術 / 文件

把資訊來源標明，讓讀者可以檢查。

cite precedent 法律

援引過去判例或先例，讓現在的判斷有法律脈絡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Cite 引用、舉出或依法提及某個來源 用在主張需要接上可追查來源、證據或權威時。
Quote 逐字引用 要保留原文句子時，用 quote。
Mention 提到 只是帶過某人某事，不一定提供依據。
Reference 參照、提及來源 範圍較廣，可名詞可動詞；cite 的依據感更強。

Modern Use

現代延伸

在技術文件裡，cite 是抗模糊的字。它讓限制、數據或設計選擇有來源，不必靠口耳相傳。

它也能用在批評：The report cited several failures。這時 cite 不是學術格式，而是舉出具體事例。
