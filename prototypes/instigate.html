Instigate

IN-stih-gayt · UK /ˈɪn.stɪ.ɡeɪt/ · US /ˈɪn.stə.ɡeɪt/

不是事情自己起來，而是有人在背後把火點著。

Core Idea

instigate 的好處在於精度：它把情境、語氣和搭配一起推向「有人在背後把火點著」。

Meaning

簡短定義

Instigate

表示煽動、促成、挑起某件事的開始。

不是 Start

如果 start 已經能讓句子成立，就不必硬換；需要「煽動、促成、挑起某件事的開始」時，instigate 才有必要。

Origin

字源

1540年代，由 instigation 回推而來，或者源於拉丁語的 instigatus，該詞是 instigare 的過去分詞，“鼓勵，煽動”（也是法語 instiguer 的詞源）。

像第一根火柴不大，但它讓整片乾草都知道接下來會燒起來

Memory Hook

記憶鉤子

instigate：像第一根火柴不大，但它讓整片乾草都知道接下來會燒起來

這個畫面能幫你把 instigate 和 Start 分開，因為它把「有人在背後把火點著」那條界線變得可見。

Usage

生活與專業情境

日常版

當人們說 instigate a protest 時，焦點通常就在「有人在背後把火點著」上，所以這個搭配很能代表 instigate 的語感。

數位 / 專業版

到了 組織 / 改革 的場景，instigate the change 會更常出現；這裡要說清楚的，正是「有人在背後把火點著」。

Collocations

常見搭配與語域

常見用法集中在 instigate a protest 和 instigate the change；這幾個搭配分別落在 公共 / 社會 和 組織 / 改革 的場景裡。

instigate a protest 公共 / 社會

在 公共 / 社會 的語境裡，這個搭配會把動作直接落在 a protest 上。

instigate the change 組織 / 改革

在 組織 / 改革 的語境裡，這個搭配會把動作直接落在 the change 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Instigate 煽動、促成、挑起某件事的開始 當較普通的說法太鬆，無法交代 動作是否真的落地 時。
Start 開始 如果上下文還沒有給出足夠理由支撐 instigate，先用 start。

Modern Use

現代延伸

現在最常見的就是 instigate a protest 和 instigate the change 這類說法；它們一出現，通常就在替句子劃清「有人在背後把火點著」的範圍。

當句子要把「有人在背後把火點著」說準時，instigate 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
