Expunge

ik-SPUNJ · UK /ɪkˈspʌndʒ/ · US /ɪkˈspʌndʒ/

不是刪一行，而是把痕跡徹底從紀錄裡抹掉。

Core Idea

expunge 的好處在於精度：它把情境、語氣和搭配一起推向「把痕跡徹底從紀錄裡抹掉」。

Meaning

簡短定義

Expunge

表示抹除、除名或正式刪去紀錄。

不是 Erase

如果 erase 已經能讓句子成立，就不必硬換；需要「抹除、除名或正式刪去紀錄」時，expunge 才有必要。

Origin

字源

\"用筆標記或塗抹，擦掉（文字），抹去\"，大約於1600年，源自拉丁語 expungere，通過在名稱上方或下方刺出點來標記（列表中的名稱）以進行刪除，字面意思是\"刺出\"，由 ex \"出\"（見 ex-)和 pungere \"刺，穿透\"（來自 PIE 詞根 *peuk- \"刺\")的後綴形式組成。

像紙上的墨不是劃掉，而是連壓痕都想一起磨平

Memory Hook

記憶鉤子

expunge：像紙上的墨不是劃掉，而是連壓痕都想一起磨平

這個畫面有用，是因為它先把「把痕跡徹底從紀錄裡抹掉」釘住；回到實際搭配時，就不容易把它和 Erase 混成一團。

Usage

生活與專業情境

日常版

當人們說 expunge the record 時，焦點通常就在「把痕跡徹底從紀錄裡抹掉」上，所以這個搭配很能代表 expunge 的語感。

數位 / 專業版

到了 資料 / 安全 的場景，expunge sensitive data 會更常出現；這裡要說清楚的，正是「把痕跡徹底從紀錄裡抹掉」。

Collocations

常見搭配與語域

常見用法集中在 expunge the record 和 expunge sensitive data；這幾個搭配分別落在 法務 / 程序 和 資料 / 安全 的場景裡。

expunge the record 法務 / 程序

在 法務 / 程序 的語境裡，這個搭配會把動作直接落在 the record 上。

expunge sensitive data 資料 / 安全

在 資料 / 安全 的語境裡，這個搭配會把動作直接落在 sensitive data 上。

Modern Use

現代延伸

現在最常見的就是 expunge the record 和 expunge sensitive data 這類說法；它們一出現，通常就在替句子劃清「把痕跡徹底從紀錄裡抹掉」的範圍。

當句子要把「把痕跡徹底從紀錄裡抹掉」說準時，expunge 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
