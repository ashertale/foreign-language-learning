Amend

uh-MEND · UK /əˈmend/ · US /əˈmend/

不是重新寫掉一切，而是在既有文本、規則或計畫上正式修正。

Core Idea

amend 用來描述對合約、法律、文件、設定或計畫做有意識的修補，讓它更正確或更合用。

Meaning

簡短定義

Amend

表示修正、修改或補充正式文件、規則、法律或計畫。

不是 Edit

edit 可以是一般編輯；amend 更正式，常涉及規則、條文或已發布內容。

既有版本存在
→
發現缺口或錯誤
→
正式修補

Origin

字源

amend 與拉丁語 emendare 有關，核心是把錯誤或缺陷修正掉。

它像在文件邊上補上一筆，讓原本的承諾不再漏水。

Memory Hook

記憶鉤子

amend 是把已經成立的東西修到更站得住。

這個字保留原本框架，只修正需要補強的地方。

Usage

生活與專業情境

日常版

你可以 amend a plan，把出發時間改掉，但不是整個旅行推翻。

數位 / 專業版

在規格或合約裡，amend the document 表示正式更新條文，讓版本與實際決策一致。

Collocations

常見搭配與語域

Amend 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

amend a contract 法律 / 商務

正式修改合約內容。

amend a policy 治理 / 管理

調整已存在的政策。

amend the wording 文件 / 寫作

修正措辭以避免誤解。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Amend 正式修正既有文本或規則 談合約、法規、政策、規格或正式文件時
Edit 一般地修改內容 只是調整文字或格式，不需要正式語氣時

Modern Use

現代延伸

在 issue、spec 與 legal review 裡，amend 很適合表示小而正式的修正，避免聽起來像整份重寫。
