Legitimate

luh-JIT-ih-mut · UK /lɪˈdʒɪt.ə.mət/ · US /lɪˈdʒɪt̬.ə.mət/

不是看起來合理，而是有正當性、資格或合法基礎。

Core Idea

legitimate 不只是看起來合理，而是有正當理由、資格、權限或法律基礎。

Meaning

簡短定義

Legitimate

形容理由、關切、權威、權利或行為正當、合法或有資格被承認。

不是 Reasonable

reasonable 是合理；legitimate 多了正當性或權限基礎。

主張被提出
→
檢查權限與理由
→
正當性成立

Origin

字源

來自 Latin legitimus，和法律、正規性有關。

法律、正規性的字源是背景；現代核心是正當性。

Memory Hook

記憶鉤子

把 legitimate security concern 想成它不一定決定方案，但絕不能被當成雜音掃掉。

正當性先讓它有資格進入討論。

Usage

生活與專業情境

資安

security concern legitimate，不代表一定要照對方方案做，但不能把它當噪音。

理由

A legitimate reason should survive being written down. 這裡放在理由情境時，是在說某主張、行為或權威有資格被承認，而不是只聽起來可以。

權威

Legitimate. 這裡放在權威情境時，是在說某主張、行為或權威有資格被承認，而不是只聽起來可以。

Collocations

常見搭配與語域

legitimate 常接 concern、reason、authority。搭配都在問正當性從哪裡來。

legitimate concern 職場 / 政策 / 安全

有正當性的關切，值得被處理。

legitimate reason 通用 / 正式

站得住的理由。

legitimate authority 法律 / 管理

被承認有權做某判斷或命令。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Legitimate 正當的、合法的或合理成立的 用在某主張、行為或權威有資格被承認，而不是只聽起來可以時。
Reasonable 合理 可能只是說得通；legitimate 多了正當性。
Legal 合法 只看法律；legitimate 可更廣。
Valid 有效、成立 重邏輯或資格成立。

Modern Use

現代延伸

Legitimate 很適合風險溝通：legitimate concern 不等於 veto，但它需要被納入判斷。

這個字也能阻止 dismissive culture。人提出正當疑慮時，先處理理由，不要先處理面子。
