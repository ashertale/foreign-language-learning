Morose

muh-ROHS · UK /məˈrəʊs/ · US /məˈroʊs/

不是悲傷而已，而是情緒暗下去後連人也收起來。

Core Idea

morose 不只是 Gloomy 的近義替代；它用來描述「情緒暗下去後連人也收起來」這種更窄、更準確的情境。

Meaning

簡短定義

Morose

表示陰鬱、悶悶不樂且不太想互動。

不是 Gloomy

把它們分開記：gloomy 先保留大方向，morose 負責把邊界收乾淨。

Origin

字源

1530年代，“陰鬱的，脾氣暴躁的，憂鬱而嚴肅”，源自拉丁語 morosus “陰鬱的，脾氣暴躁的，吹毛求疵的，挑剔的”，源自 mos（屬格 moris）“習慣，風俗”（見 moral（形容詞））。在英語中， manners 本身的意思是“（好的）禮貌”，但在拉丁語中的暗示是“（壞的）禮貌”。

像窗簾整片拉下來，光不是沒有，只是很難進得來

Memory Hook

記憶鉤子

morose：像窗簾整片拉下來，光不是沒有，只是很難進得來

這個畫面能幫你把 morose 和 Gloomy 分開，因為它把「情緒暗下去後連人也收起來」那條界線變得可見。

Usage

生活與專業情境

日常版

像 morose mood 這樣的說法，多半出現在 情緒 / 敘事 的場景；句子真正要說的，就是「情緒暗下去後連人也收起來」。

數位 / 專業版

到了 人際 / 場景 的場景，morose silence 會更常出現；這裡要說清楚的，正是「情緒暗下去後連人也收起來」。

Collocations

常見搭配與語域

常見用法集中在 morose mood 和 morose silence；這幾個搭配分別落在 情緒 / 敘事 和 人際 / 場景 的場景裡。

morose mood 情緒 / 敘事

在 情緒 / 敘事 的語境裡，這個搭配通常就在形容 mood 的狀態或氣質。

morose silence 人際 / 場景

在 人際 / 場景 的語境裡，這個搭配通常就在形容 silence 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 情緒 / 敘事、人際 / 場景、家庭 / 描寫 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
