Core Idea

poignant 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Poignant

表示深刻動人、酸楚而有力。

不是 Touching

如果 touching 已經能讓句子成立，就不必硬換；需要「深刻動人、酸楚而有力」時，poignant 才有必要。

Origin

字源

14世紀晚期， poinaunt，“令人身體或精神感到痛苦的”（指醬料、香料、葡萄酒以及影響感受的事物），源自於古法語 poignant “尖銳的，銳利的”（13世紀），是 poindre “刺，刺痛”的現在分詞，源自於拉丁語 pungere “刺，穿透，刺痛”，比喻地，“使煩惱，悲傷，困擾”（來自於 PIE 詞根 *peuk- “刺痛”）。

像熟悉旋律突然在舊房間裡響起，心一下被拉回曾經的時刻

Memory Hook

記憶鉤子

poignant：像熟悉旋律突然在舊房間裡響起，心一下被拉回曾經的時刻

這個畫面有用，是因為它先把「感覺裡帶著一點刺，會直接扎進心裡」釘住；回到實際搭配時，就不容易把它和 Touching 混成一團。

Usage

生活與專業情境

日常版

當人們說 poignant memory 時，焦點通常就在「感覺裡帶著一點刺，會直接扎進心裡」上，所以這個搭配很能代表 poignant 的語感。

數位 / 專業版

到了 影視 / 評論 的場景，poignant scene 會更常出現；這裡要說清楚的，正是「感覺裡帶著一點刺，會直接扎進心裡」。

Collocations

常見搭配與語域

常見用法集中在 poignant memory 和 poignant scene；這幾個搭配分別落在 情感 / 回憶 和 影視 / 評論 的場景裡。

poignant memory 情感 / 回憶

在 情感 / 回憶 的語境裡，這個搭配通常就在形容 memory 的狀態或氣質。

poignant scene 影視 / 評論

在 影視 / 評論 的語境裡，這個搭配通常就在形容 scene 的狀態或氣質。

Neighbors

Modern Use

現代延伸

現在最常見的就是 poignant memory 和 poignant scene 這類說法；它們一出現，通常就在替句子劃清「感覺裡帶著一點刺，會直接扎進心裡」的範圍。

當句子要把「感覺裡帶著一點刺，會直接扎進心裡」說準時，poignant 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
