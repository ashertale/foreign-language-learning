Orient

OR-ee-ent · UK /ˈɔː.ri.ent/ · US /ˈɔːr.i.ent/

不是告訴方向而已，而是讓人知道自己在整個系統裡的位置。

Core Idea

orient 不只是指方向，而是讓人知道自己在整個環境裡的位置，接著才知道怎麼行動。

Meaning

簡短定義

Orient

表示使定位、使熟悉方向，也可指朝向某目標或方向。

不是 Point

point 是指向；orient 讓人或系統重新找到方向和位置。

進入陌生環境

Origin

字源

原與東方、日出方向有關；後來延伸為找方向、定位。

東方 / 日出方向的歷史很有畫面；現代核心是找方向與定位。

Memory Hook

記憶鉤子

把 orient newcomers 想成先給地圖和地標，而不是直接丟 issue。

人知道自己在哪裡，才知道下一步問什麼。

Usage

生活與專業情境

Onboarding

好的 onboarding 會 orient newcomers，讓他們知道哪些問題該先問。

方向

A system can be oriented toward reliability or toward speed; trade-offs reveal the truth. 這裡放在方向情境時，是在說讓人或系統找到相對位置、方向和行動入口。

訓練

An orientation session should reduce disorientation, not just transmit policies. 這裡放在訓練情境時，是在說讓人或系統找到相對位置、方向和行動入口。

Collocations

常見搭配與語域

orient 常接 newcomers、toward、orientation。搭配會分成幫人定位和把系統朝某方向調整。

orient newcomers 職場 / 教育

幫新人找到位置、脈絡和基本方向。

orient toward 正式 / 分析

朝某目標或方向調整。

orientation session 教育 / 職場

入門說明或導覽。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Orient 定位、使適應或朝向某方向 用在讓人或系統找到相對位置、方向和行動入口時。
Point 指向 只給方向。
Guide 引導 帶領行動。
Position 定位 放到某位置，也可指市場定位。

Modern Use

現代延伸

Orient 是 onboarding 的核心字。新人缺的常不是努力，而是坐標系。

在策略語言裡 orient toward X 表示選擇把設計或資源朝 X 對齊。
