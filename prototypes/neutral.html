Neutral

NOO-trul · UK /ˈnjuː.trəl/ · US /ˈnuː.trəl/

不是沒有影響，而是不偏向任何一邊。

Core Idea

neutral 不是不在乎，而是不把語氣、位置或系統推向任何一邊。

Meaning

簡短定義

Neutral

形容立場、語言、顏色、效果或狀態中立，不偏向特定一方。

不是 Indifferent

indifferent 是不在乎；neutral 是站位不偏，仍可能很關心結果。

多方存在
→
不偏任何一方
→
保持可被信任

Origin

字源

來自 Latin neuter，意思接近「兩者都不是」。

neuter 的「兩者都不是」提供方向；neutral 是不站到任一邊。

Memory Hook

記憶鉤子

把 neutral language 想成 incident report 先讓證據站出來，而不是先把人推到防衛位置。

中立不是冷淡，是保留信任。

Usage

生活與專業情境

報告

incident report 用 neutral language，能降低防衛心，讓證據先說話。

立場

A neutral position can still care about the outcome; it just does not favor a side.

Collocations

常見搭配與語域

neutral 常接 language、position、carbon。搭配會分辨是語氣中立、立場中立，還是碳平衡。

neutral language 文件 / 調查

不帶責備或偏見的語言。

neutral position 政治 / 人際

不偏向任一方的位置。

carbon neutral 環境 / 商務

碳排放透過減量或抵換達到平衡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Neutral 中立的、不帶偏向的 用在不偏向任一方，或效果被平衡掉時。
Indifferent 不在乎 重缺乏關心；neutral 可以很關心但不偏。
Impartial 公正不偏 重判斷過程。
Objective 客觀 重可被外部證據檢查。

Modern Use

現代延伸

Neutral 在寫 incident 和 review 時很重要。中立語言能讓討論先處理系統，而不是先處理面子。

但 neutral 不等於沒價值判斷；你仍可以中立描述一個很嚴重的事。
