Drastic

DRAS-tik · UK /ˈdræs.tɪk/ · US /ˈdræs.tɪk/

不是大動作而已，而是會把整個局面一下拉到另一邊。

Core Idea

drastic 的好處在於精度：它把情境、語氣和搭配一起推向「會把整個局面一下拉到另一邊」。

Meaning

簡短定義

Drastic

表示激烈、劇烈，帶來顯著而強硬的改變。

不是 Severe

severe 可以先說出 嚴重；drastic 則把句子推到「會把整個局面一下拉到另一邊」這個更細的位置。

Origin

字源

1690年代，最初用於藥物，意爲“有力的，強有力的”，尤其是對腸道的影響，源自希臘語 drastikos “有效的，有功效的； 積極的，暴力的”，來自 drasteon “（要做的事情）”，來自 drāo “做，製造，行動，執行”（尤其是一些偉大的行爲，無論是好是壞），其詞源不確定 . “極端的，嚴重的，用力或暴力行動”的意義記錄於1808年。相關： Drastically。

像不是微調旋鈕，而是直接把整條桿子扳到底

Memory Hook

記憶鉤子

drastic：像不是微調旋鈕，而是直接把整條桿子扳到底

這個畫面能幫你把 drastic 和 Severe 分開，因為它把「會把整個局面一下拉到另一邊」那條界線變得可見。

Usage

生活與專業情境

日常版

像 drastic measure 這樣的說法，多半出現在 管理 / 危機 的場景；句子真正要說的，就是「會把整個局面一下拉到另一邊」。

數位 / 專業版

到了 財務 / 成本 的場景，drastic cut 會更常出現；這裡要說清楚的，正是「會把整個局面一下拉到另一邊」。

Collocations

常見搭配與語域

常見用法集中在 drastic measure 和 drastic cut；這幾個搭配分別落在 管理 / 危機 和 財務 / 成本 的場景裡。

drastic measure 管理 / 危機

在 管理 / 危機 的語境裡，這個搭配通常就在形容 measure 的狀態或氣質。

drastic cut 財務 / 成本

在 財務 / 成本 的語境裡，這個搭配通常就在形容 cut 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Drastic 激烈、劇烈，帶來顯著而強硬的改變 當句子需要把「會把整個局面一下拉到另一邊」說清楚，而不是只留在 嚴重 的外圈時。
Severe 嚴重 當你只需要先說 嚴重，不必把語氣收進「會把整個局面一下拉到另一邊」時。

Modern Use

現代延伸

現在最常見的就是 drastic measure 和 drastic cut 這類說法；它們一出現，通常就在替句子劃清「會把整個局面一下拉到另一邊」的範圍。

當句子要把「會把整個局面一下拉到另一邊」說準時，drastic 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
