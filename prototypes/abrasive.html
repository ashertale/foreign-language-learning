Abrasive

uh-BRAY-siv · UK /əˈbreɪ.sɪv/ · US /əˈbreɪ.sɪv/

不是直接而已，而是帶著磨擦感，讓人一接觸就覺得被刮到。

Core Idea

abrasive 最值得保留的語感，是它讓「表面粗糙，或說話做事方式生硬刺人、容易引發反感」不再只是模糊大意。

Meaning

簡短定義

Abrasive

表示表面粗糙，或說話做事方式生硬刺人、容易引發反感。

不是 Harsh

把它們分開記：harsh 先保留大方向，abrasive 負責把邊界收乾淨。

先遇到 abrasive surface
→
看它是否只是 尖銳或嚴厲
→
再決定是否需要 abrasive

Origin

字源

\"磨料，研磨劑\"，1850年，來自 abrasive（形容詞）。Abradant 在這個意義上是從1868年開始使用的。

像砂紙不是故意打人，但一碰就會把表面磨得不舒服

Memory Hook

記憶鉤子

abrasive：像砂紙不是故意打人，但一碰就會把表面磨得不舒服

能用這個畫面回到「表面粗糙，或說話做事方式生硬刺人、容易引發反感」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 abrasive surface 這樣的說法，多半出現在 材料 / 工程 的場景；句子真正要說的，就是「帶著磨擦感，讓人一接觸就覺得被刮到」。

數位 / 專業版

到了 溝通 / 人際 的場景，abrasive tone 會更常出現；這裡要說清楚的，正是「帶著磨擦感，讓人一接觸就覺得被刮到」。

Collocations

常見搭配與語域

常見用法集中在 abrasive surface 和 abrasive tone；這幾個搭配分別落在 材料 / 工程 和 溝通 / 人際 的場景裡。

abrasive surface 材料 / 工程

在 材料 / 工程 的語境裡，這個搭配通常就在形容 surface 的狀態或氣質。

abrasive tone 溝通 / 人際

在 溝通 / 人際 的語境裡，這個搭配通常就在形容 tone 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Abrasive 表面粗糙，或說話做事方式生硬刺人、容易引發反感 當搭配和語境都已經指向「帶著磨擦感，讓人一接觸就覺得被刮到」，這個字才自然。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 材料 / 工程、溝通 / 人際、職場 / 協作 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
