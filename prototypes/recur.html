Word 281 / verb

Recur

rih-KUR · UK /rɪˈkɜːr/ · US /rɪˈkɝː/

不是一直沒走，而是隔一段時間又回來。

CEFR
C1

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

recur 最值得保留的語感，是它讓「再度出現、反覆發生或週期性重來」不再只是模糊大意。

Meaning

簡短定義

Recur

表示再度出現、反覆發生或週期性重來。

不是 Repeat

把它們分開記：repeat 先保留大方向，recur 負責把邊界收乾淨。

先遇到 the issue recurs
→
看它是否只是 重複
→
再決定是否需要 recur

Origin

字源

14世紀晚期， recuren，“從疾病或痛苦中恢復”（現已過時）； 15世紀中期，“返回”（到或進入一個地方），源自拉丁語 recurrere “返回，跑回來，匆忙返回”，比喻意義上是“迴歸，再次發生”，由 re- “向後，再次”（見 re-)和 currere “奔跑”（源自 PIE 詞根 *kers- “奔跑”）組成。最初指人； 應用於思想、觀念等，“回到頭腦中”，記錄於1620年代。意思是“再次發生”，始於1670年代。相關： Recurred； recurring。

像浪退了以為安靜了，沒多久又同樣拍回岸邊

Memory Hook

記憶鉤子

recur：像浪退了以為安靜了，沒多久又同樣拍回岸邊

能用這個畫面回到「再度出現、反覆發生或週期性重來」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 the issue recurs 這樣的說法，多半出現在 工程 / 除錯 的場景；句子真正要說的，就是「隔一段時間又回來」。

數位 / 專業版

到了 分析 / 趨勢 的場景，recur over time 會更常出現；這裡要說清楚的，正是「隔一段時間又回來」。

Collocations

常見搭配與語域

常見用法集中在 the issue recurs 和 recur over time；這幾個搭配分別落在 工程 / 除錯 和 分析 / 趨勢 的場景裡。

the issue recurs 工程 / 除錯

在 工程 / 除錯 的語境裡，這個搭配最容易看出「隔一段時間又回來」實際怎麼落在句子裡。

recur over time 分析 / 趨勢

在 分析 / 趨勢 的語境裡，這個搭配會把動作直接落在 over time 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Recur 再度出現、反覆發生或週期性重來 當搭配和語境都已經指向「隔一段時間又回來」，這個字才自然。
Repeat 重複 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 工程 / 除錯、分析 / 趨勢、維運 / 追蹤 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
