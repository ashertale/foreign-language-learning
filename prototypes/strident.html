Strident

STRY-dənt · UK /ˈstraɪ.dənt/ · US /ˈstraɪ.dənt/

不是大聲，而是大聲到刺耳、壓人。

Core Idea

strident 的強硬帶刺耳感；聲音、語氣或立場不只大，還壓人。

Meaning

簡短定義

Strident

形容聲音刺耳，或語氣、立場尖銳強硬。

不是 Loud

loud 只是聲量大；strident 更像高而刺、帶壓迫感。

聲量先被推高
→
質地開始刺耳
→
整體帶出壓迫與對抗感

Origin

字源

strident 來自拉丁語裡「刺耳作響、尖銳摩擦」的聲音感，先是聽覺上的 harsh；所以它後來用在語氣或立場時，也保留那種吵、硬、刮耳朵的感覺。

Memory Hook

記憶鉤子

把 strident 想成喇叭不只是開大，而是尖到讓人想退。

它批評的是聲音或立場的質地。

Usage

生活與專業情境

語氣

有些聲明不是堅定，而是過度 strident，讓人先被刺到。

媒體

形容輿論時，strident 常帶一種越喊越硬、越喊越尖的感覺。

Modern Use

現代延伸

strident 很適合用來批評過度尖銳、刺耳的聲音與立場，比 aggressive 更有聽覺感。
