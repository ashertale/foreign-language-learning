Prelude

PREL-yood · UK /ˈprel.juːd/ · US /ˈprel.uːd/

不是前面那段，而是替後面真正主體暖場的開端。

Core Idea

prelude 指那種「序幕鋪墊」的狀態、力量、場面或事物。它常把抽象感受壓縮成一個可指認的名詞。

Meaning

簡短定義

Prelude

指那種「序幕鋪墊」的狀態、力量、場面或事物。

不是 Introduction

introduction 很中性；prelude 更有序幕、預示和氣氛鋪陳感。

先有一段暖場
→
氣氛逐漸被推起來
→
後面主體才真正進場

Origin

字源

prelude 來自法語、拉丁語裡「先玩、先演」的概念，最早就是主曲前的短段演奏；所以它一路保留了「不是主體，而是替主體先把氣氛與方向鋪好」的味道。

Memory Hook

記憶鉤子

把 prelude 想成演出前燈光先暗下來的那幾秒。

它不是主菜，但它會決定你怎麼走進主菜。
