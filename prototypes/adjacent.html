Adjacent

uh-JAY-sunt · UK /əˈdʒeɪ.sənt/ · US /əˈdʒeɪ.sənt/

不是泛泛附近，而是隔著一條邊界就在旁邊，近到可能互相影響。

Core Idea

adjacent 不是把地點說得模糊一點，而是把邊界說清楚：A 在 B 旁邊，兩者可能相接、相鄰，或至少緊貼到足以被一起考慮。

Meaning

簡短定義

Adjacent

形容事物在位置、次序、領域或概念上相鄰。它比 nearby 更精準，常暗示兩者中間沒有太多緩衝。

不是 Nearby

nearby 只說距離近；adjacent 會讓人想到隔壁、下一格、相鄰區塊或接壤邊界。

Origin

字源

adjacent 來自 Latin adjacere，意思接近「躺在旁邊」。

記成「就在旁邊躺著」即可：不是 distant，不是 vague nearby，而是你畫出邊界後，下一個碰到的東西。

Memory Hook

記憶鉤子

adjacent 是 memory map 裡緊貼在旁邊的區塊：不是遠方的風險，而是下一個 address range。

這個字好用在工程語境，因為許多問題不是發生在中心，而是發生在邊界旁邊：buffer、pin、trace、region、layer 都可能因為相鄰而互相影響。

Usage

生活與專業情境

空間 / 版圖

The lab is adjacent to the production floor 表示兩個空間緊鄰，不只是都在同一棟樓。

工程 / 記憶體

adjacent memory regions 會讓人想到 overflow、alignment 或 protection boundary；這不是裝飾性的「附近」。

商業 / 策略

adjacent markets 是和既有能力貼得很近的新市場：不是完全陌生，也不是原本那一塊。

Collocations

常見搭配與語域

搭配詞會標出 adjacency 發生在哪一種邊界：物理空間、資料區塊、產品市場，或概念領域。

adjacent to 通用 / 空間描述

最基本用法，後面接相鄰對象：adjacent to the station、adjacent to the buffer。

adjacent memory region 嵌入式 / 系統 / 除錯

用來談地址空間、保護邊界、資料覆寫或配置風險。

adjacent market 產品 / 商業策略

指和既有市場相鄰、可由現有能力延伸過去的領域。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Adjacent 緊鄰、相鄰，通常有清楚邊界感 當你要說兩個東西隔壁、接邊、下一格，或近到需要一起評估。
Nearby 距離近，但不一定相鄰 適合日常找位置；不需要強調邊界或接壤。
Neighboring 鄰近的，常用於地區、國家、房間或社群 比 adjacent 更日常，邊界感稍弱。
Contiguous 連續接在一起，中間沒有中斷 常用於資料區塊、土地或序列；比 adjacent 更強調連續性。

Modern Use

現代延伸

在技術寫作裡，adjacent 很適合用來替風險定位。A problem in an adjacent block 表示它不是主目標，但離得夠近，可能被同一個修改波及。

在產品討論裡，adjacent 也能防止策略跳太遠。An adjacent opportunity 應該和既有能力有邊界上的連接，而不是只因為看起來熱門。
