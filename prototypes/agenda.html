Agenda

uh-JEN-duh · UK /əˈdʒen.də/ · US /əˈdʒen.də/

不是時間表，而是這場討論真正要處理、推動，甚至暗中想完成的事。

Core Idea

agenda 問的不是「幾點開始」，而是「這場局想把注意力推向哪裡」。它可以是會議清單，也可以是政策方向，更可以是沒有明說的目的。

Meaning

簡短定義

Agenda

指會議、組織或個人想要討論、處理或推進的事項。它可以是公開列出的議程，也可以是較隱性的目的或立場。

不是 Schedule

schedule 管時間；agenda 管要處理的事與背後方向。

選出要談什麼
→
決定優先順序
→
把注意力推向某個結果

Origin

字源

agenda 源自 Latin agendum，意思是「要被做的事」；agenda 原本是複數形式，現代英文通常當單數名詞使用。

記憶時不要只想成會議表格；把它想成「things to be done」的清單，以及清單背後的推力。

Memory Hook

記憶鉤子

agenda 是會議桌上的那張紙，但真正重要的是：誰決定紙上有哪些項目，哪些項目被排到最後。

好的 agenda 讓討論有方向；壞的 agenda 會讓會議看似有序，實際上只是把最重要的衝突藏到時間用完。

Usage

生活與專業情境

會議

Please send the agenda before the meeting 不是要知道日曆時間，而是要知道要準備哪些議題、誰需要做決定。

政治 / 組織

policy agenda 指一組政策優先事項；它不是單一法案，而是一段時間內想推動的方向。

隱性目的

A hidden agenda 表示表面理由之外還有沒說出口的目的，語氣通常帶懷疑。

Collocations

常見搭配與語域

agenda 的搭配會告訴你它是公開清單、權力排序，還是未說出口的目的。

set the agenda 管理 / 政治 / 媒體

不是只排清單，而是決定哪些議題值得被討論，哪些議題被擠到旁邊。

meeting agenda 商務 / 專案

會議前的議題清單，通常包含討論項目、決策點與時間分配。

hidden agenda 評論 / 人際 / 組織政治

暗示某人表面說一套，實際上想推另一件事。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Agenda 要處理、討論或推動的事項與方向 當重點是議題選擇、優先順序或背後目的，而不是時間安排。
Schedule 時間安排 告訴你何時發生，不一定告訴你為什麼要談。
Itinerary 旅行或活動行程 多用於移動路線、景點、交通與活動順序。
Plan 做事方案或安排 範圍較廣；不一定是會議、組織或政策優先事項。

Modern Use

現代延伸

在工作裡，agenda 是會議效率的前置條件。沒有 agenda 的會議通常會把同步、討論、決策混在一起，最後每個人都以為自己參加了不同的會。

在公共討論中，agenda 也和權力有關。能 set the agenda 的人，往往不是直接決定答案，而是先決定大家有資格問哪些問題。
