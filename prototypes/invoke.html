Invoke

in-VOHK · UK /ɪnˈvəʊk/ · US /ɪnˈvoʊk/

不是隨口提到，而是把規則、情緒或函式真的叫進場。

Core Idea

invoke 用來描述「把規則、情緒或函式真的叫進場」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Invoke

表示援引、喚起、調用某個力量、原則或程式。

不是 Call

如果 call 已經能讓句子成立，就不必硬換；需要「援引、喚起、調用某個力量、原則或程式」時，invoke 才有必要。

Origin

字源

15世紀晚期，源自於古法語 invoquer， envoquer， envochier “祈求，懇求”（12世紀），源自於拉丁語 invocare “呼喚，懇求”，由 in- “在……上”（源自於 PIE 詞根 *en “在……裏”）和 vocare “呼叫”組成，與 vox（屬格 vocis）“聲音”（源自於 PIE 詞根 *wekw- “說話”）有關。

Usage

生活與專業情境

日常版

當人們說 invoke the function 時，焦點通常就在「把規則、情緒或函式真的叫進場」上，所以這個搭配很能代表 invoke 的語感。

數位 / 專業版

到了 法規 / 制度 的場景，invoke a rule 會更常出現；這裡要說清楚的，正是「把規則、情緒或函式真的叫進場」。

Collocations

常見搭配與語域

常見用法集中在 invoke the function 和 invoke a rule；這幾個搭配分別落在 軟體 / 程式 和 法規 / 制度 的場景裡。

invoke the function 軟體 / 程式

在 軟體 / 程式 的語境裡，這個搭配會把動作直接落在 the function 上。

invoke a rule 法規 / 制度

在 法規 / 制度 的語境裡，這個搭配會把動作直接落在 a rule 上。

Neighbors

Modern Use

現代延伸

現在最常見的就是 invoke the function 和 invoke a rule 這類說法；它們一出現，通常就在替句子劃清「把規則、情緒或函式真的叫進場」的範圍。

當句子要把「把規則、情緒或函式真的叫進場」說準時，invoke 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
