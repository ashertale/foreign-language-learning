Objective

ub-JEK-tiv · UK /əbˈdʒek.tɪv/ · US /əbˈdʒek.tɪv/

不是沒有立場，而是判斷盡量靠外部證據，而不是個人感覺。

Core Idea

objective 不是人沒有立場，而是判斷盡量移到個人感覺之外，讓別人也能檢查。

Meaning

簡短定義

Objective

形容證據、評估或標準客觀；也可作名詞指目標。

不是 Subjective

subjective 來自個人感受；objective 盡量讓判斷可被他人檢查。

感受先放旁邊
→
找外部證據
→

Origin

字源

來自 object 的對象概念；現代語感是把判斷放到個人之外。

object 的對象感可記成：把判斷放到個人之外的對象上。

Memory Hook

記憶鉤子

把 objective metric 想成大家先同意的量測尺。

尺不一定完美，但比各自憑印象吵更可追蹤。

Usage

生活與專業情境

指標

Objective metric 不一定完美，但至少讓討論不用全靠印象。

證據

Objective evidence should be inspectable by people who disagree with you.

目標

A project objective is what the work is trying to achieve, not how you feel about it.

Collocations

常見搭配與語域

objective 常接 measure、evidence、assessment。搭配若作名詞，則會指目標。

objective measure 評估 / 工程

可外部檢查的量測方式。

objective evidence 法律 / 科學 / debug

不靠個人感受的證據。

objective assessment 管理 / 評估

盡量依標準和證據的評估。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Objective 客觀的、以證據或外部標準為依據的 用在判斷需要可被外部證據檢查，或作名詞談目標時。
Subjective 主觀 來自個人感受或觀點。
Neutral 中立 不偏一方。
Goal 目標 名詞義的 objective 可和 goal 接近。

Modern Use

現代延伸

Objective 不等於完全沒有偏差。量測方式仍可能選錯，但至少它讓偏差有機會被檢查。

在需求文件裡，objective 作名詞也很常見：先講目標，再講方案。
