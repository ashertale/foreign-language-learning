Plummet

PLUM-it · UK /ˈplʌm.ɪt/ · US /ˈplʌm.ət/

不是下降，而是往下掉得又快又狠。

CEFR
C1

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

plummet 寫的是數字、價格或狀態突然往下砸，速度和跌幅都比一般下降更狠。

Meaning

簡短定義

Plummet

快速而大幅下跌，常用於價格、溫度、信心或指標。

不是 Decline

decline 可以慢慢降；plummet 有一種失重直落感。

先往下走
→
速度突然加快
→
很快掉到低點

Origin

字源

plummet 原本是鉛做的測垂小重錘，也就是 plumb line 上那顆往下墜的鉛塊；所以它後來變成暴跌時，畫面感非常直接，就是垂直往下掉。

Memory Hook

記憶鉤子

把 plummet 想成不是滑坡，而是電梯斷線。

這個字的速度感非常強，幾乎總伴隨驚嚇。

Usage

生活與專業情境

數據

如果留存率在一週內直直掉下去，plummet 的力道就很對。

情緒

有些消息不只是讓士氣下降，而是讓它瞬間 plummet。

Collocations

常見搭配與語域

plummet in value 商業 / 財經

價格、信心、溫度或數據快速往下掉。

temperatures plummet 新聞 / 日常

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Plummet 急墜下滑 用在價格、信心、溫度或數據快速往下掉時。
Decline 逐步下降 若變化是緩慢或長期趨勢，用 decline 更自然。

Modern Use

現代延伸

plummet 在數據、財務與新聞語境很常見，因為它把『快速下墜』寫得很有畫面。
