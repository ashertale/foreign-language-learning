Amicable

AM-ih-kuh-bul · UK /ˈæm.ɪ.kə.bəl/ · US /ˈæm.ɪ.kə.bəl/

不是沒有分歧，而是即使立場不同，仍能平和處理。

Core Idea

amicable 用來描述「即使立場不同，仍能平和處理」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Amicable

表示關係或解決方式友善、和氣，沒有敵意。

不是 Friendly

friendly 可以先說出 友善；amicable 則把句子推到「即使立場不同，仍能平和處理」這個更細的位置。

Origin

字源

15世紀早期，“愉快的”，源自晚期拉丁語 amicabilis “友好的”，這是羅馬法中的一個詞，源自拉丁語 amicus “朋友”，最終源自 amare “愛”（參見 Amy）。在現代用法中，“以友好爲特徵，沒有不良感情，和平，社交和諧”。比較 amiable，這是通過法語的同一個詞。相關： Amicableness。

Usage

生活與專業情境

日常版

像 amicable settlement 這樣的說法，多半出現在 法務 / 協商 的場景；句子真正要說的，就是「即使立場不同，仍能平和處理」。

數位 / 專業版

到了 人際 / 關係 的場景，amicable split 會更常出現；這裡要說清楚的，正是「即使立場不同，仍能平和處理」。

Collocations

常見搭配與語域

常見用法集中在 amicable settlement 和 amicable split；這幾個搭配分別落在 法務 / 協商 和 人際 / 關係 的場景裡。

amicable settlement 法務 / 協商

在 法務 / 協商 的語境裡，這個搭配通常就在形容 settlement 的狀態或氣質。

amicable split 人際 / 關係

在 人際 / 關係 的語境裡，這個搭配通常就在形容 split 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Amicable 關係或解決方式友善、和氣，沒有敵意 當句子需要把「即使立場不同，仍能平和處理」說清楚，而不是只留在 友善 的外圈時。
Friendly 友善 當你只需要先說 友善，不必把語氣收進「即使立場不同，仍能平和處理」時。

Modern Use

現代延伸

現在最常見的就是 amicable settlement 和 amicable split 這類說法；它們一出現，通常就在替句子劃清「即使立場不同，仍能平和處理」的範圍。

當句子要把「即使立場不同，仍能平和處理」說準時，amicable 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
