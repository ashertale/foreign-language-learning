Confound

kuhn-FOUND · UK /kənˈfaʊnd/ · US /kənˈfaʊnd/

不是單純困惑，而是把訊號和干擾攪在一起，讓判讀失真。

Core Idea

confound 的好處在於精度：它把情境、語氣和搭配一起推向「把訊號和干擾攪在一起，讓判讀失真」。

Meaning

簡短定義

Confound

表示使人困惑，或在分析中造成干擾、混淆結果。

不是 Confuse

如果 confuse 已經能讓句子成立，就不必硬換；需要「使人困惑，或在分析中造成干擾、混淆結果」時，confound 才有必要。

Origin

字源

約於1300年，“譴責，詛咒”，也指“徹底摧毀”； 來自盎格魯-法語 confoundre，古法語 confondre（12世紀）“粉碎，毀滅，使混亂”，源自拉丁語 confundere “混淆，混雜在一起，使混亂”，尤指思想或感官，“使困惑，使迷惑”，本意爲“倒，混合或混合在一起”，來自於 com “一起”（見 con-)和 fundere “倒”（來自於 PIE 詞根 *gheu- “倒”經過鼻化形成）的同化形式。

像兩條線纏在一起後，你分不清哪條才是原本要追的那一條

Memory Hook

記憶鉤子

confound：像兩條線纏在一起後，你分不清哪條才是原本要追的那一條

能用這個畫面回到「使人困惑，或在分析中造成干擾、混淆結果」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 confound the results 時，焦點通常就在「把訊號和干擾攪在一起，讓判讀失真」上，所以這個搭配很能代表 confound 的語感。

數位 / 專業版

到了 統計 / 實驗 的場景，confounding variable 會更常出現；這裡要說清楚的，正是「把訊號和干擾攪在一起，讓判讀失真」。

Collocations

常見搭配與語域

常見用法集中在 confound the results 和 confounding variable；這幾個搭配分別落在 研究 / 分析 和 統計 / 實驗 的場景裡。

confound the results 研究 / 分析

在 研究 / 分析 的語境裡，這個搭配會把動作直接落在 the results 上。

confounding variable 統計 / 實驗

在 統計 / 實驗 的語境裡，這個搭配最容易看出「把訊號和干擾攪在一起，讓判讀失真」實際怎麼落在句子裡。

Modern Use

現代延伸

現在最常見的就是 confound the results 和 confounding variable 這類說法；它們一出現，通常就在替句子劃清「把訊號和干擾攪在一起，讓判讀失真」的範圍。

當句子要把「把訊號和干擾攪在一起，讓判讀失真」說準時，confound 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
