Infrastructure

IN-fruh-struk-chur · UK /ˈɪn.frəˌstrʌk.tʃər/ · US /ˈɪn.frəˌstrʌk.tʃɚ/

不是使用者看到的功能，而是讓功能能穩定存在的底層支撐。

Core Idea

infrastructure 是功能底下那層支撐。使用者未必看見，但沒有它，上面的服務很難穩定存在。

Meaning

簡短定義

Infrastructure

指基礎設施、底層支撐系統或組織運作所需的基礎結構。

不是 Feature

feature 是看得見的功能；infrastructure 是讓功能能跑、能維護的底層。

底層被建立
→
服務在上面運作
→
穩定性變可能

Origin

字源

由 infra「下面」與 structure「結構」組合；字面就是底下的結構。

infra 是下面，structure 是結構；字面就是底下的支撐。

Memory Hook

記憶鉤子

把 infrastructure 想成測試、build、deploy、monitoring 那些平常不被 demo 的東西。

它們不搶眼，但決定功能能不能長期活著。

Usage

生活與專業情境

測試

test infrastructure 做得好，工程師才敢快速改 code。

網路

成本

Infrastructure cost often grows quietly behind every new feature. 這裡放在成本情境時，是在說談支撐功能、服務或組織長期運作的底層結構。

Collocations

常見搭配與語域

infrastructure 常接 test、network、cost。搭配會指出支撐的是工程流程、連線，還是財務負擔。

test infrastructure 工程 / 品質

支撐測試執行、資料、環境和報告的基礎設施。

network infrastructure IT / 通訊

網路連線與服務的底層結構。

infrastructure cost 雲端 / 財務

維持底層系統運作的成本。

Neighbors

對立與鄰近概念

Modern Use

現代延伸

Infrastructure 的價值常在出事時才被看見。好的 infrastructure 讓快變得安全，讓維護不靠英雄。

它不是雜務。對長期產品而言，測試與部署基礎設施就是速度的一部分。
