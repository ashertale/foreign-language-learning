Core Idea

infrastructure 把「基礎設施、底層支撐系統」抓成可以討論的名詞，讓句子不只停在感覺，而能指向一個可檢查的狀態。

Meaning

簡短定義

Infrastructure

指基礎設施、底層支撐系統。這個名詞通常把注意力放在某種狀態、關係或判準上，讓問題的輪廓更清楚。

不是 Feature

feature 是看得見的功能；infrastructure 是讓功能能跑、能維護的底層。

Origin

字源

由 infra「下面」與 structure「結構」組合；字面就是底下的結構。

記憶時先抓「基礎設施、底層支撐系統」這條線；字源是輔助，不要把諧音或畫面誤當成歷史。

Memory Hook

記憶鉤子

infrastructure 可以先記成一個畫面：底層被建立，接著服務在上面運作，最後穩定性變可能。

這個畫面只用來幫你抓住「基礎設施、底層支撐系統」；真正使用時，要回到句子裡看它標出的邊界。
