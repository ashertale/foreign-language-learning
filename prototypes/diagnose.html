Diagnose

Core Idea

diagnose 不是猜原因，而是讀症狀、收資料、排除錯路，直到問題的性質浮出來。

Meaning

簡短定義

Diagnose

表示診斷、判斷問題本質或根因，通常需要根據症狀、證據和排除法。

不是 Guess

guess 是猜；diagnose 要靠症狀、資料與排除法。

觀察症狀
→

→

Origin

字源

源自 Greek diagnosis，有「透過辨別而知道」的意思。

Greek 裡「透過辨別而知道」的方向很準：diagnose 是分辨後才知道。

Memory Hook

記憶鉤子

把 diagnose 想成先分 symptom，再動 code。

急著修常會修到影子；diagnose 要先找出問題到底是哪一類。

Usage

生活與專業情境

故障

Diagnose fault 時，先把症狀分類，比直接改 code 更接近根因。

醫療

A doctor diagnoses illness by matching symptoms, tests, and patient history。

流程

流程情境下，diagnose 不是猜原因，而是根據症狀和證據判斷問題本質。

Collocations

常見搭配與語域

diagnose 的搭配通常有一個待判斷的問題：fault、problem、illness。early diagnosis 則強調越早辨認越能降低損害。

diagnose a fault 工程 / 維修

根據現象判斷故障類型或位置。

diagnose the problem 通用 / 管理

找出問題本質，而不是只處理表面。

early diagnosis 醫療 / 風險

早期診斷，讓後續處理更有機會成功。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Diagnose 診斷、辨認問題原因 用在你要根據證據辨認問題本質，而不是憑感覺猜時。
Guess 猜 缺少證據，只是先押一個可能原因。
Detect 偵測 發現某現象存在，不一定知道原因。
Troubleshoot 排除問題 工程動作較廣，可包含 diagnose 和修復。

Modern Use

現代延伸

Diagnose 在工程裡很好用，因為它要求你尊重 symptom 和 evidence。

好的 incident review 會分清 detect、diagnose、fix：看到問題、理解問題、修掉問題是三件事。
