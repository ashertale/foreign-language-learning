Criterion

kry-TEER-ee-un · UK /kraɪˈtɪə.ri.ən/ · US /kraɪˈtɪr.i.ən/

不是一般條件，而是用來判斷是否合格的標準。

Core Idea

criterion 是判斷用的尺。它不是任意條件，而是用來決定合格、不合格、選或不選的標準。

Meaning

簡短定義

Criterion

指判準、標準或評估依據。複數是 criteria，常用於選擇、評估、驗收和研究。

不是 Requirement

requirement 是需求；criterion 是拿來判斷的尺。

定義判斷尺
→
套到案例
→
得出合格與否

Origin

字源

源自 Greek kriterion，意思接近判斷的工具或標準。

Greek 的判斷工具感很直覺：criterion 就是拿來判斷的工具。

Memory Hook

記憶鉤子

把 criterion 想成 acceptance test 裡那條可判斷的線。

沒有它，done 只會變成每個人心裡不同的感覺。

Usage

生活與專業情境

驗收

acceptance criterion 寫清楚，大家才知道什麼叫做完成。

評估

An evaluation criterion should tell reviewers what evidence matters。

選擇

Selection criteria make hiring less dependent on gut feeling。

Collocations

常見搭配與語域

criterion 常和 selection、evaluation、acceptance 搭配。每個搭配都把模糊偏好變成可檢查的尺。

selection criterion 招募 / 決策

用來決定誰或哪個方案被選上。

evaluation criterion 評估 / 研究

評審時要看的判準。

acceptance criterion 產品 / 敏捷 / 測試

定義什麼情況下工作可被接受。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Criterion 評估或判斷用的標準 用在需要明確判斷尺，而不只是描述需求時。
Requirement 需求 描述必須滿足的條件；criterion 是拿來判斷的標準。
Standard 標準 較廣，可是規範或水準；criterion 是具體判斷依據。

Modern Use

現代延伸

Criterion 對工程管理很重要，因為它能把「我覺得可以」變成「我們依什麼判斷可以」。

注意單複數：one criterion, multiple criteria。這個錯在正式文件裡很顯眼。
