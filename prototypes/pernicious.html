Pernicious

per-NISH-us · UK /pəˈnɪʃ.əs/ · US /pɚˈnɪʃ.əs/

不是立刻爆炸，而是慢慢傷到根部。

Core Idea

pernicious 的核心是把「有害但不一定立刻顯現，常帶長期侵蝕性」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Pernicious

表示有害但不一定立刻顯現，常帶長期侵蝕性。

不是 Harmful

把它們分開記：harmful 先保留大方向，pernicious 負責把邊界收乾淨。

Origin

字源

15世紀初，用於行爲“邪惡的，惡劣的”； 1520年代開始用於“具有破壞性或有害性的特性”，源自古法語 pernicios（13世紀，現代法語 pernicieux)，直接源自拉丁語 perniciosus “破壞性的”，源自 pernicies “毀滅，死亡，毀壞”，源自 per “完全”（見 per）+ necis “暴力死亡，謀殺”，與 necare “殺死”， nocere “傷害，損害”， noxa “傷害，損害”相關（源自 PIE 詞根 *nek-（1）“死亡”）。

像白蟻不會第一天拆掉房子，卻會在你看不到的地方一直吃

Memory Hook

記憶鉤子

pernicious：像白蟻不會第一天拆掉房子，卻會在你看不到的地方一直吃

這個畫面有用，是因為它先把「慢慢傷到根部」釘住；回到實際搭配時，就不容易把它和 Harmful 混成一團。

Usage

生活與專業情境

日常版

像 pernicious myth 這樣的說法，多半出現在 公共 / 教育 的場景；句子真正要說的，就是「慢慢傷到根部」。

數位 / 專業版

到了 分析 / 評估 的場景，pernicious effect 會更常出現；這裡要說清楚的，正是「慢慢傷到根部」。

Collocations

常見搭配與語域

常見用法集中在 pernicious myth 和 pernicious effect；這幾個搭配分別落在 公共 / 教育 和 分析 / 評估 的場景裡。

pernicious myth 公共 / 教育

在 公共 / 教育 的語境裡，這個搭配通常就在形容 myth 的狀態或氣質。

pernicious effect 分析 / 評估

在 分析 / 評估 的語境裡，這個搭配通常就在形容 effect 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Pernicious 有害但不一定立刻顯現，常帶長期侵蝕性 當搭配和語境都已經指向「慢慢傷到根部」，這個字才自然。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 公共 / 教育、分析 / 評估、健康 / 行為 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
