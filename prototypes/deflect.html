Deflect

dih-FLEKT · UK /dɪˈflekt/ · US /dɪˈflekt/

不是正面承受，而是把來勢偏開。

Core Idea

deflect 不只是 Redirect 的近義替代；它用來描述「把來勢偏開」這種更窄、更準確的情境。

Meaning

簡短定義

Deflect

表示轉移撞擊、注意力、批評或問題方向。

不是 Redirect

Redirect 可以先說大方向；deflect 用在你要把「把來勢偏開」這條語氣邊界說得更準的時候。

Origin

字源

1550年代，“使偏離”（及物動詞），源自拉丁語 deflectere “將（某物）彎曲或向下彎曲”，源自 de “離開”（參見 de-) + flectere “彎曲”，其起源不確定。不及物動詞“轉向或偏離”的意義來自1610年代。

像球本來直衝過來，拍面只偏一點，路徑就整個改了

Memory Hook

這個畫面之所以有用，是因為它能幫你確認 deflect 是否真的在談「把來勢偏開」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 deflect criticism 這樣的說法，多半出現在 溝通 / 組織 的場景；句子真正要說的，就是「把來勢偏開」。

數位 / 專業版

到了 光學 / 工程 的場景，deflect the beam 會更常出現；這裡要說清楚的，正是「把來勢偏開」。

Collocations

常見搭配與語域

常見用法集中在 deflect criticism 和 deflect the beam；這幾個搭配分別落在 溝通 / 組織 和 光學 / 工程 的場景裡。

Modern Use

現代延伸

現在最常見的就是 deflect criticism 和 deflect the beam 這類說法；它們一出現，通常就在替句子劃清「把來勢偏開」的範圍。

比起 redirect，deflect 更適合用在你想直接點出「轉移撞擊、注意力、批評或問題方向」的時候。
