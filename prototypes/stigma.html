Stigma

STIG-muh · UK /ˈstɪɡ.mə/ · US /ˈstɪɡ.mə/

不是標籤，而是帶羞恥與排斥感的標記。

Core Idea

stigma 指帶羞恥與排斥感的標記。

Meaning

簡短定義

Stigma

指帶羞恥與排斥感的標記。

不是 Label

label 可以中性；stigma 幾乎一定帶負面烙印。

社會先貼上看法
→
當事人被附著羞恥
→
人因此被推遠或自我收縮

Origin

字源

stigma 原本是用燒紅鐵器烙在皮膚上的記號，帶著公開標記與羞辱；今天雖然多半抽象化了，但那種被社會貼上印的感覺其實沒變。

Memory Hook

記憶鉤子

把 stigma 想成不是便利貼，而是難洗掉的印記。

它的重點是社會眼光如何黏在人身上。

Usage

生活與專業情境

社會

談心理健康、貧窮或疾病時，stigma 常指那層讓人不敢開口的社會羞恥。

組織

如果求助被看成軟弱，團隊裡就會慢慢形成一種 stigma。

Collocations

常見搭配與語域

social stigma 社會 / 政策

某身分、疾病或經歷被社會附著羞恥與排斥。

stigma around mental health 醫療 / 公共

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Stigma 污名烙印 用在某身分、疾病或經歷被社會附著羞恥與排斥時。
Label 被命名、被歸類 若只是分類，不帶羞恥感，用 label 即可。

Modern Use

現代延伸

stigma 在公共衛生、社會政策與 DEI 討論都非常關鍵，因為它抓住的是羞恥如何被制度化。
