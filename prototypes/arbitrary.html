Arbitrary

AR-buh-trer-ee · UK /ˈɑː.bɪ.trər.i/ · US /ˈɑːr.bə.trer.i/

不是單純隨機，而是缺少可被說服的理由或一致標準。

Core Idea

arbitrary 用來批評某個決策、門檻、規則或數字看起來像憑個人意思定的，而不是根據原則。

Meaning

簡短定義

Arbitrary

形容決定、規則或選擇缺乏合理理由、固定標準或可預測性。

不是 Random

random 是機率上的隨機；arbitrary 是決策上缺乏理由或標準。

有人做出選擇
→
理由不清或標準不一致
→
結果顯得任意

Origin

字源

arbitrary 來自拉丁語 arbiter，和仲裁者、判斷者有關；後來帶出由個人裁量決定的意味。

它的陰影是權力：不是沒有人決定，而是決定的人沒有說出足夠理由。

Memory Hook

記憶鉤子

arbitrary 是規則看起來像從空中掉下來。

聽到這個字，要問的不是「是不是亂數」，而是「標準在哪裡」。

Usage

生活與專業情境

日常版

如果老師給分標準每天不同，學生會覺得 grading is arbitrary。

數位 / 專業版

API limit、timeout 或 feature cutoff 若沒有資料支撐，很容易被質疑為 arbitrary。

Collocations

常見搭配與語域

Arbitrary 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

arbitrary decision 管理 / 法律

缺乏清楚理由的決策。

arbitrary rule 制度 / 教育

看不出原則的一條規則。

arbitrary threshold 工程 / 資料

數值門檻沒有明確依據。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Arbitrary 缺少合理理由或一致標準 批評規則、門檻、權力裁量或設計選擇時
Random 由機率或亂數決定 真的在談 random sampling 或 stochastic behavior 時

Modern Use

現代延伸

工程討論裡，arbitrary 常用來要求設計者說明取值依據；它不是小抱怨，而是對決策品質的追問。
