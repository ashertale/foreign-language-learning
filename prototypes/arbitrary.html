Arbitrary

AR-bi-trer-ee · UK /ˈɑː.bɪ.trər.i/ · US /ˈɑːr.bə.trer.i/

不是有原則的選擇，而是看誰說了算或隨手定一個。

Core Idea

arbitrary 用來描述「看誰說了算或隨手定一個」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Arbitrary

表示武斷、任意，缺乏一致標準或合理依據。

不是 Random

如果 random 已經能讓句子成立，就不必硬換；需要「武斷、任意，缺乏一致標準或合理依據」時，arbitrary 才有必要。

Usage

生活與專業情境

日常版

當人們說 arbitrary rule 時，焦點通常就在「看誰說了算或隨手定一個」上，所以這個搭配很能代表 arbitrary 的語感。

數位 / 專業版

到了 產品 / 介面 的場景，arbitrary limit 會更常出現；這裡要說清楚的，正是「看誰說了算或隨手定一個」。

Collocations

常見搭配與語域

常見用法集中在 arbitrary rule 和 arbitrary limit；這幾個搭配分別落在 制度 / 規範 和 產品 / 介面 的場景裡。

在 產品 / 介面 的語境裡，這個搭配通常就在形容 limit 的狀態或氣質。

Modern Use

現代延伸

現在最常見的就是 arbitrary rule 和 arbitrary limit 這類說法；它們一出現，通常就在替句子劃清「看誰說了算或隨手定一個」的範圍。

當句子要把「看誰說了算或隨手定一個」說準時，arbitrary 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
