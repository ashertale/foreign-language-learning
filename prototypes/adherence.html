Adherence

ad-HEER-ens · UK /ədˈhɪə.rəns/ · US /ədˈhɪr.əns/

Core Idea

adherence 的畫面是「黏住」。規範、療程、原則或流程不是放在旁邊參考，而是被持續貼在實際行動上；這個字關心的不是你知不知道規則，而是你有沒有一路照著走。

Meaning

簡短定義

Adherence

指持續遵守規則、流程、原則、療程或承諾；也可指物理上的附著。用在工作或醫療語境時，它常帶有「一段時間內是否穩定做到」的判斷。

不是 Compliance

compliance 偏向符合外部要求、通過檢查；adherence 更像長時間貼著某套做法不偏離，語感多一點持續性。

Origin

字源

adherence 和 Latin adhaerere 有關，意思接近「黏附、貼住」；其中 haerere 帶有 stick 的概念。

字源的黏著感很好用：把 rule、protocol、principle 想成表面，把 action 想成要貼上去的東西。貼得住，才叫 adherence。

Memory Hook

記憶鉤子

adherence 像標籤貼在板子上：真正的問題不是貼上那一秒，而是熱、濕氣和時間過去後，它還黏不黏。

用在流程時也是一樣。一次照做不難；難的是在 deadline、例外狀況與壓力底下，仍然不把關鍵步驟偷偷省掉。

Usage

生活與專業情境

流程 / 品質

release checklist 上每格都有勾，不等於有 adherence。如果測試紀錄是事後補的，那只是表面符合，流程其實已經鬆動。

醫療 / 習慣

medication adherence 指病人是否按時、按量持續用藥；它不是醫囑寫得好不好，而是實際生活中能不能跟上。

原則 / 團隊文化

A team's adherence to principles 不是看口號，而是看壓力來時，原則有沒有被拿來約束決策。

Collocations

常見搭配與語域

這個字常接 to，後面放規則、流程、原則或療程。搭配的重點是「貼住哪一套東西」。

strict adherence to protocol 醫療 / 實驗 / 安全流程

強調每一步都照 protocol 走，適合高風險、可追溯、不能靠臨場感的場景。

medication adherence 醫療 / 公衛

指病人實際服藥行為是否跟醫囑一致，常用於長期治療與照護研究。

adherence to standards 工程 / 品質 / 合規

比 simply following standards 更正式，暗示標準不是一次性檢查，而是長期做法。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Adherence 持續貼合規則、流程、原則或療程 當你要強調長時間照做、沒有偏離，而不是只在某次檢查時符合要求。
Compliance 符合外部規定、政策或要求 適合 audit、法規、公司政策；重點是有沒有達標。
Obedience 服從命令或權威 重點在人對權威的服從，不一定表示流程品質或長期一致性。
Conformity 和群體、標準或慣例一致 常帶社會或文化語感；不一定有明確 protocol。

Modern Use

現代延伸

在工程文件裡，adherence 很適合用來談 process discipline：不是每個人都知道流程，而是流程有沒有真的進到日常行為裡。

這個字也能戳破漂亮報告。A team may claim compliance, but poor adherence shows up in skipped reviews, late test evidence, and undocumented exceptions.
