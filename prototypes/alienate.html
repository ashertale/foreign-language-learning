Alienate

AY-lee-uh-nayt · UK /ˈeɪ.li.ə.neɪt/ · US /ˈeɪ.li.ə.neɪt/

不是一時不合，而是讓對方慢慢覺得自己不再被接納。

Core Idea

alienate 不是單次冒犯，而是讓人慢慢覺得自己不屬於這裡、不再被接納。

Meaning

簡短定義

Alienate

表示使疏離、使反感、使支持者或使用者離開心理上的共同圈。

不是 Offend

offend 可指一次冒犯；alienate 是把人推離原本的共同圈。

原本有連結
→
行為讓對方不被接納
→
關係慢慢疏遠

Origin

字源

alienate 來自 Latin alienare，本義是「轉給他人、使其變成別人的」；因此它一面能指轉讓財產，一面也能指把人越推越遠、變得疏離。

Memory Hook

記憶鉤子

把 alienate users 想成產品每次都告訴他們：你不是我們設計時想到的人。

疏離常是累積出來的。

Usage

生活與專業情境

使用者

在使用者這類情境裡，alienate 的重點是：不是一時不合，而是讓對方慢慢覺得自己不再被接納。

觀眾

A tone-deaf joke may alienate the audience before the main point arrives. 這裡放在觀眾情境時，是在說行為或設計把原本可能支持或靠近的人推遠。

盟友

Ignoring feedback can alienate close allies more than open disagreement does. 這裡放在盟友情境時，是在說行為或設計把原本可能支持或靠近的人推遠。

Collocations

常見搭配與語域

alienate 常接 users、audience、allies。搭配都在描述某群人被推離原本的關係。

alienate users 產品 / UX

讓使用者感到疏離或不再被服務。

alienate the audience 溝通 / 媒體

讓觀眾反感或失去連結。

alienate close allies 政治 / 組織

讓原本支持者疏遠。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Alienate 使人疏離 用在行為或設計把原本可能支持或靠近的人推遠時。
Offend 冒犯 可能是單次事件。
Annoy 惹惱 較輕。
Estrange 使疏遠 更文學或關係長期疏離。

Modern Use

現代延伸

Alienate 對產品和組織很重要，因為很多流失不是突然討厭，而是一次次覺得自己不被理解。

它比 offend 更長、更深，常指關係被推離。
