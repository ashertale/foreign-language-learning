Alienate

AY-lee-uh-nayt · UK /ˈeɪ.li.ə.neɪt/ · US /ˈeɪ.li.ə.neɪt/

不是一時不合，而是讓對方慢慢覺得自己不再被接納。

Core Idea

alienate 的力道，在於它會把動作背後那層「讓對方慢慢覺得自己不再被接納」說得更清楚，不讓句子只停在表面的中文對應。

Meaning

簡短定義

Alienate

表示使人疏離、疏遠，或讓某群體對你失去認同感。讀到它時，最好不要只翻成中文動詞，而要留意句子想把事情收斂到哪一種走向。

不是 Offend

Offend 比較像基礎說法；alienate 常用來把那層更具體的「使人疏離」拉到前景。

→
結果語感會從平鋪直述，變成更有方向感的描述

Memory Hook

記憶鉤子

alienate 的畫面是：像本來握著的手沒有突然甩開，而是一點一點鬆到最後滑掉。

這種記法的好處，是它先讓字義落地。你不用先背抽象定義，而是先把「讓對方慢慢覺得自己不再被接納」看成一個會發生的場面。

Usage

生活與專業情境

日常版

與其背這個動詞的中文，不如記 alienate users：它會直接告訴你這個字最自然的落點在哪裡。

數位 / 專業版

在 媒體 / 表達 裡，alienate the audience 讓句子多出的，不只是資訊，而是那股往「使人疏離」推進的語氣。

延伸版

碰到 政治 / 關係 場景時，alienate close allies 常能幫你把這個字用得不空，因為它讓場面自己說話。

Collocations

常見搭配與語域

這些搭配把動作真正會發生的場面拉了出來，讓語感不會停在字典對應上。

這個搭配常出現在需要把事情往「使人疏離」講清楚的句子裡。

在 政治 / 關係 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Modern Use

現代延伸

現在看到 alienate，可以先看它黏著哪些搭配出現。像 alienate users、alienate the audience 都在提醒你：這個字擅長把動作往更有方向感的地方推。

也因此，它不只是 Offend 的華麗版本，而是專門拿來補上「讓對方慢慢覺得自己不再被接納」這層語氣。
