Contradict

kon-truh-DIKT · UK /ˌkɒn.trəˈdɪkt/ · US /ˌkɑːn.trəˈdɪkt/

不是補充不同角度，而是直接和前一個說法互相撞上。

CEFR
B2

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

contradict 不是補另一個角度，而是讓兩個說法不能同時站著。

Meaning

簡短定義

Contradict

表示與某說法、證據、期待或自己先前的話相矛盾。重點是內容衝突，不只是不同意。

不是 Disagree

disagree 是不同意；contradict 是內容本身互相衝突。

一個說法成立
→
另一個說法相撞
→
兩者不能同時為真

Origin

字源

來自 Latin contra「相反」與 dicere「說」。

contra 加 dicere 很直：反著說。現代重點是內容相撞。

Memory Hook

記憶鉤子

把 contradict 想成 log 直接把 hypothesis 推倒。

這不是語氣問題，而是兩者在事實上對不起來。

Usage

生活與專業情境

Debug

log contradicts the theory 時，不是誰講話難聽，而是理論要重修。

說法

He contradicted himself 表示前後說法互相打架。

期待

The result contradicted expectations，代表結果不是普通意外，而是撞上既有預期。

Collocations

常見搭配與語域

contradict 常接 evidence、oneself、expectations。搭配會指出被撞倒的是證據、自己話語，還是原本預期。

contradict evidence 研究 / 法律 / debug

說法和證據不合，通常需要修改說法。

contradict oneself 日常 / 辯論

前後說法衝突，削弱可信度。

contradict expectations 分析 / 報導

結果和預期方向相反或不相容。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Contradict 與某說法、資料或期待相矛盾 用在兩個主張、資料或期待彼此不能同時成立時。
Disagree 不同意 可以只是立場不同；contradict 是內容不能同時為真。
Conflict with 與...衝突 範圍較廣，可指規則、需求、排程衝突。

Modern Use

現代延伸

Contradict 是很好的思考工具：當 evidence contradicts theory，成熟做法是改 theory，不是修飾 evidence。

在人際上這個字語氣偏強；說 someone contradicted you 會比 disagreed with you 更像正面撞上。
