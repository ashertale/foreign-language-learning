Illuminate

ih-LOO-muh-nayt · UK /ɪˈluː.mɪ.neɪt/ · US /ɪˈluː.mə.neɪt/

不是只把燈打開，而是讓原本看不懂的東西變得清楚。

CEFR
C1
Zipf Frequency

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

illuminate 用來描述光照亮空間，也可比喻例子、資料或分析揭露某個問題的結構。

Meaning

簡短定義

Illuminate

表示照亮，或使某件事變得清楚、容易理解。

不是 Show

show 是讓人看到；illuminate 更像用光把隱藏的結構照出來。

原本暗或混亂
→
光或分析進來
→
結構變清楚

Origin

字源

illuminate 來自拉丁語 illuminare，意思是照亮。

它像把手電筒照進機箱深處，問題的位置突然浮出來。

Memory Hook

記憶鉤子

illuminate 是讓看不清的東西開始有輪廓。

這個字比 explain 更有光感，適合說資料或例子把問題照亮。

Usage

生活與專業情境

日常版

一個好故事可以 illuminate a feeling，讓你突然懂自己為什麼在意。

數位 / 專業版

一張清楚的 trace 或 dashboard can illuminate the failure path，比長篇猜測更有用。

Collocations

常見搭配與語域

Illuminate 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

illuminate a room 日常 / 物理

照亮房間。

illuminate a problem 分析 / 工程

讓問題結構變清楚。

illuminating example 教學 / 寫作

能讓概念突然清楚的例子。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Illuminate 照亮或揭示，使人看清 談光線、分析、例子、資料、trace 或問題理解時
Show 讓人看見或展示 只是呈現資訊，不強調理解被點亮時

Modern Use

現代延伸

資料產品的價值常在於 illuminate：不是堆更多圖表，而是讓決策者看見真正有用的結構。
