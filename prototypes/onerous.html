Onerous

ON-er-us · UK /ˈəʊ.nər.əs/ · US /ˈoʊ.nɚ.əs/

不是麻煩，而是負擔重到讓人明顯吃力。

CEFR
C1
Zipf Frequency
2.61
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

onerous 把要求寫成壓在身上的重量；麻煩不是小摩擦，而是足以拖垮執行者。

Meaning

簡短定義

Onerous

形容責任、條件或程序負擔沉重、難以承受。

不是 Demanding

demanding 是要求高；onerous 更強調負擔壓得人喘不過氣。

要求先落下來
→
負擔越積越重
→
執行的人開始被壓垮

Origin

字源

onerous 經 Old French / Latin 傳入時，就是 burdensome、像重物壓在身上的負擔；所以它的累不是主觀喊累，而是客觀重量真的很重。

Memory Hook

記憶鉤子

把 onerous 想成背包不是多裝一本書，而是塞進整塊磚。

這個字在乎的是重量感，而不是單純不方便。

Usage

生活與專業情境

制度

如果申請流程重到連懂規則的人都嫌累，那就是 onerous。

團隊

把所有風險審查都壓在同一個人身上，會讓角色變得過度 onerous。

Collocations

常見搭配與語域

onerous requirement 法律 / 制度

規定、要求或責任重到不成比例。

onerous burden 政策 / 管理

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Onerous 負擔沉重 用在規定、要求或責任重到不成比例時。
Demanding 要求高、需要投入很多 若只是高標準或很費工，用 demanding 比較常見。

Modern Use

現代延伸

onerous 很常用來批評不成比例的流程與規範，特別是在法規、合約與公共服務語境。
