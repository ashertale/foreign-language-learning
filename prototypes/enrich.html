Enrich

en-RICH · UK /ɪnˈrɪtʃ/ · US /ɪnˈrɪtʃ/

不是多加一層而已，而是讓內容更有厚度。

Core Idea

enrich 的核心是把「使內容、土壤、經驗或理解變得更豐富」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Enrich

表示使內容、土壤、經驗或理解變得更豐富。

不是 Improve

把它們分開記：improve 先保留大方向，enrich 負責把邊界收乾淨。

Origin

字源

14世紀晚期，“使富裕”，源自古法語 enrichir “豐富，擴大”，由 en- “製造，放入”（見 en-（1））和 riche “富有”（見 rich）組成。比喻意義“供應豐富的令人嚮往的東西”始於1590年代。意爲“施肥”始於1600年左右。科學意義上的“增加某種物質中特定同位素的丰度”首次見於1945年。

Usage

生活與專業情境

日常版

像 enrich the dataset 這樣的說法，多半出現在 資料 / 分析 的場景；句子真正要說的，就是「讓內容更有厚度」。

數位 / 專業版

到了 會議 / 學習 的場景，enrich the discussion 會更常出現；這裡要說清楚的，正是「讓內容更有厚度」。

Collocations

常見搭配與語域

常見用法集中在 enrich the dataset 和 enrich the discussion；這幾個搭配分別落在 資料 / 分析 和 會議 / 學習 的場景裡。

enrich the dataset 資料 / 分析

在 資料 / 分析 的語境裡，這個搭配會把動作直接落在 the dataset 上。

enrich the discussion 會議 / 學習

在 會議 / 學習 的語境裡，這個搭配會把動作直接落在 the discussion 上。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 資料 / 分析、會議 / 學習、自然 / 科學 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
