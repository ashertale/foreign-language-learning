Abstain

ab-STAYN · UK /əbˈsteɪn/ · US /əbˈsteɪn/

不是單純的「不做」，而是在有誘惑、壓力或資格時主動選擇不參與。

Core Idea

abstain 用來描述你本來可以投票、飲酒、發言或介入，卻因原則、節制或利益衝突而退一步。

Meaning

簡短定義

Abstain

表示刻意避免做某事，尤其是避免投票、飲酒、表態或參與某個行動。

不是 Avoid

avoid 只是避開；abstain 更強調有意識的克制或正式的棄權。

Origin

字源

abstain 來自拉丁語 abstinere，意思接近「從某事物拉開、約束住自己」。

把它記成手已經伸到按鈕前，最後仍把手收回來。

Memory Hook

記憶鉤子

abstain 是你明明有票，卻選擇不按下任何一邊。

這個字的重點不是能力不足，而是自我約束；沉默本身就是一個立場。

Usage

生活與專業情境

日常版

聚餐時不喝酒、會議中不投票、爭論裡不加入，都可以說 you abstain。

數位 / 專業版

在治理、審查或 code review 裡，利益衝突的人可以 abstain from voting，避免讓判斷失去可信度。

Collocations

常見搭配與語域

Abstain 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

abstain from alcohol 健康 / 日常

表示因健康、宗教或節制而不喝酒。

abstain from voting 治理 / 會議

正式表示棄權，不把票投給任何選項。

abstain from comment 法律 / 公關

刻意不發表評論，常帶有謹慎或避嫌。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Abstain 在可參與的情況下主動不做 談棄權、戒除、避嫌或自我節制時
Avoid 避開某件事，不一定有正式或道德上的克制感 只是想說不要碰到風險或麻煩時

Modern Use

現代延伸

現代英文常把 abstain 用在治理、健康與倫理情境；它讓「不參與」聽起來像一個經過判斷的動作，而不是被動缺席。
