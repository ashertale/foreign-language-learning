Ornate

or-NAYT · UK /ɔːˈneɪt/ · US /ɔːrˈneɪt/

不是精緻而已，而是裝飾感明顯到成了主角。

CEFR

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

ornate 不是簡單精緻，而是裝飾層層疊上去，華麗感幾乎成為主角。

Meaning

簡短定義

Ornate

形容裝飾繁複、華麗，細節多而醒目。

不是 Elegant

elegant 可以簡潔；ornate 則是裝飾本身很顯眼。

裝飾越加越多
→
細節開始搶眼
→
整體呈現厚重華麗

Origin

字源

ornate 來自 Latin ornatus「裝飾過、整理過」；因此它的美感不是素淨，而是刻意修飾、細節很多。

Memory Hook

記憶鉤子

把 ornate 想成一扇門上不是一圈雕花，而是整面都刻滿花紋。

它描述的是裝飾量感，不一定是在稱讚。

Usage

生活與專業情境

風格

如果文字的修辭層層疊上去，讀者可能會覺得它過於 ornate。

空間

有些餐廳不是舒適，而是用很 ornate 的細節營造氣派。

Collocations

常見搭配與語域

ornate design 設計 / 評論

建築、文字、風格或設計裝飾層很厚。

ornate style 寫作 / 藝評

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Ornate 繁飾華麗 用在建築、文字、風格或設計裝飾層很厚時。
Elegant 優雅、講究、比例好 若重點是節制後的美感，用 elegant 更貼近。

Modern Use

現代延伸

ornate 常用於評論視覺與文風，語氣介於欣賞與嫌太滿之間。
