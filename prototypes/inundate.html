Inundate

IN-un-dayt · UK /ˈɪn.ʌn.deɪt/ · US /ˈɪn.ʌn.deɪt/

不是多一點，而是多到整個空間都被蓋住。

Core Idea

inundate 用來描述「多到整個空間都被蓋住」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Inundate

表示洪水淹沒，或大量資訊、請求、情緒湧入。

不是 Flood

如果 flood 已經能讓句子成立，就不必硬換；需要「洪水淹沒，或大量資訊、請求、情緒湧入」時，inundate 才有必要。

Origin

字源

1620年代，從 inundation 反形成而來，或者源自拉丁語 inundatus，它的過去分詞形式是 inundare，意爲“溢出，氾濫”（源自西班牙語 inundar、法語 inonder）。

像信件不是塞滿信箱，而是一路從槽口溢到地板上

Memory Hook

記憶鉤子

inundate：像信件不是塞滿信箱，而是一路從槽口溢到地板上

這個畫面能幫你把 inundate 和 Flood 分開，因為它把「多到整個空間都被蓋住」那條界線變得可見。

Usage

生活與專業情境

日常版

當人們說 inundate the inbox 時，焦點通常就在「多到整個空間都被蓋住」上，所以這個搭配很能代表 inundate 的語感。

數位 / 專業版

到了 營運 / 服務 的場景，inundated with requests 會更常出現；這裡要說清楚的，正是「多到整個空間都被蓋住」。

Collocations

常見搭配與語域

常見用法集中在 inundate the inbox 和 inundated with requests；這幾個搭配分別落在 工作 / 溝通 和 營運 / 服務 的場景裡。

inundate the inbox 工作 / 溝通

在 工作 / 溝通 的語境裡，這個搭配會把動作直接落在 the inbox 上。

inundated with requests 營運 / 服務

在 營運 / 服務 的語境裡，這個搭配最容易看出「多到整個空間都被蓋住」實際怎麼落在句子裡。

Modern Use

現代延伸

現在最常見的就是 inundate the inbox 和 inundated with requests 這類說法；它們一出現，通常就在替句子劃清「多到整個空間都被蓋住」的範圍。

當句子要把「多到整個空間都被蓋住」說準時，inundate 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
