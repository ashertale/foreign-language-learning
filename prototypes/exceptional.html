Exceptional

ik-SEP-shuh-nul · UK /ɪkˈsep.ʃən.əl/ · US /ɪkˈsep.ʃən.əl/

不是普通好，而是好到脫離一般範圍；也可指例外。

Core Idea

exceptional 離開一般範圍。它可以是好到不像普通水準，也可以是需要例外處理的特殊情況。

Meaning

簡短定義

Exceptional

形容非常優秀、不尋常，或作為例外的情況。意思需靠搭配判斷是正面讚美還是中性例外。

不是 Good

good 是好；exceptional 是好到成為例外。

一般水準存在
→

Origin

字源

來自 exception 的例外概念；正面或中性用法都離不開脫離常態。

exception 的例外感是核心；正面或中性都來自離開常態。

Memory Hook

記憶鉤子

把 exceptional case 想成規則之外需要單獨處理的輸入。

它特殊，不代表整套規則都錯。

Usage

生活與專業情境

例外

Exceptional case 需要特殊處理，不代表整個規則要被推翻。

表現

Exceptional. 這裡放在表現情境時，是在說某人事物明顯超出一般範圍，或案例需例外處理。

情況

Exceptional circumstances may justify a temporary exception, but should still be recorded. 這裡放在情況情境時，是在說某人事物明顯超出一般範圍，或案例需例外處理。

Collocations

常見搭配與語域

exceptional 常接 performance、case、circumstances。搭配會告訴你它是讚美、例外還是特殊條件。

exceptional performance 職場 / 評量

遠高於一般水準的表現。

exceptional case 工程 / 法律 / 分析

不適合一般規則的特殊案例。

exceptional circumstances 正式 / 法律 / 管理

特殊情況，可能讓一般規則暫時改用。

Modern Use

現代延伸

Exceptional 要看語境。exceptional engineer 是讚美；exceptional case 只是特殊，不一定好。

工程文件中，exceptional cases 最好被測試和記錄，否則例外會慢慢變成隱藏規則。
