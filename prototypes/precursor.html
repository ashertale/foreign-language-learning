Precursor

pree-KER-ser · UK /priːˈkɜː.sə/ · US /priːˈkɝː.sɚ/

不是前面那個，而是後面那件事的先行版本或徵候。

Core Idea

precursor 指後面那件事的先行版本或徵候。

Meaning

簡短定義

Precursor

指後面那件事的先行版本或徵候。

不是 Prototype

prototype 偏具體原型；precursor 可是前身、前兆或前驅。

先有一個早期形態
→
後面的大東西逐步長出
→
回頭看才知道它是前驅

Origin

字源

precursor 經 Old French / Latin 傳入時，本意就是先跑在前面的人；所以它後來指前兆、前身或先行者時，都保留那種前頭開路的角色。

Memory Hook

記憶鉤子

把 precursor 想成不是完整建築，而是地上先打下去的樁。

它關心的是歷史位置和後續關係。

Usage

生活與專業情境

技術

某些老系統看起來過時，但其實是今天架構的 precursor。

事件

有些小徵候不是偶然，而是後面大轉變的 precursor。

Collocations

常見搭配與語域

chemical precursor 科學 / 醫療

某事物先出現，並替後續更成熟或更大的東西鋪路。

precursor to reform 歷史 / 政策

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Precursor 先行前驅 用在某事物先出現，並替後續更成熟或更大的東西鋪路時。
Prototype 可實際拿來試的早期原型 若重點是開發中的試作品，用 prototype 更貼切。

Modern Use

現代延伸

precursor 很常用於技術史、制度史與科學寫作，因為它把『前身』與『後續連結』綁在一起。
