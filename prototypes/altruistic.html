Altruistic

al-troo-IS-tik · UK /ˌæl.truˈɪs.tɪk/ · US /ˌæl.truˈɪs.tɪk/

不是一般大方，而是把他人的利益放在很前面。

Core Idea

altruistic 用來說某個人、系統或局面帶著「利他導向」這種質地。它不是單純加強語氣，而是改變你怎麼看整個對象。

Meaning

簡短定義

Altruistic

表示出於利他、為他人著想，而不是先算自己的得失。重點不是程度加強，而是整個對象都帶著「利他導向」這種質地。

不是 Generous

Generous 可以只是在說「慷慨」；換成 altruistic，句子通常是在補上「利他導向」這層更具體的意思。

先有一個人、流程、系統或局面
→
它在語境裡露出「利他導向」這種質地
→
所以你感受到的不是單一特徵，而是整體氣氛被它帶著走

Memory Hook

記憶鉤子

altruistic 的畫面是：像手裡只剩一把傘，自己淋雨也先把它遞出去。

這個畫面有用，因為它把 altruistic 從翻譯拉回場面：你先看到「先想別人」，再比較容易記住它其實在說「利他導向」。

Usage

生活與專業情境

日常版

altruistic motive 會把這個字放到最自然的名詞上，讓你看到重點不是單純的「慷慨」，而是整個對象都帶著「利他導向」這種質地。

數位 / 專業版

在 公共 / 社會 裡，altruistic act 常讓語氣多一層判斷，因為它不只描述性質，還在提示你應該怎麼看這個東西。

延伸版

到了 團隊 / 文化 的場景，altruistic leadership 很適合用來練邊界：你要講的到底是一般的「慷慨」，還是更具體的「利他導向」。

Collocations

常見搭配與語域

這些搭配會把抽象質地落到具體名詞上，讓你看見這個形容詞最自然的著力點。

altruistic motive 倫理 / 判斷

這個搭配會讓「利他導向」不再停在抽象定義，而是直接貼到具體名詞上。

altruistic act 公共 / 社會

在 公共 / 社會 裡，這種說法常帶出額外的判斷味道，而不只是中性描述。

altruistic leadership 團隊 / 文化

如果你想把這個字用穩，從 團隊 / 文化 常見的這個搭配進場通常最自然。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸

現在看到 altruistic，多半不是為了把語氣寫得更花，而是為了讓讀者一眼看出某個人、系統或局面正帶著「利他導向」這種質地。

也因此，它和 Generous 的差別通常不在字面強弱，而在你要不要把那種具體氣質明白地壓到前景。
