Analogy

uh-NAL-uh-jee · UK /əˈnæl.ə.dʒi/ · US /əˈnæl.ə.dʒi/

不是舉例而已，而是借另一個結構相似的東西，讓陌生概念有路可走。

Core Idea

analogy 是理解用的橋。它不說兩件事一模一樣，而是說：這裡有一段關係或結構很像，我們可以先借那個熟悉結構來看懂這個陌生問題。

Meaning

簡短定義

Analogy

指兩件不同事物之間因結構、功能或關係相似而建立的比較。好的 analogy 幫助理解；壞的 analogy 會把不該相同的地方也偷渡進來。

不是 Example

example 是同一類裡的一個案例；analogy 是跨到另一個領域找相似結構。

Origin

字源

analogy 源自 Greek analogia，和 proportion、ratio、對應關係有關。

字源提醒你：analogy 不只是像，而是有某種比例、關係或結構的對應。記得一起記住 where it breaks。

Memory Hook

記憶鉤子

analogy 像把 scheduler 比成交通號誌：它能幫你理解誰先走、誰等待，但不能把整座城市都搬進 CPU。

記這個字時一定要連同邊界一起記。analogy 的價值在於照亮結構；危險在於讓人忘記兩件事終究不同。

Usage

生活與專業情境

教學 / 解釋

好的 analogy 會把抽象機制變成聽者能在腦中跑一遍的東西，不只是把句子說得比較漂亮。

工程討論

把 interrupt priority 比成排隊規則是一個 analogy；它能快速建立直覺，但遇到 nesting、latency、masking 時就要補真正模型。

批判思考

When an analogy breaks down, 不是表示它完全沒用，而是它能照亮的範圍到此為止。

Collocations

常見搭配與語域

analogy 常和 draw、make、use、break down 搭配；這些動詞剛好標出類比的生命周期。

draw an analogy 正式 / 教學 / 評論

主動建立兩件事之間的相似關係，常用於解釋或論證。

a useful analogy 教學 / 技術溝通

表示這個類比能幫人建立直覺，但不保證每個細節都對應。

the analogy breaks down 分析 / 討論

表示類比到某處開始失效，需要回到真正的模型或條件。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Analogy 跨領域的結構比較，用來建立理解 當你要把陌生概念接到熟悉結構上，同時保留失效邊界。
Example 同類事物中的一個案例 用來展示某概念如何出現，不一定跨領域比較。
Metaphor 把一物說成另一物，語感更修辭、更濃縮 適合文學、說服或概念框架；不一定逐項映射結構。
Model 簡化後可推理或預測的表示法 比 analogy 更系統化，通常需要明確假設與可驗證結果。

Modern Use

現代延伸

在技術溝通中，analogy 是很強的啟動器，但不是終點。它可以降低理解門檻，卻不能取代規格、時序圖或真實限制。

好用的說法是先給 analogy，再說 boundary：This is a rough analogy, but it breaks down when interrupts are nested. 這樣既幫人進門，也不讓人帶著錯模型離開。
