Allude

uh-LOOD · UK /əˈluːd/ · US /əˈluːd/

不是明說，而是把線頭露出來，讓懂的人自己接到背後那件事。

Core Idea

allude 是一種間接指向。說話的人沒有把事情攤開講，卻放了一個 reference、暗線或提示，讓聽者知道那裡還有另一層意思。

Meaning

簡短定義

Allude

表示間接提到、暗指或含蓄引用某人某事。常見結構是 allude to，後面接被暗指的對象。

不是 Mention

mention 是直接提到；allude 是不點破，但讓人看見指向。

表面句子成立
→
暗線指向別處
→
讀者或聽者補上連結

Origin

字源

allude 來自 Latin alludere，有「玩、戲弄、暗中觸及」的意味；詞史上不是直接 announce，而是側面碰到。

把它記成「用一個輕碰代替直說」。你沒有把門打開，只是敲了一下，讓對方知道門後有東西。

Memory Hook

記憶鉤子

allude 像 code review 裡一句 We have seen this pattern before：沒有點名事故，但知道的人已經懂了。

它的力道在於克制。allude 不是藏得完全看不見，也不是直接攤牌，而是讓線索剛好露出一點。

Usage

生活與專業情境

寫作 / 文學

A novel may allude to a myth without retelling it. 讀者若知道典故，就會讀到第二層意思。

會議 / 組織

Someone may allude to a past failure by saying the team should not repeat last year's mistake，這比直接翻舊帳更含蓄。

語氣邊界

allude 不等於 imply。imply 可以靠邏輯或語氣推出含意；allude 更像有意放一個 reference。

Collocations

常見搭配與語域

這個動詞幾乎總是跟 to 走。搭配時重點是「你用什麼方式間接指向什麼」。

allude to 通用 / 正式寫作

最標準結構：allude to a problem、allude to an earlier incident。

briefly allude to 報告 / 評論 / 學術

表示只是短暫提到暗線，不展開細節。

allude in passing 正式 / 書面

指順帶暗示，語氣比 directly mention 更輕。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Allude 間接提到、暗指或引用 當說話者有意留下線索，但不把對象完整說破。
Mention 直接提到 對象被清楚說出來，不需要讀者自己接線。
Refer 指稱、提及或參照 比 allude 中性；可以直接也可以間接。
Imply 暗含、意味著 重點是話中推出的含意，不一定有具體典故或 reference。

Modern Use

現代延伸

在專業溝通裡，allude 很適合描述那種不方便明講、但又不能完全不提的 reference。它讓句子保留禮貌，也保留訊號。

但 allude 也可能製造誤解。如果聽者沒有共同背景，暗線就接不上；這時候直接 mention 反而比較負責。
