Brusque

BRUSK · UK /bruːsk/ · US /bruːsk/

不是有效率而已，而是快得幾乎不留情面。

CEFR

Core Idea

brusque 是短而硬的互動；話可能沒錯，但聽起來像把人推開。

Meaning

簡短定義

Brusque

形容說話、態度或指示唐突、簡短、生硬。

不是 Blunt

blunt 著重直接；brusque 著重短硬到讓互動變冷。

話語或態度很短
→
缺少禮貌緩衝
→
對方感到被推開

Memory Hook

記憶鉤子

把 brusque reply 想成對方只回「No.」且沒有任何緩衝。

brusque 的傷人處常在形式，而不只內容。

Usage

生活與專業情境

回覆

A brusque reply can end a thread before the real issue is understood.

態度

Collocations

常見搭配與語域

brusque 常修飾 reply、manner、instruction；搭配都在描述互動表面很硬。

brusque reply 人際 / 工作

短硬回覆。

brusque manner 人物 / 職場

唐突生硬的態度。

brusque instruction 管理 / 現場

直接到近乎粗魯的指示。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Brusque 生硬短促 用在溝通短到缺乏緩衝，使對方感覺被粗暴處理時。
Blunt 直白 可只是坦率；brusque 更短促、更容易讓人受挫。
Curt 簡短冷淡 和 brusque 很近，語氣同樣不柔。

Modern Use

現代延伸

工程溝通很容易在忙碌時變 brusque；它不是效率的同義詞，因為信任也有成本。

寫人物時，brusque 能讓角色不用罵人也顯得不好接近。
