Porous

POR-us · UK /ˈpɔː.rəs/ · US /ˈpɔːr.əs/

不是鬆散而已，而是本身就有很多可滲透的孔隙。

Core Idea

porous 的好處在於精度：它把情境、語氣和搭配一起推向「本身就有很多可滲透的孔隙」。

Meaning

簡短定義

Porous

表示多孔的，也可比喻邊界、系統或規則容易滲透。

不是 Permeable

如果 permeable 已經能讓句子成立，就不必硬換；需要「多孔的，也可比喻邊界、系統或規則容易滲透」時，porous 才有必要。

先遇到 porous material
→
看它是否只是 可滲透
→
再決定是否需要 porous

Origin

字源

\"多孔的，通過具有小孔而可滲透的\"，源於14世紀晚期的古法語 poros（14世紀，現代法語 poreux）和直接源於中世紀拉丁語 porosus； 或直接源於拉丁語 porus \"一個開口\"（參見 pore（n.））。比喻用法始於1640年代。

Memory Hook

記憶鉤子

能用這個畫面回到「多孔的，也可比喻邊界、系統或規則容易滲透」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 porous material 時，焦點通常就在「本身就有很多可滲透的孔隙」上，所以這個搭配很能代表 porous 的語感。

數位 / 專業版

到了 政治 / 公共 的場景，porous border 會更常出現；這裡要說清楚的，正是「本身就有很多可滲透的孔隙」。

Collocations

常見搭配與語域

常見用法集中在 porous material 和 porous border；這幾個搭配分別落在 材料 / 工程 和 政治 / 公共 的場景裡。

porous material 材料 / 工程

在 材料 / 工程 的語境裡，這個搭配通常就在形容 material 的狀態或氣質。

porous border 政治 / 公共

在 政治 / 公共 的語境裡，這個搭配通常就在形容 border 的狀態或氣質。

Modern Use

現代延伸

現在最常見的就是 porous material 和 porous border 這類說法；它們一出現，通常就在替句子劃清「本身就有很多可滲透的孔隙」的範圍。

當句子要把「本身就有很多可滲透的孔隙」說準時，porous 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
