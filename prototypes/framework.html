Framework

FRAME-wurk · UK /ˈfreɪm.wɜːk/ · US /ˈfreɪm.wɝːk/

不是答案本身，而是讓答案能被放進來的骨架。

Core Idea

framework 不是答案，而是讓答案能被放進來、比較、重用的骨架。

Meaning

簡短定義

Framework

指框架、架構或思考模型，可用於軟體、決策、分析、政策或學習。

不是 Tool

tool 是工具；framework 是組織工具與判斷的架構。

建立骨架
→
放入細節
→
形成可重用方式

Origin

字源

由 frame 與 work 組合；畫面是一個能支撐工作的框。

frame + work 的畫面很清楚：支撐工作的一個框。

Memory Hook

記憶鉤子

把 framework 想成 debug 時那組固定問題：現象在哪裡、何時開始、如何重現、哪個假設可測。

它不替你回答，但讓你知道下一步該問什麼。

Usage

生活與專業情境

Debug

好的 debug framework 讓新人知道下一步該問什麼，而不是背別人的解法。

決策

A decision framework makes trade-offs visible before opinions harden.

軟體

A software framework gives structure, but it also brings assumptions you must live with.

Collocations

常見搭配與語域

framework 常接 decision、software、analytical。搭配會說明這副骨架服務的是判斷、程式，還是分析。

decision framework 管理 / 設計

幫助比較選項和取捨的判斷框架。

software framework 軟體

提供程式架構與常用功能的框架。

analytical framework 研究 / 分析

組織分析問題的概念架構。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Framework 框架、結構或思考架構 用在需要一副可重用骨架來組織問題、工具或判斷時。
Tool 工具 用來做特定事；framework 組織一整套做事方式。
Model 模型 對現實的抽象；framework 可包含多個模型和步驟。
Structure 結構 更廣，可物理可抽象。

Modern Use

現代延伸

Framework 容易被說空，但好的 framework 會讓下一步更清楚。它應該減少迷路，而不是增加術語。

軟體 framework 也不是免費：它給你速度，同時也把某些設計選擇預先替你做掉。
