Enact

ih-NAKT · UK /ɪˈnækt/ · US /ɪˈnækt/

不是只提案，而是把文字真正變成現實中的效力。

Core Idea

enact 的力道，在於它會把動作背後那層「把文字真正變成現實中的效力」說得更清楚，不讓句子只停在表面的中文對應。

Meaning

簡短定義

Enact

表示制定法律、實施措施，或把角色演出來。讀到它時，最好不要只翻成中文動詞，而要留意句子想把事情收斂到哪一種走向。

不是 Implement

Implement 比較像基礎說法；enact 常用來把那層更具體的「讓文字生效」拉到前景。

先有一個原本還能用一般動詞帶過的場景
→
接著句子選擇用「讓文字生效」來講它
→
結果語感會從平鋪直述，變成更有方向感的描述

Memory Hook

記憶鉤子

enact 的畫面是：像藍圖離開桌面，真正變成街角已經豎起的路牌。

這種記法的好處，是它先讓字義落地。你不用先背抽象定義，而是先把「把文字真正變成現實中的效力」看成一個會發生的場面。

Usage

生活與專業情境

日常版

與其背這個動詞的中文，不如記 enact a law：它會直接告訴你這個字最自然的落點在哪裡。

數位 / 專業版

在 公共 / 政策 裡，enact reforms 讓句子多出的，不只是資訊，而是那股往「讓文字生效」推進的語氣。

延伸版

碰到 表演 / 敘事 場景時，enact the role 常能幫你把這個字用得不空，因為它讓場面自己說話。

Collocations

常見搭配與語域

這些搭配把動作真正會發生的場面拉了出來，讓語感不會停在字典對應上。

enact a law 法規 / 制度

這個搭配常出現在需要把事情往「讓文字生效」講清楚的句子裡。

enact reforms 公共 / 政策

放到 公共 / 政策 裡，它會讓動作聽起來不只發生了，還帶著明顯的語氣或後果。

enact the role 表演 / 敘事

在 表演 / 敘事 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸

現在看到 enact，可以先看它黏著哪些搭配出現。像 enact a law、enact reforms 都在提醒你：這個字擅長把動作往更有方向感的地方推。

也因此，它不只是 Implement 的華麗版本，而是專門拿來補上「把文字真正變成現實中的效力」這層語氣。
