Retract

ri-TRAKT · UK /rɪˈtrækt/ · US /rɪˈtrækt/

不是修改，而是把說出去的話收回。

CEFR
C1

Core Idea

retract 是把已經說出、伸出或發布的東西往回收，像聲明被撤回到原點。

Meaning

簡短定義

Retract

收回已說出的話、聲明、承諾或伸出的部分。

不是 Revise

revise 是修改；retract 則是把它整段收回。

原本已經說出或伸出
→
意識到不能維持
→
整個往回收

Origin

字源

retract 來自拉丁語「拉回來」，原本可用在把東西收回、縮回；用到聲明或主張上，就成了把已說出口的話撤回。

Memory Hook

記憶鉤子

把 retract 想成不是換手勢，而是把伸出去的手整個縮回袖子裡。

這個字的方向感非常明確，就是往回收。

Usage

生活與專業情境

聲明

如果媒體公開收回指控，就是在 retract that statement。

工程

某些機構件會自動 retract，這時候它就是物理上的縮回。

Modern Use

現代延伸

retract 的好處是同時能處理語言上的收回和物理上的縮回，兩邊都帶有清楚的回收感。
