Impasse

IM-pas · UK /ˈɪm.pæs/ · US /ˈɪm.pæs/

不是慢下來，而是雙方或整件事卡到沒有出口。

Core Idea

impasse 用來描述「雙方或整件事卡到沒有出口」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Impasse

表示僵局、死結，無法再進一步。

不是 Deadlock

deadlock 可以先說出 僵局；impasse 則把句子推到「雙方或整件事卡到沒有出口」這個更細的位置。

Origin

字源

impasse 在英語裡可追到 1763；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示僵局、死結，無法再進一步」的用法。

像兩輛車在窄巷正面卡住，誰都過不去，也都不願先退

Memory Hook

記憶鉤子

impasse：像兩輛車在窄巷正面卡住，誰都過不去，也都不願先退

這個畫面有用，是因為它先把「雙方或整件事卡到沒有出口」釘住；回到實際搭配時，就不容易把它和 Deadlock 混成一團。

Usage

生活與專業情境

日常版

像 reach an impasse 這樣的說法，多半出現在 談判 / 協商 的場景；句子真正要說的，就是「雙方或整件事卡到沒有出口」。

數位 / 專業版

到了 公共 / 財務 的場景，budget impasse 會更常出現；這裡要說清楚的，正是「雙方或整件事卡到沒有出口」。

Collocations

常見搭配與語域

常見用法集中在 reach an impasse 和 budget impasse；這幾個搭配分別落在 談判 / 協商 和 公共 / 財務 的場景裡。

reach an impasse 談判 / 協商

在 談判 / 協商 的語境裡，前面的 reach an 會把這個概念限定到更具體的場景。

budget impasse 公共 / 財務

在 公共 / 財務 的語境裡，前面的 budget 會把這個概念限定到更具體的場景。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Impasse 僵局、死結，無法再進一步 當句子需要把「雙方或整件事卡到沒有出口」說清楚，而不是只留在 僵局 的外圈時。
Deadlock 僵局 當你只需要先說 僵局，不必把語氣收進「雙方或整件事卡到沒有出口」時。

Modern Use

現代延伸

現在最常見的就是 reach an impasse 和 budget impasse 這類說法；它們一出現，通常就在替句子劃清「雙方或整件事卡到沒有出口」的範圍。

當句子要把「雙方或整件事卡到沒有出口」說準時，impasse 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
