Word 214 / adjective

Assiduous

uh-SID-yoo-us · UK /əˈsɪdʒ.u.əs/ · US /əˈsɪdʒ.u.əs/

不是偶爾努力，而是細密、持續、不偷懶地照顧每個角落。

Core Idea

assiduous 稱讚的是願意長時間守在工作旁邊的努力：細、穩、耐煩，不讓小缺口被草草放過。

Meaning

簡短定義

Assiduous

形容人做事勤勉、細密而持續，尤其是長時間貼著細節、不因工作瑣碎就鬆手。

不是 Diligent

diligent 已經是勤勉；assiduous 更有持續貼著做、不鬆手的感覺。

Origin

字源

來自 Latin assiduus，有「坐在旁邊、持續在場」的意思。

Latin 裡「坐在旁邊」的畫面很貼切：assiduous 的人不是路過工作，而是坐下來把它陪完。

Memory Hook

記憶鉤子

assiduous 像 reviewer 坐在 diff 旁邊，一行一行陪它走完。

這個畫面有一種持續在場感。它不是熱血衝刺，而是耐心不離開工作本身。

Usage

生活與專業情境

Code review

An assiduous reviewer 不只看架構，也會追到邊界條件、錯字和 log 訊息的真實可用性。

研究 / 閱讀

An assiduous reader 會慢慢核對註腳、例子和語氣，不急著只抓一句結論。

語氣

這個字比 diligent 更書面，也更像在稱讚長時間貼近細節的耐性。

Collocations

常見搭配與語域

assiduous 常接 attention、effort、care。這些搭配都把焦點放在「不離開細節」的工作方式。

assiduous effort 正式 / 書面

努力不是一陣，而是持續、穩定、願意做完細節。

assiduous attention 評論 / 專業寫作

常用來稱讚對細節、證據或人的需求照顧得很細。

assiduous reader 文學 / 學術

讀者願意慢慢跟完整本書或論證，不只掃大意。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Assiduous 長時間勤勉且注意細節 用在耐心、長時間、貼近細節的努力。
Diligent 勤勉認真 一般稱讚努力可靠，用 diligent 很自然。
Meticulous 極重細節 如果重點是精細程度而不是持續投入，meticulous 更直接。

Modern Use

現代延伸

在推薦信、書評或正式評語裡，assiduous 有一種安靜但很重的稱讚：這個人不只是聰明，而是真的願意守在工作旁邊。

它不適合拿來形容短時間爆發。若努力只是一天熬夜，還不到 assiduous 的持續感。
