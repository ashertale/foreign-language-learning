Paucity

PAW-suh-tee · UK /ˈpɔː.sə.ti/ · US /ˈpɑː.sə.t̬i/

不是少，而是少到你開始意識到缺口。

Core Idea

paucity 指那種「稀少短缺」的狀態、力量、場面或事物。它常把抽象感受壓縮成一個可指認的名詞。

Meaning

簡短定義

Paucity

指那種「稀少短缺」的狀態、力量、場面或事物。

不是 Shortage

shortage 偏實際缺貨；paucity 更書面，也可指抽象資源稀少。

原本期待會有更多
→
實際數量明顯偏少
→
缺口開始影響判斷與行動

Origin

字源

paucity 經 Old French / Latin 傳入時，就是數量少、稀少、匱乏；所以它不是抽象不足，而是量本身就薄。

Memory Hook

記憶鉤子

把 paucity 想成抽屜一拉開，不是空，而是只剩幾張薄薄的紙。

它比 few 更有『這個少會造成後果』的味道。

Usage

生活與專業情境

證據

如果資料少到不足以支撐結論，就可以說有 a paucity of evidence。

人才

某些領域不是沒有候選人，而是有一種明顯的 paucity。

Collocations

常見搭配與語域

這裡放 paucity 最自然連在一起的說法；中文註解會補它落在哪種語境與語氣。

paucity of resources 政策 / 管理

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Paucity 稀少短缺 用在證據、資源、人才或機會少到成問題時。
Shortage 短缺、不夠用 若是具體供應不足的問題，用 shortage 會更直接。

Modern Use

現代延伸

paucity 雖然偏書面，但在研究、法規與評論裡很精準，因為它把『少到成問題』寫了出來。
