Linear

LIN-ee-ur · UK /ˈlɪn.i.ər/ · US /ˈlɪn.i.ɚ/

不是只是直線，而是一步接一步、關係不分岔。

Core Idea

linear 像一條線：一步接一步、輸入和輸出關係可預期，不突然分岔或跳階。

Meaning

簡短定義

Linear

形容線性的、直線的、依序的，或關係可用一條線描述。

不是 Sequential

sequential 是依序；linear 更常指關係像一條線，沒有分支或非線性跳動。

Origin

字源

來自 Latin linea「線」。

linea 給它一條線的畫面；linear 的世界沿著單一路徑往前走。

Memory Hook

記憶鉤子

把 linear memory layout 想成資料沿著地址一路排下去。

它容易推理，但不代表所有 access pattern 都最有效。

Usage

生活與專業情境

記憶體

Linear memory layout 容易推理，但不代表所有 access pattern 都高效。

流程

A linear process is easy to explain, but may fail when work needs feedback loops.

關係

A linear relationship means output changes predictably with input.

Collocations

常見搭配與語域

linear 常接 process、relationship、memory。搭配會說明線性發生在流程、數學關係或資料排列。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Linear 線性的、按直線或單一路徑排列的 用在關係、流程或排列沿單一路徑發展時。
Sequential 依序 重順序；linear 還有直線關係或無分岔感。
Nonlinear 非線性 輸入輸出不成直線，可能有突變或交互作用。
Serial 串行 一次一個，常和 parallel 相對。

Modern Use

現代延伸

Linear 在工程裡可以是好事也可以是限制。Linear flow 易懂；非線性系統才常藏真實世界的麻煩。

不要把 linear 自動翻成簡單。線性可能只是模型簡化，不一定代表問題真的單純。
