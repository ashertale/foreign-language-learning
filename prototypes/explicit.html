Explicit

ik-SPLIS-it · UK /ɪkˈsplɪs.ɪt/ · US /ɪkˈsplɪs.ɪt/

不是大家心裡知道，而是被清楚說出來、寫出來。

Core Idea

explicit 把原本可能靠猜、靠默契、靠暗示的東西攤開說清楚。

Meaning

簡短定義

Explicit

形容指令、同意、依賴、規則或說法清楚明白地表達出來，沒有只靠暗示。

不是 Clear

clear 是清楚；explicit 特別指沒有靠暗示或默契。

原本可能靠猜
→
直接寫出規則
→
歧義減少

Origin

字源

來自 Latin explicitus，有展開、攤開的意思。

展開、攤開的字源畫面很貼切：explicit 是把折起來的意思打開。

Memory Hook

記憶鉤子

把 explicit dependency 想成 build graph 裡清楚畫出的邊。

靠偶然 include 成功，不是可維護的關係。

Usage

生活與專業情境

Build

Explicit dependency 讓 build 關係可追蹤，不靠偶然 include 成功。

同意

Explicit consent must be clearly given, not inferred from silence. 這裡放在同意情境時，是在說需要把規則、關係或同意清楚攤開，不能靠推測。

指令

Explicit instructions reduce guesswork, especially when failure is costly. 這裡放在指令情境時，是在說需要把規則、關係或同意清楚攤開，不能靠推測。

Collocations

常見搭配與語域

explicit 常接 instruction、consent、dependency。搭配都和消除暗示、降低歧義有關。

explicit instruction 文件 / 教學

清楚說出要做什麼，不靠猜。

explicit consent 法律 / 隱私

明確同意，不是沉默或預設。

explicit dependency 軟體 / build

依賴關係被清楚宣告。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Explicit 明確的、清楚表達的 用在需要把規則、關係或同意清楚攤開，不能靠推測時。
Clear 清楚 可以只是易懂；explicit 特別指說出來、寫出來。
Implicit 隱含的 靠暗示或脈絡理解。
Specific 具體的 細節明確；explicit 重不隱藏。

Modern Use

現代延伸

Explicit 是好工程文化的字。Explicit contracts、dependencies、ownership 都會降低靠記憶維護的成本。

但 explicit 不代表冗長；它只是拒絕把關鍵資訊藏在默契裡。
