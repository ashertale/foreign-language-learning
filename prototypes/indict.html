Indict

in-DYTE · UK /ɪnˈdaɪt/ · US /ɪnˈdaɪt/

不是一般指責，而是進入正式程序，準備追究。

CEFR
C2

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

indict 在法律裡是起訴；在評論裡，某件事也可以成為對整個系統的控訴。

Meaning

簡短定義

Indict

表示起訴、控告；也可比喻揭示某人或制度有嚴重問題。

不是 Charge

accuse 是指控；indict 像把指控寫成正式案子。

嚴重錯誤或罪名存在
→
證據被整理成控訴
→
人或制度被正式指向責任

Origin

字源

indict 原本是把指控寫下來、正式宣告成罪名；這也是它今天拼法像 dict、發音卻保留法語痕跡的原因。

Memory Hook

記憶鉤子

把 indict the system 想成單一事故不是孤立錯，而是證明整套制度有罪證。

indict 的語氣是 formal accusation。

Usage

生活與專業情境

嫌疑人

The grand jury voted to indict the suspect on multiple charges.

制度

制度情境下，indict 不是一般指責，而是進入正式程序，準備追究。

罪名

He was indicted on charges that carried serious penalties.

Collocations

常見搭配與語域

indict 常接 suspect、system，也常用 indicted on charges；搭配要分法律與比喻。

indict the suspect 法律 / 新聞

起訴嫌疑人。

indict the system 評論 / 社會

控訴制度。

indicted on charges 法律 / 新聞

因罪名被起訴。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Indict 正式起訴 用在正式起訴，或比喻上讓某事成為強烈控訴證據時。
Charge 指控、起訴 通用法律字；indict 常指正式起訴程序。
Accuse 指控 範圍廣；indict 更正式、更有證據文件感。

Modern Use

現代延伸

Indict 的 c 不發音，拼字要小心。

比喻用法很有力：a failure can indict a process，比單純 criticize 更重。
