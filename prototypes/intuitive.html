Intuitive

in-TOO-ih-tiv · UK /ɪnˈtjuː.ɪ.tɪv/ · US /ɪnˈtuː.ə.t̬ɪv/

不是不用學，而是符合人的自然預期。

Core Idea

intuitive 不是不用學，而是行為和人心裡原本的模型對得起來。

Meaning

簡短定義

Intuitive

形容介面、設計、想法或判斷符合直覺，容易自然理解或操作。

不是 Obvious

obvious 是明顯；intuitive 是行為和心中的模型對得起來。

使用者有預期
→
介面符合預期
→
理解成本下降

Origin

字源

來自 intuition 的直覺概念；現代常用在設計與理解成本。

intuition 的直覺概念是核心；intuitive 是和心裡模型接得上。

Memory Hook

記憶鉤子

把 intuitive tool 想成下一步的位置剛好在你以為它會在的地方。

功能可以不少，但路徑不該逼人猜。

Usage

生活與專業情境

工具

Intuitive tool 不一定功能少，而是下一步在哪裡不需要猜。

介面

An intuitive interface borrows from the user’s existing mental model.

設計

A feature can feel intuitive to experts and confusing to first-time users.

Collocations

常見搭配與語域

intuitive 常接 interface、design、feel。搭配都在測試使用者的心中模型是否被尊重。

intuitive interface UX / 產品

符合使用者預期、容易操作的介面。

intuitive design 設計 / 產品

讓人自然理解的設計。

feel intuitive 通用 / 評估

感覺直覺，通常來自熟悉模型。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Intuitive 直覺的、容易自然理解的 用在設計或想法能接上人的自然預期，降低猜測成本時。
Obvious 明顯 看了就知道；intuitive 更重符合心理模型。
Simple 簡單 少或不複雜；intuitive 可以功能多但好理解。
Natural 自然 和 intuitive 接近，語氣較日常。

Modern Use

現代延伸

Intuitive 在產品討論裡常被說得太快。對誰 intuitive？基於哪個 mental model？這兩個問題要問。

對工程師直覺的東西，對新手可能完全不直覺。
