Redress

ri-DRESS · UK /rɪˈdres/ · US /rɪˈdres/

不是道歉，而是讓受損的一方得到補償或修復。

Core Idea

redress 指讓受損的一方得到補償或修復。

Meaning

簡短定義

Redress

指讓受損的一方得到補償或修復。

不是 Apology

apology 是表態；redress 更往具體補救或補償走。

先有傷害或不公
→
受損方提出要求
→
補償或修正被安排進來

Origin

字源

redress 原義就是「把歪掉的東西重新弄正、恢復到 right」，先是動詞的糾正、修正；後來名詞義才長成對受害者的補救與補償。

Memory Hook

記憶鉤子

把 redress 想成不是說一句對不起，而是真的把傾斜的秤盤拉回來。

這個字往往期待的是可執行的修補。

Usage

生活與專業情境

制度

如果申訴最後能帶來補償或修正，那才接近真正的 redress。

法律

談權益受損時，redress 常比 apology 更有實際份量。

Collocations

常見搭配與語域

seek redress 法律 / 正式

某種傷害、損失或不公需要被補正。

provide redress 政策 / 治理

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Redress 補救補償 用在某種傷害、損失或不公需要被補正時。
Apology 表達歉意或承認錯誤 若重點只是說抱歉，用 apology 即可。

Modern Use

現代延伸

redress 在法律、治理與消費者保護語境很常見，因為它把『補回來』說得比 sorry 更實際。
