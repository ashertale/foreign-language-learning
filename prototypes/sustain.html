Sustain

suh-STAYN · UK /səˈsteɪn/ · US /səˈsteɪn/

不是短暫撐一下，而是能一路供應到事情走完。

Core Idea

sustain 不只是 Maintain 的近義替代；它用來描述「能一路供應到事情走完」這種更窄、更準確的情境。

Meaning

簡短定義

Sustain

表示維持、支撐或承受，使其持續存在。

不是 Maintain

Maintain 可以先說大方向；sustain 用在你要把「能一路供應到事情走完」這條語氣邊界說得更準的時候。

→
看它是否只是 維持
→
再決定是否需要 sustain

Origin

字源

sustain，後來才慢慢落到今天這種「表示維持、支撐或承受，使其持續存在」的語境。

像橋樑不是只扛第一輛車，而是整天都能把重量穩穩接住

Memory Hook

記憶鉤子

sustain：像橋樑不是只扛第一輛車，而是整天都能把重量穩穩接住

能用這個畫面回到「維持、支撐或承受，使其持續存在」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 sustain the effort 這樣的說法，多半出現在 工作 / 專案 的場景；句子真正要說的，就是「能一路供應到事情走完」。

數位 / 專業版

到了 系統 / 運作 的場景，sustain performance 會更常出現；這裡要說清楚的，正是「能一路供應到事情走完」。

Collocations

常見搭配與語域

常見用法集中在 sustain the effort 和 sustain performance；這幾個搭配分別落在 工作 / 專案 和 系統 / 運作 的場景裡。

sustain the effort 工作 / 專案

在 工作 / 專案 的語境裡，這個搭配會把動作直接落在 the effort 上。

sustain performance 系統 / 運作

在 系統 / 運作 的語境裡，這個搭配會把動作直接落在 performance 上。

Neighbors

對立與鄰近概念

Modern Use

現代延伸

現在最常見的就是 sustain the effort 和 sustain performance 這類說法；它們一出現，通常就在替句子劃清「能一路供應到事情走完」的範圍。

比起 maintain，sustain 更適合用在你想直接點出「維持、支撐或承受，使其持續存在」的時候。
