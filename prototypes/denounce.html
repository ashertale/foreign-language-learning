Denounce

dih-NOWNS · UK /dɪˈnaʊns/ · US /dɪˈnaʊns/

不是私下抱怨，而是站出來明白說這件事不行。

CEFR

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

denounce 是公開而強烈地說：這件事錯了，而且不該被接受。

Meaning

簡短定義

Denounce

表示公開譴責、斥責某個行為、制度、攻擊或腐敗。

不是 Condemn

criticize 可以很輕；denounce 是站出來公開斥責。

問題被視為不可接受
→
說話者公開點名
→
譴責傳達清楚立場

Origin

字源

denounce 早期本來只是正式宣告、公開說明；後來因為常用來宣告指控與譴責，才長出今天那種公開點名、嚴厲批判的語氣。

Memory Hook

記憶鉤子

把 denounce corruption 想成不是私下抱怨，而是在公共場域把問題點名。

denounce 的聲音是外放的。

Usage

生活與專業情境

腐敗

在腐敗這類情境裡，denounce 的重點是：不是私下抱怨，而是站出來明白說這件事不行。

做法

Several groups denounced the practice as exploitative. 這裡放在做法情境時，是在說批評需要公開、強烈、道德立場清楚。

攻擊

Leaders denounced the attack before announcing concrete measures. 這裡放在攻擊情境時，是在說批評需要公開、強烈、道德立場清楚。

Collocations

常見搭配與語域

denounce 常接 corruption、practice、attack；搭配通常涉及公共價值與明確立場。

denounce corruption 政治 / 社會

公開譴責腐敗。

denounce the practice 評論 / 倫理

譴責某做法。

denounce the attack 新聞 / 公共

譴責攻擊事件。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Denounce 公開斥責 用在批評需要公開、強烈、道德立場清楚時。
Condemn 譴責 非常接近；denounce 更強調公開說出、點名。
Criticize 批評 範圍廣；denounce 強度高很多。

Modern Use

現代延伸

Denounce 常在新聞與政治聲明中出現，聲量比 criticize 大。

如果沒有公共立場或道德判斷，用 complain 或 criticize 會更自然。
