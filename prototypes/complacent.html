Complacent

kuhm-PLAY-suhnt · UK /kəmˈpleɪ.sənt/ · US /kəmˈpleɪ.sənt/

不是滿足，而是滿足到失去警覺。

Core Idea

complacent 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Complacent

表示因為過度自滿而不再警惕問題或改進需求。

不是 Content

content 可以先說出 滿足；complacent 則把句子推到「滿足到失去警覺」這個更細的位置。

Origin

字源

1650年代，“令人愉悅的”，源自拉丁語 complacentem（主格 complacens）“非常令人愉悅”，現在分詞 complacere “非常令人愉悅”（參見 complacence）。“自我滿足，自鳴得意”的意思來自1767年。 “友好的，善意的，願意讓人愉悅”的意思來自1790年。相關： Complacently。

像你以為系統很穩，就不再看警示燈，結果問題在角落慢慢長大

Memory Hook

記憶鉤子

complacent：像你以為系統很穩，就不再看警示燈，結果問題在角落慢慢長大

這個畫面之所以有用，是因為它能幫你確認 complacent 是否真的在談「滿足到失去警覺」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 become complacent 這樣的說法，多半出現在 工作 / 成長 的場景；句子真正要說的，就是「滿足到失去警覺」。

數位 / 專業版

到了 組織 / 文化 的場景，complacent attitude 會更常出現；這裡要說清楚的，正是「滿足到失去警覺」。

Collocations

常見搭配與語域

常見用法集中在 become complacent 和 complacent attitude；這幾個搭配分別落在 工作 / 成長 和 組織 / 文化 的場景裡。

become complacent 工作 / 成長

在 工作 / 成長 的語境裡，這個搭配最容易看出「滿足到失去警覺」實際怎麼落在句子裡。

complacent attitude 組織 / 文化

在 組織 / 文化 的語境裡，這個搭配通常就在形容 attitude 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Complacent 因為過度自滿而不再警惕問題或改進需求 當句子需要把「滿足到失去警覺」說清楚，而不是只留在 滿足 的外圈時。
Content 滿足 當你只需要先說 滿足，不必把語氣收進「滿足到失去警覺」時。

Modern Use

現代延伸

現在最常見的就是 become complacent 和 complacent attitude 這類說法；它們一出現，通常就在替句子劃清「滿足到失去警覺」的範圍。

當句子要把「滿足到失去警覺」說準時，complacent 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
