Jaded

JAY-did · UK /ˈdʒeɪ.dɪd/ · US /ˈdʒeɪ.dɪd/

不是累而已，而是看太多、做太多之後感覺變鈍。

Core Idea

jaded 是看太多、耗太久之後的新鮮感死亡；不是累一天，而是心裡不再被打動。

Meaning

簡短定義

Jaded

形容厭倦、麻木、因過度經驗或刺激而失去興趣。

不是 Tired

tired 是累；jaded 是心對新刺激不再亮。

刺激或失望累積太多
→
新鮮感下降
→
人變得麻木難被打動

Memory Hook

記憶鉤子

把 jaded audience 想成觀眾不是不懂，而是同一套驚喜已經看過太多次。

jaded 的疲乏來自 overexposure。

Usage

生活與專業情境

感受

Collocations

常見搭配與語域

jaded 常修飾 worker、audience，或用 feel jaded；搭配都含長期耗損後的麻木。

jaded worker 職場 / 評論

厭倦麻木的工作者。

feel jaded 日常 / 情緒

感到厭倦麻木。

jaded audience 媒體 / 藝術

看多後不易被打動的觀眾。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Jaded 看多做到麻木 用在疲乏不是身體累，而是長期經驗讓人不再容易被感動時。
Tired 疲倦 可能休息後恢復；jaded 是新鮮感和信任被磨掉。
Cynical 犬儒 重不信任動機；jaded 重過度經驗後的麻木。

Modern Use

現代延伸

Jaded 很適合描述職場倦怠、媒體疲勞、使用者對行銷套路的麻木。

它通常帶時間背景：被餵太多、失望太多、看過太多。
