Contrive

kuhn-TRYV · UK /kənˈtraɪv/ · US /kənˈtraɪv/

不是自然發生，而是刻意設計出來，有時甚至太刻意。

Core Idea

contrive 用來描述「刻意設計出來，有時甚至太刻意」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Contrive

表示設法安排、巧妙做成，或在故事與結果上帶有人為痕跡。

不是 Arrange

arrange 可以先說出 安排；contrive 則把句子推到「刻意設計出來，有時甚至太刻意」這個更細的位置。

Origin

字源

contrive 在英語裡可追到 early 14c.；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示設法安排、巧妙做成，或在故事與結果上帶有人為痕跡」的用法。

Memory Hook

記憶鉤子

contrive：像把舞台上的燈和站位都算好，讓某個效果一定會出現

這個畫面有用，是因為它先把「刻意設計出來，有時甚至太刻意」釘住；回到實際搭配時，就不容易把它和 Arrange 混成一團。

Usage

生活與專業情境

日常版

像 contrive a scenario 這樣的說法，多半出現在 測試 / 設計 的場景；句子真正要說的，就是「刻意設計出來，有時甚至太刻意」。

數位 / 專業版

到了 日常 / 人際 的場景，contrive an excuse 會更常出現；這裡要說清楚的，正是「刻意設計出來，有時甚至太刻意」。

Collocations

常見搭配與語域

常見用法集中在 contrive a scenario 和 contrive an excuse；這幾個搭配分別落在 測試 / 設計 和 日常 / 人際 的場景裡。

contrive a scenario 測試 / 設計

在 測試 / 設計 的語境裡，這個搭配會把動作直接落在 a scenario 上。

contrive an excuse 日常 / 人際

在 日常 / 人際 的語境裡，這個搭配會把動作直接落在 an excuse 上。

Neighbors

對立與鄰近概念

Modern Use

現代延伸

現在最常見的就是 contrive a scenario 和 contrive an excuse 這類說法；它們一出現，通常就在替句子劃清「刻意設計出來，有時甚至太刻意」的範圍。

當句子要把「刻意設計出來，有時甚至太刻意」說準時，contrive 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
