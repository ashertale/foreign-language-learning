Contrive

kun-TRIVE · UK /kənˈtraɪv/ · US /kənˈtraɪv/

不是自然形成，而是費力設計出來，常帶一點不自然。

Core Idea

contrive 指某結果被刻意安排出來，而且人工痕跡常常看得見。

Meaning

簡短定義

Contrive

表示設法做成、設計出或硬安排出某結果；語氣可中性，但常暗示不自然或費力。

不是 Devise

devise 可中性表示想出方法；contrive 常暗示人工痕跡很重。

想要結果
→
刻意安排條件
→
結果顯得不自然

Origin

字源

詞史和設計、安排有關；現代語氣常帶一點「硬做出來」。

字源裡的安排感可以記；現代使用時，注意它常比 devise 更不自然。

Memory Hook

記憶鉤子

把 contrive 想成一個為了重現 bug 而做得很窄的 test case。

它有用，但你也會懷疑：真實世界真的會這樣發生嗎？

Usage

生活與專業情境

測試

Contrived test case 可能能重現 bug，但也要確認它不是只有實驗室才會發生。

敘事

A contrived plot twist feels like the writer pushed characters by hand。

方法

They contrived a solution 表示終於弄出辦法，但可能帶一點勉強。

Collocations

常見搭配與語域

contrive 的搭配常會讓人聞到人工安排：solution、example、to do。

contrive a solution 書面 / 問題解決

設法弄出解法，語氣可能帶費力或勉強。

contrived example 教學 / 評論

例子為了說明而設計，可能不夠自然。

contrive to do 正式 / 敘事

設法做到某事，常帶一點不容易或刻意。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Contrive 刻意設計、安排或硬湊出某結果 用在某結果不是自然出現，而是被費力安排或硬做出來時。
Devise 想出、設計 較中性且正面，常用於方法或計畫。
Fabricate 製造；捏造 負面時更像造假。
Engineer 設計安排 可中性，也可比喻操控局面。

Modern Use

現代延伸

Contrive 在技術與寫作裡都能用：contrived benchmark、contrived example、contrived explanation 都在提醒讀者小心真實性。

如果你想稱讚創造力，devise 通常比 contrive 安全；contrive 常帶一點露出手痕的味道。
