Provenance

PROV-uh-nuhns · UK /ˈprɒv.ə.nəns/ · US /ˈprɑː.və.nəns/

不是只問來自哪裡，而是一路追到它怎麼到你手上。

Core Idea

provenance 最值得保留的語感，是它讓「來源、出處或流轉脈絡」不再只是模糊大意。

Meaning

簡短定義

Provenance

表示來源、出處或流轉脈絡。

不是 Origin

把它們分開記：origin 先保留大方向，provenance 負責把邊界收乾淨。

Origin

字源

\"起源、來源或產地，指任何事物的來源\"，1785年源自法語 provenance \"起源、產出\"，源自 provenant，拉丁語 provenir 的現在分詞形式，意爲\"出現、產生、起源\"，源自拉丁語 provenire \"出現、起源、顯現\"，由 pro \"向前\"（參見 pro-）和 venire \"來\"（源自 PIE 詞根 *gwa- \"去、來\"的後綴形式）組成。19世紀早期常以斜體形式出現； 英文形式爲 provenience。

像一件物品背後拖著一串看不見的標籤，指向它走過的路

Memory Hook

記憶鉤子

provenance：像一件物品背後拖著一串看不見的標籤，指向它走過的路

這個畫面能幫你把 provenance 和 Origin 分開，因為它把「一路追到它怎麼到你手上」那條界線變得可見。

Usage

生活與專業情境

日常版

像 data provenance 這樣的說法，多半出現在 資料 / 治理 的場景；句子真正要說的，就是「一路追到它怎麼到你手上」。

數位 / 專業版

到了 文物 / 研究 的場景，provenance of the artifact 會更常出現；這裡要說清楚的，正是「一路追到它怎麼到你手上」。

Collocations

常見搭配與語域

常見用法集中在 data provenance 和 provenance of the artifact；這幾個搭配分別落在 資料 / 治理 和 文物 / 研究 的場景裡。

data provenance 資料 / 治理

在 資料 / 治理 的語境裡，前面的 data 會把這個概念限定到更具體的場景。

provenance of the artifact 文物 / 研究

在 文物 / 研究 的語境裡，這個搭配會把關係直接指向 the artifact。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Provenance 來源、出處或流轉脈絡 當搭配和語境都已經指向「一路追到它怎麼到你手上」，這個字才自然。
Origin 來源 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 資料 / 治理、文物 / 研究、收藏 / 法務 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
