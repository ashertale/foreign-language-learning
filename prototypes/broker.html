Broker

BROH-ker · UK /ˈbrəʊ.kər/ · US /ˈbroʊ.kɚ/

不是自己拍板，而是讓原本分開的人終於接上。

Core Idea

broker 的核心是把「居中促成交易、協議或合作」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Broker

表示居中促成交易、協議或合作。

不是 Arrange

把它們分開記：arrange 先保留大方向，broker 負責把邊界收乾淨。

先遇到 broker a deal
→
看它是否只是 安排促成
→
再決定是否需要 broker

Origin

字源

14世紀中期（姓氏中的13世紀），“商業代理人，經紀人”，也指“骯髒生意中的代理人”，源自盎格魯-法語 brocour “小商販”，來自 abrokur “零售葡萄酒的人，酒吧老闆”； 也許來自葡萄牙語 alborcar “易貨”，但更可能來自古法語 brocheor，源自 brochier “開瓶，開孔，穿孔（一個桶）”，來自 broche（古北法語 broke， broque）“尖銳的工具”（見 broach（n.）），最初的意思是“酒商”，因此是“零售商，中間人，代理人”。在中古英語中，蔑視地用於小販和拉皮條者，“買賣公職的人”（14世紀後期的盎格魯-法語），“戀愛或婚姻中介人”（14世紀後期）。

像把兩條各自收緊的繩子在中間打成一個能承重的結

Memory Hook

記憶鉤子

broker：像把兩條各自收緊的繩子在中間打成一個能承重的結

能用這個畫面回到「居中促成交易、協議或合作」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 broker a deal 這樣的說法，多半出現在 商業 / 談判 的場景；句子真正要說的，就是「讓原本分開的人終於接上」。

數位 / 專業版

到了 外交 / 協商 的場景，broker peace 會更常出現；這裡要說清楚的，正是「讓原本分開的人終於接上」。

Collocations

常見搭配與語域

常見用法集中在 broker a deal 和 broker peace；這幾個搭配分別落在 商業 / 談判 和 外交 / 協商 的場景裡。

broker a deal 商業 / 談判

在 商業 / 談判 的語境裡，這個搭配會把動作直接落在 a deal 上。

broker peace 外交 / 協商

在 外交 / 協商 的語境裡，這個搭配會把動作直接落在 peace 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Broker 居中促成交易、協議或合作 當搭配和語境都已經指向「讓原本分開的人終於接上」，這個字才自然。
Arrange 安排促成 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 商業 / 談判、外交 / 協商、組織 / 協作 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
