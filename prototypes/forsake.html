Forsake

for-SAYK · UK /fəˈseɪk/ · US /fɔːrˈseɪk/

不是單純離開，而是離開一個你原本曾經依附或承諾過的東西。

Core Idea

forsake 的核心是把「拋棄、背離某人、原則或舊路」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Forsake

表示拋棄、背離某人、原則或舊路。

不是 Abandon

Abandon 可以先說大方向；forsake 用在你要把「離開一個你原本曾經依附或承諾過的東西」這條語氣邊界說得更準的時候。

Usage

生活與專業情境

日常版

像 forsake old habits 這樣的說法，多半出現在 成長 / 改變 的場景；句子真正要說的，就是「離開一個你原本曾經依附或承諾過的東西」。

數位 / 專業版

到了 公共 / 理念 的場景，forsake the cause 會更常出現；這裡要說清楚的，正是「離開一個你原本曾經依附或承諾過的東西」。

Collocations

常見搭配與語域

常見用法集中在 forsake old habits 和 forsake the cause；這幾個搭配分別落在 成長 / 改變 和 公共 / 理念 的場景裡。

在 公共 / 理念 的語境裡，這個搭配會把動作直接落在 the cause 上。

Modern Use

現代延伸

現在最常見的就是 forsake old habits 和 forsake the cause 這類說法；它們一出現，通常就在替句子劃清「離開一個你原本曾經依附或承諾過的東西」的範圍。

比起 abandon，forsake 更適合用在你想直接點出「拋棄、背離某人、原則或舊路」的時候。
