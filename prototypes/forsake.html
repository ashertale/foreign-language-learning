Forsake

for-SAYK · UK /fəˈseɪk/ · US /fɔːrˈseɪk/

不是單純離開，而是離開一個你原本曾經依附或承諾過的東西。

Core Idea

forsake 是背離或拋下原本有關係的東西：人、原則、傳統或舊習。

Meaning

簡短定義

Forsake

表示拋棄、離棄、背離某人、信念、習慣或傳統。

不是 Abandon

abandon 是拋棄；forsake 像背對曾經承諾過的東西。

舊關係或承諾存在
→
人選擇離開
→
離開帶道德或情感重量

Origin

字源

forsake 來自 Old English，早期就有反對、拒絕、放棄、斷開的意思；所以它不是普通離開，而是把原本該站在一起的關係主動鬆手。

Memory Hook

記憶鉤子

把 forsake old habits 想成不只是改小動作，而是和舊路正式分手。

forsake 的離開有關係斷裂感。

Usage

生活與專業情境

習慣

To forsake old habits, the team had to change the incentives that kept them alive. 這裡放在習慣情境時，是在說離開某物不只是移動，而是切斷忠誠、習慣或承諾。

事業

He refused to forsake the cause when public support faded. 這裡放在事業情境時，是在說離開某物不只是移動，而是切斷忠誠、習慣或承諾。

傳統

在傳統這類情境裡，forsake 的重點是：不是單純離開，而是離開一個你原本曾經依附或承諾過的東西。

Collocations

常見搭配與語域

forsake 常接 old habits、cause、tradition；搭配對象通常曾經重要或熟悉。

forsake old habits 成長 / 工作

拋下舊習。

forsake the cause 政治 / 信念

背離事業或理念。

forsake tradition 文化 / 評論

拋棄傳統。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Forsake 背離舊依附 用在離開某物不只是移動，而是切斷忠誠、習慣或承諾時。
Abandon 拋棄 通用；forsake 更正式、情感與道德重量更重。
Leave 離開 中性；forsake 有背離、離棄感。

Modern Use

現代延伸

Forsake 語氣較古典、正式，常見於文學、宗教、強烈信念。

不要用它描述普通離職或換工具，除非你要保留背離舊路的重量。
