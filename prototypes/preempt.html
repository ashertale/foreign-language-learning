Preempt

pree-EMPT · UK /priːˈempt/ · US /priːˈempt/

不是搶快，而是先一步動手，讓別人沒機會再做。

CEFR

Core Idea

preempt 是先一步出手占住時機或位置，讓別人的行動空間被拿掉。

Meaning

簡短定義

Preempt

預先採取行動，以阻止、取代或搶先於另一個行動。

不是 Forestall

forestall 偏阻止後續發生；preempt 更強調你先一步占掉位置。

局勢還沒完全展開
→
先一步卡位出手
→
後面的人失去空間

Origin

字源

preempt 對應的 Etymonline 詞條是 pre-empt。它 19 世紀先指依 pre-emption 權利把土地先占先買，字面上就是「在別人之前先買下」；後來才一般化成先一步出手，把位置或機會整個占走。

Memory Hook

記憶鉤子

把 preempt 想成不是排隊排得快，而是先把位置整個占走。

這個字很常跟時機和主導權綁在一起。

Usage

生活與專業情境

溝通

如果你知道誤解快要擴散，先說清楚就是一種 preempt。

競爭

有些產品不是更好，而是更早 preempt 了市場注意力。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Preempt 先發占位 用在先一步處理、回應或出手，以免別人搶走主導權時。
Forestall 事先阻止某件事 若重點是攔下結果，不特別強調主導權，用 forestall 更準。

Modern Use

現代延伸

preempt 在商業、政治與公關語境都常見，因為它精準寫出『先一步卡位』。
