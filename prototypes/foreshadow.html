Foreshadow

for-SHAD-oh · UK /fɔːˈʃæd.əʊ/ · US /fɔːrˈʃæd.oʊ/

不是直接公布，而是先投下一道影子。

Core Idea

foreshadow 常用在句子需要把動作往「先投下影子」這個方向收緊時。重點不只是做了什麼，而是事情因此偏向哪一種選擇。

Meaning

簡短定義

Foreshadow

表示預示、暗示後續將發生的事。這個字常不是在描述機械動作，而是在說事情怎麼往「先投下影子」這個方向走。

不是 Hint

Hint 可以只是在說「暗示」；換成 foreshadow，句子通常是在補上「先投下影子」這層更具體的意思。

先有一個人、做法、關係或局面
→
句子接著把動作往「先投下影子」這個方向推進
→
所以最後留下的，不只是動作完成，還有那個轉向本身

Memory Hook

記憶鉤子

foreshadow 的畫面是：像午後的風先變了方向，晚點的暴雨已經在遠處集結。

這個畫面有用，因為它把 foreshadow 從翻譯拉回場面：你先看到「風向先變了」，再比較容易記住它其實在說「先投下影子」。

Usage

生活與專業情境

日常版

foreshadow the ending 這種說法會把動作放回它真正會發生的場景裡，讓你看到重點不是字面動作，而是事情怎麼往「先投下影子」收過去。

數位 / 專業版

在 風險 / 觀察 裡，foreshadow trouble 常用來把語氣收得更準：它不只交代事情做了，還交代事情怎麼帶出那層「先投下一道影子」。

延伸版

到了 市場 / 趨勢 的場景，foreshadow the change 很適合拿來練邊界，因為它會逼你分清楚一般的「暗示」跟更具體的「先投下影子」差在哪。

Collocations

常見搭配與語域

這組搭配會告訴你，這個動詞最自然會把句子往哪種場面推；比只記中文更能抓到用法。

foreshadow the ending 寫作 / 敘事

這個搭配常出現在需要把事情往「先投下影子」講清楚的句子裡。

foreshadow trouble 風險 / 觀察

放到 風險 / 觀察 裡，它會讓動作聽起來不只發生了，還帶著明顯的語氣或後果。

foreshadow the change 市場 / 趨勢

在 市場 / 趨勢 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Foreshadow 先投下影子 當你要把事情說成「先投下一道影子」而不只是 暗示 時
Hint 暗示 當句子只需要 暗示 這個動作，不必補上「先投下一道影子」那層走向時

Modern Use

現代延伸

在今天的英文裡，foreshadow 常出現在 foreshadow the ending、foreshadow trouble 這類搭配裡。真正有用的不是背它對應哪個中文，而是看它怎麼把動作往「先投下影子」這個方向收緊。

如果一句話只想表達比較平的「暗示」，Hint 往往就夠了；但當語境需要那層更具體的「先投下一道影子」，foreshadow 會更準。
