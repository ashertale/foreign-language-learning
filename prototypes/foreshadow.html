Foreshadow

不是直接公布，而是先投下一道影子。

Core Idea

foreshadow 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Foreshadow

表示預示、暗示後續將發生的事。

不是 Hint

hint 可以先說出 暗示；foreshadow 則把句子推到「先投下一道影子」這個更細的位置。

Origin

字源

\"預示，預兆\"，來自1570年代的比喻，源自 fore- 和 shadow（v.）； 這個概念似乎是一個物體前進時投下的影子，作爲某種暗示未來事物的形象。

像午後的風先變了方向，晚點的暴雨已經在遠處集結

Memory Hook

記憶鉤子

foreshadow：像午後的風先變了方向，晚點的暴雨已經在遠處集結

這個畫面有用，是因為它先把「先投下一道影子」釘住；回到實際搭配時，就不容易把它和 Hint 混成一團。

Usage

生活與專業情境

日常版

像 foreshadow the ending 這樣的說法，多半出現在 寫作 / 敘事 的場景；句子真正要說的，就是「先投下一道影子」。

數位 / 專業版

到了 風險 / 觀察 的場景，foreshadow trouble 會更常出現；這裡要說清楚的，正是「先投下一道影子」。

Collocations

常見搭配與語域

常見用法集中在 foreshadow the ending 和 foreshadow trouble；這幾個搭配分別落在 寫作 / 敘事 和 風險 / 觀察 的場景裡。

foreshadow the ending 寫作 / 敘事

在 寫作 / 敘事 的語境裡，這個搭配會把動作直接落在 the ending 上。

foreshadow trouble 風險 / 觀察

在 風險 / 觀察 的語境裡，這個搭配會把動作直接落在 trouble 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Foreshadow 預示、暗示後續將發生的事 當句子需要把「先投下一道影子」說清楚，而不是只留在 暗示 的外圈時。
Hint 暗示 當你只需要先說 暗示，不必把語氣收進「先投下一道影子」時。

Modern Use

現代延伸

現在最常見的就是 foreshadow the ending 和 foreshadow trouble 這類說法；它們一出現，通常就在替句子劃清「先投下一道影子」的範圍。

當句子要把「先投下一道影子」說準時，foreshadow 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
