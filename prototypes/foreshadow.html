Foreshadow

for-SHAD-oh · UK /fɔːˈʃæd.əʊ/ · US /fɔːrˈʃæd.oʊ/

不是直接公布，而是先投下一道影子。

CEFR
C1

2.62
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

foreshadow 是事件還沒來，影子已經先落到前面。

Meaning

簡短定義

Foreshadow

表示預示、暗示後續發展，常用於故事、趨勢或早期跡象。

不是 Hint

hint 只是提示；foreshadow 讓提示和後來事件形成敘事連線。

早期細節出現
→
它尚未完全說明未來
→
後續事件讓那個細節變成前兆

Origin

字源

foreshadow 是 fore- 加上 shadow 形成的字，16 世紀就有「事先投下影子」的比喻用法；因此它的預示感不像 announce 那麼直白，而像輪廓先落在地上。

Memory Hook

記憶鉤子

把 foreshadow trouble 想成第一個小 timeout 不是事故本身，卻把後面的 outage 影子投了出來。

foreshadow 是 early sign with narrative weight。

Usage

生活與專業情境

結局

The opening scene foreshadowed the ending without explaining it. 這裡放在結局情境時，是在說早期細節後來會被看成某件事的前兆。

麻煩

Small inconsistencies can foreshadow trouble if they cluster around the same boundary. 這裡放在麻煩情境時，是在說早期細節後來會被看成某件事的前兆。

改變

A quiet staffing shift may foreshadow a larger change in strategy. 這裡放在改變情境時，是在說早期細節後來會被看成某件事的前兆。

Collocations

常見搭配與語域

foreshadow 常接 ending、trouble、change；搭配都指向後面將變重要的跡象。

foreshadow the ending 文學 / 影視

預示結局。

foreshadow trouble 風險 / 敘事

預示麻煩。

foreshadow the change 商務 / 評論

預示變化。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Foreshadow 先投下影子 用在早期細節後來會被看成某件事的前兆時。
Hint 暗示 較輕；foreshadow 明確和後續事件連起來。
Predict 預測 直接說未來；foreshadow 是跡象先出現。

Modern Use

現代延伸

Foreshadow 在文學裡很常見，但也能用於 incident review 和趨勢分析。

它不是保證會發生，而是讓後續發展看起來有脈絡。
