Parry

PAR-ee · UK /ˈpær.i/ · US /ˈper.i/

不是硬接，而是順勢把來的力道撥開。

Core Idea

parry 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Parry

表示擋開攻擊、質問或批評。

不是 Deflect

deflect 可以先說出 撥開或轉開；parry 則把句子推到「順勢把來的力道撥開」這個更細的位置。

Origin

字源

1630年代，“轉移或避開”武器的攻擊（及物動詞），源自法語 parez!（在擊劍課上經常聽到的詞語），是 parer 的祈使形式，意爲“避開”，源自意大利語 parare “避開或防禦（一擊）”（參見 para-（2））。

像劍尖擦著邊線滑過去，危險還在，但沒有正中身體

Memory Hook

記憶鉤子

parry：像劍尖擦著邊線滑過去，危險還在，但沒有正中身體

這個畫面能幫你把 parry 和 Deflect 分開，因為它把「順勢把來的力道撥開」那條界線變得可見。

Usage

生活與專業情境

日常版

像 parry the criticism 這樣的說法，多半出現在 溝通 / 辯論 的場景；句子真正要說的，就是「順勢把來的力道撥開」。

數位 / 專業版

到了 訪談 / 應對 的場景，parry the question 會更常出現；這裡要說清楚的，正是「順勢把來的力道撥開」。

Collocations

常見搭配與語域

常見用法集中在 parry the criticism 和 parry the question；這幾個搭配分別落在 溝通 / 辯論 和 訪談 / 應對 的場景裡。

parry the criticism 溝通 / 辯論

在 溝通 / 辯論 的語境裡，這個搭配會把動作直接落在 the criticism 上。

parry the question 訪談 / 應對

在 訪談 / 應對 的語境裡，這個搭配會把動作直接落在 the question 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Parry 擋開攻擊、質問或批評 當句子需要把「順勢把來的力道撥開」說清楚，而不是只留在 撥開或轉開 的外圈時。
Deflect 撥開或轉開 當你只需要先說 撥開或轉開，不必把語氣收進「順勢把來的力道撥開」時。

Modern Use

現代延伸

現在最常見的就是 parry the criticism 和 parry the question 這類說法；它們一出現，通常就在替句子劃清「順勢把來的力道撥開」的範圍。

當句子要把「順勢把來的力道撥開」說準時，parry 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
