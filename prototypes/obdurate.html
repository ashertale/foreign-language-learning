Obdurate

OB-duh-rit · UK /ˈɒb.djʊ.rət/ · US /ˈɑːb.dɚ.ət/

不是堅定而已，而是別人的請求怎麼敲都敲不進去。

Core Idea

obdurate 的好處在於精度：它把情境、語氣和搭配一起推向「別人的請求怎麼敲都敲不進去」。

Meaning

簡短定義

Obdurate

表示冷硬固執、不為勸說所動。

不是 Stubborn

stubborn 可以先說出 固執；obdurate 則把句子推到「別人的請求怎麼敲都敲不進去」這個更細的位置。

Origin

字源

15世紀中期，“頑固的，不屈不撓的； 尤其是對道德影響頑固不化的； “頑固地邪惡”，源自拉丁語 obduratus “硬化的”，是 obdurare “硬化，使變硬； 變得堅硬或硬化； 堅持，持久” 的過去分詞，在教會拉丁語中“使心靈對上帝變得頑固”，來自 ob “反對”（見 ob-) + durare “硬化，使變硬”，來自 durus “硬”的，源自 PIE *dru-ro-, 詞根 *deru- 的後綴變體形式，意爲“堅定，堅實，堅定不移”。變體 opturate 最早出現在15世紀的醫學中，字面意義爲“停止，阻塞”。

像冬天地凍住的土，鏟子一下去只聽見硬聲，挖不出反應

Memory Hook

記憶鉤子

obdurate：像冬天地凍住的土，鏟子一下去只聽見硬聲，挖不出反應

這個畫面有用，是因為它先把「別人的請求怎麼敲都敲不進去」釘住；回到實際搭配時，就不容易把它和 Stubborn 混成一團。

Usage

生活與專業情境

日常版

像 obdurate refusal 這樣的說法，多半出現在 談判 / 溝通 的場景；句子真正要說的，就是「別人的請求怎麼敲都敲不進去」。

數位 / 專業版

到了 人物 / 描寫 的場景，remain obdurate 會更常出現；這裡要說清楚的，正是「別人的請求怎麼敲都敲不進去」。

Collocations

常見搭配與語域

常見用法集中在 obdurate refusal 和 remain obdurate；這幾個搭配分別落在 談判 / 溝通 和 人物 / 描寫 的場景裡。

obdurate refusal 談判 / 溝通

在 談判 / 溝通 的語境裡，這個搭配通常就在形容 refusal 的狀態或氣質。

remain obdurate 人物 / 描寫

在 人物 / 描寫 的語境裡，這個搭配最容易看出「別人的請求怎麼敲都敲不進去」實際怎麼落在句子裡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Obdurate 冷硬固執、不為勸說所動 當句子需要把「別人的請求怎麼敲都敲不進去」說清楚，而不是只留在 固執 的外圈時。
Stubborn 固執 當你只需要先說 固執，不必把語氣收進「別人的請求怎麼敲都敲不進去」時。

Modern Use

現代延伸

現在最常見的就是 obdurate refusal 和 remain obdurate 這類說法；它們一出現，通常就在替句子劃清「別人的請求怎麼敲都敲不進去」的範圍。

當句子要把「別人的請求怎麼敲都敲不進去」說準時，obdurate 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
