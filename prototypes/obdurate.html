Obdurate

OB-dyuh-rət · UK /ˈɒb.djʊ.rət/ · US /ˈɑːb.dɚ.ət/

不是堅定，而是硬到怎麼勸都不鬆。

Core Idea

obdurate 描述一種「頑固不化」的狀態。它不只是在貼表面標籤，而是把氣壓、方向或隱含張力一起帶進來。

Meaning

簡短定義

Obdurate

形容一種「頑固不化」的狀態、氣質或外觀。

不是 Stubborn

stubborn 可以只是固執；obdurate 更有冷硬、拒絕被打動的感覺。

立場先鎖死
→
外界勸說進不去
→
態度維持冷硬

Origin

字源

obdurate 經 Latin 傳入時，就帶 hardened、心被硬化、對勸說不再回應的感覺；所以它不是單純固執，而像整塊硬掉。

Memory Hook

記憶鉤子

把 obdurate 想成曬乾的泥，不只是硬，還不肯再回軟。

這個字的關鍵不是有原則，而是連該有的柔軟度都拿掉了。

Usage

生活與專業情境

談判

談判桌上一方明明知道代價，卻還是維持 obdurate 的姿態。

人際

當一個人連明確傷害都不願承認時，obdurate 就比 simply stubborn 更準。

Modern Use

現代延伸

在現代評論裡，obdurate 常用來批評掌權者或決策者明知後果仍不鬆口的冷硬。
