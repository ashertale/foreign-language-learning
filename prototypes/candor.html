Candor

KAN-der · UK /ˈkæn.dər/ · US /ˈkæn.dɚ/

不是粗魯直白，而是願意把真話乾淨地說出來。

Core Idea

candor 指坦誠、直率與不遮掩，尤其是在困難對話中仍保留尊重與清楚。

Meaning

簡短定義

Candor

表示坦率、誠實、不迴避真相的說話或態度。

不是 Bluntness

bluntness 可能刺人；candor 的直通常帶有正直與清澈。

真相不舒服
→
仍選擇說清楚

保留信任

Origin

字源

candor 來自拉丁語 candor，原本有明亮、潔白的意思，後來延伸到坦白與正直。

把它記成把話拿到光下，不藏在陰影裡。

Memory Hook

記憶鉤子

candor 是清澈的真話，不是用真話當武器。

這個字的美感在於乾淨：話可能尖銳，但目的不是傷人。

Usage

生活與專業情境

日常版

朋友用 candor 告訴你問題所在，會不舒服，但你知道他不是在羞辱你。

數位 / 專業版

高信任團隊需要 radical candor 的能力：清楚指出問題，同時保留對人的尊重。

Collocations

常見搭配與語域

Candor 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

with candor 正式 / 人際

坦率地、沒有遮掩地說。

radical candor 管理 / 團隊

直接回饋與真正關心並存。

lack of candor 法律 / 組織

缺乏坦白，可能暗示隱瞞。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Candor 坦誠而清楚地說真話 談回饋、信任、調查、領導與困難對話時
Bluntness 不修飾、可能粗硬的直白 重點是刺耳或不顧感受時

Modern Use

現代延伸

在管理語境中，candor 常和 feedback culture 放在一起；它要求組織能聽見壞消息，而不是只鼓勵漂亮話。
