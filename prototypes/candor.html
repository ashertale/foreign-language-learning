Core Idea

candor 不只是 Honesty 的近義替代；它用來描述「願意直接把真實情況攤開」這種更窄、更準確的情境。

Meaning

簡短定義

Candor

表示坦率、直言不諱的真誠。

不是 Honesty

Honesty 可以先說大方向；candor 用在你要把「願意直接把真實情況攤開」這條語氣邊界說得更準的時候。

Origin

字源

\"開放的思想，公正，坦率，沒有保留或僞裝\"，大約在1600年，源自拉丁語 candor \"純潔，開放\"，最初是指\"白色，明亮，輻射\"，來自 candere \"發光，變白\"（源自 PIE 詞根 *kand- \"發光\"）。在英語中更早地借用（約在1500年），指的是拉丁語的字面意義\"極度的白色\"。

Memory Hook

記憶鉤子

candor：像霧氣被窗戶一擦開，外面的景象沒有比較美，但終於看得見

這個畫面能幫你把 candor 和 Honesty 分開，因為它把「願意直接把真實情況攤開」那條界線變得可見。

Usage

生活與專業情境

日常版

像 speak with candor 這樣的說法，多半出現在 溝通 / 回饋 的場景；句子真正要說的，就是「願意直接把真實情況攤開」。

數位 / 專業版

到了 人際 / 評價 的場景，refreshing candor 會更常出現；這裡要說清楚的，正是「願意直接把真實情況攤開」。

Collocations

常見搭配與語域

常見用法集中在 speak with candor 和 refreshing candor；這幾個搭配分別落在 溝通 / 回饋 和 人際 / 評價 的場景裡。

speak with candor 溝通 / 回饋

在 溝通 / 回饋 的語境裡，這個搭配會把關係直接指向 candor。

refreshing candor 人際 / 評價

在 人際 / 評價 的語境裡，前面的 refreshing 會把這個概念限定到更具體的場景。

Modern Use

現代延伸

現在最常見的就是 speak with candor 和 refreshing candor 這類說法；它們一出現，通常就在替句子劃清「願意直接把真實情況攤開」的範圍。

比起 honesty，candor 更適合用在你想直接點出「坦率、直言不諱的真誠」的時候。
