Renounce

ri-NOWNS · UK /rɪˈnaʊns/ · US /rɪˈnaʊns/

不是放棄而已，而是公開與它切斷關係。

Core Idea

renounce 表示把事情往「公開棄絕」的方向推。重點不只在動作發生，而在那個動作怎麼改變局面。

Meaning

簡短定義

Renounce

表示把事情往「公開棄絕」的方向推，或讓局面出現這種結果。

不是 Abandon

abandon 可以只是丟下；renounce 常有公開、正式切割的味道。

原本與某物有連結
→
人主動表態切開

Origin

字源

renounce 來自拉丁語 renuntiare，原本有公開宣告、告知、表明立場的意味；所以 modern renounce 不是默默放掉，而是明白說我和它切開。

Memory Hook

記憶鉤子

把 renounce 想成不是把東西放桌上，而是當眾把名字從它上面劃掉。

這個字有一種公開切割的戲劇感。

Usage

生活與專業情境

信念

若一個人公開放棄過去主張，可以說他 renounced those views。

權利

某些法律語境裡，renounce 也會用在放棄公民資格或繼承權。

Neighbors

Modern Use

現代延伸

renounce 常見於政治、宗教與法律語境，因為它不只是離開，而是明白切割。
