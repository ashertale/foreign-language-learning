Supplant

不是並存，而是新的東西把舊的位置接走。

Core Idea

supplant 最值得保留的語感，是它讓「取代、替換，使原本的事物失去原位」不再只是模糊大意。

Meaning

簡短定義

Supplant

表示取代、替換，使原本的事物失去原位。

不是 Replace

Replace 可以先說大方向；supplant 用在你要把「新的東西把舊的位置接走」這條語氣邊界說得更準的時候。

Origin

字源

supplant 在英語裡可追到 c. 1300；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示取代、替換，使原本的事物失去原位」的用法。

像新零件裝上去後，舊零件不是旁邊備用，而是正式退場

Memory Hook

記憶鉤子

supplant：像新零件裝上去後，舊零件不是旁邊備用，而是正式退場

這個畫面之所以有用，是因為它能幫你確認 supplant 是否真的在談「新的東西把舊的位置接走」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 supplant the legacy system 這樣的說法，多半出現在 系統 / 架構 的場景；句子真正要說的，就是「新的東西把舊的位置接走」。

數位 / 專業版

到了 研究 / 工作 的場景，supplant older methods 會更常出現；這裡要說清楚的，正是「新的東西把舊的位置接走」。
