Concede

kun-SEED · UK /kənˈsiːd/ · US /kənˈsiːd/

不是一開始就認，而是撐過一輪後終於承認某點站不住。

Core Idea

concede 不只是 Admit 的近義替代；它用來描述「撐過一輪後終於承認某點站不住」這種更窄、更準確的情境。

Meaning

簡短定義

Concede

表示承認、讓步，接受對方某部分說法或勝利。

不是 Admit

把它們分開記：admit 先保留大方向，concede 負責把邊界收乾淨。

Origin

字源

1630年代，“讓步，放棄”（及物動詞），源自法語 concéder 或直接源自拉丁語 concedere “讓步，屈服，離開，退休”，比喻地“同意，許可，給予優先權”，由 con- 組成，這裏可能是一個強調前綴（參見 con-），加上 cedere “走，授予，讓路”（來自 PIE 根 *ked- “走，屈服”）。

像棋盤上一路守到最後，終於把一格關鍵位置讓出去

Memory Hook

記憶鉤子

concede：像棋盤上一路守到最後，終於把一格關鍵位置讓出去

這個畫面能幫你把 concede 和 Admit 分開，因為它把「撐過一輪後終於承認某點站不住」那條界線變得可見。

Usage

生活與專業情境

日常版

像 concede the point 這樣的說法，多半出現在 辯論 / 討論 的場景；句子真正要說的，就是「撐過一輪後終於承認某點站不住」。

數位 / 專業版

到了 競賽 / 衝突 的場景，concede defeat 會更常出現；這裡要說清楚的，正是「撐過一輪後終於承認某點站不住」。

Collocations

常見搭配與語域

常見用法集中在 concede the point 和 concede defeat；這幾個搭配分別落在 辯論 / 討論 和 競賽 / 衝突 的場景裡。

concede the point 辯論 / 討論

在 辯論 / 討論 的語境裡，這個搭配會把動作直接落在 the point 上。

concede defeat 競賽 / 衝突

在 競賽 / 衝突 的語境裡，這個搭配會把動作直接落在 defeat 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Concede 承認、讓步，接受對方某部分說法或勝利 當搭配和語境都已經指向「撐過一輪後終於承認某點站不住」，這個字才自然。
Admit 承認 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 辯論 / 討論、競賽 / 衝突、分析 / 評論 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
