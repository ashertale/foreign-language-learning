Declarative

dih-KLAR-uh-tiv · UK /dɪˈklær.ə.tɪv/ · US /dɪˈkler.ə.t̬ɪv/

不是一步步命令，而是直接描述希望成立的狀態。

Core Idea

declarative 說的是描述想要成立的狀態，而不是一步步命令系統怎麼走到那裡。

Meaning

簡短定義

Declarative

形容語句、語法、設定或風格以宣告狀態或事實為主，而非逐步指示操作流程。

不是 Imperative

imperative 告訴系統怎麼做；declarative 告訴系統要成為什麼樣。

描述目標
→
隱藏步驟
→
由系統求出做法

Origin

字源

來自 declare 的宣告概念；重點是說出狀態，而不是指揮流程。

declare 像把旗子插下去：declarative 直接把要成立的事說出口。

Memory Hook

記憶鉤子

把 declarative config 想成告訴系統 desired state。

你說要什麼，系統自己求怎麼到；這和逐行下命令不同。

Usage

生活與專業情境

設定

Declarative config 說 desired state，而不是逐行指揮每個操作。

語法

SQL feels declarative because you describe what data you want, not every step to fetch it。 這裡放在語法情境時，是在說重點是宣告狀態、事實或目標，而不是列出操作步驟。

語句

A declarative statement simply states something; it is not a question or command。 這裡放在語句情境時，是在說重點是宣告狀態、事實或目標，而不是列出操作步驟。

Modern Use

現代延伸

Declarative 在現代基礎設施、UI 和資料查詢裡很常見，因為它把維護焦點從步驟轉到狀態。

但 declarative 不代表沒有邏輯；邏輯只是被放到工具、runtime 或 solver 裡處理。
