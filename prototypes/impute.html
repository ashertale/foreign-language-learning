Impute

im-PYOOT · UK /ɪmˈpjuːt/ · US /ɪmˈpjuːt/

不是只是看到結果，而是把背後原因算到某人頭上。

Core Idea

impute 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Impute

表示歸罪、歸因、把動機或責任加諸某人。

不是 Attribute

如果 attribute 已經能讓句子成立，就不必硬換；需要「歸罪、歸因、把動機或責任加諸某人」時，impute 才有必要。

先遇到 impute motives
→
看它是否只是 歸因
→
再決定是否需要 impute

Origin

字源

15世紀初，源自14世紀的古法語 imputer 和 emputer，直接來自拉丁語 imputare \"計算，覈算，歸因於\"，來自於 in- \"進入，到達\"的同化形式（源自 PIE 詞根 *en \"在\"）+ putare \"修剪，修整； 計算，清理（賬目）\"，來自於 PIE 詞根 *puto- \"切割，打擊\"，詞根 *pau- (2) \"切割，打擊，蓋章\"的後綴形式。

Memory Hook

記憶鉤子

impute：像帳本上有一筆缺口，大家開始追著問這一筆到底記在誰名下

能用這個畫面回到「歸罪、歸因、把動機或責任加諸某人」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 impute motives 時，焦點通常就在「把背後原因算到某人頭上」上，所以這個搭配很能代表 impute 的語感。

數位 / 專業版

到了 法務 / 判斷 的場景，impute blame 會更常出現；這裡要說清楚的，正是「把背後原因算到某人頭上」。

Collocations

常見搭配與語域

常見用法集中在 impute motives 和 impute blame；這幾個搭配分別落在 人際 / 解讀 和 法務 / 判斷 的場景裡。

impute motives 人際 / 解讀

在 人際 / 解讀 的語境裡，這個搭配會把動作直接落在 motives 上。

impute blame 法務 / 判斷

在 法務 / 判斷 的語境裡，這個搭配會把動作直接落在 blame 上。

Neighbors

對立與鄰近概念

Modern Use

現代延伸

現在最常見的就是 impute motives 和 impute blame 這類說法；它們一出現，通常就在替句子劃清「把背後原因算到某人頭上」的範圍。

當句子要把「把背後原因算到某人頭上」說準時，impute 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
