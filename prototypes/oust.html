Oust

OWST · UK /aʊst/ · US /aʊst/

不是離開，而是被人硬生生趕下位置。

CEFR
C1
Zipf Frequency
2.73
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

oust 指把原本坐在位置上的人或勢力趕出去；離開不是自願，而是被外力排除。

Meaning

簡短定義

Oust

把某人從職位、權力位置或場所中強行移走。

不是 Remove

remove 很中性；oust 強調被推出去、通常帶權力鬥爭。

原本握有位置
→
外力開始推擠
→
最後被迫退出場內

Origin

字源

oust 經 Anglo-French / Old French 傳入時，就是趕出、奪走位置、使其失去占有；所以它不是普通離開，而是被推下來。

Memory Hook

記憶鉤子

把 oust 想成不是自己下車，而是被整個人擠出座位。

它把權力感和被迫性綁在一起。

Usage

生活與專業情境

權力

董事會若主動把創辦人趕下台，最自然的動詞就是 oust。

競爭

當新平台把舊玩家擠出主位時，也常會看到 oust。

Collocations

常見搭配與語域

oust the leader 政治 / 商業

某人從權力、職位或地盤被迫退出。

oust from office 新聞 / 正式

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Oust 趕下位置 用在某人從權力、職位或地盤被迫退出時。
Remove 移除、撤掉、拿開 若只是中性的人事調整，用 remove 就夠。

Modern Use

現代延伸

oust 常出現在政治與董事會新聞裡，因為它比 remove 更有鬥爭與被逼退場的力道。
