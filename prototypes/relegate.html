Relegate

REL-uh-gayt · UK /ˈrel.ɪ.ɡeɪt/ · US /ˈrel.ə.ɡeɪt/

不是刪掉，而是把它移到比較次要、比較後面的位置。

Core Idea

relegate 不只是 Demote 的近義替代；它用來描述「把它移到比較次要、比較後面的位置」這種更窄、更準確的情境。

Meaning

簡短定義

Relegate

表示降級、打入邊緣或轉放到較不重要的區域。

不是 Demote

把它們分開記：demote 先保留大方向，relegate 負責把邊界收乾淨。

Origin

字源

relegate，後來才慢慢落到今天這種「表示降級、打入邊緣或轉放到較不重要的區域」的語境。

像文件還在，但被塞到最底層抽屜，平常幾乎不會再被看見

Memory Hook

記憶鉤子

relegate：像文件還在，但被塞到最底層抽屜，平常幾乎不會再被看見

這個畫面能幫你把 relegate 和 Demote 分開，因為它把「把它移到比較次要、比較後面的位置」那條界線變得可見。

Usage

生活與專業情境

日常版

像 relegate to the background 這樣的說法，多半出現在 設計 / 視覺 的場景；句子真正要說的，就是「把它移到比較次要、比較後面的位置」。

數位 / 專業版

到了 管理 / 專案 的場景，relegate the task 會更常出現；這裡要說清楚的，正是「把它移到比較次要、比較後面的位置」。

Collocations

常見搭配與語域

常見用法集中在 relegate to the background 和 relegate the task；這幾個搭配分別落在 設計 / 視覺 和 管理 / 專案 的場景裡。

relegate to the background 設計 / 視覺

在 設計 / 視覺 的語境裡，這個搭配會把動作直接落在 to the background 上。

relegate the task 管理 / 專案

在 管理 / 專案 的語境裡，這個搭配會把動作直接落在 the task 上。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 設計 / 視覺、管理 / 專案、寫作 / 評論 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
