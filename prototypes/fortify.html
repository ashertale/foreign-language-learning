Fortify

FOR-tuh-fy · UK /ˈfɔː.tɪ.faɪ/ · US /ˈfɔːr.t̬ə.faɪ/

不是修補一下，而是提前把它補到更能撐。

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

fortify 是在衝擊來之前把東西補強：牆、身體、論點、流程都可以。

Meaning

簡短定義

Fortify

表示加固、防禦、強化，使更能承受壓力或攻擊。

不是 Strengthen

strengthen 是變強；fortify 像在壓力來前加防線。

壓力或攻擊可預期
→
弱點被補強
→
對象更能承受

Origin

字源

fortify 早期一面可指加強藥效，一面可指替城鎮築起防禦；兩條線都保留了同一個動作，就是把原本脆弱的東西撐得更能扛。

Memory Hook

記憶鉤子

把 fortify the argument 想成補證據、補反例、補限制，讓論點不容易被打穿。

fortify 的方向是 strengthen before stress。

Usage

生活與專業情境

牆

They fortified the wall before the storm season.

論點

論點情境下，fortify 不是修補一下，而是提前把它補到更能撐。

營養

Food fortified with vitamins has nutrients added for support.

Collocations

常見搭配與語域

fortify 常接 wall、argument，也常見 fortified with vitamins；搭配跨越軍事、論證和營養。

fortify the wall 軍事 / 建築

加固牆體。

fortify the argument 寫作 / 論證

強化論點。

fortified with vitamins 食品 / 健康

添加維生素強化。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fortify 提前補強 用在加強的目的，是讓對象更能抵抗壓力、攻擊或不足時。
Strengthen 加強 通用；fortify 有防禦、承壓前補強的畫面。
Reinforce 補強 接近；fortify 防禦感更強。

Modern Use

現代延伸

Fortify 很適合 security、argument、immune system、position。

它比 improve 更具方向：不是變好而已，是更能撐。
