Fortify

FOR-tuh-fy · UK /ˈfɔː.tɪ.faɪ/ · US /ˈfɔːr.t̬ə.faɪ/

不是修補一下，而是提前把它補到更能撐。

Core Idea

fortify 不只是交代動作發生；它更常用來指出事情怎麼朝「提前補強」這條線走。

Meaning

簡短定義

Fortify

表示加強防護、鞏固身體、結構或立場。它要補上的，通常不是動作本身，而是那層更具體的「提前把它補到更能撐」。

不是 Strengthen

如果語境只需要比較平的「強化」，用 Strengthen 往往就夠了；fortify 則會把「提前把它補到更能撐」講得更明確。

Memory Hook

記憶鉤子

fortify 的畫面是：像在暴風前先把窗框多釘幾道，讓風來時不至於整片掀掉。

記這個畫面，不是為了背故事，而是讓你下次看到 fortify 時，能先抓到「提前補強」這個核心，再回頭讀細節。

Usage

生活與專業情境

日常版

讀到 fortify the wall 時，可以先別急著翻中文；先看句子是不是想把動作往「提前補強」這個方向講清楚。

數位 / 專業版

fortify the argument 放進 寫作 / 辯論 後，常會比一般近義詞更有份量，因為它把結果之外的那層語氣也帶了進來。

延伸版

如果你想把這個字放進 健康 / 食品 的情境，從 fortified with vitamins 這種搭配進場通常最穩，因為語感邊界很清楚。

Collocations

常見搭配與語域

看這些搭配時，重點不是詞組本身，而是這個動詞通常怎麼把事情往更具體的方向收緊。

fortify the wall 工程 / 結構

這個搭配常出現在需要把事情往「提前補強」講清楚的句子裡。

fortify the argument 寫作 / 辯論

放到 寫作 / 辯論 裡，它會讓動作聽起來不只發生了，還帶著明顯的語氣或後果。

fortified with vitamins 健康 / 食品

在 健康 / 食品 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fortify 提前補強 當你要把事情說成「提前把它補到更能撐」而不只是 強化 時
Strengthen 強化 當句子只需要 強化 這個動作，不必補上「提前把它補到更能撐」那層走向時

Modern Use

現代延伸

fortify 在現代語境裡很少只是字面動作。它常被拿來把一句話的走向講得更清楚，尤其是在 fortify the wall 這類搭配裡更明顯。

所以它和 Strengthen 的差別，通常不在難度，而在句子要不要把那層「提前補強」明白說出來。
