Lurid

LOOR-id · UK /ˈlʊə.rɪd/ · US /ˈlʊr.ɪd/

不是鮮明，而是鮮明到讓人不舒服或覺得被炒作。

Core Idea

lurid 用來描述「鮮明到讓人不舒服或覺得被炒作」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Lurid

表示駭人、聳動、過度誇張而強烈。

不是 Vivid

如果 vivid 已經能讓句子成立，就不必硬換；需要「駭人、聳動、過度誇張而強烈」時，lurid 才有必要。

Origin

字源

1650年代，“蒼白的，暗淡的”，源自拉丁語 luridus “蒼白的黃色，可怕的，瘀傷的顏色”，這個詞的起源和詞源不確定，可能與希臘語 khlōros “蒼白的綠色，綠黃色”（見 Chloe），或與拉丁語 lividus（見 livid）有關。

Memory Hook

記憶鉤子

lurid：像霓虹色被打得太滿，眼睛還沒看懂內容就先被刺到

這個畫面有用，是因為它先把「鮮明到讓人不舒服或覺得被炒作」釘住；回到實際搭配時，就不容易把它和 Vivid 混成一團。

Usage

生活與專業情境

日常版

當人們說 lurid detail 時，焦點通常就在「鮮明到讓人不舒服或覺得被炒作」上，所以這個搭配很能代表 lurid 的語感。

數位 / 專業版

到了 新聞 / 評論 的場景，lurid headline 會更常出現；這裡要說清楚的，正是「鮮明到讓人不舒服或覺得被炒作」。

Collocations

常見搭配與語域

常見用法集中在 lurid detail 和 lurid headline；這幾個搭配分別落在 媒體 / 報導 和 新聞 / 評論 的場景裡。

lurid detail 媒體 / 報導

在 媒體 / 報導 的語境裡，這個搭配通常就在形容 detail 的狀態或氣質。

lurid headline 新聞 / 評論

在 新聞 / 評論 的語境裡，這個搭配通常就在形容 headline 的狀態或氣質。

Neighbors

概念 核心精神 最自然的使用時機

Vivid 鮮明 如果上下文還沒有給出足夠理由支撐 lurid，先用 vivid。

Modern Use

現代延伸

現在最常見的就是 lurid detail 和 lurid headline 這類說法；它們一出現，通常就在替句子劃清「鮮明到讓人不舒服或覺得被炒作」的範圍。

當句子要把「鮮明到讓人不舒服或覺得被炒作」說準時，lurid 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
