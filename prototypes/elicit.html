Elicit

ih-LIS-it · UK /iˈlɪs.ɪt/ · US /iˈlɪs.ɪt/

不是直接拿到，而是透過提問、刺激或設計把反應引出來。

Core Idea

elicit 表示引出回答、情緒、需求或反應；它常暗示對方原本不會自動說出來。

Meaning

簡短定義

Origin

字源

elicit 來自 Latin elicere，意思接近「引出、誘出」。

它像把藏在裡面的回答拉出來；不是拿現成答案，而是讓它浮現。

Memory Hook

記憶鉤子

elicit 是用好問題把真正需求釣出來。

它重視方法：不是硬拿，而是讓東西浮上來。

Usage

生活與專業情境

訪談版

Good user interviews elicit needs that surveys miss. 這個情境凸顯「引出、誘發某種反應、資訊或回答」。

測試版

A stress test can elicit failures that normal use never shows. 讀這句時，焦點在「引出、誘發某種反應、資訊或回答」。

Modern Use

現代延伸

在需求訪談裡，elicit 比 collect 更精準，因為真正需求常需要被問法和情境引出。
