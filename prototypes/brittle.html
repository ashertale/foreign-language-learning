Brittle

BRIT-uhl · UK /ˈbrɪt.əl/ · US /ˈbrɪt̬.əl/

不是堅硬就可靠，而是看起來硬，真正受力時卻一下就裂。

Core Idea

brittle 的好處在於精度：它把情境、語氣和搭配一起推向「看起來硬，真正受力時卻一下就裂」。

Meaning

簡短定義

Brittle

表示材料、系統或情緒缺乏韌性，容易突然破裂。

不是 Fragile

fragile 可以先說出 脆弱；brittle 則把句子推到「看起來硬，真正受力時卻一下就裂」這個更細的位置。

Origin

字源

\"易碎且突然斷裂的\"，14世紀晚期， britel，可能來自未記錄的古英語形容詞 *brytel，與 brytan \"壓碎，搗碎，打碎\"有關，源自原始日耳曼語詞根 *brutila- \"脆弱\"，來自 *breutan \"分裂\"（源頭還包括古諾爾斯語 brjota \"打破\"，古高地德語 brodi \"易碎\"），源自 PIE 詞根 *bhreu- \"切割，打碎\"（參見 bruise（v.））。與 -le 一起，構成帶有\"易於\"含義的形容詞。

Memory Hook

這個畫面能幫你把 brittle 和 Fragile 分開，因為它把「看起來硬，真正受力時卻一下就裂」那條界線變得可見。

Usage

生活與專業情境

日常版

像 brittle code 這樣的說法，多半出現在 軟體 / 測試 的場景；句子真正要說的，就是「看起來硬，真正受力時卻一下就裂」。

數位 / 專業版

到了 材料 / 工程 的場景，brittle material 會更常出現；這裡要說清楚的，正是「看起來硬，真正受力時卻一下就裂」。

Collocations

常見搭配與語域

常見用法集中在 brittle code 和 brittle material；這幾個搭配分別落在 軟體 / 測試 和 材料 / 工程 的場景裡。

brittle code 軟體 / 測試

在 軟體 / 測試 的語境裡，這個搭配通常就在形容 code 的狀態或氣質。

brittle material 材料 / 工程

在 材料 / 工程 的語境裡，這個搭配通常就在形容 material 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Brittle 材料、系統或情緒缺乏韌性，容易突然破裂 當句子需要把「看起來硬，真正受力時卻一下就裂」說清楚，而不是只留在 脆弱 的外圈時。
Fragile 脆弱 當你只需要先說 脆弱，不必把語氣收進「看起來硬，真正受力時卻一下就裂」時。

Modern Use

現代延伸

現在最常見的就是 brittle code 和 brittle material 這類說法；它們一出現，通常就在替句子劃清「看起來硬，真正受力時卻一下就裂」的範圍。

當句子要把「看起來硬，真正受力時卻一下就裂」說準時，brittle 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
