Brittle

BRIT-uhl · UK /ˈbrɪt.əl/ · US /ˈbrɪt̬.əl/

不是只是硬，而是缺少彈性，一受壓就容易裂開。

Core Idea

brittle 用來描述材料、系統、計畫或關係表面堅硬，卻無法吸收變化與衝擊。

Meaning

簡短定義

Brittle

形容某物硬而易碎，也可比喻系統或狀態缺乏韌性。

不是 Fragile

fragile 泛指脆弱；brittle 特別像硬物承受不了變形而斷裂。

外表硬
→
壓力無法被吸收
→
突然裂開

Origin

字源

brittle 與古英語中容易破裂的語義相連，核心一直圍繞「脆、易斷」。

它像乾掉的樹枝，看起來硬，手一折就斷。

Memory Hook

記憶鉤子

brittle 是硬到沒有退路的脆弱。

它提醒你：硬不等於強，能變形吸收壓力才是真韌性。

Usage

生活與專業情境

日常版

冬天皮膚乾裂、餅乾一碰就碎，都可以用 brittle 描述。

數位 / 專業版

在軟體與硬體系統裡，brittle tests 或 brittle design 代表小變動就造成大量破裂。

Collocations

常見搭配與語域

Brittle 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

brittle material 材料 / 工程

硬但缺乏延展性，容易碎裂。

brittle test 軟體 / QA

對無關變動太敏感的測試。

brittle confidence 心理 / 敘事

表面自信，壓力一來就崩。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Brittle 硬而缺乏彈性，因此容易碎裂 談材料、測試、系統、關係或心理狀態時
Fragile 容易受損或需要小心保護 脆弱但不一定有硬而易裂的質地時

Modern Use

現代延伸

工程裡說某個流程 brittle，通常是在說它沒有容錯空間；它看似可用，其實只適合在理想條件下存在。
