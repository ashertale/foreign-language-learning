Fragment

FRAG-munt · UK /ˈfræɡ.mənt/ · US /ˈfræɡ.mənt/

不是完整部分，而是從整體裂出來的一小片。

Core Idea

fragment 是從整體裂出來的小片。它可能有線索價值，但不能假裝自己就是完整故事。

Meaning

簡短定義

Fragment

指碎片、片段，或使某物碎裂、分裂。常用於資料、記憶、程式碼、文本或社會群體。

不是 Piece

piece 可以是完整的一塊；fragment 暗示原本整體已破裂或被切開。

Origin

字源

來自 Latin frangere「打破」。

frangere 是打破；fragment 的畫面就是完整物裂成小片。

Memory Hook

記憶鉤子

把 fragment 想成只截到十行 log。

它珍貴，但如果把它當全貌，判斷會歪。

Usage

生活與專業情境

Log

log fragment 有價值，但不能把一小段片段當完整故事。

程式碼

在程式碼這類情境裡，fragment 的重點是：不是完整部分，而是從整體裂出來的一小片。

資料

Fragmented data makes analysis expensive because the pieces no longer line up easily. 這裡放在資料情境時，是在說某物只是整體裂出或切出的部分，需小心不要過度推論。

Collocations

常見搭配與語域

fragment 常和 memory、code、data 搭配。搭配會指出碎片來自哪個原本整體。

memory fragment 記憶 / 系統

記憶或記憶體中的片段。

fragment of code 程式 / 文件

一小段程式碼，不代表完整脈絡。

fragmented data 資料 / 系統

資料分散破碎，整合困難。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fragment 碎片、片段或不完整的部分 用在某物只是整體裂出或切出的部分，需小心不要過度推論時。
Piece 一塊、一件 可中性，不一定來自破裂。
Segment 段落、區段 有切分感，未必破碎。
Shard 碎片 更像硬物破裂後尖銳小片。

Modern Use

現代延伸

Fragment 在 debug 裡是一個很好的謹慎詞。你可以根據 fragment 形成 hypothesis，但不該直接下 conclusion。

資料系統裡 fragmented 常是成本來源：查得到不等於能合併、能解釋。
