Entrench

en-TRENCH · UK /ɪnˈtrentʃ/ · US /ɪnˈtrentʃ/

不是先放進去而已，而是深到很難再拔出來。

Core Idea

entrench 的核心是把「使觀念、制度或問題根深蒂固」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Entrench

表示使觀念、制度或問題根深蒂固。

不是 Embed

Embed 可以先說大方向；entrench 用在你要把「深到很難再拔出來」這條語氣邊界說得更準的時候。

先遇到 entrench inequality
→
看它是否只是 嵌入
→
再決定是否需要 entrench

Origin

字源

也稱 intrench，始見於1550年代，隱含於 intrenched 中，源自 en-（1）“製造，放置”和 trench（n.）。比喻用法始於1590年代。

像樹根一路往下抓住土層，之後不靠重機很難挪動

Memory Hook

記憶鉤子

entrench：像樹根一路往下抓住土層，之後不靠重機很難挪動

能用這個畫面回到「使觀念、制度或問題根深蒂固」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 entrench inequality 這樣的說法，多半出現在 社會 / 制度 的場景；句子真正要說的，就是「深到很難再拔出來」。

數位 / 專業版

到了 心理 / 行為 的場景，entrench the habit 會更常出現；這裡要說清楚的，正是「深到很難再拔出來」。

Collocations

常見搭配與語域

常見用法集中在 entrench inequality 和 entrench the habit；這幾個搭配分別落在 社會 / 制度 和 心理 / 行為 的場景裡。

entrench inequality 社會 / 制度

在 社會 / 制度 的語境裡，這個搭配會把動作直接落在 inequality 上。

entrench the habit 心理 / 行為

在 心理 / 行為 的語境裡，這個搭配會把動作直接落在 the habit 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Entrench 使觀念、制度或問題根深蒂固 用在你想讓讀者看到「使觀念、制度或問題根深蒂固」這個較窄邊界的時候。

Modern Use

現代延伸

現在最常見的就是 entrench inequality 和 entrench the habit 這類說法；它們一出現，通常就在替句子劃清「深到很難再拔出來」的範圍。

比起 embed，entrench 更適合用在你想直接點出「使觀念、制度或問題根深蒂固」的時候。
