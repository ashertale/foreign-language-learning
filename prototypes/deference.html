Deference

DEF-er-uhns · UK /ˈdef.ər.əns/ · US /ˈdef.ɚ.əns/

不是盲從，而是出於尊重而先讓對方的判斷排在前面。

Core Idea

deference 最值得保留的語感，是它讓「出於尊敬而表示順從、禮讓或依從」不再只是模糊大意。

Meaning

簡短定義

Deference

表示出於尊敬而表示順從、禮讓或依從。

不是 Respect

把它們分開記：respect 先保留大方向，deference 負責把邊界收乾淨。

Origin

字源

\"順從他人的判斷，意見上的讓步\"，1640年代，源自法語 déférence（16世紀），源自 déférer “屈服，順從”（參見 defer（v.2））。

像走廊會車時你先向旁邊退一步，讓更重要的通行先過

Memory Hook

記憶鉤子

deference：像走廊會車時你先向旁邊退一步，讓更重要的通行先過

這個畫面有用，是因為它先把「出於尊重而先讓對方的判斷排在前面」釘住；回到實際搭配時，就不容易把它和 Respect 混成一團。

Usage

生活與專業情境

日常版

像 show deference to experience 這樣的說法，多半出現在 組織 / 禮節 的場景；句子真正要說的，就是「出於尊重而先讓對方的判斷排在前面」。

數位 / 專業版

到了 法務 / 判例 的場景，deference to precedent 會更常出現；這裡要說清楚的，正是「出於尊重而先讓對方的判斷排在前面」。

Collocations

常見搭配與語域

常見用法集中在 show deference to experience 和 deference to precedent；這幾個搭配分別落在 組織 / 禮節 和 法務 / 判例 的場景裡。

show deference to experience 組織 / 禮節

在 組織 / 禮節 的語境裡，這個搭配會把關係直接指向 experience。

deference to precedent 法務 / 判例

在 法務 / 判例 的語境裡，這個搭配會把關係直接指向 precedent。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Deference 出於尊敬而表示順從、禮讓或依從 當搭配和語境都已經指向「出於尊重而先讓對方的判斷排在前面」，這個字才自然。
Respect 尊重 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 組織 / 禮節、法務 / 判例、職場 / 階序 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
