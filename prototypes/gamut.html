Gamut

GAM-uht · UK /ˈɡæm.ət/ · US /ˈɡæm.ət/

不是幾種，而是整條範圍都包進去。

Core Idea

gamut 是從一端到另一端的完整範圍，像把整個光譜攤開。

Meaning

簡短定義

Gamut

指完整範圍、全系列、全部層次。

不是 Range

range 是範圍；gamut 像把整排音階從頭到尾彈過。

某類事物有兩端
→
中間層次都被包含
→
整體範圍被看見

Origin

字源

gamut 原本是中世紀音階裡最低的 G 音，名字來自 gamma ut；後來才從整套音階延伸成「完整範圍」，所以 run the gamut 字面上其實是整個音階都走過。

Memory Hook

記憶鉤子

把 run the gamut 想成情緒不是單一反應，而是從興奮、焦慮到疲憊全部跑過。

gamut 的重點是 span。

Usage

生活與專業情境

範圍

The questions ran the gamut from naming to deployment risk. 這裡放在範圍情境時，是在說你要表示某一類東西的整個範圍都被涵蓋。

服務

The platform promises a full gamut of services, but users still care about the path between them. 這裡放在服務情境時，是在說你要表示某一類東西的整個範圍都被涵蓋。

情緒

The team went through a gamut of emotions during the incident. 這裡放在情緒情境時，是在說你要表示某一類東西的整個範圍都被涵蓋。

Collocations

常見搭配與語域

gamut 常出現在 run the gamut、full gamut of services、gamut of emotions；搭配都指完整範圍。

run the gamut 正式 / 日常

涵蓋整個範圍。

full gamut of services 商務 / 產品

全套服務。

gamut of emotions 情緒 / 敘事

各種情緒。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸
