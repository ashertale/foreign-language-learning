Gamut

GAM-uht · UK /ˈɡæm.ət/ · US /ˈɡæm.ət/

不是幾種，而是整條範圍都包進去。

Core Idea

gamut 的好處在於精度：它把情境、語氣和搭配一起推向「整條範圍都包進去」。

Meaning

簡短定義

Gamut

表示完整範圍、全系列、各種層次。

不是 Range

range 可以先說出 範圍；gamut 則把句子推到「整條範圍都包進去」這個更細的位置。

Origin

字源

gamut，後來才慢慢落到今天這種「表示完整範圍、全系列、各種層次」的語境。

像鋼琴鍵從最低到最高一整排都打開，沒有哪一段被省略

Memory Hook

記憶鉤子

gamut：像鋼琴鍵從最低到最高一整排都打開，沒有哪一段被省略

這個畫面之所以有用，是因為它能幫你確認 gamut 是否真的在談「整條範圍都包進去」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 run the gamut 這樣的說法，多半出現在 寫作 / 表達 的場景；句子真正要說的，就是「整條範圍都包進去」。

數位 / 專業版

到了 營運 / 服務 的場景，full gamut of services 會更常出現；這裡要說清楚的，正是「整條範圍都包進去」。

Collocations

常見搭配與語域

常見用法集中在 run the gamut 和 full gamut of services；這幾個搭配分別落在 寫作 / 表達 和 營運 / 服務 的場景裡。

run the gamut 寫作 / 表達

在 寫作 / 表達 的語境裡，前面的 run the 會把這個概念限定到更具體的場景。

full gamut of services 營運 / 服務

在 營運 / 服務 的語境裡，這個搭配會把關係直接指向 services。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Gamut 完整範圍、全系列、各種層次 當句子需要把「整條範圍都包進去」說清楚，而不是只留在 範圍 的外圈時。
Range 範圍 當你只需要先說 範圍，不必把語氣收進「整條範圍都包進去」時。

Modern Use

現代延伸

現在最常見的就是 run the gamut 和 full gamut of services 這類說法；它們一出現，通常就在替句子劃清「整條範圍都包進去」的範圍。

當句子要把「整條範圍都包進去」說準時，gamut 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
