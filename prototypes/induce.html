Induce

in-DOOS · UK /ɪnˈdjuːs/ · US /ɪnˈduːs/

不是直接命令，而是創造條件讓某反應發生。

Core Idea

induce 不是下命令，而是設計或形成條件，讓某個反應被引出來。

Meaning

簡短定義

Induce

表示引發、誘導或促成某反應、狀態或結果；醫學和科學語境也常見。

不是 Cause

cause 是造成；induce 常像把系統推到會產生反應的條件。

條件被設計
→
反應被觸發
→
結果出現

Origin

字源

來自 Latin inducere，有引入、帶進去的意思。

inducere 的帶進去很適合記：induce 是把條件帶到會產生反應的位置。

Memory Hook

記憶鉤子

把 induce 想成 stress test 把系統推到會失敗的邊界。

失敗不是被命令出來，而是條件讓它浮出來。

Usage

生活與專業情境

測試

stress test can induce failure，因為它刻意把系統推到邊界。

生理

Some medicines can induce sleep by changing body conditions. 這裡放在生理情境時，是在說你不是直接命令結果，而是讓條件促成結果。

反應

在反應這類情境裡，induce 的重點是：不是直接命令，而是創造條件讓某反應發生。

Collocations

常見搭配與語域

induce 常接 failure、sleep、response。搭配會說明被引出的反應是故障、生理狀態還是行為。

induce failure 工程 / 測試

透過條件設計讓 failure 出現。

induce sleep 醫療 / 日常

引發睡意或睡眠。

induce a response 科學 / 設計

引出某種反應。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Induce 引發、誘導或歸納 用在你不是直接命令結果，而是讓條件促成結果時。
Cause 造成 通用直接因果。
Trigger 觸發 常指啟動某事件。
Elicit 引出 常用於回應、資訊或情緒。

Modern Use

現代延伸

Induce 在測試裡很精準：好的壓力測試不是等問題發生，而是設計條件讓弱點出來。

它比 cause 多一點「引出反應」的感覺，常讓系統或身體像被推到某狀態。
