Extraneous

ek-STRAY-nee-us · UK /ɪkˈstreɪ.ni.əs/ · US /ɪkˈstreɪ.ni.əs/

不是多一點而已，而是多到和核心無關。

Core Idea

extraneous 用來描述「多到和核心無關」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Extraneous

表示外來的、無關的、多餘的。

不是 Irrelevant

irrelevant 可以先說出 不相關；extraneous 則把句子推到「多到和核心無關」這個更細的位置。

Origin

字源

\"不屬於或適當於某物的； 不是內在或本質的，儘管附屬； 外來的\"，1630年代，源自拉丁語 extraneus \"外部的，陌生的\"，字面意思是\"沒有，來自外部\"（作爲名詞，指\"陌生人\"），來自 extra \"在...之外\"（參見 extra-）。是 strange 的同源詞。

像機殼裡多塞了幾根不接任何端點的線，只會增加雜亂

Memory Hook

記憶鉤子

extraneous：像機殼裡多塞了幾根不接任何端點的線，只會增加雜亂

這個畫面之所以有用，是因為它能幫你確認 extraneous 是否真的在談「多到和核心無關」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 extraneous detail 這樣的說法，多半出現在 寫作 / 編輯 的場景；句子真正要說的，就是「多到和核心無關」。

數位 / 專業版

到了 研究 / 分析 的場景，extraneous variable 會更常出現；這裡要說清楚的，正是「多到和核心無關」。

Collocations

常見搭配與語域

常見用法集中在 extraneous detail 和 extraneous variable；這幾個搭配分別落在 寫作 / 編輯 和 研究 / 分析 的場景裡。

extraneous detail 寫作 / 編輯

在 寫作 / 編輯 的語境裡，這個搭配通常就在形容 detail 的狀態或氣質。

extraneous variable 研究 / 分析

在 研究 / 分析 的語境裡，這個搭配通常就在形容 variable 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Extraneous 外來的、無關的、多餘的 當句子需要把「多到和核心無關」說清楚，而不是只留在 不相關 的外圈時。
Irrelevant 不相關 當你只需要先說 不相關，不必把語氣收進「多到和核心無關」時。

Modern Use

現代延伸

現在最常見的就是 extraneous detail 和 extraneous variable 這類說法；它們一出現，通常就在替句子劃清「多到和核心無關」的範圍。

當句子要把「多到和核心無關」說準時，extraneous 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
