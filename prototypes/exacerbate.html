Exacerbate

ig-ZAS-er-bayt · UK /ɪɡˈzæs.ə.beɪt/ · US /ɪɡˈzæs.ɚ.beɪt/

不是造成新問題，而是把原來就有的痛點再往上推。

CEFR
C1

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

exacerbate 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Exacerbate

表示使局勢惡化、加劇症狀或衝突。

不是 Worsen

如果 worsen 已經能讓句子成立，就不必硬換；需要「使局勢惡化、加劇症狀或衝突」時，exacerbate 才有必要。

Origin

字源

\"增加苦澀或惡性，使（感情、衝突等）更加敵對或惡性化\"，1650年代，這是從 exacerbation 反推而來的，或者來自拉丁語 exacerbatus，是 exacerbare 的過去分詞，意爲“激怒，挑釁”。

像傷口本來就在滲，結果又被反覆碰到，紅腫更快擴大

Memory Hook

記憶鉤子

exacerbate：像傷口本來就在滲，結果又被反覆碰到，紅腫更快擴大

這個畫面有用，是因為它先把「把原來就有的痛點再往上推」釘住；回到實際搭配時，就不容易把它和 Worsen 混成一團。

Usage

生活與專業情境

日常版

當人們說 exacerbate the conflict 時，焦點通常就在「把原來就有的痛點再往上推」上，所以這個搭配很能代表 exacerbate 的語感。

數位 / 專業版

到了 健康 / 醫療 的場景，exacerbate symptoms 會更常出現；這裡要說清楚的，正是「把原來就有的痛點再往上推」。

Collocations

常見搭配與語域

常見用法集中在 exacerbate the conflict 和 exacerbate symptoms；這幾個搭配分別落在 人際 / 公共 和 健康 / 醫療 的場景裡。

exacerbate the conflict 人際 / 公共

在 人際 / 公共 的語境裡，這個搭配會把動作直接落在 the conflict 上。

exacerbate symptoms 健康 / 醫療

在 健康 / 醫療 的語境裡，這個搭配會把動作直接落在 symptoms 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Exacerbate 使局勢惡化、加劇症狀或衝突 當較普通的說法太鬆，無法交代 動作是否真的落地 時。
Worsen 惡化 如果上下文還沒有給出足夠理由支撐 exacerbate，先用 worsen。

Modern Use

現代延伸

現在最常見的就是 exacerbate the conflict 和 exacerbate symptoms 這類說法；它們一出現，通常就在替句子劃清「把原來就有的痛點再往上推」的範圍。

當句子要把「把原來就有的痛點再往上推」說準時，exacerbate 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
