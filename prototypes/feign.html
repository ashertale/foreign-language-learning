Feign

FAYN · UK /feɪn/ · US /feɪn/

不是真的感受，而是演出來讓人相信。

Core Idea

feign 最值得保留的語感，是它讓「假裝、佯裝某種情緒、病痛或興趣」不再只是模糊大意。

Meaning

簡短定義

Feign

表示假裝、佯裝某種情緒、病痛或興趣。

不是 Pretend

把它們分開記：pretend 先保留大方向，feign 負責把邊界收乾淨。

Origin

字源

feign 在英語裡可追到 A 17c. respelling of fain；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示假裝、佯裝某種情緒、病痛或興趣」的用法。

像臉上貼了一層臨時表情，底下真實的神色還藏著

Memory Hook

記憶鉤子

feign：像臉上貼了一層臨時表情，底下真實的神色還藏著

這個畫面能幫你把 feign 和 Pretend 分開，因為它把「演出來讓人相信」那條界線變得可見。

Usage

生活與專業情境

日常版

像 feign ignorance 這樣的說法，多半出現在 人際 / 溝通 的場景；句子真正要說的，就是「演出來讓人相信」。

數位 / 專業版

到了 敘事 / 表演 的場景，feign surprise 會更常出現；這裡要說清楚的，正是「演出來讓人相信」。

Collocations

常見搭配與語域

常見用法集中在 feign ignorance 和 feign surprise；這幾個搭配分別落在 人際 / 溝通 和 敘事 / 表演 的場景裡。

feign ignorance 人際 / 溝通

在 人際 / 溝通 的語境裡，這個搭配會把動作直接落在 ignorance 上。

feign surprise 敘事 / 表演

在 敘事 / 表演 的語境裡，這個搭配會把動作直接落在 surprise 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 人際 / 溝通、敘事 / 表演、日常 / 情境 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
