Impromptu

im-PROMP-too · UK /ɪmˈprɒmp.tjuː/ · US /ɪmˈprɑːmp.tuː/

不是隨便，而是沒有事先準備卻立刻成形。

Core Idea

impromptu 的核心是把「即興、臨時起意、當場發生」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Impromptu

表示即興、臨時起意、當場發生。

不是 Spontaneous

把它們分開記：spontaneous 先保留大方向，impromptu 負責把邊界收乾淨。

→
看它是否只是 自發
→
再決定是否需要 impromptu

Origin

字源

1660年代，來自法語 impromptu（1650年代），源自拉丁語 in promptu「準備好」，由 in-「進入、在、於」的同化形式（來自原始印歐語詞根 *en「在」）+ promptu，promptus 的奪格「準備好的；呈現的，提出的」，來自 promere 的過去分詞「提出」，由 pro「在前、向前、為了」（參見 pro-）+ emere「獲得」（來自原始印歐語詞根 *em-「取得，分配」）。從1764年作為形容詞使用；作為名詞從1680年代開始使用。

像原本沒打算演講，但話題一來，你就站起來說了

Memory Hook

記憶鉤子

impromptu：像原本沒打算演講，但話題一來，你就站起來說了

能用這個畫面回到「即興、臨時起意、當場發生」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 impromptu meeting 這樣的說法，多半出現在 工作 / 日常 的場景；句子真正要說的，就是「沒有事先準備卻立刻成形」。

數位 / 專業版

到了 簡報 / 表達 的場景，impromptu speech 會更常出現；這裡要說清楚的，正是「沒有事先準備卻立刻成形」。

Collocations

常見搭配與語域

常見用法集中在 impromptu meeting 和 impromptu speech；這幾個搭配分別落在 工作 / 日常 和 簡報 / 表達 的場景裡。

impromptu meeting 工作 / 日常

在 工作 / 日常 的語境裡，這個搭配通常就在形容 meeting 的狀態或氣質。

impromptu speech 簡報 / 表達

在 簡報 / 表達 的語境裡，這個搭配通常就在形容 speech 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Impromptu 即興、臨時起意、當場發生 當搭配和語境都已經指向「沒有事先準備卻立刻成形」，這個字才自然。
Spontaneous 自發 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 工作 / 日常、簡報 / 表達、工程 / 現場 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
