Deficit

DEF-uh-sit · UK /ˈdef.ɪ.sɪt/ · US /ˈdef.ə.sɪt/

不是普通不足，而是和應有水準相比出現缺口。

Core Idea

deficit 是和應有基準相比後露出的缺口。它不是普通少一點，而是差距已經能被當成問題命名。

Meaning

簡短定義

Deficit

指不足額、赤字、缺口或能力低於需求的狀態，常可被量化或和標準比較。

不是 Shortage

shortage 是缺少；deficit 更像拿標準一比後看到差額。

有應有基準
→
實際低於基準
→
缺口被量出

Origin

字源

來自 Latin deficere，意思接近缺少、失敗、未達。

deficere 的未達、缺少感正是核心；記成低於基準的差額。

Memory Hook

記憶鉤子

把 deficit 想成 target line 和 actual line 之間的空白。

那塊空白不是感覺，而是需要被補上的差距。

Usage

生活與專業情境

團隊能力

如果 team 有 test automation deficit，意思不是沒有努力，而是能力基線低於需求。

財務

財務情境下，deficit 不是普通不足，而是和應有水準相比出現缺口。

認知 / 醫學

Attention deficit 指注意力功能上的缺口，不是單純不努力。

Collocations

常見搭配與語域

deficit 常接 budget、attention、skills。搭配會顯示缺口是財務、功能還是能力。

budget deficit 財務 / 政策

支出超過收入，形成赤字。

attention deficit 醫學 / 心理

注意力功能上的不足或困難。

deficit in skills 職場 / 教育

能力相對需求有缺口，需要訓練或補人。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Deficit 赤字、不足額或能力缺口 用在實際狀態低於需求、標準或預期，形成可命名缺口時。
Shortage 短缺 供給不足，常指物資或人力。
Gap 差距 更通用；deficit 更像低於應有水準的不足。

Modern Use

現代延伸

Deficit 能讓問題比 lack 更可討論，因為它通常暗示有一條基準線。

但它也容易帶負面標籤。寫人或團隊時，最好說清 deficit 相對於哪個需求，而不是把人整體貼成不足。
