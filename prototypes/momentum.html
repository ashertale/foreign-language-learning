Momentum

moh-MEN-tum · UK /məˈmen.təm/ · US /moʊˈmen.t̬əm/

不是速度本身，而是事情已經動起來後持續往前的力。

Core Idea

momentum 不是速度本身，而是事情已經動起來後，繼續往前的慣性和推力。

Meaning

簡短定義

Momentum

指動量、勢頭、推進力或持續前進的力量，可用於物理、專案、市場、運動等。

不是 Speed

speed 是速度；momentum 是持續推進的慣性。

Origin

字源

來自 Latin movimentum，和移動、推動相關。

移動、推動的字源是核心；momentum 是動起來後留下的力。

Memory Hook

記憶鉤子

把 momentum 想成專案連續幾個小勝利後，下一個改動變得比較容易。

動起來之後，事情會比較不需要每次從零推。

Usage

生活與專業情境

專案

專案 build momentum 後，小勝利會讓下一個改動更容易發生。

中斷

A project can lose momentum when decisions wait too long between meetings.

市場

Market momentum can attract attention even before fundamentals fully catch up.

Collocations

常見搭配與語域

momentum 常接 build、lose、market。搭配會指出勢頭是被建立、被失去，還是在市場中累積。

build momentum 專案 / 運動 / 商務

建立推進勢頭。

lose momentum 專案 / 競賽

失去推力，進展變慢。

market momentum 投資 / 商務

市場趨勢或買氣形成的推力。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Momentum 動量、推進力或發展勢頭 用在事情已經動起來，且累積出持續推進的力時。
Speed 速度 當下快慢。
Progress 進展 已往前走多少。
Traction 牽引力、初步動能 常指產品或想法開始被市場接受。

Modern Use

現代延伸

Momentum 在專案管理裡很真實。很多計畫不是死於方向錯，而是每次停太久，重啟成本吃掉動能。

保持 momentum 不代表盲目前進；它代表讓下一步不要一直重新點火。
