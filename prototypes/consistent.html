Consistent

kun-SIS-tunt · UK /kənˈsɪs.tənt/ · US /kənˈsɪs.tənt/

不是永遠一樣，而是在同一規則下不互相打架。

Core Idea

consistent 說的是多次結果、規則或說法能互相站得住。它不是完全相同，而是不互相打架。

Meaning

簡短定義

Consistent

形容行為、結果、命名、說法或規則前後一致、穩定，彼此沒有矛盾。

不是 Identical

identical 是完全相同；consistent 是規則與結果能對得起來。

規則被建立
→
多次結果對齊

Origin

字源

與 Latin consistere「站在一起、穩住」有關。

字源的「站在一起」很貼切：consistent 的東西放在一起不會互相推倒。

Memory Hook

記憶鉤子

把 consistent 想成同一個 signal 每次都照同一套規則解讀。

值可以不同，但規則不能一下這樣、一下那樣。

Usage

生活與專業情境

程式碼

Consistent naming 讓 code review 少花時間猜同一概念是不是不同東西。

測試

Consistent results build trust; inconsistent results make people suspect hidden variables。

行為

A consistent manager 不是永遠做同一件事，而是取捨原則能被預期。

Collocations

常見搭配與語域

consistent 常接 behavior、naming、results。搭配裡真正被檢查的是規則是否穩定。

consistent behavior 管理 / 系統

行為模式穩定，讓人能預期。

consistent naming 工程 / 文件

同一概念用同一命名，降低認知負擔。

consistent results 測試 / 研究

結果能重複出現，支持可靠性。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Consistent 前後一致、穩定且不矛盾 用在多處表現不必相同，但必須遵守同一套邏輯時。
Identical 完全相同 強調一模一樣；consistent 允許差異，只要規則對得上。
Coherent 連貫、有整體邏輯 較重論述或系統整體是否說得通。

Modern Use

現代延伸

工程裡的 consistent 常常比 clever 更重要。命名、錯誤處理、log 格式一致，系統才容易被多人維護。

這個字也常用在人：consistent 不代表僵硬，而是讓他人知道你會按什麼原則行動。
