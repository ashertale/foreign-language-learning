Hypothesis

hy-POTH-uh-sis · UK /haɪˈpɒθ.ə.sɪs/ · US /haɪˈpɑːθ.ə.sɪs/

不是結論，而是等待證據考驗的暫時解釋。

Core Idea

hypothesis 是暫時放在桌上的解釋，等證據來測。它不是結論，而是可被淘汰的候選答案。

Meaning

簡短定義

Hypothesis

指假設、假說或暫時解釋，通常應能被測試、驗證或反駁。

不是 Conclusion

conclusion 是結論；hypothesis 是先拿來測的解釋。

現象需要解釋
→
提出可測說法
→
用證據淘汰或保留

Origin

字源

源自 Greek，意思接近「放在下面作為基礎的東西」。

Greek 的「放在下面作基礎」可記成暫時支撐下一步調查的說法。

Memory Hook

記憶鉤子

把 hypothesis 想成 debug 白板上的第一張便利貼。

它的價值不在於看起來聰明，而在於能不能設計測試。

Usage

生活與專業情境

Debug

debug hypothesis 必須能被測試；不能測的說法只會讓討論原地轉。

研究

A

關於

A hypothesis about timing drift should predict what logs would look like if it were true.

Collocations

常見搭配與語域

hypothesis 常接 test、working、about。搭配會提醒你它應該能被證據處理。

test a hypothesis 研究 / debug

用實驗或證據檢驗假設。

working hypothesis 研究 / 分析

暫時採用、方便往下查的假設。

hypothesis about 通用 / 學術

about 後面接假設要解釋的對象。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Hypothesis 假說、待驗證的解釋 用在解釋還未定案，且需要被測試或證據淘汰時。
Conclusion 結論 已經形成的判斷。
Theory 理論 可更成熟、更廣，也可口語指想法。
Assumption 假定 可能未經測試，常被拿來當前提。

Modern Use

現代延伸

Hypothesis 是 debug 的核心衛生習慣。你可以有直覺，但一旦寫成 hypothesis，就要讓它接受測試。

好的 hypothesis 會產生 prediction：如果它是真的，我應該看到什麼？
