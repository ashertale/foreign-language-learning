Abridge

uh-BRIJ · UK /əˈbrɪdʒ/ · US /əˈbrɪdʒ/

不是隨便刪短，而是把主幹留下來後壓縮篇幅。

Core Idea

abridge 用來描述「把主幹留下來後壓縮篇幅」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Abridge

表示刪節、縮編文字或內容，同時保留核心結構。

不是 Summarize

summarize 可以先說出 摘要整理；abridge 則把句子推到「把主幹留下來後壓縮篇幅」這個更細的位置。

Origin

字源

abridge 在英語裡可追到 c. 1300；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示刪節、縮編文字或內容，同時保留核心結構」的用法。

Memory Hook

記憶鉤子

abridge：像把長河引到較窄的渠道裡，水量少了，但流向還在

這個畫面能幫你把 abridge 和 Summarize 分開，因為它把「把主幹留下來後壓縮篇幅」那條界線變得可見。

Usage

生活與專業情境

日常版

像 abridged edition 這樣的說法，多半出現在 出版 / 編輯 的場景；句子真正要說的，就是「把主幹留下來後壓縮篇幅」。

數位 / 專業版

到了 寫作 / 教學 的場景，abridge the text 會更常出現；這裡要說清楚的，正是「把主幹留下來後壓縮篇幅」。

Collocations

常見搭配與語域

常見用法集中在 abridged edition 和 abridge the text；這幾個搭配分別落在 出版 / 編輯 和 寫作 / 教學 的場景裡。

abridged edition 出版 / 編輯

在 出版 / 編輯 的語境裡，這個搭配最容易看出「把主幹留下來後壓縮篇幅」實際怎麼落在句子裡。

abridge the text 寫作 / 教學

在 寫作 / 教學 的語境裡，這個搭配會把動作直接落在 the text 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Abridge 刪節、縮編文字或內容，同時保留核心結構 當句子需要把「把主幹留下來後壓縮篇幅」說清楚，而不是只留在 摘要整理 的外圈時。
Summarize 摘要整理 當你只需要先說 摘要整理，不必把語氣收進「把主幹留下來後壓縮篇幅」時。

Modern Use

現代延伸

現在最常見的就是 abridged edition 和 abridge the text 這類說法；它們一出現，通常就在替句子劃清「把主幹留下來後壓縮篇幅」的範圍。

當句子要把「把主幹留下來後壓縮篇幅」說準時，abridge 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
