Illicit

ih-LIS-it · UK /ɪˈlɪs.ɪt/ · US /ɪˈlɪs.ɪt/

不是偷偷而已，而是本身就不被允許。

Core Idea

illicit 是不被允許的暗處交易或行為，常帶法律、道德或制度違規的陰影。

Meaning

簡短定義

Illicit

形容非法、不正當、違規或未被允許的。

不是 Illegal

illegal 是違法；illicit 像違法或不正當行為躲在暗處。

規則或禁令存在
→
行為越過允許範圍
→
隱蔽或不正當感出現

Memory Hook

記憶鉤子

把 illicit access 想成不是正常權限開錯，而是本來不該進去的人進去了。

illicit 的核心是 forbidden。

Collocations

常見搭配與語域

illicit 常修飾 trade、payment、access；搭配多半和違規利益或未授權行為有關。

illicit trade 法律 / 經濟

非法交易。

illicit payment 合規 / 商務

不正當付款。

illicit access 資安 / 法規

未授權存取。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Illicit 非法違規 用在行為不只是錯，而是處在禁區或暗處時。
Illegal 非法 重法律明文；illicit 也可含不正當、見不得光。
Unauthorized 未授權 偏權限；illicit 道德與法律陰影更廣。

Modern Use

現代延伸

Illicit 很常見於 trade、drugs、payments、access。

它通常比 illegal 更有秘密和不正當的味道。
