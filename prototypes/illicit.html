Illicit

ih-LIS-it · UK /ɪˈlɪs.ɪt/ · US /ɪˈlɪs.ɪt/

不是偷偷而已，而是本身就不被允許。

Core Idea

illicit 的好處在於精度：它把情境、語氣和搭配一起推向「本身就不被允許」。

Meaning

簡短定義

Illicit

表示非法、不正當、違規。

不是 Illegal

illegal 可以先說出 非法；illicit 則把句子推到「本身就不被允許」這個更細的位置。

Origin

字源

大約在1500年，源自於14世紀的古法語單詞 illicite \"違法的，被禁止的\"，來自拉丁語的單詞 illicitus \"不允許的，違法的，非法的\"，由 in- \"不，相反\"（參見 in- (1)）以及 licitus \"合法的\"，過去分詞形式爲 licere \"被允許\"（參見 licence (n.)）所組成。

像後門不是剛好沒人看，而是從一開始就不該被打開

Memory Hook

記憶鉤子

illicit：像後門不是剛好沒人看，而是從一開始就不該被打開

這個畫面能幫你把 illicit 和 Illegal 分開，因為它把「本身就不被允許」那條界線變得可見。

Usage

生活與專業情境

日常版

像 illicit trade 這樣的說法，多半出現在 公共 / 法規 的場景；句子真正要說的，就是「本身就不被允許」。

數位 / 專業版

到了 商務 / 合規 的場景，illicit payment 會更常出現；這裡要說清楚的，正是「本身就不被允許」。

Collocations

常見搭配與語域

常見用法集中在 illicit trade 和 illicit payment；這幾個搭配分別落在 公共 / 法規 和 商務 / 合規 的場景裡。

illicit trade 公共 / 法規

在 公共 / 法規 的語境裡，這個搭配通常就在形容 trade 的狀態或氣質。

illicit payment 商務 / 合規

在 商務 / 合規 的語境裡，這個搭配通常就在形容 payment 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Illicit 非法、不正當、違規 當句子需要把「本身就不被允許」說清楚，而不是只留在 非法 的外圈時。
Illegal 非法 當你只需要先說 非法，不必把語氣收進「本身就不被允許」時。

Modern Use

現代延伸

現在最常見的就是 illicit trade 和 illicit payment 這類說法；它們一出現，通常就在替句子劃清「本身就不被允許」的範圍。

當句子要把「本身就不被允許」說準時，illicit 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
