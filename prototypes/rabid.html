Rabid

RAB-id · UK /ˈræb.ɪd/ · US /ˈræb.ɪd/

不是熱情，而是熱到帶攻擊性。

Core Idea

rabid 把熱情推到失控和攻擊性；它常用來批評狂熱支持或敵意。

Meaning

簡短定義

Rabid

形容狂熱、激烈到不理性，常帶攻擊性。

不是 Fervent

fervent 可以是正面的熱誠；rabid 則常帶失衡與攻擊性。

Origin

字源

rabid 來自拉丁語 rabidus「狂怒的、發狂的」，本來就和狂犬病那種失控狀態連在一起；所以比喻成 fan base 或 opposition 時，也不是熱情而已，而是熱到帶攻擊性。

Memory Hook

記憶鉤子

把 rabid 想成不是火旺，而是火旺到開始亂噴。

它批評的不是投入，而是投入失去比例。

Usage

生活與專業情境

支持者

如果一群支持者的熱情已經帶出攻擊性，rabid 的語感就到了。

評論

有些反對聲浪不是強烈而已，而是近乎 rabid。

Collocations

常見搭配與語域

rabid fan base 媒體 / 文化

支持、反對或情緒強度高到近乎失控。

rabid opposition 政治 / 評論

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Rabid 狂熱失控 用在支持、反對或情緒強度高到近乎失控時。
Fervent 熱切、真誠而投入 若重點是深切熱誠，不帶失控感，用 fervent 更好。

Modern Use

現代延伸

rabid 在現代評論裡常用來寫狂熱過頭、甚至帶攻擊性的支持或反對。
