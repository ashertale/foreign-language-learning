Ambivalent

am-BIV-uh-luhnt · UK /æmˈbɪv.ə.lənt/ · US /æmˈbɪv.ə.lənt/

不是不知道，而是兩邊都各有吸引力或抗拒點，心裡拉扯。

Core Idea

ambivalent 的核心是把「對同一件事同時有正反兩種感受，難以爽快表態」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Ambivalent

表示對同一件事同時有正反兩種感受，難以爽快表態。

不是 Uncertain

Uncertain 可以先說大方向；ambivalent 用在你要把「兩邊都各有吸引力或抗拒點，心裡拉扯」這條語氣邊界說得更準的時候。

Origin

字源

\"對某事物同時存在矛盾的情感或想法\"，1916年，最初是心理學術語； 是從 ambivalence 中反推出來的。1929年開始普遍使用。

像腳踩在岔路口的中間，兩邊都看得見，也都還放不下

Memory Hook

記憶鉤子

ambivalent：像腳踩在岔路口的中間，兩邊都看得見，也都還放不下

這個畫面有用，是因為它先把「兩邊都各有吸引力或抗拒點，心裡拉扯」釘住；回到實際搭配時，就不容易把它和 Uncertain 混成一團。

Usage

生活與專業情境

日常版

像 feel ambivalent 這樣的說法，多半出現在 情緒 / 日常 的場景；句子真正要說的，就是「兩邊都各有吸引力或抗拒點，心裡拉扯」。

數位 / 專業版

到了 溝通 / 回應 的場景，ambivalent response 會更常出現；這裡要說清楚的，正是「兩邊都各有吸引力或抗拒點，心裡拉扯」。

Collocations

常見搭配與語域

常見用法集中在 feel ambivalent 和 ambivalent response；這幾個搭配分別落在 情緒 / 日常 和 溝通 / 回應 的場景裡。

feel ambivalent 情緒 / 日常

在 情緒 / 日常 的語境裡，這個搭配最容易看出「兩邊都各有吸引力或抗拒點，心裡拉扯」實際怎麼落在句子裡。

ambivalent response 溝通 / 回應

在 溝通 / 回應 的語境裡，這個搭配通常就在形容 response 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Ambivalent 對同一件事同時有正反兩種感受，難以爽快表態 用在你想讓讀者看到「對同一件事同時有正反兩種感受，難以爽快表態」這個較窄邊界的時候。
Uncertain 不確定 用在大方向比細邊界重要的句子；它讓意思先站住，不急著精修。

Modern Use

現代延伸

現在最常見的就是 feel ambivalent 和 ambivalent response 這類說法；它們一出現，通常就在替句子劃清「兩邊都各有吸引力或抗拒點，心裡拉扯」的範圍。

比起 uncertain，ambivalent 更適合用在你想直接點出「對同一件事同時有正反兩種感受，難以爽快表態」的時候。
