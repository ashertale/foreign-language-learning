Reticent

RET-uh-sənt · UK /ˈret.ɪ.sənt/ · US /ˈret̬.ə.sənt/

不是害羞，而是不願把話全部攤開。

Core Idea

reticent 是知道可以說更多，卻選擇收著；它比 shy 更重保留和不願揭露。

Meaning

簡短定義

Reticent

形容寡言、保留，不願透露想法或細節。

不是 Shy

shy 偏社交膽怯；reticent 更像有意識地收住話。

知道可以多說
→
卻選擇收著
→
資訊只露一部分

Origin

字源

reticent 來自拉丁語 reticere「保持沉默」，字面就是往回收住不說；所以它不是沒內容，而是不肯多透露。

Memory Hook

記憶鉤子

把 reticent 想成抽屜沒有鎖，但人就是只拉開一條縫。

這個字寫的是保留，不一定是軟弱。

Usage

生活與專業情境

人際

有些人不是沒想法，而是對自己的經歷特別 reticent。

會議

如果一個團隊成員只願意透露必要資訊，他可能顯得很 reticent。

Collocations

常見搭配與語域

reticent about the details 人際 / 訪談

人刻意少說、保留、或不願完全打開。

reticent manner 敘事 / 評論

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Reticent 寡言保留 用在人刻意少說、保留、或不願完全打開時。
Shy 害羞、不敢表現 若重點是膽怯，不是保留，用 shy 更自然。

Modern Use

現代延伸

reticent 在人物描寫與訪談語境很好用，因為它能把『不多說』寫得更有主動性。
