Opaque

不是深奧而已，而是你根本看不進去。

Core Idea

opaque 的核心是把「不透明，或制度、說法缺乏可理解性」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Opaque

表示不透明，或制度、說法缺乏可理解性。

不是 Unclear

Unclear 可以先說大方向；opaque 用在你要把「你根本看不進去」這條語氣邊界說得更準的時候。

Origin

字源

15世紀初， opake，意爲“黑暗的，陰暗的”（現已過時），源自拉丁語 opacus，意爲“有陰影的，在陰影中的，陰暗的，昏暗的，模糊的”，其起源不明。在1650年左右受到法語 opaque（約1500年）的影響，拼寫發生了變化。意爲“不透光的”是從1640年代開始的。比喻意義上的“模糊的，難以理解的”源於1761年。

Usage

生活與專業情境

日常版

像 opaque process 這樣的說法，多半出現在 組織 / 制度 的場景；句子真正要說的，就是「你根本看不進去」。

數位 / 專業版

到了 材料 / 視覺 的場景，opaque material 會更常出現；這裡要說清楚的，正是「你根本看不進去」。

Collocations

常見搭配與語域

常見用法集中在 opaque process 和 opaque material；這幾個搭配分別落在 組織 / 制度 和 材料 / 視覺 的場景裡。

opaque process 組織 / 制度

opaque material 材料 / 視覺

在 材料 / 視覺 的語境裡，這個搭配通常就在形容 material 的狀態或氣質。

Neighbors

Modern Use

現代延伸

現在最常見的就是 opaque process 和 opaque material 這類說法；它們一出現，通常就在替句子劃清「你根本看不進去」的範圍。

比起 unclear，opaque 更適合用在你想直接點出「不透明，或制度、說法缺乏可理解性」的時候。
