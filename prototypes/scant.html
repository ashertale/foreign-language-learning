Scant

SKANT · UK /skænt/ · US /skænt/

不是少，而是少到快不夠用。

CEFR
C1
Zipf Frequency
2.52
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

scant 的少帶緊繃感：數量不只是偏低，而是接近不夠用。

Meaning

簡短定義

Scant

形容數量很少、勉強不足，常讓人感到不夠。

不是 Little

little 只是少；scant 更有『少得不太夠』的緊張感。

數量先偏低
→
離夠用只差一線
→
整體開始帶緊張感

Origin

字源

scant 來自北歐語系裡「短、少、不足」的概念，先是 quantity 不夠；所以今天它不只是 small，而是離夠用還差一截。

Memory Hook

記憶鉤子

把 scant 想成布不是沒有，但只夠勉強蓋住。

這個字常把『不足邊緣』寫得很明顯。

Usage

生活與專業情境

證據

如果資料少到撐不起結論，就會被形容為 scant evidence。

時間

當時間不是少，而是少得讓每一步都得縮，scant 很好用。

Collocations

常見搭配與語域

scant evidence 研究 / 法律

證據、時間、衣料或資源少到邊邊緊繃。

scant resources 管理 / 報導

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Scant 少得發緊 用在證據、時間、衣料或資源少到邊邊緊繃時。
Little 不多、數量少 若只要一般地說不多，用 little 或 few 更中性。

Modern Use

現代延伸

scant 常用於正式寫作，因為它比 little 更能表達『少到不太夠』。
