Augment

awg-MENT · UK /ɔːɡˈment/ · US /ɑːɡˈment/

不是替換原本的東西，而是在它上面加能力、加量或加支援。

Core Idea

augment 用來描述在既有系統、能力或資源上補強，使整體更有力量。

Meaning

簡短定義

Augment

表示增加、補強或擴充某個原本已存在的事物。

不是 Replace

replace 是換掉；augment 是保留原本，再加一層能力。

原本能力存在
→
額外資源加入
→
整體被補強

Origin

字源

augment 來自拉丁語 augere，意思是增加、使變大。

它像替工具加上附件，不是丟掉工具重買。

Memory Hook

記憶鉤子

augment 是在原本的力量旁邊再接上一股力量。

這個字常帶工程感：不是全盤推翻，而是加模組、加資料、加能力。

Usage

生活與專業情境

日常版

你可以用筆記 app augment your memory，不是取代記憶，而是替它補一層外部支援。

數位 / 專業版

AI tools can augment engineers by handling repetitive checks，讓人把注意力放在判斷與架構上。

Collocations

常見搭配與語域

Augment 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

augment capacity 營運 / 系統

增加可承受的量。

augment human judgment AI / 決策

補強人的判斷，而不是取代。

augment a dataset 資料 / ML

擴充資料量或多樣性。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Augment 在既有基礎上增加或補強 談能力、資源、資料、系統容量或工具支援時
Replace 用新的東西取代舊的 原本的東西被移除或換掉時

Modern Use

現代延伸

現代科技討論常說 augmented intelligence，重點正是讓工具補強人的能力，而不是把人從流程裡刪掉。
