Embitter

em-BIT-er · UK /ɪmˈbɪt.ər/ · US /ɪmˈbɪt̬.ɚ/

不是只讓人難過，而是讓心裡整體變苦。

Core Idea

embitter 的好處在於精度：它把情境、語氣和搭配一起推向「讓心裡整體變苦」。

Meaning

簡短定義

Embitter

表示使人怨恨、憤懣或因受傷而性情轉苦。

不是 Upset

如果 upset 已經能讓句子成立，就不必硬換；需要「使人怨恨、憤懣或因受傷而性情轉苦」時，embitter 才有必要。

先遇到 embitter a generation
→
看它是否只是 使難過
→
再決定是否需要 embitter

Origin

字源

“使變苦”，約於1600年，源自 bitter （形容詞） + em- （動詞）。現在字面意義上的用法已罕見； 1630年代開始出現了“使苦澀或不快樂”的比喻意義。

像茶本來溫熱可入口，卻被滴進太多苦汁，整杯味道都變了

Memory Hook

記憶鉤子

embitter：像茶本來溫熱可入口，卻被滴進太多苦汁，整杯味道都變了

能用這個畫面回到「使人怨恨、憤懣或因受傷而性情轉苦」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 embitter a generation 時，焦點通常就在「讓心裡整體變苦」上，所以這個搭配很能代表 embitter 的語感。

數位 / 專業版

到了 情緒 / 敘事 的場景，embittered by loss 會更常出現；這裡要說清楚的，正是「讓心裡整體變苦」。

Collocations

常見搭配與語域

常見用法集中在 embitter a generation 和 embittered by loss；這幾個搭配分別落在 公共 / 社會 和 情緒 / 敘事 的場景裡。

embitter a generation 公共 / 社會

在 公共 / 社會 的語境裡，這個搭配會把動作直接落在 a generation 上。

embittered by loss 情緒 / 敘事

在 情緒 / 敘事 的語境裡，這個搭配最容易看出「讓心裡整體變苦」實際怎麼落在句子裡。

Neighbors

對立與鄰近概念

Embitter 使人怨恨、憤懣或因受傷而性情轉苦 當較普通的說法太鬆，無法交代 動作是否真的落地 時。
Upset 使難過 如果上下文還沒有給出足夠理由支撐 embitter，先用 upset。

Modern Use

現代延伸

現在最常見的就是 embitter a generation 和 embittered by loss 這類說法；它們一出現，通常就在替句子劃清「讓心裡整體變苦」的範圍。

當句子要把「讓心裡整體變苦」說準時，embitter 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
