Perverse

per-VERS · UK /pəˈvɜːs/ · US /pɚˈvɝːs/

不是奇怪，而是故意往不該去的方向拗。

Core Idea

perverse 描述一種「故意拗反」的狀態。它不只是在貼表面標籤，而是把氣壓、方向或隱含張力一起帶進來。

Meaning

簡短定義

Perverse

形容一種「故意拗反」的狀態、氣質或外觀。

不是 Contrary

contrary 是唱反調；perverse 更強，像故意往壞方向拗。

明明看得見更好的路
→
卻故意往反方向扭
→
結果常更壞

Origin

字源

perverse 經 Old French / Latin 傳入時，本義就是 turned the wrong way、扭向不該去的方向；所以它不是普通不同，而是明明知道路卻偏要反著來。

Memory Hook

記憶鉤子

把 perverse 想成門明明往外推就開，卻偏偏硬往裡撞。

它帶著一點故意、甚至自找麻煩的味道。

Usage

生活與專業情境

決策

如果制度獎勵的結果和原本目標相反，就常被說成帶有 perverse incentives。

性格

有些人不是單純不合作，而是帶著一種 perverse 的拗勁。

Modern Use

現代延伸
