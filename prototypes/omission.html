Omission

oh-MISH-un · UK /əʊˈmɪʃ.ən/ · US /oʊˈmɪʃ.ən/

不是寫錯，而是該出現的東西缺席。

Core Idea

omission 不是寫錯，而是該出現的資訊、步驟或責任缺席了。

Meaning

簡短定義

Omission

指遺漏、省略或未包含某本該存在的部分。

不是 Error

error 是錯；omission 是少了某個本該存在的部分。

預期某物存在
→
實際缺席
→
造成誤解或風險

Origin

字源

來自 Latin omittere，有放過、略去的意思。

字源裡有略過、放掉的動作；omission 的畫面是該在場的東西沒有出現。

Memory Hook

記憶鉤子

把 omission 想成 release note 少寫一條限制，support 於是以為限制不存在。

沒寫的東西也會造成後果。

Usage

生活與專業情境

Release note

release note 的 omission 可能讓 support 以為某個限制不存在。

細節

在細節這類情境裡，omission 的重點是：不是寫錯，而是該出現的東西缺席。

重大遺漏

A material omission is serious because the missing fact would affect judgment. 這裡放在重大遺漏情境時，是在說問題來自某必要部分缺席，而不是已有內容錯誤。

Collocations

常見搭配與語域

omission 常接 detail、material、accidental。搭配會指出遺漏的內容、嚴重性和是否故意。

omission of detail 文件 / 法律

細節遺漏，可能造成誤解。

material omission 法律 / 商務

重大遺漏，足以影響判斷。

accidental omission 通用 / 文件

非故意的遺漏。

Neighbors

Modern Use

現代延伸

Omission 在文件和合規裡很重要，因為沉默也可能誤導。

工程文件最怕 omissions around limits、known issues、rollback steps。讀者會根據缺席資訊做錯假設。
