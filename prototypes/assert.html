Assert

uh-SURT · UK /əˈsɜːt/ · US /əˈsɝːt/

不是輕輕提出，而是帶著確定感把主張放到桌上。

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

assert 用來描述明確宣稱、堅持權利或在程式中檢查某個條件必須成立。

Meaning

簡短定義

Assert

表示明確主張、斷言或堅持某事為真，也可指維護權利或地位。

不是 Suggest

suggest 留有試探空間；assert 是把立場清楚站穩。

形成判斷
→
清楚說出主張
→
要求對方正視

Origin

字源

assert 來自拉丁語 asserere，有聲明、主張或宣稱權利的脈絡。

它像把旗子插在地上：這是我的立場，不是隨口猜測。

Memory Hook

記憶鉤子

assert 是把模糊意見推成可被檢驗的主張。

在程式裡 assert 也很貼切：條件若不成立，世界就不該繼續假裝正常。

Usage

生活與專業情境

日常版

當別人誤解你時，你可能需要 assert your boundaries，而不是只期待對方猜到。

數位 / 專業版

測試與除錯裡，assert a condition 是明確告訴系統：這個前提必須成立。

Collocations

常見搭配與語域

Assert 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

assert a claim 論證 / 法律

清楚提出一個主張。

assert one's rights 法律 / 人際

明確維護自己的權利。

assert a condition 程式 / 測試

檢查某個前提必須成立。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Assert 明確而有力量地提出主張 談論證、權利、測試條件或清楚立場時
Suggest 提出可能性或建議 語氣還在試探、沒有要斷言時

Modern Use

現代延伸

在工程語境中，assert 同時是語言動作與程式動作；它把假設變成可見、可失敗、可修正的邊界。
