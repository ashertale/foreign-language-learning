Enigma

ih-NIG-muh · UK /ɪˈnɪɡ.mə/ · US /ɪˈnɪɡ.mə/

不是一個小問題，而是整體都透著解不開的感覺。

Core Idea

enigma 不只是 Mystery 的近義替代；它用來描述「整體都透著解不開的感覺」這種更窄、更準確的情境。

Meaning

簡短定義

Enigma

表示難解之謎，或難以看透的人事物。

不是 Mystery

把它們分開記：mystery 先保留大方向，enigma 負責把邊界收乾淨。

Origin

字源

1530年代，“用晦澀的語言或形式掩蓋隱藏的含義或已知事物的陳述”，早期爲 enigmate（15世紀中期），源自拉丁語 aenigma “謎語”，來自希臘語 ainigma（複數 ainigmata）“晦澀的話，謎語”，來自 ainissesthai “說晦澀的話，說謎語”，來自 ainos “故事，傳說； 諺語，格言”； 根據 Liddell & Scott 的說法，這是一個詩意和伊奧尼亞語的詞彙，起源不明。英語中“對觀察者來說無法解釋的任何事物”的一般意義始於大約1600年。

像窗內有人影在走動，你看見輪廓很多次，卻始終看不清臉

Memory Hook

記憶鉤子

enigma：像窗內有人影在走動，你看見輪廓很多次，卻始終看不清臉

能用這個畫面回到「難解之謎，或難以看透的人事物」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 remain an enigma 這樣的說法，多半出現在 人物 / 描寫 的場景；句子真正要說的，就是「整體都透著解不開的感覺」。

數位 / 專業版

到了 公共 / 分析 的場景，political enigma 會更常出現；這裡要說清楚的，正是「整體都透著解不開的感覺」。

Collocations

常見搭配與語域

常見用法集中在 remain an enigma 和 political enigma；這幾個搭配分別落在 人物 / 描寫 和 公共 / 分析 的場景裡。

remain an enigma 人物 / 描寫

在 人物 / 描寫 的語境裡，前面的 remain an 會把這個概念限定到更具體的場景。

political enigma 公共 / 分析

在 公共 / 分析 的語境裡，前面的 political 會把這個概念限定到更具體的場景。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Enigma 難解之謎，或難以看透的人事物 當搭配和語境都已經指向「整體都透著解不開的感覺」，這個字才自然。
Mystery 謎 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 人物 / 描寫、公共 / 分析、敘事 / 評論 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
