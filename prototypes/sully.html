Sully

SUL-ee · UK /ˈsʌl.i/ · US /ˈsʌl.i/

不是弄髒而已，而是把原本的潔淨或名聲抹上一層污。

Core Idea

sully 把原本乾淨的名聲、形象或事物沾上一層污點，之後再看就不一樣。

Meaning

簡短定義

Sully

玷污、弄髒名聲、形象或原本清白的事物。

不是 Stain

stain 可以是物理污漬；sully 更常延伸到名譽與象徵。

原本有一層潔淨感
→
污點被抹上去
→
之後看它都帶著那層髒

Origin

字源

sully 16 世紀先指把東西弄髒、染污，可能經法語進來；後來很自然就擴成把名聲、形象或紀錄抹黑。

Memory Hook

記憶鉤子

把 sully 想成白襯衫不是沾灰，而是被甩上一道很難忽略的墨。

這個字常把物理髒轉成名聲上的髒。

Usage

生活與專業情境

名聲

如果一件醜聞把多年建立的信任弄髒了，就很像在 sully that reputation。

記憶

某些細節不一定改變事實，但會 sully 原本乾淨的回憶。

Collocations

常見搭配與語域

sully a reputation 媒體 / 人際

名聲、記憶、形象或象徵被弄髒。

sully the memory 敘事 / 評論

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Sully 玷污抹黑 用在名聲、記憶、形象或象徵被弄髒時。
Stain 留下污點或痕跡 若是具體污漬，用 stain 更直接。

Modern Use

現代延伸

sully 在名譽、品牌與象徵書寫裡很好用，因為它能把『變髒』延伸成『被玷污』。
