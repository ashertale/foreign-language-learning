Fabricate

FAB-ri-kate · UK /ˈfæb.rɪ.keɪt/ · US /ˈfæb.rə.keɪt/

不是普通製作，而是建造出來；在負面語境裡也指捏造。

Core Idea

fabricate 可以是把材料製造成實物，也可以是把假的故事或證據捏造成看似存在的東西。

Meaning

簡短定義

Fabricate

表示製造、組裝，或在負面語境中捏造、偽造資訊、故事或證據。

不是 Make

make 很廣；fabricate 可指實體製造，也可指把假的故事做出來。

材料或說法被組合
→
形成一個成品
→
判斷真實性

Origin

字源

來自 Latin fabricare，和製作、工匠工作有關。

工匠製作的字源提供中性義；現代負面義是「把假的東西做出來」。

Memory Hook

記憶鉤子

把 fabricate 想成工廠做零件，也想成有人把 evidence 做假。

同一個字在材料和真實性之間切換。

Collocations

常見搭配與語域

fabricate 的搭配會告訴你它是物理製造還是道德問題：parts、evidence、story。

fabricate parts 製造 / 工程

製造零件，通常是實體加工。

fabricate evidence 法律 / 調查

偽造證據，明確負面。

fabricated story 日常 / 新聞

捏造的故事，不是真實經驗。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fabricate 製造、建構，或捏造不實內容 用在實體製造，或負面地說某資訊被捏造出來時。
Make 製作 最通用。
Manufacture 製造 偏工業生產。
Forge 偽造；鍛造 偽造義常用於文件、簽名，也可指金屬鍛造。

Modern Use

現代延伸

Fabricate 的雙義很實用：fabricated bracket 和 fabricated evidence 完全不同語氣。

讀這個字時先看受詞。受詞是 parts，通常中性；受詞是 story/evidence，幾乎一定有真實性問題。
