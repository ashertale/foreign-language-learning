Fabricate

FAB-ri-kayt · UK /ˈfæb.rɪ.keɪt/ · US /ˈfæb.rə.keɪt/

不是想像，而是編出來後拿去當真。

Core Idea

fabricate 最值得保留的語感，是它讓「捏造故事、證據或理由」不再只是模糊大意。

Meaning

簡短定義

Fabricate

表示捏造故事、證據或理由。

不是 Invent

把它們分開記：invent 先保留大方向，fabricate 負責把邊界收乾淨。

Origin

字源

\"製作，製造，建造\"的意思，起源於15世紀中葉，源自拉丁語 fabricatus，是 fabricare 的過去分詞，意爲\"製作，構建，建造\"，源自 fabrica（參見 fabric）。在\"撒謊（等）\"的貶義意義上，它最早見於1779年。

像空白紙上硬畫出指紋，再說那一直都在

Memory Hook

記憶鉤子

fabricate：像空白紙上硬畫出指紋，再說那一直都在

這個畫面有用，是因為它先把「編出來後拿去當真」釘住；回到實際搭配時，就不容易把它和 Invent 混成一團。

Usage

生活與專業情境

日常版

像 fabricate evidence 這樣的說法，多半出現在 法務 / 調查 的場景；句子真正要說的，就是「編出來後拿去當真」。

數位 / 專業版

到了 人際 / 對話 的場景，fabricate a story 會更常出現；這裡要說清楚的，正是「編出來後拿去當真」。

Collocations

常見搭配與語域

常見用法集中在 fabricate evidence 和 fabricate a story；這幾個搭配分別落在 法務 / 調查 和 人際 / 對話 的場景裡。

fabricate evidence 法務 / 調查

在 法務 / 調查 的語境裡，這個搭配會把動作直接落在 evidence 上。

fabricate a story 人際 / 對話

在 人際 / 對話 的語境裡，這個搭配會把動作直接落在 a story 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fabricate 捏造故事、證據或理由 當搭配和語境都已經指向「編出來後拿去當真」，這個字才自然。
Invent 編造 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 法務 / 調查、人際 / 對話、媒體 / 查核 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
