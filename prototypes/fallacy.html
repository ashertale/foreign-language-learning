Fallacy

FAL-uh-see · UK /ˈfæl.ə.si/ · US /ˈfæl.ə.si/

不是單純錯誤，而是推理看似合理、其實有漏洞。

Core Idea

fallacy 不是任何錯誤，而是推理本身看似順、實際上藏了漏洞。

Meaning

簡短定義

Fallacy

指謬誤，尤其是推理結構、前提或因果判斷上的錯誤。

不是 Mistake

mistake 是錯；fallacy 特別指推理結構有問題。

論點看似順
→
隱藏錯誤前提
→
結論不成立

Origin

字源

來自 Latin fallacia，有欺騙、誤導的意思。

欺騙、誤導的字源提醒你：fallacy 常讓人覺得合理，所以更危險。

Memory Hook

記憶鉤子

把 fallacy 想成 debug 時 correlation 看起來太誘人，讓人忘了查 causation。

錯不在資料存在，而在推理跳太快。

Usage

生活與專業情境

Debug

把 correlation 當 causation 是常見 fallacy，尤其在 debug 時很誘人。

論證

A logical fallacy can make a confident argument collapse.

常見錯法

常見錯法情境下，fallacy 不是單純錯誤，而是推理看似合理、其實有漏洞。

Collocations

常見搭配與語域

fallacy 常接 logical、common、fallacy of。搭配會指向哪一種推理錯法。

logical fallacy 邏輯 / 辯論

推理形式或結構有問題。

common fallacy 教學 / 評論

常見謬誤，容易反覆出現。

fallacy of 正式 / 分析

後面接具體謬誤內容。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fallacy 謬誤、錯誤推理或迷思 用在錯誤來自推理方式，而不是單純資料輸入錯時。
Mistake 錯誤 任何錯都可用。
Error 錯誤 更通用，可技術可行為。
Falsehood 不真實的說法 重真假，不一定重推理結構。

Modern Use

現代延伸

Fallacy 是思考訓練裡的好字。它讓你不是只問結論對不對，也問走到結論的路有沒有裂。

在工程裡，很多事故報告的壞 root cause 都藏著 fallacy：單點事件被誤讀成完整原因。
