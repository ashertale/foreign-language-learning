Bias

Core Idea

bias 是判斷、資料或流程裡的斜度。危險之處在於：站在系統裡面的人，常把那個斜度看成正常。

Meaning

簡短定義

Bias

指判斷、資料、流程或制度朝某個方向偏斜。它不一定是故意偏袒，也可能是樣本、設計或習慣造成的系統性失真。

不是 Preference

preference 是偏好；bias 常暗示判斷被扭斜，未必公平。

看似中立
→
某方向被放大
→
結果偏斜

Origin

字源

原指斜線或斜向；現代延伸到心理、資料與制度上的偏斜。

原本的斜向畫面很適合記：bias 不是偶然撞歪一下，而是基準線帶著角度。

Memory Hook

記憶鉤子

bias 像水平儀本身歪了，所以每次量出來都偏同一邊。

你看到的不是單一錯誤，而是一種重複把結果推向某方向的斜度。

Usage

生活與專業情境

資料

測試只挑成功案例會造成 sampling bias，讓品質看起來比實際更好。

心理

Confirmation bias 會讓人特別看見支持自己想法的 evidence，忽略反例。

制度

Hiring bias 不一定來自惡意；有時是篩選條件把某些背景的人系統性排除。

Collocations

常見搭配與語域

bias 常和資料來源、認知習慣、制度設計連在一起。讀搭配時要問：偏斜是從哪個環節進來的？

confirmation bias 心理 / 決策

只偏好支持既有信念的資訊，讓判斷越來越封閉。

sampling bias 資料 / 研究

樣本取得方式已經偏掉，導致結果不能代表整體。

implicit bias 社會 / 組織

未被明說、甚至本人未察覺的偏見或傾向。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Bias 讓判斷偏向某一邊的傾向 用在偏斜會影響判斷、資料代表性或公平性的時候。
Preference 偏好 只是喜歡某選項，不一定造成不公平或失真。
Prejudice 偏見，常指對人群的預設負面判斷 道德和社會批判更強；bias 可用在資料與模型。

Modern Use

現代延伸

在 AI、研究和組織管理裡，bias 幾乎是核心風險詞。它提醒你：輸出偏掉，可能不是模型最後一步才錯，而是資料和流程一開始就歪了。

好用法會把 bias 接到來源：selection bias、measurement bias、confirmation bias。只說 biased 有時太籠統，追不到可修的地方。
