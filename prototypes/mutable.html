Mutable

MYOO-tuh-bul · UK /ˈmjuː.tə.bəl/ · US /ˈmjuː.t̬ə.bəl/

不是不穩，而是本來就設計成可變。

Core Idea

mutable 的好處在於精度：它把情境、語氣和搭配一起推向「本來就設計成可變」。

Meaning

簡短定義

Mutable

表示可變的、易改動的。

不是 Flexible

flexible 可以先說出 可調整；mutable 則把句子推到「本來就設計成可變」這個更細的位置。

Origin

字源

\"易變的\"的意思是14世紀後期的，源自拉丁語 mutabilis \"changeable\"，源自 mutare \"to change\"，源自 PIE 詞根 *mei- (1) \"to change, go, move\"，其派生詞指的是按照習俗或法律規定的貨物和服務的交換（比較拉丁語 mutuus \"done in exchange\"）。

像白板上的字不是還沒定，而是本來就預留了隨時改寫的空間

Memory Hook

記憶鉤子

mutable：像白板上的字不是還沒定，而是本來就預留了隨時改寫的空間

這個畫面能幫你把 mutable 和 Flexible 分開，因為它把「本來就設計成可變」那條界線變得可見。

Usage

生活與專業情境

日常版

像 mutable state 這樣的說法，多半出現在 工程 / 程式 的場景；句子真正要說的，就是「本來就設計成可變」。

數位 / 專業版

到了 專案 / 規劃 的場景，mutable plan 會更常出現；這裡要說清楚的，正是「本來就設計成可變」。

Collocations

常見搭配與語域

常見用法集中在 mutable state 和 mutable plan；這幾個搭配分別落在 工程 / 程式 和 專案 / 規劃 的場景裡。

mutable state 工程 / 程式

在 工程 / 程式 的語境裡，這個搭配通常就在形容 state 的狀態或氣質。

mutable plan 專案 / 規劃

在 專案 / 規劃 的語境裡，這個搭配通常就在形容 plan 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Mutable 可變的、易改動的 當句子需要把「本來就設計成可變」說清楚，而不是只留在 可調整 的外圈時。
Flexible 可調整 當你只需要先說 可調整，不必把語氣收進「本來就設計成可變」時。

Modern Use

現代延伸

現在最常見的就是 mutable state 和 mutable plan 這類說法；它們一出現，通常就在替句子劃清「本來就設計成可變」的範圍。

當句子要把「本來就設計成可變」說準時，mutable 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
