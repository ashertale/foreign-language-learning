Muster

MUS-ter · UK /ˈmʌs.tər/ · US /ˈmʌs.tɚ/

不是天生就有，而是努力把散掉的力重新湊起來。

Core Idea

muster 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Muster

表示鼓起勇氣、召集資源或集中力量。

不是 Gather

如果 gather 已經能讓句子成立，就不必硬換；需要「鼓起勇氣、召集資源或集中力量」時，muster 才有必要。

Origin

字源

14世紀早期， moustren，“展示，揭示，顯示或演示”（現已過時的意義），也指“出現，存在”，源自古法語 mostrer “出現，展示，揭示”，也有軍事意義（10世紀，現代法語 montrer），源自拉丁語 monstrare “展示”，源自 monstrum “預兆，標誌”（見 monster）。

像把四散的火種重新攏成一小堆，好讓下一把火能點起來

Memory Hook

記憶鉤子

muster：像把四散的火種重新攏成一小堆，好讓下一把火能點起來

這個畫面之所以有用，是因為它能幫你確認 muster 是否真的在談「努力把散掉的力重新湊起來」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

當人們說 muster the courage 時，焦點通常就在「努力把散掉的力重新湊起來」上，所以這個搭配很能代表 muster 的語感。

數位 / 專業版

到了 組織 / 協作 的場景，muster support 會更常出現；這裡要說清楚的，正是「努力把散掉的力重新湊起來」。

Collocations

常見搭配與語域

常見用法集中在 muster the courage 和 muster support；這幾個搭配分別落在 情緒 / 行動 和 組織 / 協作 的場景裡。

muster the courage 情緒 / 行動

在 情緒 / 行動 的語境裡，這個搭配會把動作直接落在 the courage 上。

muster support 組織 / 協作

在 組織 / 協作 的語境裡，這個搭配會把動作直接落在 support 上。

Neighbors

對立與鄰近概念

Modern Use

現代延伸

現在最常見的就是 muster the courage 和 muster support 這類說法；它們一出現，通常就在替句子劃清「努力把散掉的力重新湊起來」的範圍。

當句子要把「努力把散掉的力重新湊起來」說準時，muster 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
