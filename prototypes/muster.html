Muster

MUS-ter · UK /ˈmʌs.tə/ · US /ˈmʌs.tɚ/

不是突然變多，而是把零散的力氣硬是湊成可用的一股。

CEFR
C1
Zipf Frequency
2.74
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

muster 是在資源不足時，硬把勇氣、人手、證據或力氣聚成可用的一份。

Meaning

簡短定義

Muster

勉強聚集勇氣、力量、資源或支持，使它足以應付眼前需要。

不是 Gather

gather 比較中性；muster 常帶費力、原本不夠的感覺。

原本分散或不足
→
用力把它們叫回來
→
勉強形成可用份量

Origin

字源

muster 經 Old French 來自 Latin monstrare「展示、顯示」；它先有把人馬排出來檢閱的意思，後來才變成把兵力、勇氣或資源一口氣湊出來。

Memory Hook

記憶鉤子

把 muster 想成只剩幾顆電池，還是硬把它們湊進手電筒裡照一段路。

這個字常帶出資源有限卻仍要撐出一點作用的味道。

Usage

生活與專業情境

勇氣

She finally mustered the courage to ask the harder question.

資源

The team could barely muster enough evidence to justify a rollback.

Collocations

常見搭配與語域

muster the courage 人際 / 敘事

把勇氣、能量、資源或支持一點點聚起來。

muster enough support 管理 / 政策

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Muster 勉強湊出 用在把勇氣、能量、資源或支持一點點聚起來時。
Gather 把東西集中起來 若只是一般收集或聚集，不必特別突出勉強感，用 gather 即可。

Modern Use

現代延伸

在現代英文裡，muster 很常用來寫人在資源不足時仍硬湊出一點行動能力。
