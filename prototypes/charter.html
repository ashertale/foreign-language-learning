Charter

CHAR-ter · UK /ˈtʃɑː.tər/ · US /ˈtʃɑːr.t̬ɚ/

不是口頭開始，而是把這件事的邊界和方向正式寫清楚。

Core Idea

charter 不只是 Authorize 的近義替代；它用來描述「把這件事的邊界和方向正式寫清楚」這種更窄、更準確的情境。

Meaning

簡短定義

Charter

表示正式批准、規劃或界定某個計畫與組織。

不是 Authorize

把它們分開記：authorize 先保留大方向，charter 負責把邊界收乾淨。

先遇到 charter the project
→
看它是否只是 正式授權
→
再決定是否需要 charter

Origin

字源

“正式的書面文件，授予特權和權利，作爲它們的法律證據”，公元1200年左右，源自古法語 chartre（12世紀）“特許狀，信函，文件，契約”，源自拉丁語 chartula/cartula，字面意思是“小紙張”，是 charta/carta “紙張，文件”的小型詞（參見 chart（名詞））。“爲特定目的僱用的飛機”一詞始於1922年。

像出海前先把航線畫在圖上，讓大家知道不是隨便漂

Memory Hook

記憶鉤子

charter：像出海前先把航線畫在圖上，讓大家知道不是隨便漂

能用這個畫面回到「正式批准、規劃或界定某個計畫與組織」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 charter the project 這樣的說法，多半出現在 專案 / 管理 的場景；句子真正要說的，就是「把這件事的邊界和方向正式寫清楚」。

數位 / 專業版

到了 組織 / 程序 的場景，charter a committee 會更常出現；這裡要說清楚的，正是「把這件事的邊界和方向正式寫清楚」。

Collocations

常見搭配與語域

常見用法集中在 charter the project 和 charter a committee；這幾個搭配分別落在 專案 / 管理 和 組織 / 程序 的場景裡。

charter the project 專案 / 管理

在 專案 / 管理 的語境裡，這個搭配會把動作直接落在 the project 上。

charter a committee 組織 / 程序

在 組織 / 程序 的語境裡，這個搭配會把動作直接落在 a committee 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Charter 正式批准、規劃或界定某個計畫與組織 當搭配和語境都已經指向「把這件事的邊界和方向正式寫清楚」，這個字才自然。
Authorize 正式授權 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 專案 / 管理、組織 / 程序、治理 / 公共 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
