Potent

POH-tuhnt · UK /ˈpəʊ.tənt/ · US /ˈpoʊ.t̬ənt/

不是大，而是效力強。

Core Idea

potent 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Potent

表示藥物、論點、象徵或情緒具有強大作用力。

不是 Powerful

powerful 可以先說出 強大；potent 則把句子推到「效力強」這個更細的位置。

Origin

字源

早在15世紀，這個詞的意思是「強大、非常有力，擁有內在的力量」，源自拉丁語 potentem（主格 potens）意為「有力的」，是 posse 的現在分詞，意指「能夠、具備力量」，實際上是 potis esse 的縮寫，翻譯過來就是「能夠掌控，成為主宰」。這個詞又來自 potis，意思是「有力的、能幹的、可行的」。在形容人時，還有「更好、更可取；首要的、主要的；最強的、最前沿的」等含義，這些都可以追溯到原始印歐語根 *poti-，意為「有力的；領主」。至於從 potis 加上 esse 到 posse 的具體演變過程，目前學界還存在爭議 [de Vaan]。

Usage

生活與專業情境

日常版

像 potent drug 這樣的說法，多半出現在 醫療 / 科學 的場景；句子真正要說的，就是「效力強」。

數位 / 專業版

到了 論證 / 評論 的場景，potent argument 會更常出現；這裡要說清楚的，正是「效力強」。

Collocations

常見搭配與語域

常見用法集中在 potent drug 和 potent argument；這幾個搭配分別落在 醫療 / 科學 和 論證 / 評論 的場景裡。

potent drug 醫療 / 科學

在 醫療 / 科學 的語境裡，這個搭配通常就在形容 drug 的狀態或氣質。

potent argument 論證 / 評論

在 論證 / 評論 的語境裡，這個搭配通常就在形容 argument 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Potent 藥物、論點、象徵或情緒具有強大作用力 當句子需要把「效力強」說清楚，而不是只留在 強大 的外圈時。
Powerful 強大 當你只需要先說 強大，不必把語氣收進「效力強」時。

Modern Use

現代延伸

現在最常見的就是 potent drug 和 potent argument 這類說法；它們一出現，通常就在替句子劃清「效力強」的範圍。

當句子要把「效力強」說準時，potent 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
