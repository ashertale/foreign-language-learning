Exempt

ig-ZEMPT · UK /ɪɡˈzempt/ · US /ɪɡˈzempt/

不是沒關係，而是被正式排除在某項要求之外。

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

exempt 不是規則不存在，而是某對象被正式拿出規則適用範圍。

Meaning

簡短定義

Exempt

形容或表示免除某義務、要求、稅、限制或規定，通常需要正式理由。

不是 Excluded

excluded 是被排除；exempt 強調免除某項義務或限制。

規則通常適用
→
某對象被正式排除
→
義務不再要求

Origin

字源

來自 Latin eximere，有拿出、免除的意思。

eximere 的拿出、免除感可記：exempt 是從規則籃子裡被拿出來。

Memory Hook

記憶鉤子

把 exempt 想成 legacy device 被 policy 特別排除。

這不該靠默契存在，否則例外會變成漏洞。

Usage

生活與專業情境

更新政策

某 legacy device exempt from update policy，應該要有明確理由和期限。

稅務

A tax-exempt organization is legally excused from certain taxes. 這裡放在稅務情境時，是在說某對象被正式免除通常適用的要求。

狀態

Exempt status should be auditable; otherwise it invites abuse. 這裡放在狀態情境時，是在說某對象被正式免除通常適用的要求。

Collocations

常見搭配與語域

exempt 常接 tax、from、status。搭配都帶正式免除，不是隨口放過。

tax exempt 稅務 / 法律

免稅，通常基於法律身份。

exempt from 正式 / 制度

from 後面接被免除的要求或規則。

exempt status 法律 / 組織

免除資格或狀態。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Exempt 豁免的、不受某規則約束的 用在某對象被正式免除通常適用的要求時。
Excluded 被排除 只是被排除在外；exempt 強調免除義務。
Immune 免疫、不受影響 法律或生物語境不同，可能是不能被追訴或不受感染。
Waived 被免除 / 放棄要求 常指某費用或要求被放棄。

Modern Use

現代延伸

Exempt 在制度設計裡很敏感，因為每個例外都可能變成維護成本或公平問題。

好的文件會寫明 exempt from what、why、until when。
