Uphold

up-HOHLD · UK /ʌpˈhəʊld/ · US /ʌpˈhoʊld/

不是嘴上支持，而是讓它真的繼續立著。

Core Idea

uphold 用來描述「讓它真的繼續立著」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Uphold

表示維護、支持或確認規則、價值與裁決有效。

不是 Support

如果 support 已經能讓句子成立，就不必硬換；需要「維護、支持或確認規則、價值與裁決有效」時，uphold 才有必要。

Origin

字源

大約在公元1200年，upholden這個詞出現，意思是「支持、維持」某人或某物的物理狀態，來自於up（副詞）和hold（動詞）的結合。到了1520年代，它開始有了「維持、保證」（一個陳述、一個事實）的含義；而「保持良好狀態或修理」的意思則出現在1570年代。可以參考hold-up這個詞。相關詞彙包括Upheld（過去式）、upholding（現在分詞）、upholder（名詞）。在古弗里西語中有類似的構詞upholda，在中荷蘭語中是ophouden，德語則是aufhalten。

像柱子不是在旁邊鼓掌，而是真的把屋頂撐住

Memory Hook

記憶鉤子

uphold：像柱子不是在旁邊鼓掌，而是真的把屋頂撐住

這個畫面之所以有用，是因為它能幫你確認 uphold 是否真的在談「讓它真的繼續立著」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

當人們說 uphold the ruling 時，焦點通常就在「讓它真的繼續立著」上，所以這個搭配很能代表 uphold 的語感。

數位 / 專業版

到了 品質 / 工程 的場景，uphold the standard 會更常出現；這裡要說清楚的，正是「讓它真的繼續立著」。

Collocations

常見搭配與語域

常見用法集中在 uphold the ruling 和 uphold the standard；這幾個搭配分別落在 法務 / 判決 和 品質 / 工程 的場景裡。

uphold the ruling 法務 / 判決

在 法務 / 判決 的語境裡，這個搭配會把動作直接落在 the ruling 上。

uphold the standard 品質 / 工程

在 品質 / 工程 的語境裡，這個搭配會把動作直接落在 the standard 上。

Modern Use

現代延伸

現在最常見的就是 uphold the ruling 和 uphold the standard 這類說法；它們一出現，通常就在替句子劃清「讓它真的繼續立著」的範圍。

當句子要把「讓它真的繼續立著」說準時，uphold 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
