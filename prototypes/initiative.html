Initiative

ih-NISH-uh-tiv · UK /ɪˈnɪʃ.ə.tɪv/ · US /ɪˈnɪʃ.ə.t̬ɪv/

不是被交辦的任務，而是主動開始推進的能力或計畫。

Core Idea

initiative 是主動開局的力：看見需要後，不等任務被派下來，就先把事情推動起來。

Meaning

簡短定義

Initiative

可指主動性，也可指新計畫、倡議或策略性行動。

不是 Task

task 是任務；initiative 有主動開始和推動方向的意味。

看見需要
→
主動開局

推動事情前進

Origin

字源

來自 initiate 的開始概念；核心是主動開端。

initiate 有開始一件事的動作；initiative 更像有人先把第一步拿起來做。

Memory Hook

記憶鉤子

把 initiative 想成沒有人收斂問題時，先寫出下一步和 owner。

不是搶功，而是打開停住的局面。

Usage

生活與專業情境

主動性

take initiative 不是搶做所有事，而是在沒人收斂時先把下一步打開。

策略

A strategic initiative needs resources, not just a title on a roadmap.

新計畫

A new initiative can fail if it adds work without removing older commitments.

Collocations

常見搭配與語域

initiative 常接 take、strategic、new。搭配會分辨它是個人主動性，還是組織計畫。

take initiative 職場 / 人際

主動開始推動，而不是等待指派。

strategic initiative 管理 / 產品

策略性計畫，通常跨多個團隊或季度。

new initiative 組織 / 政策

新推動的計畫或倡議。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Initiative 主動性、倡議或新計畫 用在主動開始推進，或指一個被正式啟動的計畫時。
Task 任務 被分派的工作。
Project 專案 有範圍和目標的工作。
Proactivity 主動性 偏個人特質；initiative 可指具體計畫。

Modern Use

現代延伸

Initiative 是職場裡容易被稱讚也容易被濫用的字。真正 take initiative 會補上 ownership 和 next step，不只是提出想法。

作計畫名時，它需要資源和停止條件，否則 initiative 會變成永遠新增工作的容器。
