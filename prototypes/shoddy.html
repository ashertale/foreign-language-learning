Shoddy

SHOD-ee · UK /ˈʃɒd.i/ · US /ˈʃɑː.di/

不是便宜，而是粗糙到看得出不講究。

Core Idea

shoddy 指品質粗劣到看得出不講究；便宜不是問題，偷工和馬虎才是。

Meaning

簡短定義

Shoddy

形容做工、材料或處理方式粗糙低劣。

不是 Cheap

cheap 只是便宜；shoddy 更直接批評品質差。

看似能交差
→
細看充滿馬虎
→
品質感一下就垮下來

Origin

字源

shoddy 原本是紡織業裡把舊羊毛拆碎再重做的再生布料名，後來很快就帶上「看起來像樣、其實品質虛」的負面評價；所以今天說 shoddy workmanship，批的就是偷工減料。

Memory Hook

記憶鉤子

把 shoddy 想成表面有油漆，但一摸就整片掉粉。

這個字把『隨便做』的痕跡直接指出來。

Usage

生活與專業情境

產品

如果一件東西一拿就知道工法很差，shoddy 的批評就很到位。

流程

報告也可以很 shoddy，不是字醜，而是思路和細節都在偷懶。

Collocations

常見搭配與語域

shoddy workmanship 製造 / 日常

shoddy reporting 媒體 / 評論

Modern Use

現代延伸

shoddy 很常用來批評產品、內容和流程品質，語氣直接而不客氣。
