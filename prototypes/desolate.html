Desolate

DES-uh-luht · UK /ˈdes.ələt/ · US /ˈdes.ə.lət/

不是安靜，而是安靜到只剩荒涼。

Core Idea

desolate 的核心是把「荒蕪、淒涼，或情感上感到被掏空」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Desolate

表示荒蕪、淒涼，或情感上感到被掏空。

不是 Lonely

把它們分開記：lonely 先保留大方向，desolate 負責把邊界收乾淨。

Origin

字源

14世紀中期，用於人，“悲傷的，痛苦的，被悲傷壓倒的，失去安慰的”； 14世紀後期，用於人，“沒有伴侶的，孤獨的”； 也用於地方，“無人居住的，被遺棄的”，源自拉丁語 desolatus，是 desolare 的過去分詞，“獨自離開，遺棄”，由 de- “完全”（見 de-)和 solare “使孤獨”組成，源自 solus “獨自”（見 sole（形容詞））。

像風穿過空屋，不是沒聲音，而是每一聲都顯得更空

Memory Hook

記憶鉤子

desolate：像風穿過空屋，不是沒聲音，而是每一聲都顯得更空

這個畫面有用，是因為它先把「安靜到只剩荒涼」釘住；回到實際搭配時，就不容易把它和 Lonely 混成一團。

Usage

生活與專業情境

日常版

像 desolate landscape 這樣的說法，多半出現在 敘事 / 場景 的場景；句子真正要說的，就是「安靜到只剩荒涼」。

數位 / 專業版

到了 情緒 / 日常 的場景，feel desolate 會更常出現；這裡要說清楚的，正是「安靜到只剩荒涼」。

Collocations

常見搭配與語域

常見用法集中在 desolate landscape 和 feel desolate；這幾個搭配分別落在 敘事 / 場景 和 情緒 / 日常 的場景裡。

desolate landscape 敘事 / 場景

在 敘事 / 場景 的語境裡，這個搭配通常就在形容 landscape 的狀態或氣質。

feel desolate 情緒 / 日常

在 情緒 / 日常 的語境裡，這個搭配最容易看出「安靜到只剩荒涼」實際怎麼落在句子裡。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 敘事 / 場景、情緒 / 日常、新聞 / 描寫 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
