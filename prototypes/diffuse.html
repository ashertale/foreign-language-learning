Word 144 / adjective

Diffuse

dih-FYOOS · UK /dɪˈfjuːs/ · US /dɪˈfjuːs/

不是豐富，而是散得很開，焦點不再集中。

Core Idea

diffuse 用來描述「散得很開，焦點不再集中」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Diffuse

表示光線、注意力、文字或責任分散而不集中。

不是 Spread

spread 可以先說出 散開；diffuse 則把句子推到「散得很開，焦點不再集中」這個更細的位置。

Origin

字源

1520年代（及物動詞），“傾倒和擴散，使流動和擴散”； 1650年代（不及物動詞），“廣泛傳播，四處散佈”； 來自拉丁語 diffundere 的過去分詞 diffusus “倒出或流失”，由 dis- “分開，向各個方向”（見 dis-)和 fundere “傾倒”（來自 PIE 詞根 *gheu- 的鼻化形式“傾倒”）組成。相關： Diffused； diffusing。

像霧天裡的光沒有明確邊緣，整片亮，卻沒有一點特別亮

Memory Hook

記憶鉤子

diffuse：像霧天裡的光沒有明確邊緣，整片亮，卻沒有一點特別亮

這個畫面之所以有用，是因為它能幫你確認 diffuse 是否真的在談「散得很開，焦點不再集中」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 diffuse light 這樣的說法，多半出現在 視覺 / 攝影 的場景；句子真正要說的，就是「散得很開，焦點不再集中」。

數位 / 專業版

到了 組織 / 管理 的場景，diffuse responsibility 會更常出現；這裡要說清楚的，正是「散得很開，焦點不再集中」。

Collocations

常見搭配與語域

常見用法集中在 diffuse light 和 diffuse responsibility；這幾個搭配分別落在 視覺 / 攝影 和 組織 / 管理 的場景裡。

diffuse light 視覺 / 攝影

在 視覺 / 攝影 的語境裡，這個搭配通常就在形容 light 的狀態或氣質。

diffuse responsibility 組織 / 管理

在 組織 / 管理 的語境裡，這個搭配通常就在形容 responsibility 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Diffuse 光線、注意力、文字或責任分散而不集中 當句子需要把「散得很開，焦點不再集中」說清楚，而不是只留在 散開 的外圈時。
Spread 散開 當你只需要先說 散開，不必把語氣收進「散得很開，焦點不再集中」時。

Modern Use

現代延伸

現在最常見的就是 diffuse light 和 diffuse responsibility 這類說法；它們一出現，通常就在替句子劃清「散得很開，焦點不再集中」的範圍。

當句子要把「散得很開，焦點不再集中」說準時，diffuse 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
