Foresight

不是預知未來，而是提前看見後果並替未來留路。

Core Idea

foresight 不是會預知未來，而是能提前看見後果，現在就替未來留下路。

Meaning

簡短定義

Foresight

指遠見、預見後果並提前準備的能力。它比 prediction 更重行動上的準備。

不是 Prediction

prediction 是預測結果；foresight 是因為預見而做出準備。

Origin

字源

由 fore 與 sight 組成；字面就是往前看。

fore + sight 的字面很好記：往前看。但真正的 foresight 會把看見變成準備。

Memory Hook

記憶鉤子

把 foresight 想成 board layout 上多留的 debug pins。

今天可能用不到，明天問題真的出現時，它會讓你少走很多黑路。

Usage

生活與專業情境

硬體設計

在 board layout 預留 debug pins 是 foresight，未必今天會用，但明天會救命。

策略

Strategic foresight asks what future constraints will make today’s easy choice expensive.

缺乏遠見

A lack of foresight often appears later as emergency work.

Collocations

常見搭配與語域

foresight 常接 strategic、lack of、show。搭配會標出遠見是能力、缺失，還是具體行動。

strategic foresight 策略 / 管理

提前想像未來條件，讓現在的決策不只看短期。

lack of foresight 評論 / 事後檢討

缺乏遠見，常在問題爆發後被看見。

show foresight 正式 / 評價

透過預先安排展現遠見。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Foresight 遠見、預見與提前準備 用在提前看見後果，並因此現在先留選項或做準備時。
Prediction 預測結果 重猜未來會發生什麼；foresight 還包含準備。
Forecast 預報、預測 常用於數據或趨勢預測。
Wisdom 智慧 範圍更廣，不一定專指未來準備。

Modern Use

現代延伸

Foresight 對工程特別實在：多留 test point、rollback path、observability，都是未來問題還沒出現前的善意。

它不是悲觀，而是承認未來的你會需要現在的你幫忙。
