Concurrent

kun-KUR-unt · UK /kənˈkʌr.ənt/ · US /kənˈkɝː.ənt/

不是先後很近，而是多件事在同一段時間內一起發生。

Core Idea

concurrent 讓多條流程同時存在。它不只是時間靠近，而是執行或發生區間真的重疊。

Meaning

簡短定義

Concurrent

形容事件、任務、流程或權限在同一段時間內同時發生或並行存在。

不是 Sequential

sequential 是依序；concurrent 是時間上重疊或並行。

多條流程存在
→
時間重疊
→
互相影響

Origin

字源

來自 Latin concurrere，有「一起跑」的意思。

Latin 的「一起跑」很直觀：多條線不是排隊，而是同時在跑。

Memory Hook

記憶鉤子

把 concurrent 想成兩個 thread 同時碰同一段 shared state。

麻煩不在單一步驟，而在交錯。

Usage

生活與專業情境

軟體

Concurrent access 會讓 bug 變難抓，因為錯誤來自交錯而不是單一步驟。

專案

Concurrent tasks can save calendar time but increase coordination cost。

事件

Concurrent events 可能互相影響，也可能只是同時發生。

Collocations

常見搭配與語域

concurrent 常接 tasks、access、events。搭配會告訴你重疊的是工作、資料接觸，還是外部事件。

concurrent tasks 專案 / 系統

多個任務同時進行，可能提高效率也提高協調成本。

concurrent access 軟體 / 資料

多個流程同時讀寫或使用同一資源，是 race condition 常見入口。

concurrent events 報導 / 分析

多件事在同一段時間發生，因果仍需另查。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Concurrent 同時發生或並行存在 用在多件事的時間區間重疊，且重疊本身影響判斷時。
Sequential 依序 一件接一件發生，沒有重疊。
Simultaneous 同時 更通用；concurrent 常帶流程或期間重疊感。
Parallel 平行 技術上常指真的並行執行；concurrent 可包含交錯執行。

Modern Use

現代延伸

Concurrent 在軟體裡特別重要，因為它讓 correctness 從單一路徑問題變成 interleaving 問題。

管理上 concurrent work 也有代價：同時做不等於免費加速，接口和上下文切換會一起增加。
