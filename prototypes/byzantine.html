Byzantine

BIZ-un-teen · UK /bɪˈzæn.tiːn/ · US /ˈbɪz.ən.tiːn/

不是複雜而已，而是彎來彎去，規則像迷宮一樣。

Core Idea

byzantine 的好處在於精度：它把情境、語氣和搭配一起推向「彎來彎去，規則像迷宮一樣」。

Meaning

簡短定義

Byzantine

表示結構、程序或權力關係極端繁複曲折。

不是 Complex

如果 complex 已經能讓句子成立，就不必硬換；需要「結構、程序或權力關係極端繁複曲折」時，byzantine 才有必要。

Origin

字源

關於 Byzantium（參見相關詞條，即現代 Istanbul 的原名 Constantinople），1770年使用，源自於晚期拉丁語 Byzantinus； 最初用於描述4-5世紀在那裏發展起來的藝術和建築風格； 後來用於指代君士坦丁堡皇家宮廷的複雜、狡猾和耐人尋味的性格（1937年）。作爲名詞的用法始於1770年。Byzantian 的用法始於1610年代。

Memory Hook

記憶鉤子

byzantine：像走進沒有窗的走廊群，每個轉角都像還藏著另一條規則

能用這個畫面回到「結構、程序或權力關係極端繁複曲折」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 byzantine procedure 時，焦點通常就在「彎來彎去，規則像迷宮一樣」上，所以這個搭配很能代表 byzantine 的語感。

數位 / 專業版

到了 法規 / 管理 的場景，byzantine rules 會更常出現；這裡要說清楚的，正是「彎來彎去，規則像迷宮一樣」。

Collocations

常見搭配與語域

常見用法集中在 byzantine procedure 和 byzantine rules；這幾個搭配分別落在 制度 / 流程 和 法規 / 管理 的場景裡。

byzantine procedure 制度 / 流程

在 制度 / 流程 的語境裡，這個搭配通常就在形容 procedure 的狀態或氣質。

byzantine rules 法規 / 管理

在 法規 / 管理 的語境裡，這個搭配通常就在形容 rules 的狀態或氣質。

Modern Use

現代延伸

現在最常見的就是 byzantine procedure 和 byzantine rules 這類說法；它們一出現，通常就在替句子劃清「彎來彎去，規則像迷宮一樣」的範圍。

當句子要把「彎來彎去，規則像迷宮一樣」說準時，byzantine 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
