Extrapolate

ek-STRAP-uh-layt · UK /ɪkˈstræp.ə.leɪt/ · US /ɪkˈstræp.ə.leɪt/

不是亂猜，而是沿著已知趨勢往外推。

Core Idea

extrapolate 最值得保留的語感，是它讓「根據已有資料或模式推估未知區間」不再只是模糊大意。

Meaning

簡短定義

Extrapolate

表示根據已有資料或模式推估未知區間。

不是 Predict

把它們分開記：predict 先保留大方向，extrapolate 負責把邊界收乾淨。

Origin

字源

\"通過推斷已知數據的趨勢來估算未知值的近似計算\"，1862年（在哈佛天文臺對1858年彗星的描述中），源自 extra- + interpolate 的詞尾。早期的參考資料中稱這是英國數學家和天文學家喬治·艾裏爵士（1801-1892）的特徵詞。

像你先看到幾個座標點，接著把那條線往外延伸

Memory Hook

記憶鉤子

extrapolate：像你先看到幾個座標點，接著把那條線往外延伸

這個畫面能幫你把 extrapolate 和 Predict 分開，因為它把「沿著已知趨勢往外推」那條界線變得可見。

Usage

生活與專業情境

日常版

像 extrapolate from the data 這樣的說法，多半出現在 分析 / 研究 的場景；句子真正要說的，就是「沿著已知趨勢往外推」。

數位 / 專業版

到了 商業 / 市場 的場景，extrapolate a trend 會更常出現；這裡要說清楚的，正是「沿著已知趨勢往外推」。

Collocations

常見搭配與語域

常見用法集中在 extrapolate from the data 和 extrapolate a trend；這幾個搭配分別落在 分析 / 研究 和 商業 / 市場 的場景裡。

extrapolate from the data 分析 / 研究

在 分析 / 研究 的語境裡，這個搭配會把動作直接落在 from the data 上。

extrapolate a trend 商業 / 市場

在 商業 / 市場 的語境裡，這個搭配會把動作直接落在 a trend 上。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 分析 / 研究、商業 / 市場、統計 / 實驗 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
