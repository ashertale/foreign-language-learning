Avid

AV-id · UK /ˈæv.ɪd/ · US /ˈæv.ɪd/

不是有興趣而已，而是會主動追著資訊、活動或機會跑。

Core Idea

avid 的熱不是禮貌性興趣，而是人會主動追、一直看、很快抓住下一個機會。

Meaning

簡短定義

Avid

形容人對某活動、主題或取得某物有強烈而持續的熱衷。

不是 Interested

interested 可以是輕輕打開門；avid 是人已經走進去，還想待久一點。

對象引起強烈吸引
→
人主動反覆靠近
→
興趣變成穩定行為

Memory Hook

記憶鉤子

把 avid reader 想成書不是任務，而是他會自己找空檔回去的地方。

avid 的能量會讓人主動靠近。

Usage

生活與專業情境

閱讀

An avid reader does not need a reading assignment to keep going.

粉絲

Avid fans notice small changes because they have been watching for a long time.

好奇心

Avid

Collocations

常見搭配與語域

avid 常接 reader、fan、collector、interest、curiosity；名詞後面通常是一個人會持續投入的場域。

avid reader 日常 / 教育

大量且主動閱讀的人。

avid fan 媒體 / 社群

持續關注、投入度高的粉絲。

avid curiosity 寫作 / 學習

不是一時好奇，而是很想繼續追問。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Avid 熱衷渴求 用在興趣強到會改變人的行為頻率，而不是只停在口頭喜歡時。
Interested 感興趣 程度較低，可能只是願意聽；avid 已經會主動靠近。
Eager 急切 偏當下想做；avid 可描述長期興趣。

Modern Use

現代延伸

Avid 在履歷或介紹裡可用，但不要把所有 hobby 都寫成 avid；它暗示投入很深。

它也可有貪求感，例如 avid for power，語氣會變得不只是正面熱情。
