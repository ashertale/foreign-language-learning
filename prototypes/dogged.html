Dogged

DOG-id · UK /ˈdɒɡ.ɪd/ · US /ˈdɑː.ɡɪd/

不是熱血一陣，而是被擋住很多次還繼續往前鑽。

Core Idea

dogged 是咬住不放的堅持，不華麗，但很難被拖走。

Meaning

簡短定義

Dogged

形容頑強、鍥而不捨，即使困難也持續推進。

不是 Determined

determined 是有決心；dogged 像把牙咬在問題上不鬆。

目標長時間不易完成
→
人持續回到同一件事
→
堅持成為主要特徵

Origin

字源

dogged 最早只是「像狗一樣」，而且多半偏負面，如陰沉、難纏；到 18 世紀才轉出那種像狗咬住不放的頑固堅持。

Memory Hook

記憶鉤子

把 dogged pursuit 想成一個問題查了三週，還是每天補一塊證據。

dogged 的美感在不放棄。

Usage

生活與專業情境

追查

Her dogged pursuit of the root cause kept the incident from being blamed on luck.

努力

努力情境下，dogged 不是熱血一陣，而是被擋住很多次還繼續往前鑽。

持續

Dogged persistence can become stubbornness if feedback is ignored.

Collocations

常見搭配與語域

dogged 常修飾 pursuit、effort、persistence；搭配都含長時間不鬆口。

dogged pursuit 調查 / 學習

鍥而不捨的追查或追求。

dogged effort 工作 / 評論

頑強努力。

dogged persistence 正式 / 反思

頑強持續。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Dogged 頑強不放棄 用在堅持不是一時熱血，而是反覆回到難題上時。
Determined 有決心 通用且可正面；dogged 更像咬住目標不放。
Tenacious 堅韌 接近且較漂亮；dogged 更樸拙、更硬撐。

Modern Use

現代延伸

Dogged 常是讚美，但也可能暗示缺乏彈性。

在工程問題上，dogged debugging 很有價值，但仍要讓新證據改變路徑。
