Dogged

DOG-id · UK /ˈdɒɡ.ɪd/ · US /ˈdɑː.ɡɪd/

不是熱血一陣，而是被擋住很多次還繼續往前鑽。

Core Idea

dogged 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Dogged

表示頑強、鍥而不捨地持續追做某件事。

不是 Determined

determined 可以先說出 堅定；dogged 則把句子推到「被擋住很多次還繼續往前鑽」這個更細的位置。

Origin

字源

“有狗的特質”（主要是貶義，指“卑鄙、脾氣壞、可鄙”），大約在1300年，源自於 dog（名詞）。意思爲“堅持不懈的，默默地頑固的”始於1779年。因此， doggedly（14世紀晚期）意爲“殘忍地，惡意地”； 後來意爲“像狗一樣地堅持不懈”（1773年）。

像雨天裡一路濕著往前走，鞋重了、風大了，但步子沒停

Memory Hook

記憶鉤子

dogged：像雨天裡一路濕著往前走，鞋重了、風大了，但步子沒停

這個畫面能幫你把 dogged 和 Determined 分開，因為它把「被擋住很多次還繼續往前鑽」那條界線變得可見。

Usage

生活與專業情境

日常版

像 dogged pursuit 這樣的說法，多半出現在 研究 / 調查 的場景；句子真正要說的，就是「被擋住很多次還繼續往前鑽」。

數位 / 專業版

到了 工作 / 執行 的場景，dogged effort 會更常出現；這裡要說清楚的，正是「被擋住很多次還繼續往前鑽」。

Collocations

常見搭配與語域

常見用法集中在 dogged pursuit 和 dogged effort；這幾個搭配分別落在 研究 / 調查 和 工作 / 執行 的場景裡。

dogged pursuit 研究 / 調查

在 研究 / 調查 的語境裡，這個搭配通常就在形容 pursuit 的狀態或氣質。

dogged effort 工作 / 執行

在 工作 / 執行 的語境裡，這個搭配通常就在形容 effort 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Dogged 頑強、鍥而不捨地持續追做某件事 當句子需要把「被擋住很多次還繼續往前鑽」說清楚，而不是只留在 堅定 的外圈時。
Determined 堅定 當你只需要先說 堅定，不必把語氣收進「被擋住很多次還繼續往前鑽」時。

Modern Use

現代延伸

現在最常見的就是 dogged pursuit 和 dogged effort 這類說法；它們一出現，通常就在替句子劃清「被擋住很多次還繼續往前鑽」的範圍。

當句子要把「被擋住很多次還繼續往前鑽」說準時，dogged 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
