Compatible

kum-PAT-uh-bul · UK /kəmˈpæt.ə.bəl/ · US /kəmˈpæt̬.ə.bəl/

不是看起來相似，而是放在一起能正常運作。

Core Idea

compatible 說的是兩個東西放在一起能不能順利工作。相似不是重點；不衝突、接得上、能共存才是重點。

Meaning

簡短定義

Compatible

形容裝置、軟體、想法、條件或人彼此相容，能一起運作或共處而不互相衝突。

不是 Similar

similar 是相像；compatible 是能一起用。

兩者接在一起
→
介面或目標不衝突
→
共同運作

Origin

字源

詞史和「能一起受苦、能共處」有關；現代常用在系統相容性。

詞史裡的共處感很適合記：compatible 不是像，而是能一起承受同一個環境。

Memory Hook

記憶鉤子

把 compatible 想成插上去不只 fit，還真的能跑。

外形接得上還不夠；協定、資料、電氣條件或目標也要能一起工作。

Usage

生活與專業情境

韌體 / 系統

firmware update backward compatible，代表舊工具或舊資料仍能被正確處理。

人際 / 工作

Two working styles can be compatible even if the people are not similar。

限制

Compatible with 後面常接平台、版本、設備或條件。

Collocations

常見搭配與語域

compatible 的搭配多半在測試「能不能一起用」：版本、設備、目標、工作方式都可以成為測試點。

backward compatible 工程 / 產品

新版本仍能支援舊資料、舊 API 或舊行為。

compatible with 通用 / 技術

with 後面接要共存或互通的對象。

compatible devices 產品 / 技術

設備彼此能互接、互通或符合相同規格。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Compatible 彼此能共存、互通或不衝突 用在判斷兩者是否能共存、互接、互用或目標不衝突時。
Similar 相似 只是外觀或特徵像，不保證能一起運作。
Interoperable 可互通 技術語氣更強，重點是系統間能交換資料或服務。

Modern Use

現代延伸

技術英文裡，compatible 幾乎總是在問隱藏 contract：版本、格式、電壓、協定、期待行為是否對得上。

這個字也能用在人與策略：compatible goals 不代表大家一樣，只代表放在一起不互相毀掉。
