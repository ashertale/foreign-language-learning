Assail

Core Idea

assail 不只是 Attack 的近義替代；它用來描述「成串地從各方向打過來」這種更窄、更準確的情境。

Meaning

簡短定義

Assail

表示猛烈攻擊、抨擊或襲擊。

不是 Attack

把它們分開記：attack 先保留大方向，assail 負責把邊界收乾淨。

Origin

字源

“attack violently”，約1200年，來自古法語 assalir “攻擊，襲擊，攻擊”（12世紀，現代法語 assaillir），源自通俗拉丁語 *adsalire “跳躍”，來自拉丁語 ad “到，向”（見 ad-）+ salire “跳躍”（見 salient（形容詞））。比喻用法，指心理狀態、情感等，始於14世紀中期； “用論據、謾罵、批評等攻擊”意義始於約1400年。

像暴雨不是一滴一滴落，而是整片斜打到你身上

Memory Hook

記憶鉤子

assail：像暴雨不是一滴一滴落，而是整片斜打到你身上

這個畫面之所以有用，是因為它能幫你確認 assail 是否真的在談「成串地從各方向打過來」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 assail the proposal 這樣的說法，多半出現在 評論 / 公共 的場景；句子真正要說的，就是「成串地從各方向打過來」。

數位 / 專業版

到了 心理 / 情緒 的場景，assailed by doubts 會更常出現；這裡要說清楚的，正是「成串地從各方向打過來」。

Collocations

常見搭配與語域

常見用法集中在 assail the proposal 和 assailed by doubts；這幾個搭配分別落在 評論 / 公共 和 心理 / 情緒 的場景裡。

assail the proposal 評論 / 公共

在 評論 / 公共 的語境裡，這個搭配會把動作直接落在 the proposal 上。

assailed by doubts 心理 / 情緒

在 心理 / 情緒 的語境裡，這個搭配最容易看出「成串地從各方向打過來」實際怎麼落在句子裡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 評論 / 公共、心理 / 情緒、敘事 / 動作 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
