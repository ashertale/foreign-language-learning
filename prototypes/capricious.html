Capricious

kuh-PRISH-us · UK /kəˈprɪʃ.əs/ · US /kəˈprɪʃ.əs/

不是單純多變，而是變得沒有理由、讓人難以預測。

Core Idea

capricious 說的不是彈性，而是變化不肯服從穩定規則。它讓人覺得像任性在掌方向盤。

Meaning

簡短定義

Capricious

形容人、決策、天氣或系統反覆無常、難以預測，而且變化似乎缺乏穩定理由。語氣通常帶批評。

不是 Unpredictable

unpredictable 只是難預測；capricious 暗示變化像任性地跳動。

期待規則
→
行為突然改變
→
信任下降

Origin

字源

詞史常和跳動、反覆的感覺相連；現代語氣帶一點批判。

不用硬背詞史；抓住「任性地跳」就能分開 capricious 和普通的 changeable。

Memory Hook

記憶鉤子

capricious 像一個今天通過、明天同樣輸入卻失敗的 flaky API。

真正煩人的不是它會變，而是你找不到可信規則，因此信任被慢慢磨掉。

Usage

生活與專業情境

系統 / API

A capricious API 讓人不知道錯在 client，還是服務端今天又改了未公開規則。

管理

Capricious decisions 會讓團隊學會猜主管心情，而不是學會判斷原則。

自然

Capricious weather 不是單純多變，而是變得像沒有邏輯可追。

Collocations

常見搭配與語域

它常接 weather、decision、behavior。這些名詞都需要可預期性；capricious 正是在說可預期性被破壞。

capricious weather 日常 / 寫作

天氣變化像任性跳動，計畫很難穩定安排。

capricious decision 管理 / 法律 / 評論

決策看不到穩定原則，容易讓人質疑公平性。

capricious behavior 心理 / 人際

行為忽冷忽熱或反覆，旁人難以預測。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Capricious 反覆無常、缺少穩定規則 用在變化缺乏理由、破壞信任或讓人難以依規劃行動時。
Unpredictable 不可預測 中性描述難預測，不一定批評動機或任性。
Fickle 善變，常指心意或喜好 多用在人或市場喜好變來變去；capricious 可用在制度和決策。
Erratic 不規則、忽上忽下 偏行為或數據的波動，不一定有任性味。

Modern Use

現代延伸

在法律和管理評論裡，capricious 是很重的字，因為它暗示決策沒有穩定理由。

工程裡拿它形容系統時，也是在說可重現性出了問題：同樣條件下結果不該像心情一樣改變。
