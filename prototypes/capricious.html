Capricious

kuh-PRISH-us · UK /kəˈprɪʃ.əs/ · US /kəˈprɪʃ.əs/

不是靈活，而是沒有穩定規律地忽然改變。

Core Idea

capricious 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Capricious

表示情緒、決定或外部條件反覆無常、難以預測。

不是 Unpredictable

unpredictable 可以先說出 無法預測；capricious 則把句子推到「沒有穩定規律地忽然改變」這個更細的位置。

Origin

字源

1590年代，“幽默的”； 大約1600年，“容易突然改變主意，善變”，源自法語 capricieux “異想天開的”（16世紀），來自意大利語 capriccioso，源自 capriccio（見 caprice）。

像天氣原本還亮著，忽然就轉雨，連前奏都沒有

Memory Hook

記憶鉤子

capricious：像天氣原本還亮著，忽然就轉雨，連前奏都沒有

這個畫面有用，是因為它先把「沒有穩定規律地忽然改變」釘住；回到實際搭配時，就不容易把它和 Unpredictable 混成一團。

Usage

生活與專業情境

日常版

像 capricious mood 這樣的說法，多半出現在 情緒 / 人際 的場景；句子真正要說的，就是「沒有穩定規律地忽然改變」。

數位 / 專業版

到了 自然 / 日常 的場景，capricious weather 會更常出現；這裡要說清楚的，正是「沒有穩定規律地忽然改變」。

Collocations

常見搭配與語域

常見用法集中在 capricious mood 和 capricious weather；這幾個搭配分別落在 情緒 / 人際 和 自然 / 日常 的場景裡。

capricious mood 情緒 / 人際

在 情緒 / 人際 的語境裡，這個搭配通常就在形容 mood 的狀態或氣質。

capricious weather 自然 / 日常

在 自然 / 日常 的語境裡，這個搭配通常就在形容 weather 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Capricious 情緒、決定或外部條件反覆無常、難以預測 當句子需要把「沒有穩定規律地忽然改變」說清楚，而不是只留在 無法預測 的外圈時。
Unpredictable 無法預測 當你只需要先說 無法預測，不必把語氣收進「沒有穩定規律地忽然改變」時。

Modern Use

現代延伸

現在最常見的就是 capricious mood 和 capricious weather 這類說法；它們一出現，通常就在替句子劃清「沒有穩定規律地忽然改變」的範圍。

當句子要把「沒有穩定規律地忽然改變」說準時，capricious 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
