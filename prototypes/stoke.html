Stoke

STOHK · UK /stəʊk/ · US /stoʊk/

不是點火那一瞬間，而是不斷加料讓它燒旺。

C1

Core Idea

stoke 用來描述「不斷加料讓它燒旺」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Stoke

表示添柴助長火勢，也可比喻推高情緒、需求或期待。

不是 Fuel

fuel 可以先說出 助長；stoke 則把句子推到「不斷加料讓它燒旺」這個更細的位置。

Origin

字源

1680年代，“喂养和搅动”（壁炉或炉中的火），是从stoker“维护炉中火焰的人”（1650年代）的后形成词；最终源自荷兰语stoken“搅动”，来自中荷兰语stoken“戳，推”，与stoc“棍子，树桩”相关，来自原始日耳曼语*stok-“刺，戳”（来自原始印欧语*steug-，扩展形式的词根*(s)teu- (1)“推动，刺，敲，打”；参见steep (adj.)）。

像火已經有了，你再補進乾木頭，整個熱度馬上往上躥

Memory Hook

記憶鉤子

能用這個畫面回到「添柴助長火勢，也可比喻推高情緒、需求或期待」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 stoke demand 這樣的說法，多半出現在 商業 / 市場 的場景；句子真正要說的，就是「不斷加料讓它燒旺」。

數位 / 專業版

到了 情緒 / 媒體 的場景，stoke anxiety 會更常出現；這裡要說清楚的，正是「不斷加料讓它燒旺」。

Collocations

常見搭配與語域

常見用法集中在 stoke demand 和 stoke anxiety；這幾個搭配分別落在 商業 / 市場 和 情緒 / 媒體 的場景裡。

stoke demand 商業 / 市場

在 商業 / 市場 的語境裡，這個搭配會把動作直接落在 demand 上。

stoke anxiety 情緒 / 媒體

在 情緒 / 媒體 的語境裡，這個搭配會把動作直接落在 anxiety 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Fuel 助長 當你只需要先說 助長，不必把語氣收進「不斷加料讓它燒旺」時。

Modern Use

現代延伸

現在最常見的就是 stoke demand 和 stoke anxiety 這類說法；它們一出現，通常就在替句子劃清「不斷加料讓它燒旺」的範圍。

當句子要把「不斷加料讓它燒旺」說準時，stoke 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
