Endeavor

en-DEV-er · UK /ɪnˈdev.ər/ · US /ɪnˈdev.ɚ/

不是隨手試試，而是帶著目的和投入往前推的一件事。

Core Idea

endeavor 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「哪個現象被單獨叫出來」？

Meaning

簡短定義

Endeavor

表示認真追求的努力、事業或嘗試。

不是 Effort

如果 effort 已經能讓句子成立，就不必硬換；需要「認真追求的努力、事業或嘗試」時，endeavor 才有必要。

Origin

字源

15世紀初，“爲達到目標而付出的努力”，字面意思是“在責任中”，來自短語 put (oneself) in dever “使之成爲責任”（對古法語短語 mettre en deveir “放在責任中”的部分翻譯），源自古法語 dever “責任”，來自拉丁語 debere “欠債”，最初是指“將某物遠離某人”，由 de- “遠離”（參見 de-）和 habere “擁有”（來自 PIE 詞根 *ghabh- “給予或接受”）組成。某人的 endeavors 意味着某人的“最大努力”，始於15世紀晚期。

像船不是在原地打轉，而是明知有浪還朝某個方向穩穩划

Memory Hook

記憶鉤子

endeavor：像船不是在原地打轉，而是明知有浪還朝某個方向穩穩划

這個畫面之所以有用，是因為它能幫你確認 endeavor 是否真的在談「帶著目的和投入往前推的一件事」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

當人們說 joint endeavor 時，焦點通常就在「帶著目的和投入往前推的一件事」上，所以這個搭配很能代表 endeavor 的語感。

數位 / 專業版

到了 創作 / 藝術 的場景，creative endeavor 會更常出現；這裡要說清楚的，正是「帶著目的和投入往前推的一件事」。

Collocations

常見搭配與語域

常見用法集中在 joint endeavor 和 creative endeavor；這幾個搭配分別落在 合作 / 團隊 和 創作 / 藝術 的場景裡。

joint endeavor 合作 / 團隊

在 合作 / 團隊 的語境裡，前面的 joint 會把這個概念限定到更具體的場景。

creative endeavor 創作 / 藝術

在 創作 / 藝術 的語境裡，前面的 creative 會把這個概念限定到更具體的場景。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Endeavor 認真追求的努力、事業或嘗試 當較普通的說法太鬆，無法交代 哪個現象被單獨叫出來 時。
Effort 努力 如果上下文還沒有給出足夠理由支撐 endeavor，先用 effort。

Modern Use

現代延伸

現在最常見的就是 joint endeavor 和 creative endeavor 這類說法；它們一出現，通常就在替句子劃清「帶著目的和投入往前推的一件事」的範圍。

當句子要把「帶著目的和投入往前推的一件事」說準時，endeavor 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
