Core Idea

mire 的核心是把「陷入泥淖、困境、繁瑣程序或麻煩中」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

不是 Trap

Origin

字源

\"深泥，泥潭，沼澤地\"，約1300年，來自斯堪的納維亞源，如古諾爾斯語 myrr \"泥潭，沼澤\"，源自原始日耳曼語 *miuzja-（古英語 mos \"泥潭，沼澤\"的來源），源自原始印歐語 *meus- \"潮溼\"（見 moss）。

像車輪一陷進濕泥，轉得越快，反而陷得越深

Memory Hook

記憶鉤子

mire：像車輪一陷進濕泥，轉得越快，反而陷得越深

這個畫面有用，是因為它先把「陷進去後每一步都更難抽身」釘住；回到實際搭配時，就不容易把它和 Trap 混成一團。

Usage

生活與專業情境

日常版

像 mired in paperwork 這樣的說法，多半出現在 工作 / 行政 的場景；句子真正要說的，就是「陷進去後每一步都更難抽身」。

數位 / 專業版

到了 人際 / 衝突 的場景，mired in conflict 會更常出現；這裡要說清楚的，正是「陷進去後每一步都更難抽身」。

Collocations

常見搭配與語域

常見用法集中在 mired in paperwork 和 mired in conflict；這幾個搭配分別落在 工作 / 行政 和 人際 / 衝突 的場景裡。

mired in paperwork 工作 / 行政

在 工作 / 行政 的語境裡，這個搭配最容易看出「陷進去後每一步都更難抽身」實際怎麼落在句子裡。

mired in conflict 人際 / 衝突

在 人際 / 衝突 的語境裡，這個搭配最容易看出「陷進去後每一步都更難抽身」實際怎麼落在句子裡。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 工作 / 行政、人際 / 衝突、財務 / 困境 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
