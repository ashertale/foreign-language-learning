Divest

dy-VEST · UK /daɪˈvest/ · US /daɪˈvest/

不是丟掉，而是有計畫地把持有的東西卸出去。

Core Idea

divest 不只是 Sell 的近義替代；它用來描述「有計畫地把持有的東西卸出去」這種更窄、更準確的情境。

Meaning

簡短定義

Divest

表示出售資產、剝離業務，或使自己不再持有某物。

不是 Sell

Sell 可以先說大方向；divest 用在你要把「有計畫地把持有的東西卸出去」這條語氣邊界說得更準的時候。

Origin

字源

1560年代， devest（現代拼寫約爲1600年），意爲“剝奪財產”，源自法語 devester “剝奪財產”（古法語 desvestir），由 des- “離開”（見 dis-)和 vestir “穿衣”組成，源自拉丁語 vestire “穿衣”（來自 PIE *wes-（2）“穿衣”的擴展形式，根源爲 *eu- “穿衣”）。

像樹把過重的枝條修掉，不是因為討厭，而是為了讓整體活得更穩

Memory Hook

記憶鉤子

divest：像樹把過重的枝條修掉，不是因為討厭，而是為了讓整體活得更穩

能用這個畫面回到「出售資產、剝離業務，或使自己不再持有某物」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

像 divest the assets 這樣的說法，多半出現在 財務 / 企業 的場景；句子真正要說的，就是「有計畫地把持有的東西卸出去」。

數位 / 專業版

到了 公共 / 投資 的場景，divest from fossil fuels 會更常出現；這裡要說清楚的，正是「有計畫地把持有的東西卸出去」。

Collocations

常見搭配與語域

常見用法集中在 divest the assets 和 divest from fossil fuels；這幾個搭配分別落在 財務 / 企業 和 公共 / 投資 的場景裡。

divest the assets 財務 / 企業

在 財務 / 企業 的語境裡，這個搭配會把動作直接落在 the assets 上。

divest from fossil fuels 公共 / 投資

在 公共 / 投資 的語境裡，這個搭配會把動作直接落在 from fossil fuels 上。

Modern Use

現代延伸

現在最常見的就是 divest the assets 和 divest from fossil fuels 這類說法；它們一出現，通常就在替句子劃清「有計畫地把持有的東西卸出去」的範圍。

比起 sell，divest 更適合用在你想直接點出「出售資產、剝離業務，或使自己不再持有某物」的時候。
