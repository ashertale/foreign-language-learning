Divest

dy-VEST · UK /daɪˈvest/ · US /daɪˈvest/

不是丟掉，而是有計畫地把持有的東西卸出去。

Core Idea

divest 不只是交代動作發生；它更常用來指出事情怎麼朝「有計畫卸出去」這條線走。

Meaning

簡短定義

Divest

表示出售資產、剝離業務，或使自己不再持有某物。它要補上的，通常不是動作本身，而是那層更具體的「有計畫地把持有的東西卸出去」。

不是 Sell

如果語境只需要比較平的「出售」，用 Sell 往往就夠了；divest 則會把「有計畫地把持有的東西卸出去」講得更明確。

Memory Hook

記憶鉤子

divest 的畫面是：像樹把過重的枝條修掉，不是因為討厭，而是為了讓整體活得更穩。

記這個畫面，不是為了背故事，而是讓你下次看到 divest 時，能先抓到「有計畫卸出去」這個核心，再回頭讀細節。

Usage

生活與專業情境

日常版

讀到 divest the assets 時，可以先別急著翻中文；先看句子是不是想把動作往「有計畫卸出去」這個方向講清楚。

數位 / 專業版

divest from fossil fuels 放進 公共 / 投資 後，常會比一般近義詞更有份量，因為它把結果之外的那層語氣也帶了進來。

延伸版

如果你想把這個字放進 治理 / 權責 的情境，從 divest responsibility 這種搭配進場通常最穩，因為語感邊界很清楚。

Collocations

常見搭配與語域

看這些搭配時，重點不是詞組本身，而是這個動詞通常怎麼把事情往更具體的方向收緊。

divest the assets 財務 / 企業

這個搭配常出現在需要把事情往「有計畫卸出去」講清楚的句子裡。

divest from fossil fuels 公共 / 投資

放到 公共 / 投資 裡，它會讓動作聽起來不只發生了，還帶著明顯的語氣或後果。

divest responsibility 治理 / 權責

在 治理 / 權責 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Divest 有計畫卸出去 當你要把事情說成「有計畫地把持有的東西卸出去」而不只是 出售 時
Sell 出售 當句子只需要 出售 這個動作，不必補上「有計畫地把持有的東西卸出去」那層走向時

Modern Use

現代延伸

divest 在現代語境裡很少只是字面動作。它常被拿來把一句話的走向講得更清楚，尤其是在 divest the assets 這類搭配裡更明顯。

所以它和 Sell 的差別，通常不在難度，而在句子要不要把那層「有計畫卸出去」明白說出來。
