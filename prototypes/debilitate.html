Debilitate

dih-BIL-ih-tayt · UK /dɪˈbɪl.ɪ.teɪt/ · US /dɪˈbɪl.ə.teɪt/

不是累而已，而是弱到原本能做的事開始做不動。

Core Idea

debilitate 的核心是把「使虛弱、削弱功能或行動力」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Debilitate

表示使虛弱、削弱功能或行動力。

不是 Weaken

Weaken 可以先說大方向；debilitate 用在你要把「弱到原本能做的事開始做不動」這條語氣邊界說得更準的時候。

Origin

字源

\"削弱，損害力量，使無效或無力，使無生氣\"，來自1530年代的拉丁語 debilitatus，是 debilitare 的過去分詞，意爲\"削弱\"，源自 debilis \"虛弱的，無助的\"，來自 de \"從，離開\"（見 de-) + -bilis \"力量\"，源自 PIE 詞根 *bel- \"強壯\"（見 Bolshevik）。

像電池不是掉一格，而是掉到連開機都變得吃力

Memory Hook

記憶鉤子

debilitate：像電池不是掉一格，而是掉到連開機都變得吃力

這個畫面之所以有用，是因為它能幫你確認 debilitate 是否真的在談「弱到原本能做的事開始做不動」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 debilitating illness 這樣的說法，多半出現在 健康 / 醫療 的場景；句子真正要說的，就是「弱到原本能做的事開始做不動」。

數位 / 專業版

到了 工程 / 系統 的場景，debilitate the network 會更常出現；這裡要說清楚的，正是「弱到原本能做的事開始做不動」。

Collocations

常見搭配與語域

常見用法集中在 debilitating illness 和 debilitate the network；這幾個搭配分別落在 健康 / 醫療 和 工程 / 系統 的場景裡。

debilitating illness 健康 / 醫療

在 健康 / 醫療 的語境裡，這個搭配最容易看出「弱到原本能做的事開始做不動」實際怎麼落在句子裡。

debilitate the network 工程 / 系統

在 工程 / 系統 的語境裡，這個搭配會把動作直接落在 the network 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Debilitate 使虛弱、削弱功能或行動力 用在你想讓讀者看到「使虛弱、削弱功能或行動力」這個較窄邊界的時候。
Weaken 削弱 用在大方向比細邊界重要的句子；它讓意思先站住，不急著精修。

Modern Use

現代延伸

現在最常見的就是 debilitating illness 和 debilitate the network 這類說法；它們一出現，通常就在替句子劃清「弱到原本能做的事開始做不動」的範圍。

比起 weaken，debilitate 更適合用在你想直接點出「使虛弱、削弱功能或行動力」的時候。
