Parity

PAIR-uh-tee · UK /ˈpær.ə.ti/ · US /ˈper.ə.t̬i/

不是相似，而是拉到同一個等級線上。

Core Idea

parity 指那種「同等齊平」的狀態、力量、場面或事物。它常把抽象感受壓縮成一個可指認的名詞。

Meaning

簡短定義

Parity

指那種「同等齊平」的狀態、力量、場面或事物。

不是 Equality

equality 偏平權與原則；parity 更像具體指標上的齊平。

Origin

字源

parity 經 French / Latin 傳入時，就是 rank、status 或數值上的對等；所以它不是模糊差不多，而是放到同一水平線。

Memory Hook

記憶鉤子

把 parity 想成兩個儀表板的指針終於對齊。

它說的是可比較的齊平，而不是抽象上的公平感。

Usage

生活與專業情境

產品

薪資

談 parity 時，通常是在看具體的級距、不是只談理念。

Modern Use

現代延伸

parity 在產品、薪資與制度討論裡很常見，因為它把『同一標準線』說得很明確。
