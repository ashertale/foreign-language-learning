Inscrutable

in-SKROO-tuh-bul · UK /ɪnˈskruː.tə.bəl/ · US /ɪnˈskruː.t̬ə.bəl/

不是神秘有趣，而是你怎麼看都看不穿。

Core Idea

inscrutable 用來描述「你怎麼看都看不穿」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Inscrutable

表示難以理解、難以解讀的。

不是 Mysterious

如果 mysterious 已經能讓句子成立，就不必硬換；需要「難以理解、難以解讀的」時，inscrutable 才有必要。

先遇到 inscrutable expression
→
看它是否只是 神秘
→
再決定是否需要 inscrutable

Origin

字源

\"無法通過搜索發現的，神祕的\"，大約於1500年，源自晚期拉丁語 inscrutabilis，來自 in- \"不，相反\"（見 in-（1））+ *scrutabilis，來自 scrutari \"檢查，搜查\"（見 scrutiny）。

像一扇沒有把手也沒有窗的門，站在外面只能猜裡面是什麼

Memory Hook

記憶鉤子

inscrutable：像一扇沒有把手也沒有窗的門，站在外面只能猜裡面是什麼

能用這個畫面回到「難以理解、難以解讀的」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 inscrutable expression 時，焦點通常就在「你怎麼看都看不穿」上，所以這個搭配很能代表 inscrutable 的語感。

數位 / 專業版

到了 人際 / 情緒 的場景，inscrutable silence 會更常出現；這裡要說清楚的，正是「你怎麼看都看不穿」。

Collocations

常見搭配與語域

常見用法集中在 inscrutable expression 和 inscrutable silence；這幾個搭配分別落在 人物 / 描寫 和 人際 / 情緒 的場景裡。

inscrutable expression 人物 / 描寫

在 人物 / 描寫 的語境裡，這個搭配通常就在形容 expression 的狀態或氣質。

inscrutable silence 人際 / 情緒

在 人際 / 情緒 的語境裡，這個搭配通常就在形容 silence 的狀態或氣質。

Modern Use

現代延伸

現在最常見的就是 inscrutable expression 和 inscrutable silence 這類說法；它們一出現，通常就在替句子劃清「你怎麼看都看不穿」的範圍。

當句子要把「你怎麼看都看不穿」說準時，inscrutable 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
