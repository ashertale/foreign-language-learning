Inscrutable

in-SKROO-tuh-bul · UK /ɪnˈskruː.tə.bəl/ · US /ɪnˈskruː.t̬ə.bəl/

不是神秘有趣，而是你怎麼看都看不穿。

Core Idea

inscrutable 是看不穿；表情、沉默或行為在你面前，意思卻不打開。

Meaning

簡短定義

Inscrutable

形容難以理解、難以解讀、看不透。

不是 Mysterious

mysterious 可以迷人；inscrutable 讓人卡在解讀失敗。

表情或行為可被觀察
→
線索不足以解碼
→
意圖與原因保持封閉

Origin

字源

inscrutable 原本指就算仔細搜索也查不出來；因此它的神祕感不是華麗，而是你怎麼挖都碰不到底。

Memory Hook

記憶鉤子

把 inscrutable silence 想成對方不說話，但你完全判斷不出是同意、反對，還是在等。

inscrutable 的焦點是 unreadability。

Usage

生活與專業情境

表情

His inscrutable expression made the room work harder than the answer did. 這裡放在表情情境時，是在說資訊就在眼前，但意圖、原因或意義仍無法讀出來。

沉默

Inscrutable silence can be more destabilizing than open disagreement. 這裡放在沉默情境時，是在說資訊就在眼前，但意圖、原因或意義仍無法讀出來。

行為

在行為這類情境裡，inscrutable 的重點是：不是神秘有趣，而是你怎麼看都看不穿。

Collocations

常見搭配與語域

inscrutable 常修飾 expression、silence、behavior；搭配都和無法讀出意圖有關。

inscrutable expression 敘事 / 人際

看不透的表情。

inscrutable silence 人際 / 文學

難以解讀的沉默。

inscrutable behavior UX / 評論

難以理解的行為。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Inscrutable 看不穿 用在資訊就在眼前，但意圖、原因或意義仍無法讀出來時。
Mysterious 神秘 可有吸引力；inscrutable 更重無法解讀。
Opaque 不透明 常指資訊或系統；inscrutable 更可指人與表情。

Modern Use

現代延伸

Inscrutable 對 UX 也很有用：system behavior can be inscrutable。

它比 mysterious 少一點浪漫，多一點讀不懂的挫折。
