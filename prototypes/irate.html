Irate

eye-RAYT · UK /aɪˈreɪt/ · US /aɪˈreɪt/

不是不高興而已，而是怒氣已經寫在臉上。

Core Idea

irate 最值得保留的語感，是它讓「盛怒、惱火」不再只是模糊大意。

Meaning

簡短定義

Irate

表示盛怒、惱火。

不是 Angry

把它們分開記：angry 先保留大方向，irate 負責把邊界收乾淨。

Origin

字源

1838年，源自拉丁語 iratus “憤怒的，暴怒的，狂暴的”，是 irasci “變得憤怒”的過去分詞，源自 ira “憤怒”（參見 ire）。

像壓力鍋的閥門已經開始尖叫，再多一點火就要掀蓋

Memory Hook

記憶鉤子

irate：像壓力鍋的閥門已經開始尖叫，再多一點火就要掀蓋

這個畫面能幫你把 irate 和 Angry 分開，因為它把「怒氣已經寫在臉上」那條界線變得可見。

Usage

生活與專業情境

日常版

像 irate customer 這樣的說法，多半出現在 服務 / 客訴 的場景；句子真正要說的，就是「怒氣已經寫在臉上」。

數位 / 專業版

到了 人際 / 溝通 的場景，irate response 會更常出現；這裡要說清楚的，正是「怒氣已經寫在臉上」。

Collocations

常見搭配與語域

常見用法集中在 irate customer 和 irate response；這幾個搭配分別落在 服務 / 客訴 和 人際 / 溝通 的場景裡。

irate customer 服務 / 客訴

在 服務 / 客訴 的語境裡，這個搭配通常就在形容 customer 的狀態或氣質。

irate response 人際 / 溝通

在 人際 / 溝通 的語境裡，這個搭配通常就在形容 response 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Irate 盛怒、惱火 當搭配和語境都已經指向「怒氣已經寫在臉上」，這個字才自然。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 服務 / 客訴、人際 / 溝通、敘事 / 描寫 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
