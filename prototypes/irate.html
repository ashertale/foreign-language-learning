Irate

eye-RAYT · UK /aɪˈreɪt/ · US /aɪˈreɪt/

不是不高興而已，而是怒氣已經寫在臉上。

Core Idea

irate 真正抓住的，不是程度高低，而是整體怎麼被「怒氣已經寫在臉上」這個感覺支配。

Meaning

簡短定義

Irate

表示盛怒、惱火。它會影響的，不只是一個特徵，而是你怎麼判斷整個場面。

不是 Angry

如果語境只需要比較平的「生氣」，用 Angry 往往就夠了；irate 則會把「怒氣已經寫在臉上」講得更明確。

接著這個字把它往「怒氣已經寫在臉上」這種更具體的樣子收緊
→
所以它不是裝飾，而是在告訴你應該怎麼看那個對象

Memory Hook

記憶鉤子

irate 的畫面是：像壓力鍋的閥門已經開始尖叫，再多一點火就要掀蓋。

記這個畫面，不是為了背故事，而是讓你下次看到 irate 時，能先抓到「怒氣外露」這個核心，再回頭讀細節。

Usage

生活與專業情境

日常版

看到 irate customer 時，可以先抓住一點：這不是把形容詞寫得更漂亮，而是把「怒氣外露」這層氣質壓到前景。

數位 / 專業版

irate response 放進 人際 / 溝通 後，通常會比普通近義詞更有畫面，因為它讓整個對象的輪廓變得更清楚。

延伸版

如果你想把這個字放進 敘事 / 描寫 的情境，從 sound irate 這種說法進場通常最自然，因為它會逼你分清楚質地差在哪。

Modern Use

現代延伸

irate 在現代英文裡最有用的地方，是它能快速替整個對象定調。像 irate customer、irate response 這些搭配，就會讓那種氣質立刻落地。

如果只說比較平的「生氣」，Angry 也許夠用；但當你需要的是更具體的「怒氣已經寫在臉上」，irate 會更準。
