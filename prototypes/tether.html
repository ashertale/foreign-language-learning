Tether

TETH-er · UK /ˈteð.ər/ · US /ˈteð.ɚ/

不是完全鎖死，而是留一條線讓它不要跑遠。

Core Idea

tether 用來描述「留一條線讓它不要跑遠」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Tether

表示用繩索拴住，也可比喻把想法或功能綁定在基準上。

不是 Tie

如果 tie 已經能讓句子成立，就不必硬換；需要「用繩索拴住，也可比喻把想法或功能綁定在基準上」時，tether 才有必要。

Origin

字源

在14世紀末，出現了teder和tether這兩個詞，意指「用來將動物固定在某個點上的繩子」。這個詞在古英語中並不存在，可能源自斯堪地那維亞語，類似於古諾爾斯語的tjoðr，而這又可以追溯到原始日耳曼語的*teudran（這個詞也衍生出了丹麥語的tøir、古瑞典語的tiuther、瑞典語的tjuder、古弗里西語的tiader、中荷蘭語的tuder、荷蘭語的tuier，意指「線，繩子」；還有古高地德語的zeotar，意為「車輛的桿子」）。這一詞源於原始印歐語根*deu-，意為「固定」，加上工具性後綴*-tro-。而將其引申為「衡量個人極限的標準」的比喻意義，則可以追溯到16世紀70年代。

Memory Hook

記憶鉤子

tether：像風箏可以飛，但一定有一條線把它拉回來

這個畫面之所以有用，是因為它能幫你確認 tether 是否真的在談「留一條線讓它不要跑遠」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

當人們說 tether the device 時，焦點通常就在「留一條線讓它不要跑遠」上，所以這個搭配很能代表 tether 的語感。

數位 / 專業版

到了 評論 / 分析 的場景，tether to reality 會更常出現；這裡要說清楚的，正是「留一條線讓它不要跑遠」。

Collocations

常見搭配與語域

常見用法集中在 tether the device 和 tether to reality；這幾個搭配分別落在 硬體 / 連線 和 評論 / 分析 的場景裡。

tether the device 硬體 / 連線

在 硬體 / 連線 的語境裡，這個搭配會把動作直接落在 the device 上。

tether to reality 評論 / 分析

在 評論 / 分析 的語境裡，這個搭配會把動作直接落在 to reality 上。

Modern Use

現代延伸

現在最常見的就是 tether the device 和 tether to reality 這類說法；它們一出現，通常就在替句子劃清「留一條線讓它不要跑遠」的範圍。

當句子要把「留一條線讓它不要跑遠」說準時，tether 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
