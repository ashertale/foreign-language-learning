Infiltrate

IN-fil-trayt · UK /ˈɪn.fɪl.treɪt/ · US /ˈɪn.fɪl.treɪt/

不是正面衝進去，而是從縫裡慢慢滲入。

CEFR
C1
Zipf Frequency
2.81
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

infiltrate 是悄悄滲進去，不是正面闖入；它靠隱蔽、耐心和縫隙。

Meaning

簡短定義

Infiltrate

表示潛入、滲透組織、群體、網路或系統。

不是 Invade

invade 像大門被撞開；infiltrate 像水從縫裡滲進來。

邊界或防線存在
→
進入者隱蔽穿過縫隙
→
內部被慢慢滲透

Origin

字源

infiltrate 先有像液體經過孔隙慢慢滲入的字面義；後來轉到軍事、組織與資訊場景時，仍保留那種不是正面衝進去，而是悄悄滲進去的動作。

Memory Hook

記憶鉤子

把 infiltrate the network 想成攻擊者不是敲正門，而是從一個被忽略的小入口慢慢進來。

infiltrate 的路徑是 covert entry。

Usage

生活與專業情境

網路

Attackers infiltrated the network through an abandoned credential. 這裡放在網路情境時，是在說進入是隱蔽、逐步、違反邊界的時候。

群體

The group was infiltrated by someone who gained trust over months. 這裡放在群體情境時，是在說進入是隱蔽、逐步、違反邊界的時候。

系統

Malicious. 這裡放在系統情境時，是在說進入是隱蔽、逐步、違反邊界的時候。

Collocations

常見搭配與語域

infiltrate 常接 network、group、system；搭配都涉及進入本不該進入的內部。

infiltrate the network 資安 / 工程

滲透網路。

infiltrate the group 政治 / 社會

潛入群體。

infiltrate the system 工程 / 安全

滲入系統。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Infiltrate 悄悄滲入 用在進入是隱蔽、逐步、違反邊界的時候。
Invade 入侵 較正面、明顯；infiltrate 更隱蔽、更慢。
Penetrate 穿透 可技術或物理；infiltrate 重秘密進入內部。

Modern Use

現代延伸

Infiltrate 對資安非常自然，也常見於政治與間諜語境。

它不只是 enter；它暗示防線被悄悄越過。
