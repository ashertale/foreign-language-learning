Infiltrate

IN-fil-trayt · UK /ˈɪn.fɪl.treɪt/ · US /ˈɪn.fɪl.treɪt/

不是正面衝進去，而是從縫裡慢慢滲入。

Core Idea

infiltrate 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Infiltrate

表示潛入、滲透某個群體、區域或系統。

不是 Invade

invade 可以先說出 入侵；infiltrate 則把句子推到「從縫裡慢慢滲入」這個更細的位置。

Origin

字源

1758年，關於流體，源自 in-（2）“內部”和 filtrate（v.）。“內部”可能是模仿法語 infiltrer（16世紀）而來。軍事意義上的“滲透敵方陣地”最早見於1934年。

像雨水不是砸破屋頂，而是先從細縫一滴一滴滲進來

Memory Hook

記憶鉤子

infiltrate：像雨水不是砸破屋頂，而是先從細縫一滴一滴滲進來

這個畫面有用，是因為它先把「從縫裡慢慢滲入」釘住；回到實際搭配時，就不容易把它和 Invade 混成一團。

Usage

生活與專業情境

日常版

像 infiltrate the network 這樣的說法，多半出現在 工程 / 安全 的場景；句子真正要說的，就是「從縫裡慢慢滲入」。

數位 / 專業版

到了 社會 / 組織 的場景，infiltrate the group 會更常出現；這裡要說清楚的，正是「從縫裡慢慢滲入」。

Collocations

常見搭配與語域

常見用法集中在 infiltrate the network 和 infiltrate the group；這幾個搭配分別落在 工程 / 安全 和 社會 / 組織 的場景裡。

infiltrate the network 工程 / 安全

在 工程 / 安全 的語境裡，這個搭配會把動作直接落在 the network 上。

infiltrate the group 社會 / 組織

在 社會 / 組織 的語境裡，這個搭配會把動作直接落在 the group 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Infiltrate 潛入、滲透某個群體、區域或系統 當句子需要把「從縫裡慢慢滲入」說清楚，而不是只留在 入侵 的外圈時。
Invade 入侵 當你只需要先說 入侵，不必把語氣收進「從縫裡慢慢滲入」時。

Modern Use

現代延伸

現在最常見的就是 infiltrate the network 和 infiltrate the group 這類說法；它們一出現，通常就在替句子劃清「從縫裡慢慢滲入」的範圍。

當句子要把「從縫裡慢慢滲入」說準時，infiltrate 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
