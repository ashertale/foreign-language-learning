Novice

Core Idea

novice 不是能力差，而是剛進入領域，心裡的基本地圖還在生成。

Meaning

簡短定義

Novice

指新手、初學者，通常經驗尚少、仍在建立基礎模型。

不是 Beginner

beginner 是初學者；novice 常帶剛入門、經驗尚少的狀態。

進入新領域
→
經驗不足
→
建立基礎模型

Origin

字源

來自 Latin novus「新的」。

novus 是新的；novice 就是新進入某領域的人。

Memory Hook

記憶鉤子

把 novice user 的困惑想成產品送來的訊號。

如果只有熟手看得懂，設計其實在排除新人。

Usage

生活與專業情境

產品

把 novice user 的困惑當成訊號，產品才不會只服務熟手。

程式

程式情境下，novice 不是能力差，而是剛進入某領域、還在建立基本模型的人。

完全新手

A complete novice is starting without the background insiders forget they have.

Collocations

常見搭配與語域

novice 常接 complete、programmer、user。搭配會說明新手在哪個領域還沒有地圖。

complete novice 日常 / 教學

完全新手，幾乎沒有背景。

novice programmer 教育 / 工程

初學程式的人。

novice user UX / 產品

剛接觸產品或領域的使用者。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Novice 新手、初學者 用在強調某人剛進入領域、經驗和心智模型尚在建立時。
Beginner 初學者 最通用。
Amateur 業餘者 可指非專業，也可帶貶義。
Newcomer 新來者 重剛加入群體或地方。

Modern Use

現代延伸

Novice 對設計和教學很重要，因為新手不是小型專家。他們缺的不是速度，而是路標。

好的 onboarding 不會責怪 novice 問錯問題，而是看見系統哪裡沒有給入口。
