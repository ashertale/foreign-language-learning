Exasperate

ig-ZAS-puh-rayt · UK /ɪɡˈzɑː.spə.reɪt/ · US /ɪɡˈzæs.pə.reɪt/

不是惹煩而已，而是煩到忍耐層被磨穿。

CEFR
C1
Zipf Frequency
2.71
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

exasperate 是把人的耐心磨到刺起來；不是單純惹煩，而是煩到快爆。

Meaning

簡短定義

Exasperate

表示使人惱怒、極度不耐、氣急敗壞。

不是 Annoy

annoy 是煩；exasperate 是煩到耐心被刮破。

問題反覆刺激人
→
耐心逐步消耗
→
情緒變成氣急不耐

Origin

字源

exasperate 來自 Latin，和 rough、harsh 那支字根有關，原意近於把表面磨粗、把刺感加重；所以它不是小煩，而是把人磨到火氣全面起來。

Memory Hook

記憶鉤子

把 exasperated by delays 想成 delay 第一次可以理解，第六次就開始讓人咬牙。

exasperate 通常有累積感。

Usage

生活與專業情境

團隊

Changing the priority every morning exasperated the team.

延遲

Users were exasperated by delays because each update promised a fix.

觀眾

A plot that refuses to resolve anything can exasperate the audience.

Collocations

常見搭配與語域

exasperate 常接 team、audience，或用 exasperated by delays；搭配都在描述耐心被磨穿。

exasperate the team 工作 / 管理

讓團隊極度惱火。

exasperated by delays 專案 / 日常

因延遲而氣惱不耐。

exasperate the audience 媒體 / 寫作

讓觀眾失去耐心。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Exasperate 把耐心磨穿 用在反覆阻礙、失望或愚蠢情況把人的耐心逼到邊緣時。
Annoy 惹煩 程度較輕；exasperate 是耐心幾乎耗盡。
Frustrate 使挫折 重目標受阻；exasperate 重情緒惱火。

Modern Use

現代延伸

Exasperated 是很自然的情緒形容詞，介於 annoyed 和 furious 之間但更有疲憊感。

它適合形容被流程、延遲、反覆錯誤折磨的人。
