Word 413 / verb

Daunt

DONT · UK /dɔːnt/ · US /dɔːnt/

不是直接打倒，而是先把勇氣往下壓。

CEFR
C1
Zipf Frequency
2.76
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

daunt 是困難先壓到人的膽量，讓人還沒開始就縮了一下。

Meaning

簡短定義

Daunt

表示使人畏縮、怯步、感到難以面對。

不是 Intimidate

intimidate 常像被人或權威嚇到；daunt 常是任務本身大到讓人停住。

挑戰顯得龐大
→
人的膽量被壓低
→
第一步變得困難

Origin

字源

daunt 經 Old French 傳入，早期核心是征服、壓倒、制服對手；所以現代說被 daunt，不只是嚇到，而是氣勢被整個壓下去。

Memory Hook

記憶鉤子

把 daunted by the scale 想成 migration 還沒動手，光看相依圖就想關 laptop。

daunt 的效果發生在勇氣和行動之間。

Usage

生活與專業情境

新人

The size of the codebase can daunt the newcomer before any bug appears.

規模

Being daunted by the scale is not weakness; it is a signal to break the work down.

形容詞

A daunting task feels large enough to slow the first step.

Collocations

常見搭配與語域

daunt 常以 daunting、daunted by 出現；搭配會說明是什麼壓住人的膽量。

daunt the newcomer 教育 / 工作

讓新人怯步。

seem daunting 日常 / 專案

看起來令人卻步。

daunted by the scale 工程 / 管理

被規模嚇住。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Daunt 先把勇氣壓下去 用在挑戰的大小或困難感壓低人的行動勇氣時。
Intimidate 威嚇、使畏懼 可來自人或權勢；daunt 常來自任務難度或規模。
Discourage 使氣餒 偏降低意願；daunt 更像先讓人怯步。

Modern Use

現代延伸

Daunting 是專案語境常用形容詞，既承認難度，也不等於放棄。

好管理會把 daunting work 切成可開始的第一步。
