Daunt

DONT · UK /dɔːnt/ · US /dɔːnt/

不是直接打倒，而是先把勇氣往下壓。

CEFR
C1

Core Idea

daunt 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「動作是否真的落地」？

Meaning

簡短定義

Daunt

表示使人畏縮、怯步，因困難或規模而不敢前進。

不是 Intimidate

如果 intimidate 已經能讓句子成立，就不必硬換；需要「使人畏縮、怯步，因困難或規模而不敢前進」時，daunt 才有必要。

先遇到 daunt the newcomer
→
看它是否只是 使畏懼
→
再決定是否需要 daunt

Origin

字源

約於1300年，意爲“征服，制服，征服”，源自古法語 danter，是 donter（12世紀，現代法語 dompter）的變體，意爲“害怕，恐懼，懷疑； 控制，約束”，源自拉丁語 domitare，是 domare “馴服”的頻率動詞（參見 tame（v.））。意爲“恐嚇，壓制勇氣”來自15世紀後期。

像山還沒開始爬，抬頭看見坡度就先覺得腿軟

Memory Hook

記憶鉤子

daunt：像山還沒開始爬，抬頭看見坡度就先覺得腿軟

能用這個畫面回到「使人畏縮、怯步，因困難或規模而不敢前進」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 daunt the newcomer 時，焦點通常就在「先把勇氣往下壓」上，所以這個搭配很能代表 daunt 的語感。

數位 / 專業版

到了 學習 / 任務 的場景，seem daunting 會更常出現；這裡要說清楚的，正是「先把勇氣往下壓」。

Collocations

常見搭配與語域

常見用法集中在 daunt the newcomer 和 seem daunting；這幾個搭配分別落在 職場 / 新手 和 學習 / 任務 的場景裡。

daunt the newcomer 職場 / 新手

在 職場 / 新手 的語境裡，這個搭配會把動作直接落在 the newcomer 上。

seem daunting 學習 / 任務

在 學習 / 任務 的語境裡，這個搭配最容易看出「先把勇氣往下壓」實際怎麼落在句子裡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Daunt 使人畏縮、怯步，因困難或規模而不敢前進 當較普通的說法太鬆，無法交代 動作是否真的落地 時。
Intimidate 使畏懼 如果上下文還沒有給出足夠理由支撐 daunt，先用 intimidate。

Modern Use

現代延伸

現在最常見的就是 daunt the newcomer 和 seem daunting 這類說法；它們一出現，通常就在替句子劃清「先把勇氣往下壓」的範圍。

當句子要把「先把勇氣往下壓」說準時，daunt 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
