Enshrine

en-SHRYN · UK /ɪnˈʃraɪn/ · US /ɪnˈʃraɪn/

不是暫時保留，而是把它放進不易被動搖的位置。

Core Idea

enshrine 是把某個權利、原則或記憶放進制度或共同記憶的神龕裡。

Meaning

簡短定義

Enshrine

表示正式珍藏、奉為重要；常指把權利或原則寫入法律、制度或記憶。

不是 Preserve

preserve 是保存；enshrine 是把保存對象抬到值得敬重的位置。

價值或記憶被認為重要
→
它被放入制度或共同記憶
→
位置變得莊重且難任意移除

Origin

字源

enshrine 原本就是把某物放進 shrine 裡保存；後來才延伸成把價值、原則或記憶安放到不輕易碰動的位置。

Memory Hook

記憶鉤子

把 enshrine the right 想成權利不只被支持，而是被寫進一個更難任意移動的位置。

enshrine 讓價值有正式位置。

Usage

生活與專業情境

權利

權利情境下，enshrine 不是暫時保留，而是把它放進不易被動搖的位置。

原則

A handbook can enshrine a principle, but practice decides whether it lives.

記憶

Communities enshrine in memory what they cannot afford to forget.

Collocations

常見搭配與語域

enshrine 常接 right、principle，也常用 enshrine in memory；搭配都有珍視與正式保存。

enshrine the right 法律 / 政治

將權利正式寫入制度。

enshrine the principle 組織 / 倫理

把原則制度化或奉為核心。

enshrine in memory 歷史 / 人際

珍藏於記憶中。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Enshrine 正式珍藏 用在某物不只是被保留，而是被正式尊崇、制度化或記入共同記憶時。
Preserve 保存 範圍廣；enshrine 更有尊崇和正式位置。
Include 包含 太平；enshrine 表示被安放為重要價值。

Modern Use

現代延伸

Enshrine 在法律、憲法、價值宣言中很常見。

它語氣很高，不適合描述普通存檔。
