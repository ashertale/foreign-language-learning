Advocate

AD-vuh-kayt · UK /ˈæd.və.keɪt/ · US /ˈæd.və.keɪt/

不是只是喜歡某個想法，而是公開替它提出理由、爭取空間。

Core Idea

advocate 描述你站出來支持某個政策、做法或族群，並用論點讓別人認真看待它。

Meaning

簡短定義

Advocate

表示公開支持、主張或提倡某個想法、行動、政策或群體利益。

不是 Support

support 可以只是贊成；advocate 更像主動出面推動與辯護。

看見值得推動的事
→
提出理由
→
替它爭取採納

Origin

字源

advocate 來自拉丁語 advocare，意思接近「把人叫來協助、為一方發聲」。

記成有人站到你旁邊，替你把理由說清楚。

Memory Hook

記憶鉤子

advocate 是把支持從心裡拿到桌面上。

這個字有行動感：不只是同意，而是願意替某件事承擔說服成本。

Usage

生活與專業情境

日常版

你可以 advocate for 更安全的通勤環境，意思是持續提出理由並推動改變。

數位 / 專業版

工程團隊裡，資深成員可能 advocate for automated testing，不是因為測試時髦，而是因為它降低長期風險。

Collocations

常見搭配與語域

Advocate 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

advocate for change 公共議題 / 組織

主動替改革發聲。

advocate a policy 政治 / 管理

公開主張某項政策或做法。

developer advocate 科技 / 社群

在產品與開發者之間替使用者需求發聲的人。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Advocate 主動公開支持並提出理由 談政策、流程、權益、技術實踐或公共倡議時
Support 支持某事，不一定親自推動 只是態度上贊成或提供幫助時

Modern Use

現代延伸

在科技公司裡，advocate 也常是角色名稱，強調替開發者、使用者或某種工程實踐發聲。
