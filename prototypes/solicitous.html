Solicitous

suh-LIS-it-us · UK /səˈlɪs.ɪ.təs/ · US /səˈlɪs.ə.t̬əs/

不是客氣，而是帶著照看意味的關心。

CEFR

Core Idea

solicitous 的關心帶照看動作；不是禮貌問候，而是主動注意對方需要。

Meaning

簡短定義

Solicitous

形容關切、體貼，常帶主動照料或擔心。

不是 Polite

polite 是有禮；solicitous 更像真正把對方放進心裡照看。

注意到對方需要
→
主動多看一眼
→
關心裡帶著照料感

Origin

字源

solicitous 來自拉丁語 sollicitus，早先更接近「心裡被攪動、掛心、發愁」；所以 modern solicitous 的關心裡，常還帶一點焦慮式的留心。

Memory Hook

記憶鉤子

把 solicitous 想成不是說歡迎，而是先幫你把椅子調到最舒服。

這個字裡有一層溫柔的主動性。

Usage

生活與專業情境

照顧

如果一個人關心不是停在嘴上，而是會主動顧細節，就很 solicitous。

服務

過度 solicitous 有時也會讓人覺得被盯得太緊。

Collocations

常見搭配與語域

solicitous host 人際 / 敘事

人對他人需求、舒適或安危特別留心。

solicitous concern 正式 / 評述

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Solicitous 體貼掛心 用在人對他人需求、舒適或安危特別留心時。
Polite 有禮貌、守分寸 若只是表面禮貌，用 polite 更直接。

Modern Use

現代延伸

solicitous 常用來描寫帶照料感的關心，細緻到有時幾乎過頭。
