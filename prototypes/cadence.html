Cadence

KAY-duhns · UK /ˈkeɪ.dəns/ · US /ˈkeɪ.dəns/

不是節拍器式的拍點，而是整段動作或語句流動起來的節奏感。

Core Idea

cadence 最值得保留的語感，是它讓「語言、步伐、流程或工作推進的節律」不再只是模糊大意。

Meaning

簡短定義

Cadence

表示語言、步伐、流程或工作推進的節律。

不是 Rhythm

Rhythm 可以先說大方向；cadence 用在你要把「整段動作或語句流動起來的節奏感」這條語氣邊界說得更準的時候。

Origin

字源

14世紀末，\"散文或詩歌中的韻律流動\"，源自法語 cadence，源自意大利古老的 cadenza \"音樂中的結束\"，字面意思是\"下降\"，源自通俗拉丁語 *cadentia，源自拉丁語 cadens 的中性複數形式，現在分詞是 cadere \"下降\"（源自 PIE 詞根 *kad- \"下降\"）。是 chance（名詞）的同源詞。

記憶鉤子

cadence：像你一聽就知道這段話是慢慢鋪陳還是短促推進

這個畫面之所以有用，是因為它能幫你確認 cadence 是否真的在談「整段動作或語句流動起來的節奏感」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 speaking cadence 這樣的說法，多半出現在 口語 / 簡報 的場景；句子真正要說的，就是「整段動作或語句流動起來的節奏感」。

數位 / 專業版

到了 產品 / 流程 的場景，release cadence 會更常出現；這裡要說清楚的，正是「整段動作或語句流動起來的節奏感」。

Collocations

常見搭配與語域

常見用法集中在 speaking cadence 和 release cadence；這幾個搭配分別落在 口語 / 簡報 和 產品 / 流程 的場景裡。

speaking cadence 口語 / 簡報

在 口語 / 簡報 的語境裡，前面的 speaking 會把這個概念限定到更具體的場景。

release cadence 產品 / 流程

在 產品 / 流程 的語境裡，前面的 release 會把這個概念限定到更具體的場景。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Cadence 語言、步伐、流程或工作推進的節律 用在你想讓讀者看到「語言、步伐、流程或工作推進的節律」這個較窄邊界的時候。
Rhythm 節奏 用在大方向比細邊界重要的句子；它讓意思先站住，不急著精修。

Modern Use

現代延伸

現在最常見的就是 speaking cadence 和 release cadence 這類說法；它們一出現，通常就在替句子劃清「整段動作或語句流動起來的節奏感」的範圍。

比起 rhythm，cadence 更適合用在你想直接點出「語言、步伐、流程或工作推進的節律」的時候。
