Fickle

FIK-uhl · UK /ˈfɪk.əl/ · US /ˈfɪk.əl/

不是有彈性，而是一下這邊一下那邊，很難長久依靠。

Core Idea

fickle 用來描述「一下這邊一下那邊，很難長久依靠」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Fickle

表示喜好、情緒或支持反覆無常。

不是 Unstable

unstable 可以先說出 不穩定；fickle 則把句子推到「一下這邊一下那邊，很難長久依靠」這個更細的位置。

Origin

字源

約1200年，“虛假的，背叛的，欺騙的，狡猾的”（已過時），可能來自古英語 ficol “欺詐的，狡猾的，狡猾的”，與 befician “欺騙”相關，以及 facen “欺騙，背叛； 瑕疵，缺陷”。共同的日耳曼語（比較古撒克遜語 fekan “欺詐”，古高地德語 feihhan “欺詐，欺詐，背叛”），來自與 foe 相同的來源。

像風向旗一直轉，才剛對準一邊，下一秒又變了

Memory Hook

記憶鉤子

fickle：像風向旗一直轉，才剛對準一邊，下一秒又變了

這個畫面之所以有用，是因為它能幫你確認 fickle 是否真的在談「一下這邊一下那邊，很難長久依靠」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 fickle audience 這樣的說法，多半出現在 媒體 / 受眾 的場景；句子真正要說的，就是「一下這邊一下那邊，很難長久依靠」。

數位 / 專業版

到了 人際 / 組織 的場景，fickle loyalty 會更常出現；這裡要說清楚的，正是「一下這邊一下那邊，很難長久依靠」。

Collocations

常見搭配與語域

常見用法集中在 fickle audience 和 fickle loyalty；這幾個搭配分別落在 媒體 / 受眾 和 人際 / 組織 的場景裡。

fickle audience 媒體 / 受眾

在 媒體 / 受眾 的語境裡，這個搭配通常就在形容 audience 的狀態或氣質。

fickle loyalty 人際 / 組織

在 人際 / 組織 的語境裡，這個搭配通常就在形容 loyalty 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fickle 喜好、情緒或支持反覆無常 當句子需要把「一下這邊一下那邊，很難長久依靠」說清楚，而不是只留在 不穩定 的外圈時。
Unstable 不穩定 當你只需要先說 不穩定，不必把語氣收進「一下這邊一下那邊，很難長久依靠」時。

Modern Use

現代延伸

現在最常見的就是 fickle audience 和 fickle loyalty 這類說法；它們一出現，通常就在替句子劃清「一下這邊一下那邊，很難長久依靠」的範圍。

當句子要把「一下這邊一下那邊，很難長久依靠」說準時，fickle 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
