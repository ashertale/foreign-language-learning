Repertoire

REP-er-twahr · UK /ˈrep.ə.twɑː/ · US /ˈrep.ɚ.twɑːr/

不是清單，而是你手上那套真正能拿出來用的本事。

Core Idea

repertoire 指那種「可用本領庫」的狀態、力量、場面或事物。它常把抽象感受壓縮成一個可指認的名詞。

Meaning

簡短定義

Repertoire

指那種「可用本領庫」的狀態、力量、場面或事物。

不是 Inventory

inventory 是庫存清單；repertoire 更像隨時可上場的本領。

Origin

字源

repertoire 先指表演者手上已經練熟、隨時能上場的劇目或曲目庫；所以它後來擴到 skills 時，也不是收藏清單，而是能真正拿出來用的那一套。

Memory Hook

記憶鉤子

把 repertoire 想成不是工具箱，而是你知道怎麼用、用得順的那幾樣工具。

它比 collection 更有熟練與調度感。

Usage

生活與專業情境

技能

如果一個人不只會一招，而是有一整套拿得出手的做法，就可以談他的 repertoire。

表演

在音樂、戲劇語境裡，repertoire 也常指可演出的作品庫。

Collocations

常見搭配與語域

這裡放 repertoire 最自然連在一起的說法；中文註解會補它落在哪種語境與語氣。

expand one's repertoire 學習 / 表演

這個搭配常用來寫某人或某團體手上能熟練拿出來的技能、作品或招式集合。

這個搭配常用來寫某人或某團體手上能熟練拿出來的技能、作品或招式集合。

Modern Use

現代延伸

repertoire 在技能成長、表演藝術與教學討論都很好用，因為它強調的是可調度的熟手庫。
