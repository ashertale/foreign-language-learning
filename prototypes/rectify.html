Rectify

REK-tuh-fy · UK /ˈrek.tɪ.faɪ/ · US /ˈrek.tə.faɪ/

不是隨便修一下，而是把錯誤、偏差或不公正校回正確狀態。

CEFR
C1

Core Idea

rectify 用來描述修正錯誤、校正偏差、彌補不公平或讓系統回到應有的位置。

Meaning

簡短定義

Rectify

表示糾正、矯正或修復錯誤、問題、偏差或不公。

不是 Fix

fix 很泛用；rectify 更正式，帶有把錯的校正回正的感覺。

發現錯誤或偏差
→
採取校正動作
→
回到正確狀態

Origin

字源

rectify 來自拉丁語 rectus 的脈絡，意思是直的、正的。

它像把歪掉的線重新拉直。

Memory Hook

記憶鉤子

rectify 是把歪掉的東西校回正。

這個字常出現在正式通知、品質流程與責任修復裡，語氣比 fix 更慎重。

Usage

生活與專業情境

日常版

帳單算錯時，店家需要 rectify the error，而不是只說抱歉。

數位 / 專業版

若 release note 漏掉重要限制，團隊應 rectify the documentation and notify users。

Collocations

常見搭配與語域

Rectify 的搭配重點在於看見它自然連到哪些名詞、場景或動作，而不是只記中文翻譯。

rectify an error 正式 / 品質

修正錯誤。

rectify a mistake 日常 / 工作

把犯錯造成的問題補正。

rectify the situation 管理 / 客服

把不正確或不公平的狀況拉回來。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Rectify 正式地校正錯誤或偏差 談品質、文件、帳務、責任、不公或正式修復時
Fix 一般修理或解決問題 只是讓東西能用，不強調校正回正時

Modern Use

現代延伸

在品質與合規語境中，rectify 很精準，因為它不只是 make it work，而是讓紀錄、流程與結果回到正確狀態。
