Amiss

uh-MISS · UK /əˈmɪs/ · US /əˈmɪs/

Core Idea

amiss 不只是 Wrong 的近義替代；它用來描述「你直覺先感到哪裡不太對」這種更窄、更準確的情境。

Meaning

簡短定義

Amiss

表示有點不對勁、出差錯或不合適。

不是 Wrong

把它們分開記：wrong 先保留大方向，amiss 負責把邊界收乾淨。

Origin

字源

13世紀中期， amis “偏離目標”，也指“失常”，字面意思是“偏離目標”，來自 a “在，上”（見 a-（1））和 missen “未命中”（見 miss（v.））。從14世紀後期開始，意爲“不當的，錯誤的，有缺陷的”； 最初（14世紀末）的 take (something) amiss 的意思是“誤解”（見 mistake）。現在它的意思是“以不良意義曲解”。

像牆上的畫只歪了一點點，但你一進房就覺得視線卡住

Memory Hook

記憶鉤子

amiss：像牆上的畫只歪了一點點，但你一進房就覺得視線卡住

這個畫面能幫你把 amiss 和 Wrong 分開，因為它把「你直覺先感到哪裡不太對」那條界線變得可見。

Usage

生活與專業情境

日常版

像 something is amiss 這樣的說法，多半出現在 日常 / 判斷 的場景；句子真正要說的，就是「你直覺先感到哪裡不太對」。

數位 / 專業版

到了 品質 / 檢查 的場景，seem amiss 會更常出現；這裡要說清楚的，正是「你直覺先感到哪裡不太對」。

Collocations

常見搭配與語域

常見用法集中在 something is amiss 和 seem amiss；這幾個搭配分別落在 日常 / 判斷 和 品質 / 檢查 的場景裡。

something is amiss 日常 / 判斷

在 日常 / 判斷 的語境裡，這個搭配最容易看出「你直覺先感到哪裡不太對」實際怎麼落在句子裡。

seem amiss 品質 / 檢查

在 品質 / 檢查 的語境裡，這個搭配最容易看出「你直覺先感到哪裡不太對」實際怎麼落在句子裡。
