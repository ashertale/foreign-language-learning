Inception

in-SEP-shuhn · UK /ɪnˈsep.ʃən/ · US /ɪnˈsep.ʃən/

不是背景，而是事情真正被啟動的起點。

Core Idea

inception 的核心是把「開始、創始、發端」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Inception

表示開始、創始、發端。

不是 Beginning

把它們分開記：beginning 先保留大方向，inception 負責把邊界收乾淨。

現象浮現

Origin

字源

15世纪初，“一个开始，一个起始”，来自古法语 inception，直接源自拉丁语 inceptionem（主格 inceptio）“一个开始；一个事业”，名词形式来自过去分词词干 incipere “开始，着手”，源自 in- “在，上”（来自原始印欧语根 *en “在”）+ -cipere，结合形式的 capere “拿，抓”，来自原始印欧语根 *kap- “抓住”。

像按下電源鍵那一瞬間，整套流程從無到有被喚醒

Memory Hook

記憶鉤子

inception：像按下電源鍵那一瞬間，整套流程從無到有被喚醒

這個畫面有用，是因為它先把「事情真正被啟動的起點」釘住；回到實際搭配時，就不容易把它和 Beginning 混成一團。

Usage

生活與專業情境

日常版

像 since inception 這樣的說法，多半出現在 商業 / 專案 的場景；句子真正要說的，就是「事情真正被啟動的起點」。

數位 / 專業版

到了 創作 / 學習 的場景，inception of the idea 會更常出現；這裡要說清楚的，正是「事情真正被啟動的起點」。

Collocations

常見搭配與語域

常見用法集中在 since inception 和 inception of the idea；這幾個搭配分別落在 商業 / 專案 和 創作 / 學習 的場景裡。

since inception 商業 / 專案

在 商業 / 專案 的語境裡，前面的 since 會把這個概念限定到更具體的場景。

inception of the idea 創作 / 學習

在 創作 / 學習 的語境裡，這個搭配會把關係直接指向 the idea。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Inception 開始、創始、發端 當搭配和語境都已經指向「事情真正被啟動的起點」，這個字才自然。
Beginning 開始 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 商業 / 專案、創作 / 學習、敘事 / 分析 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
