Sparse

SPAHS · UK /spɑːs/ · US /spɑːrs/

不是少，而是點和點之間隔得很開。

CEFR
B2

Core Idea

sparse 不只說少，而是點與點之間隔得開；畫面會留下很多空白。

Meaning

簡短定義

Sparse

形容稀疏、分散，數量少且間距明顯。

不是 Scant

scant 強調少得不夠；sparse 更強調分布疏開。

數量本來就不密
→
彼此距離拉開
→
整體留下很多空白

Origin

字源

sparse 來自拉丁語 sparsus「撒開、散布」，和 disperse 同族；所以它不是單純少，而是彼此隔得開、散得疏。

Memory Hook

記憶鉤子

把 sparse 想成不是缺幾棵樹，而是一整片地只有零零落落幾棵。

它的視覺重點在空白感。

Usage

生活與專業情境

資料

如果樣本點之間隔很大，資料看起來就會很 sparse。

設計

介面也可以刻意做得 sparse，讓空白成為一部分訊息。

Collocations

常見搭配與語域

sparse data 研究 / 工程

資料、人口、植被或說明少且分布鬆散。

sparse population 地理 / 報導

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Sparse 稀疏分散 用在資料、人口、植被或說明少且分布鬆散時。
Scant 少到接近不足 若重點是量不夠，用 scant 更準。

Modern Use

現代延伸

sparse 在資料科學、設計和地理語境都很常用，因為它精準寫出『少且疏開』。
