Sanction

Core Idea

sanction 指不是處罰而已，它也可以是正式批准；重點是制度把力道放下來。

Meaning

簡短定義

Sanction

指不是處罰而已，它也可以是正式批准；重點是制度把力道放下來。

不是 Penalty

penalty 只偏處罰；sanction 還可能指正式批准，所以要看語境。

制度先介入
→
力量被正式放下來
→
結果可能是准許也可能是懲罰

Origin

字源

sanction 來自拉丁語 sancire「制定成法、使其具約束力」，一開始就同時帶有批准與處罰的制度力道；所以 modern sanction 會出現 authorize 和 penalize 兩面，並不是巧合。

Memory Hook

記憶鉤子

把 sanction 想成蓋章本身既能放行，也能禁行。

這個字最值得記的是它的雙面性。

Usage

生活與專業情境

政策

談國際政治時，sanction 很常指制裁；但在別的語境，也可能是正式批准。

閱讀

讀到 sanction 時，先不要急著翻『制裁』，要先看它是在 punish 還是 authorize。

Collocations

常見搭配與語域

economic sanctions 政治 / 媒體

制度以正式方式施加懲罰或給出批准。

official sanction 法律 / 正式

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Sanction 制度裁可 用在制度以正式方式施加懲罰或給出批准時。
Penalty 單純的處罰 若語境沒有『制度正式出手』或『批准』這種制度語感，用 penalty 更單純。

Modern Use

現代延伸

sanction 是高價值字，因為它同時有處罰與批准兩面，讀寫時都要依語境解碼。
