Finite

FYE-nite · UK /ˈfaɪ.naɪt/ · US /ˈfaɪ.naɪt/

不是很少，而是有清楚邊界、終究會用完。

Core Idea

finite 不是很少，而是有邊界、有終點、不能假裝無限。

Meaning

簡短定義

Finite

形容數量、資源、狀態或時間有限，可被界定或終究會用完。

不是 Limited

limited 是受限制；finite 更直接說它不是無限。

邊界存在
→
資源可數
→
終點會到

Origin

字源

來自 Latin finis「邊界、終點」。

finis 是邊界、終點；finite 就是有終點。

Memory Hook

記憶鉤子

把 finite 想成 RAM：不是哲學概念，而是每個 allocation 都會碰到的牆。

有限性會逼設計做取捨。

Usage

生活與專業情境

記憶體

RAM is finite，所以設計必須承認每一個 allocation 都有代價。

狀態機

A finite state machine has a defined set of states, which makes behavior easier to reason about.

時間

Attention is finite; every meeting spends some of it.

Collocations

常見搭配與語域

finite 常接 resource、state、amount。搭配都在強調邊界和可數性。

finite resource 工程 / 經濟

有限資源，使用需要取捨。

finite state 電腦科學 / 系統

有限狀態，行為被限制在明確集合中。

finite amount 通用 / 數量

有限數量，不可無限延伸。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Finite 有限的、有終點的 用在必須承認邊界、終點或資源不可無限使用時。
Limited 受限制的 可泛指限制；finite 直接表示不是無限。
Scarce 稀缺 不只有限，還不夠用。
Bounded 有界的 數學或工程語氣，強調上下界。

Modern Use

現代延伸

Finite 是工程設計裡非常實在的字。CPU time、RAM、battery、human attention 都 finite，所以取捨不能靠願望。

它不等於 scarce；有限的東西可能暫時夠用，但仍需要邊界意識。
