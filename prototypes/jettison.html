Jettison

JET-uh-sun · UK /ˈdʒet.ɪ.sən/ · US /ˈdʒet.ɪ.sən/

不是整理收好，而是為了生存或速度，直接把累贅丟掉。

C2

Core Idea

jettison 用來描述「為了生存或速度，直接把累贅丟掉」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Jettison

表示拋棄不再需要的東西、想法或負擔。

不是 Discard

如果 discard 已經能讓句子成立，就不必硬換；需要「拋棄不再需要的東西、想法或負擔」時，jettison 才有必要。

先遇到 jettison the legacy code
→
看它是否只是 丟棄
→
再決定是否需要 jettison

Origin

字源

1848年，“拋棄”，尤其是爲了拯救處於危險中的船隻，源自 jettison（n.）“拋棄”的行爲，以減輕船隻的負重。這個名詞是18世紀海上保險作家恢復了15世紀單詞的早期形式和原始意義，後者已經變成了 jetsam，可能是因爲 jetsam 已經具有了“拋棄物”的意義，需要一個明確的詞來表示“拋棄物的行爲”。

像熱氣球為了拉高高度，先把多餘沙袋一袋袋丟下去

Memory Hook

記憶鉤子

jettison：像熱氣球為了拉高高度，先把多餘沙袋一袋袋丟下去

能用這個畫面回到「拋棄不再需要的東西、想法或負擔」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 jettison the legacy code 時，焦點通常就在「為了生存或速度，直接把累贅丟掉」上，所以這個搭配很能代表 jettison 的語感。

數位 / 專業版

到了 學習 / 分析 的場景，jettison old assumptions 會更常出現；這裡要說清楚的，正是「為了生存或速度，直接把累贅丟掉」。

Collocations

常見搭配與語域

常見用法集中在 jettison the legacy code 和 jettison old assumptions；這幾個搭配分別落在 工程 / 維護 和 學習 / 分析 的場景裡。

jettison the legacy code 工程 / 維護

在 工程 / 維護 的語境裡，這個搭配會把動作直接落在 the legacy code 上。

jettison old assumptions 學習 / 分析

在 學習 / 分析 的語境裡，這個搭配會把動作直接落在 old assumptions 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Jettison 拋棄不再需要的東西、想法或負擔 當較普通的說法太鬆，無法交代 動作是否真的落地 時。
Discard 丟棄 如果上下文還沒有給出足夠理由支撐 jettison，先用 discard。

Modern Use

現代延伸

現在最常見的就是 jettison the legacy code 和 jettison old assumptions 這類說法；它們一出現，通常就在替句子劃清「為了生存或速度，直接把累贅丟掉」的範圍。

當句子要把「為了生存或速度，直接把累贅丟掉」說準時，jettison 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
