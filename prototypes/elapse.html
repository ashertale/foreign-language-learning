Elapse

ih-LAPS · UK /ɪˈlæps/ · US /ɪˈlæps/

不是做了什麼，而是時間自己默默走過去。

CEFR

Core Idea

elapse 讓時間自己走過去；人沒有做動作，時間在背景裡流完一段。

Meaning

簡短定義

Elapse

表示一段時間流逝、過去。

不是 Pass

pass 日常又廣；elapse 像紀錄器冷靜標出時間經過。

一段時間開始計算
→
期間沒有被事件打斷成焦點
→
時間段完成流逝

Origin

字源

elapse 原意是滑走、溜走、像連續滑動般過去；因此它說時間時，不是跳一下過去，而是你沒抓住就一路滑掉。

Memory Hook

記憶鉤子

把 hours elapsed 想成 spinner 還在轉，而你只能看著時間從旁邊流掉。

elapse 的主角是時間。

Usage

生活與專業情境

小時

Several hours elapsed before the first useful log arrived. 這裡放在小時情境時，是在說你要讓時間段成為句子的主角，而不是人為動作。

快速

在快速這類情境裡，elapse 的重點是：不是做了什麼，而是時間自己默默走過去。

等待

Before long elapsed, the team had already changed the plan twice. 這裡放在等待情境時，是在說你要讓時間段成為句子的主角，而不是人為動作。

Collocations

常見搭配與語域

elapse 常讓時間名詞作主詞：hours、time、days。搭配通常不強調人做了什麼。

hours elapsed 正式 / 敘事

幾個小時過去。

time elapses quickly 日常 / 反思

時間過得快。

before long elapsed 敘事 / 書面

不久之後。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Elapse 時間流逝 用在你要讓時間段成為句子的主角，而不是人為動作時。
Pass 過去 最通用；elapse 較正式，特別指時間段流逝。
Expire 到期 時間限制結束；elapse 只是時間經過。

Modern Use

現代延伸

Elapsed time 是技術語境裡非常常見的名詞片語。

它乾淨、客觀，適合 log、測試、流程紀錄。
