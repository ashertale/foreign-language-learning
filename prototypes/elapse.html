Elapse

ih-LAPS · UK /ɪˈlæps/ · US /ɪˈlæps/

不是做了什麼，而是時間自己默默走過去。

Core Idea

elapse 不只是交代動作發生；它更常用來指出事情怎麼朝「時間流逝」這條線走。

Meaning

簡短定義

Elapse

表示一段時間過去、流逝。它要補上的，通常不是動作本身，而是那層更具體的「時間自己默默走過去」。

不是 Pass

如果語境只需要比較平的「過去」，用 Pass 往往就夠了；elapse 則會把「時間自己默默走過去」講得更明確。

Memory Hook

記憶鉤子

記這個畫面，不是為了背故事，而是讓你下次看到 elapse 時，能先抓到「時間流逝」這個核心，再回頭讀細節。

Usage

生活與專業情境

日常版

讀到 hours elapsed 時，可以先別急著翻中文；先看句子是不是想把動作往「時間流逝」這個方向講清楚。

數位 / 專業版

time elapses quickly 放進 生活 / 描寫 後，常會比一般近義詞更有份量，因為它把結果之外的那層語氣也帶了進來。

延伸版

如果你想把這個字放進 程序 / 文件 的情境，從 before long elapsed 這種搭配進場通常最穩，因為語感邊界很清楚。

Collocations

常見搭配與語域

看這些搭配時，重點不是詞組本身，而是這個動詞通常怎麼把事情往更具體的方向收緊。

hours elapsed 日常 / 時間

這個搭配常出現在需要把事情往「時間流逝」講清楚的句子裡。

time elapses quickly 生活 / 描寫

放到 生活 / 描寫 裡，它會讓動作聽起來不只發生了，還帶著明顯的語氣或後果。

before long elapsed 程序 / 文件

在 程序 / 文件 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Modern Use

現代延伸

elapse 在現代語境裡很少只是字面動作。它常被拿來把一句話的走向講得更清楚，尤其是在 hours elapsed 這類搭配裡更明顯。

所以它和 Pass 的差別，通常不在難度，而在句子要不要把那層「時間流逝」明白說出來。
