Elapse

ih-LAPS · UK /ɪˈlæps/ · US /ɪˈlæps/

不是做了什麼，而是時間自己默默走過去。

Core Idea

elapse 用來描述「時間自己默默走過去」這種更窄、更準確的情境；它不是泛稱，而是帶邊界的選字。

Meaning

簡短定義

Elapse

表示一段時間過去、流逝。

不是 Pass

pass 可以先說出 過去；elapse 則把句子推到「時間自己默默走過去」這個更細的位置。

Origin

字源

\"滑動、滑落或滑行； 隨着連續的滑動運動消逝\"，用於描述時間，來自1640年代的法語 elapser，源自拉丁語 elapsus，是 elabi 的過去分詞，意爲\"滑落、滑行、逃脫\"，由 ex（參見 ex-)和 labi（參見 lapse（n.））組成。現在對應 elapse 的名詞是 lapse，但 elapse（n.）最近也被使用。

像沙漏不是誰在推它，卻還是一粒一粒穩穩往下掉

Memory Hook

記憶鉤子

elapse：像沙漏不是誰在推它，卻還是一粒一粒穩穩往下掉

這個畫面有用，是因為它先把「時間自己默默走過去」釘住；回到實際搭配時，就不容易把它和 Pass 混成一團。

Usage

生活與專業情境

日常版

像 hours elapsed 這樣的說法，多半出現在 日常 / 時間 的場景；句子真正要說的，就是「時間自己默默走過去」。

數位 / 專業版

到了 生活 / 描寫 的場景，time elapses quickly 會更常出現；這裡要說清楚的，正是「時間自己默默走過去」。

Collocations

常見搭配與語域

常見用法集中在 hours elapsed 和 time elapses quickly；這幾個搭配分別落在 日常 / 時間 和 生活 / 描寫 的場景裡。

hours elapsed 日常 / 時間

在 日常 / 時間 的語境裡，這個搭配最容易看出「時間自己默默走過去」實際怎麼落在句子裡。

time elapses quickly 生活 / 描寫

在 生活 / 描寫 的語境裡，這個搭配最容易看出「時間自己默默走過去」實際怎麼落在句子裡。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Elapse 一段時間過去、流逝 當句子需要把「時間自己默默走過去」說清楚，而不是只留在 過去 的外圈時。
Pass 過去 當你只需要先說 過去，不必把語氣收進「時間自己默默走過去」時。

Modern Use

現代延伸

現在最常見的就是 hours elapsed 和 time elapses quickly 這類說法；它們一出現，通常就在替句子劃清「時間自己默默走過去」的範圍。

當句子要把「時間自己默默走過去」說準時，elapse 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
