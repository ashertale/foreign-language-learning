Sunder

SUN-der · UK /ˈsʌn.də/ · US /ˈsʌn.dɚ/

不是分開，而是硬生生裂成兩邊。

Core Idea

sunder 表示把事情往「劈裂分離」的方向推。重點不只在動作發生，而在那個動作怎麼改變局面。

Meaning

簡短定義

Sunder

表示把事情往「劈裂分離」的方向推，或讓局面出現這種結果。

不是 Separate

separate 是分開；sunder 更像被撕裂。

原本是一體
→
外力把它扯開
→
兩邊出現不可忽視的裂口

Origin

字源

sunder 來自古英語裡「分開、拆散」，和 asunder 同族；所以它比 separate 更有被硬生生扯開的古老力道。

Memory Hook

記憶鉤子

把 sunder 想成布不是剪開，而是從中間硬扯裂。

它的張力比 divide 強，也比 split 更帶撕裂。

Usage

生活與專業情境

群體

如果一個事件把原本同陣線的人整個扯開，sunder 的畫面就很強。

敘事

文學裡常用 sunder 寫命運或戰爭如何把人分裂。
