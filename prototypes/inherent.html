Inherent

in-HEER-uhnt · UK /ɪnˈhɪə.rənt/ · US /ɪnˈher.ənt/

不是外面加上去的，而是事物本身就帶著的特性。

Core Idea

inherent 描述某種性質、風險或限制內在於事物本身，不是偶然附加。

Meaning

簡短定義

Inherent

形容內在固有的、本身具有的特質。

不是 Added

added 是後來加上；inherent 是從一開始就在裡面。

事物存在
→
特性內建其中
→
無法完全分離

Origin

字源

inherent 來自 Latin inhaerere，意思是「黏在裡面、附著於」。

它不是外貼標籤，而是黏在事物本身裡面的性質。

Memory Hook

記憶鉤子

inherent 是木頭本身的紋理，不是貼紙。

它提醒你：有些限制不是 bug，而是材料本性。

Usage

生活與專業情境

風險版

Wireless communication has inherent latency and interference risks.

設計版

Every abstraction has inherent trade-offs.

Inherent 形容內在固有的、本身具有的特質。 用在事物本身就帶著的特性時。
Intrinsic intrinsic 也指內在；inherent 更常用於風險、限制或性質本身存在。 當 Intrinsic 這邊的語氣更貼近目標時，不要硬套 inherent。

Modern Use

現代延伸

在工程取捨中，inherent 能阻止你追求不可能的完美：有些代價是架構選擇內建的。
