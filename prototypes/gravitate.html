Gravitate

GRAV-uh-tayt · UK /ˈɡræv.ɪ.teɪt/ · US /ˈɡræv.ə.teɪt/

不是被命令移動，而是被某種吸引力慢慢拉過去。

Core Idea

gravitate 不只是 Drift 的近義替代；它用來描述「被某種吸引力慢慢拉過去」這種更窄、更準確的情境。

Meaning

簡短定義

Gravitate

表示人自然地偏向某種選擇、風格或群體。

不是 Drift

Drift 可以先說大方向；gravitate 用在你要把「被某種吸引力慢慢拉過去」這條語氣邊界說得更準的時候。

Origin

字源

1640年代，“施加重量； 向下移動”（已過時），源自現代拉丁語 gravitare（16世紀的科學寫作），源自拉丁語 gravitas “沉重，重量”，源自 gravis “沉重”（源自 PIE 詞根 *gwere- (1) “沉重”）。意思是“受到重力影響”始於1690年代。比喻意義上的“強烈被吸引，具有自然傾向”始於1670年代。

像鐵粉在磁場裡不需要喊口令，也會自己排出方向

Memory Hook

記憶鉤子

gravitate：像鐵粉在磁場裡不需要喊口令，也會自己排出方向

這個畫面之所以有用，是因為它能幫你確認 gravitate 是否真的在談「被某種吸引力慢慢拉過去」；一旦畫面對上，語氣邊界就會清楚很多。

Usage

生活與專業情境

日常版

像 gravitate toward simple tools 這樣的說法，多半出現在 產品 / 使用者 的場景；句子真正要說的，就是「被某種吸引力慢慢拉過去」。

數位 / 專業版

到了 日常 / 空間 的場景，gravitate to the window 會更常出現；這裡要說清楚的，正是「被某種吸引力慢慢拉過去」。

Collocations

常見搭配與語域

常見用法集中在 gravitate toward simple tools 和 gravitate to the window；這幾個搭配分別落在 產品 / 使用者 和 日常 / 空間 的場景裡。

gravitate toward simple tools 產品 / 使用者

在 產品 / 使用者 的語境裡，這個搭配會把動作直接落在 toward simple tools 上。

gravitate to the window 日常 / 空間

在 日常 / 空間 的語境裡，這個搭配會把動作直接落在 to the window 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機

Modern Use

現代延伸

現在最常見的就是 gravitate toward simple tools 和 gravitate to the window 這類說法；它們一出現，通常就在替句子劃清「被某種吸引力慢慢拉過去」的範圍。

比起 drift，gravitate 更適合用在你想直接點出「人自然地偏向某種選擇、風格或群體」的時候。
