Forfeit

FOR-fit · UK /ˈfɔː.fɪt/ · US /ˈfɔːr.fɪt/

不是一般失去，而是因為違規、放棄或代價交換而失掉。

CEFR
C1

2.73
Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

forfeit 是因為規則、錯誤或選擇而失去原本可以保有的權利、金錢或機會。

Meaning

簡短定義

Forfeit

表示喪失、被沒收，或放棄比賽、權利、押金、機會。

不是 Lose

lose 只是失去；forfeit 讓人看到規則在背後收回東西。

某權利或利益原本可保有
→
條件被違反或選擇被作出
→
權利或利益被收回

Origin

字源

forfeit 早期既可指對權威犯下的過失，也可指因這個過失而失去的權利或財物；所以它一直帶「做錯後付出代價」的結構。

Memory Hook

記憶鉤子

把 forfeit the deposit 想成不是花掉錢，而是因條件沒達成，押金回不來。

forfeit 的失去常和規則條件有關。

Usage

生活與專業情境

押金

If you cancel late, you may forfeit the deposit.

比賽

The team forfeited the game because it could not field enough players.

機會

Ignoring the deadline means you forfeit the chance to appeal.

Collocations

常見搭配與語域

forfeit 常接 deposit、game、chance；搭配會指出失去的是什麼權利或利益。

forfeit the deposit 合約 / 日常

喪失押金。

forfeit the game 運動 / 規則

棄權或被判輸。

forfeit the chance 正式 / 日常

失去機會。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Forfeit 因代價而喪失 用在失去不是偶然掉了，而是因規則或條件被剝奪時。
Lose 失去 通用；forfeit 常因規則、條件或自己的行為而失去。
Surrender 交出、投降 可主動放棄；forfeit 多半有規則性後果。

Modern Use

現代延伸

Forfeit 在合約、遊戲、運動和法律語境裡很常見。

它提醒你看條件：哪個行為會讓你失去原本的權利？
