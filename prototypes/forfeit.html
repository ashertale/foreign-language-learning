Forfeit

FOR-fit · UK /ˈfɔː.fɪt/ · US /ˈfɔːr.fɪt/

不是一般失去，而是因為違規、放棄或代價交換而失掉。

Core Idea

forfeit 不只是 Lose 的近義替代；它用來描述「因為違規、放棄或代價交換而失掉」這種更窄、更準確的情境。

Meaning

簡短定義

Forfeit

表示喪失權利、金錢、機會或資格。

不是 Lose

Lose 可以先說大方向；forfeit 用在你要把「因為違規、放棄或代價交換而失掉」這條語氣邊界說得更準的時候。

Origin

字源

forfeit 在英語裡可追到 late 14c.；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示喪失權利、金錢、機會或資格」的用法。

像手上握著的票不是掉了，而是因為一步走錯被收回去

Memory Hook

記憶鉤子

forfeit：像手上握著的票不是掉了，而是因為一步走錯被收回去

這個畫面能幫你把 forfeit 和 Lose 分開，因為它把「因為違規、放棄或代價交換而失掉」那條界線變得可見。

Usage

生活與專業情境

日常版

像 forfeit the deposit 這樣的說法，多半出現在 財務 / 合約 的場景；句子真正要說的，就是「因為違規、放棄或代價交換而失掉」。

數位 / 專業版

到了 競賽 / 規則 的場景，forfeit the game 會更常出現；這裡要說清楚的，正是「因為違規、放棄或代價交換而失掉」。

Collocations

常見搭配與語域

常見用法集中在 forfeit the deposit 和 forfeit the game；這幾個搭配分別落在 財務 / 合約 和 競賽 / 規則 的場景裡。

forfeit the deposit 財務 / 合約

在 競賽 / 規則 的語境裡，這個搭配會把動作直接落在 the game 上。

Modern Use

現代延伸

比起 lose，forfeit 更適合用在你想直接點出「喪失權利、金錢、機會或資格」的時候。
