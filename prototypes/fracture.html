Fracture

FRAK-cher · UK /ˈfræk.tʃər/ · US /ˈfræk.tʃɚ/

不是完全粉碎，而是先裂開，內部連續性被打斷。

Core Idea

fracture 常用在句子需要把動作往「裂開出痕」這個方向收緊時。重點不只是做了什麼，而是事情因此偏向哪一種選擇。

Meaning

簡短定義

Fracture

表示骨頭、材料或關係出現裂痕。這個字常不是在描述機械動作，而是在說事情怎麼往「裂開出痕」這個方向走。

不是 Break

Break 可以只是在說「破裂」；換成 fracture，句子通常是在補上「裂開出痕」這層更具體的意思。

Memory Hook

記憶鉤子

fracture 的畫面是：像玻璃上先出現一道白線，整塊還在，但完整性已經回不去。

這個畫面有用，因為它把 fracture 從翻譯拉回場面：你先看到「玻璃出現第一道白線」，再比較容易記住它其實在說「裂開出痕」。

Usage

生活與專業情境

日常版

fracture the bone 這種說法會把動作放回它真正會發生的場景裡，讓你看到重點不是字面動作，而是事情怎麼往「裂開出痕」收過去。

數位 / 專業版

在 政治 / 關係 裡，fracture the alliance 常用來把語氣收得更準：它不只交代事情做了，還交代事情怎麼帶出那層「先裂開，內部連續性被打斷」。

延伸版

到了 材料 / 工程 的場景，fractured surface 很適合拿來練邊界，因為它會逼你分清楚一般的「破裂」跟更具體的「裂開出痕」差在哪。

Collocations

常見搭配與語域

這組搭配會告訴你，這個動詞最自然會把句子往哪種場面推；比只記中文更能抓到用法。

這個搭配常出現在需要把事情往「裂開出痕」講清楚的句子裡。

fracture the alliance 政治 / 關係

放到 政治 / 關係 裡，它會讓動作聽起來不只發生了，還帶著明顯的語氣或後果。

fractured surface 材料 / 工程

在 材料 / 工程 的場景裡，這種說法能幫你看清楚它和近義詞的邊界。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Fracture 裂開出痕 當你要把事情說成「先裂開，內部連續性被打斷」而不只是 破裂 時

Modern Use

現代延伸

在今天的英文裡，fracture 常出現在 fracture the bone、fracture the alliance 這類搭配裡。真正有用的不是背它對應哪個中文，而是看它怎麼把動作往「裂開出痕」這個方向收緊。

如果一句話只想表達比較平的「破裂」，Break 往往就夠了；但當語境需要那層更具體的「先裂開，內部連續性被打斷」，fracture 會更準。
