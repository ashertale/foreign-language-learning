Partisan

PAR-tuh-zən · UK /ˌpɑː.tɪˈzæn/ · US /ˈpɑːr.t̬ə.zən/

不是有立場，而是立場先選邊，再看事實。

Core Idea

partisan 指判斷先站隊再看事實；它不是單純有觀點，而是陣營感主導了解讀。

Meaning

簡短定義

Partisan

形容強烈偏向某一黨派、陣營或立場。

不是 Biased

biased 是有偏見；partisan 更明確地指向黨派或陣營站位。

先有陣營身份
→
判斷往己方傾斜
→
事實被站位重新排序

Origin

字源

partisan 來自義法語系裡的「部分、派別」這條線，原本就是站在某一方的人；所以它不是單純參與，而是立場已經跟某個 faction 綁在一起。

Memory Hook

記憶鉤子

把 partisan 想成球賽還沒開打，分數板就先被你偏向一邊。

這個字不只是說你有意見，而是說你先選隊。

Usage

生活與專業情境

媒體

當一個平台每次都沿著同一陣營解讀事件時，讀者會覺得它很 partisan。

討論

如果所有判斷都先問誰得利而不是什麼為真，討論就容易變得 partisan。

Collocations

常見搭配與語域

partisan divide 政治 / 媒體

討論或機構先按陣營站位，而不是先看證據。

partisan rhetoric 公共 / 評論

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Partisan 偏派選邊 用在討論或機構先按陣營站位，而不是先看證據時。
Biased 帶偏見、不夠公正 若只是一般偏頗，不一定涉及陣營站位，用 biased 更自然。

Modern Use

現代延伸

partisan 在現代公共討論裡很常見，尤其用來批評資訊被陣營邏輯綁死。
