Impose

im-POHZ · UK /ɪmˈpəʊz/ · US /ɪmˈpoʊz/

不是單純提出，而是把規則、負擔或限制加到別人身上。

Core Idea

impose 描述施加規則、稅、限制、負擔或意志，常暗示接受方沒有太多選擇。

Meaning

簡短定義

Impose

表示強加、施加，使某人承受規則、限制或負擔。

不是 Suggest

suggest 是建議；impose 是加上去，帶權力或壓力。

一方有權力
→
限制被加上
→
另一方承受

Origin

字源

impose 來自 Latin imponere，意思是「放在上面」。其中 ponere 是 place、put 的概念。

想成把重量放到別人肩上；規則、限制、負擔都是被放上去的。

Memory Hook

記憶鉤子

impose 是把一塊重量放到別人肩上。

它常帶不對等感：規則不是自然來的，是被施加的。

Usage

生活與專業情境

政策版

The government may impose fines for violations.

工程版

A strict memory limit imposes constraints on the design.

Collocations

常見搭配與語域

impose restrictions 政策 / 管理

impose constraints 工程 / 設計

給設計加上限制。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Impose 表示強加、施加，使某人承受規則、限制或負擔。 用在把規則、負擔或限制加到別人身上時。
Enforce enforce 是執行規則；impose 是把規則或負擔加上去。 當 Enforce 這邊的語氣更貼近目標時，不要硬套 impose。

Modern Use

現代延伸

在 API 和系統設計中，impose 可以描述介面對使用者或呼叫端加上的限制。
