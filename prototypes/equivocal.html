Equivocal

ih-KWIV-uh-kul · UK /ɪˈkwɪv.ə.kəl/ · US /ɪˈkwɪv.ə.kəl/

不是細膩，而是模稜到你抓不到他到底站哪邊。

Core Idea

equivocal 是話語留在兩邊之間，讓人抓不到明確立場或結論。

Meaning

簡短定義

Equivocal

形容含糊、模稜兩可、可作多種解讀。

不是 Ambiguous

ambiguous 說多義；equivocal 常讓人感覺對方不願明講。

訊息被說出
→
它可被讀成兩邊
→
承諾或結論保持不明

Memory Hook

記憶鉤子

把 equivocal answer 想成回答有字句，但你聽完仍不知道對方到底同不同意。

equivocal 的問題是 ambiguity with consequence。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Equivocal 模稜兩可 用在含糊本身會影響判斷、承諾或責任時。
Ambiguous 模糊多義 通用；equivocal 常暗示說話者沒有給明確承諾。
Unclear 不清楚 範圍廣；equivocal 更偏可兩面解讀。

Modern Use

現代延伸

Equivocal 在政治、法律、醫療結果描述中常見。

它不只是 unclear；很多時候聽起來像故意不站穩。
