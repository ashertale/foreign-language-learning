Core Idea

equivocal 的核心是把「含糊不清、模稜兩可」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Equivocal

表示含糊不清、模稜兩可。

不是 Ambiguous

把它們分開記：ambiguous 先保留大方向，equivocal 負責把邊界收乾淨。

Origin

字源

equivocal 在英語裡可追到 \"of doubtful signification；它的詞史往前接到較早的 拉丁／希臘／法語層，進入英語後才慢慢收斂成今天這種「表示含糊不清、模稜兩可」的用法。

Memory Hook

Usage

生活與專業情境

日常版

像 equivocal answer 這樣的說法，多半出現在 溝通 / 回應 的場景；句子真正要說的，就是「模稜到你抓不到他到底站哪邊」。

數位 / 專業版

到了 法務 / 文件 的場景，equivocal language 會更常出現；這裡要說清楚的，正是「模稜到你抓不到他到底站哪邊」。

Collocations

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 溝通 / 回應、法務 / 文件、公共 / 立場 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
