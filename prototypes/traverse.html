Traverse

truh-VURS · UK /trəˈvɜːs/ · US /trəˈvɝːs/

不是只是走過，而是橫越一段空間、結構或資料路徑。

Core Idea

traverse 表示穿越、橫越或按路徑逐一經過；句子的力道來自移動沿著一條需要被跨過或掃過的路徑。

Meaning

簡短定義

Traverse

表示穿越、橫越或按路徑逐一經過。常見語境會讓移動沿著一條需要被跨過或掃過的路徑變得清楚。

不是 Cross

cross 很通用；traverse 更常暗示路徑較長、複雜或被系統性掃過。

Origin

字源

traverse 字源依 Online Etymology Dictionary；來源段落記錄：early 14c., "pass across, over, or through," from Old French traverser "to cross, place across" (11c.), from Vulgar Latin *traversare, from Latin transversare "to cross, throw across," from Latin transversus "turn across" (see transverse ). As an adjective from early 15c. Related: Traversed ; traversing .。這裡只把這段資料當作字源線索，現代用法仍以本頁定義與詞典義為準。

Memory Hook

記憶鉤子

把 traverse 想成游標沿著 tree 一個 node 一個 node 走過去。

這個畫面保留的是移動沿著一條需要被跨過或掃過的路徑，不是單純把中文意思套上去。

Usage

生活與專業情境

地理

The hikers traversed the ridge before sunset.

資料結構

程式需要 traverse the graph，才能找到所有可達節點。

Collocations

常見搭配與語域

Traverse 的自然搭配多半讓移動沿著一條需要被跨過或掃過的路徑具體化，而不是只替名詞加強語氣。

traverse a landscape 旅行 / 地理

穿過地形，通常路徑有長度和阻力。

traverse a tree 電腦科學

按規則拜訪資料結構中的節點。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Traverse 橫越一段空間、結構或資料路徑 適合描述移動沿著一條需要被跨過或掃過的路徑的句子。
Cross 從一邊到另一邊 若只是跨過街道或界線，用 cross；若路徑複雜，用 traverse。

Modern Use

現代延伸

在 software 裡，traverse 很常見，因為它把 movement 和 structured path 放在同一個字裡。
