Repudiate

ri-PYOO-dee-ayt · UK /rɪˈpjuː.di.eɪt/ · US /rɪˈpjuː.di.eɪt/

不是不同意，而是明白把它撇開、否認、切割。

CEFR
C2

Reading Path 核心 定義 字源 記憶 情境 搭配詞 辨析 現代 來源

Core Idea

repudiate 是把某主張、關係或責任明白否斥掉，通常帶公開切割的力道。

Meaning

簡短定義

Repudiate

公開拒絕承認、接受或支持某主張、責任或關聯。

不是 Reject

reject 是拒絕；repudiate 更像公開切割、甚至否認和它有關。

先有某關聯或主張
→
人公開站出來否斥
→
連帶關係被切斷

Origin

字源

repudiate 來自拉丁語，早期可指離婚式地把人「撇開、棄絕」，力道很重；因此今天說 repudiate a claim 或 repudiate violence，都有公開切割的硬度。

Memory Hook

記憶鉤子

把 repudiate 想成不是把信退回，而是當場撕掉並說跟我無關。

它的語氣比 disagree 或 reject 都更重。

Usage

生活與專業情境

立場

如果一個組織公開否認某說法並切割，就可以說它 repudiated the claim。

責任

在正式語境裡，repudiate 也常指否認自己對某責任的承接。

Collocations

常見搭配與語域

repudiate the claim 法律 / 媒體

立場、責任或主張被正式否認並切割。

repudiate violence 政治 / 公共

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Repudiate 公開否斥 用在立場、責任或主張被正式否認並切割時。
Reject 不接受、退回 若只要一般拒絕，用 reject 即可。

Modern Use

現代延伸

repudiate 常見於政治聲明與法律語境，因為它帶有高強度的公開切割。
