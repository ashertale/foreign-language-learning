Mediate

MEE-dee-ayt · UK /ˈmiː.di.eɪt/ · US /ˈmiː.di.eɪt/

不是替一方贏，而是讓雙方能重新說話。

Core Idea

mediate 的核心是把「調停衝突、在中間協助兩方找到可走的路」說到有邊界，而不是把普通詞換成更難的詞。

Meaning

簡短定義

Mediate

表示調停衝突、在中間協助兩方找到可走的路。

不是 Negotiate

把它們分開記：negotiate 先保留大方向，mediate 負責把邊界收乾淨。

Origin

字源

1540年代，\"將某物分成兩等份\"（現已廢棄此義），源自拉丁語 mediatus，過去分詞形式爲 mediare，意爲\"將某物分成兩等份\"，後來演變爲\"位於中間\"，源自拉丁語 medius，意爲\"中間\"（源自 PIE 詞根 *medhyo-，意爲\"中間\"）； 從1640年代開始，意爲\"佔據中間位置\"。1610年代開始有\"充當調解人，爲達成和解而介入\"的意思； 1560年代開始有\"通過調解解決，使和諧，使和解\"的意思，可能是從 mediation 或 mediator 中派生出來的。

Memory Hook

記憶鉤子

mediate：像兩岸之間架一座臨時橋，先讓人能重新走過去

這個畫面有用，是因為它先把「讓雙方能重新說話」釘住；回到實際搭配時，就不容易把它和 Negotiate 混成一團。

Usage

生活與專業情境

日常版

像 mediate the conflict 這樣的說法，多半出現在 人際 / 管理 的場景；句子真正要說的，就是「讓雙方能重新說話」。

數位 / 專業版

到了 法務 / 公共 的場景，mediate between parties 會更常出現；這裡要說清楚的，正是「讓雙方能重新說話」。

Collocations

常見搭配與語域

常見用法集中在 mediate the conflict 和 mediate between parties；這幾個搭配分別落在 人際 / 管理 和 法務 / 公共 的場景裡。

mediate the conflict 人際 / 管理

在 人際 / 管理 的語境裡，這個搭配會把動作直接落在 the conflict 上。

mediate between parties 法務 / 公共

在 法務 / 公共 的語境裡，這個搭配會把動作直接落在 between parties 上。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Mediate 調停衝突、在中間協助兩方找到可走的路 當搭配和語境都已經指向「讓雙方能重新說話」，這個字才自然。
Negotiate 協調 當讀者只需要知道外圈分類，而不是更窄的判斷時。

Modern Use

現代延伸

這個字在現代文本裡靠語境活著；離開搭配，它常常只剩模糊翻譯。

在 人際 / 管理、法務 / 公共、會議 / 溝通 之間切換時，留意同一個核心如何換衣服，而不是把每個搭配分開背。
