Word 467 / adjective

Immutable

ih-MYOO-tuh-bul · UK /ɪˈmjuː.tə.bəl/ · US /ɪˈmjuː.t̬ə.bəl/

不是暫時穩定，而是設定後就不打算再動。

CEFR
C2

Core Idea

immutable 是不可變的；一旦設定，後面不能悄悄改掉。

Meaning

簡短定義

Immutable

形容固定不變、不可更改，常用於資料、規則、原則或性質。

不是 Fixed

fixed 是固定；immutable 是原則上不能被改寫。

狀態被建立
→
修改被禁止或不被期待
→
後續推理依賴不變性

Origin

字源

immutable 原本就指 unchanging、不能改動；所以它不是暫時沒變，而是被理解成那個性質本身不會轉向。

Memory Hook

記憶鉤子

把 immutable data 想成物件建立後就不再被修改，變更只能產生新的版本。

immutable 的信任來自不變。

Usage

生活與專業情境

資料

Immutable records are easier to audit because later code cannot quietly rewrite them.

規則

An immutable rule can protect fairness, but it can also block necessary exceptions.

保持

Some assumptions remain immutable only because no one has been allowed to question them.

Collocations

常見搭配與語域

immutable 常修飾 data、rule，也常和 remain 搭配；搭配會說明哪個層面不被改動。

immutable data 工程 / 程式

不可變資料。

immutable rule 制度 / 正式

不可更改的規則。

remain immutable 正式 / 分析

保持不變。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Immutable 不可變更 用在不可變性本身對推理、信任或限制很重要時。
Fixed 固定 通用；immutable 更正式、更像原則上不可改。
Constant 常數、不變 偏數值或狀態；immutable 可用於物件、規則、性質。

Modern Use

現代延伸

工程裡 immutable 是高頻概念，尤其在 state management、functional programming、ledger。

但對制度來說 immutable 可能是保護，也可能是僵化。
