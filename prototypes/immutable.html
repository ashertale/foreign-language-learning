Immutable

ih-MYOO-tuh-bul · UK /ɪˈmjuː.tə.bəl/ · US /ɪˈmjuː.t̬ə.bəl/

不是暫時穩定，而是設定後就不打算再動。

Core Idea

immutable 不是單字卡上的高級替換；它回答的是：這裡到底需要哪一種「句子被加上哪一層質地」？

Meaning

簡短定義

Immutable

表示不可變更、固定不變。

不是 Fixed

如果 fixed 已經能讓句子成立，就不必硬換；需要「不可變更、固定不變」時，immutable 才有必要。

先遇到 immutable data
→
看它是否只是 固定
→
再決定是否需要 immutable

Origin

字源

15世紀早期，“不變的，不可改變的”，來自古法語 immutable（現代法語 immuable），並直接源自拉丁語 immutabilis “不可改變的，不可變的”，由否定前綴 in-（見 in-（1））和 mutabilis “可改變的”組成，源自 mutare “改變”（源自 PIE 語根 *mei-（1）\"改變、前去、移動\"）。

像石頭上刻下的刻痕，不像白板字一擦就能改

Memory Hook

記憶鉤子

immutable：像石頭上刻下的刻痕，不像白板字一擦就能改

能用這個畫面回到「不可變更、固定不變」，比背出一段漂亮解釋更重要。

Usage

生活與專業情境

日常版

當人們說 immutable data 時，焦點通常就在「設定後就不打算再動」上，所以這個搭配很能代表 immutable 的語感。

數位 / 專業版

到了 制度 / 定義 的場景，immutable rule 會更常出現；這裡要說清楚的，正是「設定後就不打算再動」。

Collocations

常見搭配與語域

常見用法集中在 immutable data 和 immutable rule；這幾個搭配分別落在 工程 / 程式 和 制度 / 定義 的場景裡。

immutable data 工程 / 程式

在 工程 / 程式 的語境裡，這個搭配通常就在形容 data 的狀態或氣質。

immutable rule 制度 / 定義

在 制度 / 定義 的語境裡，這個搭配通常就在形容 rule 的狀態或氣質。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Immutable 不可變更、固定不變 當較普通的說法太鬆，無法交代 句子被加上哪一層質地 時。
Fixed 固定 如果上下文還沒有給出足夠理由支撐 immutable，先用 fixed。

Modern Use

現代延伸

現在最常見的就是 immutable data 和 immutable rule 這類說法；它們一出現，通常就在替句子劃清「設定後就不打算再動」的範圍。

當句子要把「設定後就不打算再動」說準時，immutable 才真的有必要；如果只是一般描述，常見近義詞通常就夠。
