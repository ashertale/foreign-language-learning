Eradicate

ih-RAD-ih-kate · UK /ɪˈræd.ɪ.keɪt/ · US /ɪˈræd.ə.keɪt/

不是減少，而是連根拔起到不再存在。

Core Idea

eradicate 的目標不是少一點，而是把根拔掉，讓問題不再從同一來源長回來。

Meaning

簡短定義

Eradicate

表示根除、消滅或徹底清除疾病、缺陷、貧困、錯誤來源等。

不是 Reduce

reduce 是降低；eradicate 是目標放在完全拔掉。

Origin

字源

來自 Latin radix「根」；字面畫面就是連根拔起。

radix 是根；eradicate 的記憶畫面就是連根拔起。

Memory Hook

記憶鉤子

把 eradicate flaky tests 想成不是 rerun 到綠，而是拔掉不穩定的根因。

紅燈少一點不是根除；不再長回來才是。

Usage

生活與專業情境

測試

Eradicate flaky tests 的意思不是少幾個紅燈，而是拔掉造成不穩定的根源。

疾病

Public health may aim to eradicate a disease, not merely reduce cases.

缺陷

To eradicate defects, you often need process changes, not more heroic inspection.

Collocations

常見搭配與語域

eradicate 常接 disease、defects、poverty。這些搭配的語氣都很大，目標是根本移除。

eradicate disease 公共衛生

使疾病不再存在於某範圍。

eradicate defects 品質 / 製造

移除缺陷來源，而不只是抓出缺陷。

eradicate poverty 政策 / 社會

語氣宏大，指徹底消除貧困。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Eradicate 根除、消滅某問題或疾病 用在目標是徹底移除根源，而不是降低數量或影響時。
Reduce 降低 只是變少。
Eliminate 消除 和 eradicate 接近，但 eradicate 的連根拔起畫面更強。
Mitigate 緩解 降低影響，不一定移除來源。

Modern Use

現代延伸

Eradicate 是高承諾字。工程上說 eradicate defects，就要準備談 root cause、prevention 和 verification。

如果只是降低發生率，用 reduce 或 mitigate 會誠實得多。
