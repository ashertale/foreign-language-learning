Encounter

en-KOWN-ter · UK /ɪnˈkaʊn.tər/ · US /ɪnˈkaʊn.t̬ɚ/

不是刻意尋找，而是在路上遇到問題、人或情況。

Core Idea

encounter 是在前進途中迎面碰到人、問題或情況。它通常不是刻意尋找，而是事情走到你面前。

Meaning

簡短定義

Encounter

表示遇到、遭遇或碰見，常用於問題、阻力、情況、人或經驗。

不是 Find

find 可表示找到；encounter 更像在行進中迎面碰上。

行動正在進行
→
情況迎面出現
→
必須回應

Origin

字源

來自 Old French 與相遇、對上的概念相關；畫面是路上迎面碰到。

相遇、對上的詞史畫面很好記；encounter 的問題常是迎面而來。

Memory Hook

記憶鉤子

把 encounter 想成測試跑著跑著，罕見 failure 自己跳出來。

你不是搜尋它；你是在路上撞見它。

Usage

生活與專業情境

測試

測試中 encounter rare failure，通常代表情境比預期複雜。

阻力

A proposal may encounter resistance when it changes people’s routines。

第一次

A first encounter with a codebase often reveals naming and architecture habits.

Collocations

常見搭配與語域

encounter 常接 problem、resistance、first encounter。搭配裡常有迎面碰上、需要回應的感覺。

encounter a problem 通用 / 工程

進行中碰到問題。

encounter resistance 組織 / 政治

遇到反對或阻力。

first encounter 日常 / 學習

第一次接觸或相遇。

Neighbors

對立與鄰近概念

概念 核心精神 最自然的使用時機
Encounter 遭遇、遇見或碰到 用在行動途中碰上某狀況，而那狀況需要被注意或回應時。
Find 找到 可主動尋找也可偶然發現。
Meet 見面、遇見 多用於人，也可正式約見。
Run into 碰到 口語，和 encounter 接近但較輕。

Modern Use

現代延伸

Encounter 在工程紀錄裡很自然：encountered an error、encountered resistance、encountered a limitation。

它保留偶然性和現場感，不像 discover 那樣暗示你成功找到了什麼。
