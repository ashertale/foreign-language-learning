Erode

ih-ROHD · UK /ɪˈrəʊd/ · US /ɪˈroʊd/

不是一下子毀掉，而是長時間一點一點磨掉基礎。

Core Idea

erode 原本可指水或風侵蝕土地，也常用來描述信任、利潤、安全邊界或品質逐步被削弱。

Meaning

簡短定義

Erode

表示侵蝕、逐漸削弱，使原本穩固的東西變薄或變弱。

不是 Destroy

destroy 是摧毀；erode 是慢慢磨損到失去力量。

Origin

字源

erode 來自 Latin erodere，意思是「咬掉、啃蝕」。其中 rodere 是 gnaw 的概念。

侵蝕不是爆炸，而是每天咬掉一點，最後基礎變薄。

Memory Hook

記憶鉤子

erode 是海浪每天拍一點，最後岸線退後。

它的危險在慢：每次都不大，但累積後很深。

Usage

生活與專業情境

組織版

Repeated broken promises erode trust. 這個情境凸顯「侵蝕、逐漸削弱，使原本穩固的東西變薄或變弱」。

商務版

Rising costs can erode margins over time. 讀這句時，焦點在「侵蝕、逐漸削弱，使原本穩固的東西變薄或變弱」。

Modern Use

現代延伸

在 reliability work 中，erode 能描述那些每天只壞一點的系統習慣，最後會變成大事故。
